## Upload und Speichern von Inhalten im persönlichen Besitz <a id="uploading-and-storing-personally-owned-content" />

Dieser Ablauf erklärt, wie Sie Ihre eigenen, von der Covata-Plattform verwalteten Inhalte hochladen und speichern können.

<Note>

Diese Funktion wird nur unterstützt, wenn Safe Share for Web auf einem Desktop- oder Laptop-Computer genutzt wird. Uploads über auf Tablets, Smartphones oder ähnlichen Geräten ausgeführte Webbrowser werden nicht unterstützt. Wenn Sie ein iOS- oder Android-Gerät nutzen, beachten Sie jedoch bitte, dass Covata für diese Plattformen auch eigene Apps zur Verfügung stellt ([Safe Share for iOS](https://itunes.apple.com/au/app/safe-share/id874127973) bzw. [Safe Share for Android](https://play.google.com/store/apps/details?id=io.covata.android.safeshare)), die das sichere Hochladen und Speichern von Daten unterstützen.

</Note>

**Sicheres Hochladen und Speichern von Inhalten im persönlichen Besitz:**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.4/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer [Organisation](/3.4/de/user#organisations). Sie können daher direkt zum [nächsten Schritt](/3.4/de/user/uploading-storing-and-sharing-content-securely#selecting-and-dragging-files) weitergehen. <br />
   *Andernfalls*, d. h. wenn rechts neben dem Namen Ihrer aktuellen Organisation ein Dropdown-Symbol erscheint, ist Ihr Covata-Benutzer-Account auf Ihrer Instanz der Covata-Plattform Mitglied mehrerer Organisationen. Wenn Sie sich eben erst angemeldet haben, ist Ihre „Start“-Organisation (d. h. Ihre Standardorganisation) ausgewählt und wird angezeigt. Wenn Sie für den Upload und die Speicherung Ihrer Inhalte eine andere Organisation auswählen möchten (bei der Sie Mitglied sind), wählen Sie die betreffende Organisation aus dem Dropdown-Menü. Zum Beispiel:

   ![Auswahl einer Organisation](/images/355ce7b0cd6c-choosing-an-organisation.png)

   <br />
   **Tipp:** Sie können Ihre Start- bzw. Standardorganisation anhand der [Funktionen zur Verwaltung Ihres Covata-Benutzer-Accounts](/3.4/de/user/managing-your-account) ändern.
3. <a id="selecting-and-dragging-files" />Wählen Sie auf Ihrem Desktop-/Laptop-Computer eine oder mehrere Datei(en) und ziehen Sie sie in den Elementebereich auf der Safe Share-Hauptseite: <br />
   ![Datei-Upload durch Drag&Drop](/images/72785b7b328f-dragging-a-file-to-upload.png)
   <br />
   **Tipps:**

   - Wenn Sie eine oder mehrere Datei(en) über den Elementebereich auf der Safe Share-Hauptseite ziehen, erscheint über diesem Bereich eine Grafik mit der Meldung „*Dateien zum Upload hierher ziehen*“ (falls diese nicht bereits angezeigt wird). Dies zeigt an, dass Safe Share for Web zum Upload Ihrer Datei(en) bereit ist.
   - Sie können auch eine oder mehrere Datei(en) hochladen, indem Sie links oben in der Symbolleiste auf die Schaltfläche **Hochladen** klicken und anschließend die Datei(en) auf Ihrem Computer auswählen.
   - Sie können auch eine oder mehrere Datei(en) in einen vorhandenen Ordner hochladen, indem Sie die Datei(en) in den betreffenden Ordner im Elementebereich ziehen. Der Ordner wird in einer anderen Farbe hervorgehoben um anzuzeigen, dass die Dateien in diesen Ordner hochgeladen werden. Für weitere Informationen siehe [Organisation von Inhalten in Ordnern](/3.4/de/user/managing-secure-content#organising-content-with-folders).
   - Wenn Sie versuchen, eine Datei hochzuladen, deren Namen mit dem einer am jeweiligen Speicherort bereits vorhandenen Datei übereinstimmt, erhalten Sie die Meldung **Datei existiert bereits** mit der Aufforderung zu bestätigen, ob eine neue Version dieser Datei hochgeladen werden soll. Wenn Sie anschließend auf **Ja** klicken, wird die neue Version der Datei hochgeladen. Siehe [Verwaltung von Dateiversionen](/3.4/de/user/managing-file-versions) für weitere Informationen. <br />
     **Hinweis:** Wenn Sie in der Meldung **Datei existiert bereits** das Kontrollkästchen **Immer neue Version hochladen** aktivieren, ehe Sie auf **Ja** klicken, wird beim Drag & Drop einer neuen Datei mit demselben Namen wie eine bereits vorhandene Datei immer direkt die neue Version hochgeladen (ohne dass die Meldung angezeigt wird).
   - Klicken Sie zunächst auf das Dropdown-Menü **Alle Dateien** links oben auf der Safe Share-Hauptseite und wählen Sie den [Filter](/3.4/de/user/managing-secure-content#filtering-items) **Meine Dateien**, um vor dem Upload von Dateien sicherzustellen, dass Sie nur mit Ihren eigenen der im Elementebereich gezeigten Elemente arbeiten.

   **Hinweise:**

   - Unter den folgenden Bedingungen können Sie keine Dateien hochladen:

     - Ihrem Account ist für Ihre Organisation eventuell keine **Ersteller**-Rolle zugewiesen. Dieses Problem lässt sich folgendermaßen beheben:

       - Bitten Sie einen Safe Share-Organisations-Administrator Ihrer Organisation, Ihrem Benutzer-Account diese Rolle zuzuweisen.
       - Wenn Sie alternativ Mitglied einer anderen Organisation sind, in der Sie die **Ersteller**-Rolle innehaben, wählen Sie stattdessen diese Organisation.
     - Sie sind eventuell nicht berechtigt, an den aktuellen Speicherort im Dateienbereich Daten hochzuladen. Für Einzelheiten siehe die [Tipps](/3.4/de/user/managing-secure-content#folder-tips) im Abschnitt [Organisation von Inhalten in Ordnern](/3.4/de/user/managing-secure-content#organising-content-with-folders).
   - Die maximal zulässige Größe einer hochzuladenden Datei hängt von den auf der Covata-Plattform konfigurierten Eigenschaften ab. Einer Ihrer Covata-Plattform-Safe Share-Administratoren kann Ihnen diese Größe mitteilen.
4. Das Symbol „Uploads im Gang“
   ![Symbol Uploads im Gang](/images/85e121d5519f-uploads-in-progress-icon.png)

    (in der Kopfleiste) zeigt die Zahl der Dateien an, die aktuell auf von der Covata-Plattform verwalteten Speicher hochgeladen werden. Beachten Sie, dass Dateien verschlüsselt werden, *bevor* sie gespeichert werden.

   - Während Dateien hochgeladen werden, können Sie Dateien, deren Uploads noch im Gang sind, folgendermaßen anzeigen und/oder ihren Upload abbrechen:

     1. Klicken Sie gegebenenfalls auf das Symbol „Uploads im Gang“ um die Dateien, die aktuell hochgeladen werden, anzuzeigen:

        ![Uploads im Gang](/images/fdcc983dd6c4-uploads-in-progress.png)
     2. Klicken Sie im Popup-Fenster neben den Dateien, deren Upload Sie abbrechen möchten, auf das **x** (oder klicken Sie auf **Alle abbrechen**, um den Upload aller im Popup-Fenster aufgeführten Dateien abzubrechen). <br />
        **Tipp:** Klicken Sie auf die Schaltfläche **Ausblenden** oder auf einen Punkt außerhalb des Popup-Fensters, um das Fenster zu schließen.

     **Hinweis:** Diese Funktion „Uploads/Downloads anzeigen und/oder abbrechen“ funktioniert am besten mit großen Dateien. Bei kleinen Dateien haben Sie eventuell nicht genügend Zeit, um diese Funktion zu nutzen.

   Nach Abschluss des Upload-Vorgangs werden Ihre Inhalte von Safe Share (am angegebenen Speicherort innerhalb Ihrer Organisation) sicher gespeichert.

<Tip>

**Tipps und Hinweise:**

- Sobald ein Element ausgewählt wird, werden seine Register **Details** und **Verlauf** standardmäßig rechts vom Elementebereich angezeigt:

  - Wenn Sie das gewählte Element hochgeladen und [es einer oder mehreren Personen freigegeben](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) haben, wird (im Abschnitt **Datei-/Ordner-Details** im Register **Details**) ein Abschnitt **Freigabe und Berechtigungen** angezeigt, in dem die Covata-Benutzer aufgeführt sind, denen Sie das Element aktuell freigegeben haben.
  - Wenn ein anderer Benutzer das gewählte Element erstellt hat, wird (im Abschnitt **Datei-/Ordner-Details** im Register **Details**) ein Abschnitt **Besitzerdetails** angezeigt. Wenn dieser Besitzer Ihnen (als Mitwirkenden am betreffenden Element) **Upload**-, **Änderungs**- oder **Verwaltungs**-Berechtigung erteilt hat (dies geschieht anhand des [Dialogfelds „Freigeben“](/3.4/de/user/uploading-storing-and-sharing-content-securely#share-dialog-box) (für weitere Informationen siehe [Freigabe sicherer Inhalte](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) unten), erscheint auch der Abschnitt **Freigabe und Berechtigungen** (unter **Besitzerdetails**) mit den Benutzern, denen das Element aktuell freigegeben ist (sowie dem Besitzer des Elements).
  - Der Bereich **Details/Verlauf** kann durch Anklicken des betreffenden Symbols **&gt;** / **&lt;** oben in diesem Bereich reduziert oder erweitert werden.
- *Drag & Drop von Ordnern in den Dateibereich auf der Safe Share-Hauptseite wird nicht unterstützt*, da verschiedene Browser diesen Vorgang unterschiedlich handhaben. Zum Beispiel:

  - Bei manchen Browsern (darunter Chrome) werden nur die Dateien im gezogenen Ordner zum (von der Covata-Plattform verwalteten) Speicher am aktuellen, im Elementebereich gezeigten Speicherort hochgeladen.
  - Bei anderen Browsern (darunter Firefox) werden der gezogene Ordner und seine Inhalte nicht auf den Speicher hochgeladen.

</Tip>

## Änderung von Organisationen <a id="changing-organisations" />

Links oben auf der Safe Share-Hauptseite sehen Sie das Home-Symbol für Ihre Startseite, gefolgt vom Namen Ihrer aktuellen Organisation <sup>(1)</sup>. Wenn rechts neben dem Namen Ihrer aktuellen Organisation ein Dropdown-Symbol erscheint, ist Ihr Covata-Benutzer-Account auf Ihrer Instanz der Covata-Plattform Mitglied mehrerer [Organisationen](/3.4/de/user#organisations).

Ihre (links oben angegebene) aktuelle Organisation steht mit den Inhalten in Verbindung, die Sie im Elementebereich der Safe Share-Hauptseite angezeigt sehen, wo Sie weitere Inhalte [hochladen und speichern](/3.4/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) oder [freigeben](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) sowie vorhandene Inhalte [verwalten](/3.4/de/user/managing-secure-content) und darauf [zugreifen](/3.4/de/user/accessing-secure-content) können.

Wenn Sie sich bei Safe Share for Web eben erst [angemeldet](/3.4/de/user/signing-in) haben, ist Ihre „Start“-Organisation (d. h. Ihre Standardorganisation) ausgewählt und wird angezeigt. Wenn Sie eine andere Organisation auswählen möchten (bei der Sie Mitglied sind), wählen Sie die betreffende Organisation aus dem Dropdown-Menü daneben. Zum Beispiel:

![Auswahl einer Organisation](/images/355ce7b0cd6c-choosing-an-organisation.png)

<Tip>

Sie können Ihre Start- bzw. Standardorganisation anhand der [Funktionen zur Verwaltung Ihres Covata-Benutzer-Accounts](/3.4/de/user/managing-your-account) ändern, wenn Sie die [Speichernutzung und -kontingente Ihres Accounts aufrufen](/3.4/de/user/managing-your-account#viewing-your-storage-usages-and-quotas).

</Tip>

<sup>(1)</sup> Wenn Sie von der Stammebene zu einem tief verschachtelten Unterordner navigieren (für weitere Informationen siehe [Organisation von Inhalten in Ordnern](/3.4/de/user/managing-secure-content#organising-content-with-folders)), wird der Name Ihrer Organisation eventuell nicht mehr angezeigt. Dies ist insbesondere bei schmalen Browserseiten der Fall. Verbreitern Sie in diesem Fall Ihr Browserfenster oder navigieren Sie zu einem näher an der Stammebene angeordneten Unterordner, um Ihre aktuelle Organisation zu prüfen.

## Freigabe sicherer Inhalte <a id="sharing-secure-content" />

Dieser Ablauf erklärt die folgenden Möglichkeiten für die Freigabe:

- sicherer Inhalte in Ihrem persönlichen Besitz, die [Sie](/3.4/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) oder eine [andere Person](/3.4/de/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) hochgeladen haben, an andere Personen und
- sicherer Inhalte im Besitz eines anderen Covata-Benutzers, die Ihnen mit **Verwaltungs**-Berechtigung freigegeben wurden.

Hier finden Sie auch Informationen, wie Sie den Kreis der Personen, die auf diese Inhalte zugreifen können, (so genannte „Mitwirkende“) und/oder die Zugriffsberechtigungen dieser Mitwirkenden auf diese Inhalte ändern können.

<Note>

Berechtigungen sind im folgenden Ablauf ([unten](/3.4/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set)) detailliert erklärt.

</Note>

**Freigabe sicher gespeicherter Inhalte an andere Personen (oder Änderung vorhandener Freigaben dieser Inhalte):**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.4/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.4/de/user/uploading-storing-and-sharing-content-securely#locating-an-item-to-share) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.4/de/user/uploading-storing-and-sharing-content-securely#locating-an-item-to-share), um anschließend ein Element dieser Organisation freizugeben, oder
   - Freigabe eines Elements einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.4/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="locating-an-item-to-share" />Zur Freigabe der folgenden Elemente:

   - *Inhalte in Ihrem persönlichen Besitz*: [Suchen Sie](/3.4/de/user/managing-secure-content#finding-secure-content) die Datei oder den Ordner (in Ihrem Besitz) in Ihrer aktuellen Organisation, die/den Sie einer oder mehreren Personen freigeben möchten oder deren/dessen vorhandene Mitwirkende Sie ändern möchten. <br />
     **Tipp:** Um sicherzustellen, dass Sie nur mit Ihren eigenen Elementen im Elementebereich arbeiten, klicken Sie auf den Drop-Down-[Filter](/3.4/de/user/managing-secure-content#filtering-items) **Alle Dateien** links oben in der Symbolleiste und vergewissern Sie sich, dass der Filter **Meine Dateien** ausgewählt ist.
   - *Inhalte im Besitz eines anderen Covata-Benutzers* (als Mitwirkender dieser Inhalte): Suchen Sie die Datei oder den Ordner des betreffenden Benutzers, die/den Sie anderen Personen freigeben möchten oder deren/dessen vorhandene Mitwirkende Sie ändern möchten, in Ihrer aktuellen Organisation. <br />
     **Tipp:** Um sicherzustellen, dass Sie nur mit Elementen arbeiten, die andere Benutzer Ihnen als Mitwirkender freigegeben haben, klicken Sie auf den Drop-Down-[Filter](/3.4/de/user/managing-secure-content#filtering-items) **Alle Dateien** links oben neben der Symbolleiste und vergewissern Sie sich, dass der Filter **Mir freigegeben** ausgewählt ist.
4. <a id="opening-the-share-dialog-box" />Öffnen Sie für das gewünschte Element das Dialogfeld **Freigeben** auf eine der folgenden Weisen:

   - *Klicken Sie mit der rechten Maustaste auf die Zeile des Elements* und wählen Sie aus dem Popup-Menü **Freigeben**:

     ![Rechtsklick auf Datei als Besitzer - Kontextmenü](/images/6cde1cb4ccc3-right-clicking-a-file-context-menu-owner.png)

     <br />
     **Hinweis:** Wenn diese Menüoption nicht verfügbar ist, können Sie das Element nicht freigeben, da Sie nur Mitwirkender dieses Elements sind *und* Ihnen für das Element bei seiner Freigabe (bzw. der Freigabe eines übergeordneten Ordners) keine **Verwaltungs**-Berechtigung erteilt wurde. (Ihre aktuellen Berechtigungen an einem gewählten Element werden anhand des Werts im Feld **Zugriff** im Abschnitt **Datei-/Ordnerdetails** im Register **Details** rechts im Elementebereich angezeigt.) <br />
     *ODER*

   1. *Fokussieren Sie* entweder das Element, indem Sie mit der Maus über die betreffende Zeile fahren, oder *wählen Sie es aus*, indem Sie auf seine Zeile klicken (bei Ordnern rechts vom Namen): <br />
      ![Auswahl eines Elements als Besitzer](/images/5de202e7ab6d-selecting-an-item-owner.png)
   2. Wenn Sie:

      - das Element *fokussiert* haben, klicken Sie auf das Symbol „Freigeben“
        ![Symbol Freigeben](/images/fdae0b1f935f-share-icon.png)

         in der betreffenden Zeile.
      - das Element *ausgewählt* haben, klicken Sie auf das Symbol „Freigeben“
        ![Symbol Freigeben](/images/fdae0b1f935f-share-icon.png)

         in der betreffenden Zeile oder rechts in der Symbolleiste am oberen Seitenrand.

      Beachten Sie, dass das Symbol „Freigeben“ nicht verfügbar ist, wenn Sie lediglich Mitwirkender des Elements sind *und* dafür keine **Verwaltungs**-Berechtigung innehaben.
5. <a id="share-dialog-box" />Führen Sie im Dialogfeld **Freigeben** einen der folgenden Schritte aus:

   - *Geben Sie zur Freigabe des Elements an eine Person* die E-Mail-Adresse dieser Person (d. h. dieses „Mitwirkenden“) im Textfeld ein und gehen Sie weiter zum [nächsten Schritt](/3.4/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set), um die Berechtigungen dieses Mitwirkenden festzulegen. (Lesen Sie davor die **Hinweise über ...** unter diesem Bild, die wichtige Informationen über die Funktionalitäten des Dialogfelds **Freigeben** enthalten.)

     ![Freigabe-Dialogfeld](/images/75f4337268ea-share-dialog-box.png)

     <br />
     **Hinweise über das Dialogfeld „Freigeben“:**

     - Wenn die von Ihnen eingegebene E-Mail-Adresse in einer Dropdown-Liste zur Auswahl angezeigt wird, *ehe* Sie sie fertig eingegeben haben:

       - haben Sie:

         - diese E-Mail-Adresse bereits verwendet, um Elemente freizugeben (und die Adresse wurde Ihrer Kontaktliste damit automatisch hinzugefügt - für weitere Informationen siehe [Verwaltung Ihrer Kontakte](/3.4/de/user/managing-your-account#managing-your-contacts))
         - oder diese E-Mail-Adresse Ihrer Kontaktliste bereits manuell hinzugefügt.
       - hat ein Organisations-Administrator (Ihrer aktuellen Organisation) die Adressbuch-Funktion aktiviert, anhand der die E-Mail-Adressen aller Mitglieder Ihrer aktuellen Organisation automatisch vervollständigt werden. Für weitere Informationen über diese [Funktion](/3.4/de/admin-org/configuring-organisation-administration-properties#address-book-feature) der Safe Share-Organisationsverwaltung siehe [Konfiguration von Eigenschaften der Safe Share-Organisationsverwaltung](/3.4/de/admin-org/configuring-organisation-administration-properties) in der [Organisations-Administratorenanleitung](/3.4/de/admin-org).
     - Wenn Sie einen Ordner freigeben, erscheint ein etwas anderes Dialogfeld. (Die Unterschiede sind unten erläutert.)
     - Wenn ein Organisations-Administrator (Ihrer aktuellen Organisation) im System keine Klassifikationen konfiguriert hat, fehlt der Abschnitt **Klassifikationen** im Dialogfeld **Freigeben**. Für weitere Informationen über Klassifikationen siehe [Verwaltung von Klassifikationen](/3.4/de/admin-org/managing-classifications) im Handbuch für Organisations-Administratoren.
   - *Wenn Sie die Berechtigungen eines vorhandenen Mitwirkenden am betreffenden Element ändern möchten*, suchen Sie die E-Mail-Adresse dieses Mitwirkenden in der Liste der **Aktuellen Mitwirkenden** (in diesem Dialogfeld) und gehen Sie direkt zum [nächsten Schritt](/3.4/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) zur Auswahl der Berechtigungen für diesen Mitwirkenden.
   - *Wenn Sie vorhandene Mitwirkende vom betreffenden Element entfernen möchten*, suchen Sie die E-Mail-Adressen dieser Mitwirkenden in der Liste der **Aktuellen Mitwirkenden** (in diesem Dialogfeld) und klicken Sie auf den Link **Entfernen** neben den jeweiligen E-Mail-Adressen. Wenn Sie dem Element weitere Mitwirkende hinzufügen oder die Berechtigungen vorhandener Mitwirkender ändern möchten, führen Sie die entsprechenden Schritte/Optionen in diesem Schritt (siehe oben) aus. Gehen Sie andernfalls weiter zu Schritt 9 ([unten](/3.4/de/user/uploading-storing-and-sharing-content-securely#choosing-a-classification)), nachdem Sie die gewünschten Mitwirkenden von diesem Element entfernt haben.

   **Tipps:**

   - Wenn Sie lediglich die Berechtigungen vorhandener Mitwirkender an einem Element ändern oder vorhandene Mitwirkende von einem Element entfernen möchten, können Sie dies folgendermaßen schnell und einfach tun (ohne das Dialogfeld **Freigeben** zu öffnen):

     1. Wählen Sie das Element im Elementebereich der Safe Share-Hauptseite aus.
     2. Suchen Sie im Abschnitt **Freigabe und Berechtigungen** im Register **Details** rechts vom Elementebereich die E-Mail-Adressen der betreffenden Mitwirkenden und wählen Sie in den jeweiligen Dropdown-Menüs **Berechtigung** die gewünschte Berechtigung bzw. wählen Sie **Benutzer entfernen**, um einen Benutzer vom Element zu entfernen.
   - Zur Freigabe mehrerer Elemente in einem Schritt siehe die [zusätzlichen Tipps](/3.4/de/user/uploading-storing-and-sharing-content-securely#additional-tips) am Ende der Beschreibung dieses Ablaufs.
   - Das Dialogfeld **Freigeben** ist auch über den [Content-Viewer](/3.4/de/user/accessing-secure-content#content-viewer) verfügbar (sofern Sie der Besitzer des jeweils aufgerufenen Inhalts sind).
6. <a id="selecting-a-permission-set" />Wählen Sie aus der Dropdown-Liste eine der folgenden Berechtigungen aus, um den Zugriff des betreffenden Mitwirkenden auf das Element zu definieren:

   - **Anzeigen** - gewährt die individuelle Berechtigung zur *Anzeige* der Datei (aus dem schreibgeschützten Safe Share-[Content-Viewer](/3.4/de/user/accessing-secure-content#content-viewer) heraus) bzw., wenn es sich um einen Ordner handelt <sup>(2)</sup>, dieselbe individuelle Berechtigung zur *Anzeige* aller Dateien im betreffenden Ordner (und etwaigen Unterordnern). Für eine Liste der vom Content-Viewer unterstützten Dateitypen siehe [Vom Content-Viewer unterstützte Dateiformate](/3.4/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer).
   - **Herunterladen** - gewährt die individuellen Berechtigungen zur *Anzeige* und zum *Ausdruck* der Datei (ebenfalls aus dem schreibgeschützten Safe Share-Content-Viewer heraus) sowie zu ihrem *Download* bzw., wenn es sich um einen Ordner handelt <sup>(2)</sup>, dieselben individuellen Berechtigungen für alle Dateien im betreffenden Ordner (und etwaigen Unterordnern).
   - **Upload** - gewährt die individuellen Berechtigungen zur *Anzeige*, zum *Ausdruck* und zum *Download* vorhandener Dateien sowie zum *Upload* neuer Versionen von Dateien. Wenn es sich bei dem Element um einen Ordner handelt, gilt Folgendes <sup>(2)</sup>:

     - Dieselben individuellen Berechtigungen werden auch für alle Dateien und Unterordner innerhalb des Ordners gewährt.
     - Die individuellen Berechtigungen zum *Upload* neuer Dateien und ihrer Versionen sowie zum *Erstellen neuer Unterordner* (innerhalb des betreffenden Ordners) werden gewährt.
   - **Änderung** - gewährt die individuellen Berechtigungen zur *Anzeige*, zum *Ausdruck*, zum *Download*, zur *Umbenennung* und zum *Entfernen* der betreffenden Datei. Wenn es sich bei dem Element um einen Ordner handelt, gilt Folgendes <sup>(2)</sup>:

     - Dieselben individuellen Berechtigungen werden auch für alle Dateien und Unterordner innerhalb des Ordners gewährt.
     - Die individuellen Berechtigungen zum *Umbenennen* und *Entfernen* werden für den Ordner selbst gewährt.
     - Die individuellen Berechtigungen zum *Upload* neuer Dateien und ihrer Versionen, *Erstellen neuer Unterordner* und *Entfernen vorhandener Unterordner* (innerhalb des betreffenden Ordners) werden gewährt.
     - Die individuelle Berechtigung zum *Verschieben* einer Datei oder eines Unterordners in einen anderen Unterordner (innerhalb desselben Ordners) wird ebenfalls gewährt.
     - Die Berechtigung zum Zugriff auf andere Versionen einer Datei, d. h. zur Anzeige, zum Ausdruck, zum Download und zur Festlegung als **aktive** Version, wird ebenfalls gewährt.
   - **Verwalten** - gewährt die individuellen Berechtigungen zur *Anzeige*, zum *Ausdruck*, zum *Download*, zur *Umbenennung*, zur *Freigabe* und zum *Entfernen* der betreffenden Datei. Wenn es sich bei dem Element um einen Ordner handelt, gilt Folgendes <sup>(2)</sup>:

     - Dieselben individuellen Berechtigungen werden auch für alle Dateien und Unterordner innerhalb des Ordners gewährt.
     - Die individuellen Berechtigungen zum *Umbenennen*, zur *Freigabe* und zum *Entfernen* werden für den Ordner selbst gewährt.
     - Die individuellen Berechtigungen zum *Upload* neuer Dateien und ihrer Versionen, *Erstellen neuer Unterordner* und *Entfernen vorhandener Unterordner* (innerhalb des betreffenden Ordners) werden gewährt.
     - Die individuelle Berechtigung zum *Verschieben* einer Datei oder eines Unterordners in einen anderen Unterordner (innerhalb desselben Ordners) wird ebenfalls gewährt.
     - Die Berechtigung zum Zugriff auf andere Versionen einer Datei, d. h. zur Anzeige, zum Ausdruck, zum Download und zur Festlegung als **aktive** Version, wird ebenfalls gewährt.

     Beachten Sie hierbei Folgendes: Wenn Ihr Covata-Benutzer-Account im Dialogfeld **Freigeben** als Mitwirkender (mit **Verwaltungs**-Berechtigung) aufgeführt ist und Sie diese Berechtigung auf eine andere Ebene herunterstufen, verlieren Sie die Möglichkeit, für die betreffenden Inhalte auf dieses Dialogfeld zuzugreifen, sobald Sie **Freigeben/Aktualisieren** angeklickt und den Vorgang so abgeschlossen haben. Um diese Möglichkeit wieder zu erhalten, müssen Sie den Besitzer der Inhalte (oder einen anderen Mitwirkenden mit **Verwaltungs**-Berechtigung) bitten, Ihre Berechtigung an den betreffenden Inhalten wieder zu **Verwaltung** zu ändern.

   Wenn Sie dem Element keine neuen Mitwirkenden hinzufügen, gehen Sie weiter zu Schritt 8 ([unten](/3.4/de/user/uploading-storing-and-sharing-content-securely#share-dialog-box-again)). <br />
   <sup>(2)</sup> **Hinweis:** Bei der Freigabe eines Ordners gilt Folgendes:

   - Mitwirkende und ihre Berechtigungen (zum Zugriff auf Inhalte innerhalb des Ordners) werden *implizit* an alle im betreffenden Ordner enthaltenen Elemente weitergegeben (d. h. auf sie angewendet).
   - Wenn Mitwirkende an einem Unterordner (in diesem Ordner) und/oder ihre Berechtigungen geändert werden, werden diese Änderungen *explizit* für den betreffenden Unterordner festgelegt und von dort aus *implizit* über die Elementehierarchie des betreffenden Unterordners weitergegeben.
   - Die Berechtigungen eines Mitwirkenden, die für den betreffenden Unterordner *explizit* vorgegeben wurden, haben Vorrang gegenüber Berechtigungen, die der Mitwirkende eventuell *implizit* von einem übergeordneten Ordner übernommen hat.
7. <a id="adding-collaborator-to-list" />Wenn die E-Mail-Adresse des Mitwirkenden (in diesem Dialogfeld) nicht in der Liste der **Aktuellen Mitwirkenden** erscheint, klicken Sie auf die Schaltfläche **Hinzufügen** (oder drücken Sie zur Auswahl der standardmäßigen **Anzeige/Download**-Berechtigung nach der Eingabe der E-Mail-Adresse einfach die Eingabe-/Return-Taste), und die E-Mail-Adresse und gewählten Zugriffsberechtigungen des Mitwirkenden werden der Liste der Mitwirkenden hinzugefügt.

   ![Hinzugefügter Mitwirkender](/images/38a87c9f089c-added-collaborator.png)

   <br />
   **Tipp:** Sie können in diesem Textfeld auch mehrere E-Mail-Adressen/Mitwirkende eingeben und diese gleichzeitig hinzufügen. Dies geschieht folgendermaßen:

   - Geben Sie nach jeder E-Mail-Adresse ein Trennzeichen (z. B. Komma, Semikolon oder Leerstelle) ein - die E-Mail-Adresse wird nach der Eingabe jedes Trennzeichens automatisch zur Liste hinzugefügt.

   Beachten Sie, dass bei beiden Methoden die in der daneben gezeigten Dropdown-Liste aktuell gewählte Berechtigung auf alle hinzugefügten Mitwirkenden angewendet wird.
8. <a id="share-dialog-box-again" />Wiederholen Sie diesen Vorgang ab Schritt 5 ([oben](/3.4/de/user/uploading-storing-and-sharing-content-securely#share-dialog-box)), um der Liste *weitere Mitwirkende hinzuzufügen* oder die *Berechtigungen vorhandener Mitwirkender am Element zu ändern*. Setzen Sie den Vorgang andernfalls fort.
9. <a id="choosing-a-classification" />( *Optional und nur bei der Freigabe einer Datei verfügbar, **sofern** einer Ihrer Organisations-Administratoren für Ihre aktuelle Organisation [Klassifikationen](/3.4/de/admin-org/managing-classifications) konfiguriert hat* ) Wählen Sie im Dropdown-Menü **Klassifikationen** eine vordefinierte Klassifikation. Die Standardeinstellung lautet **Keine Klassifikation**. (Klassifikationen ermöglichen es Ihnen, die Freigabe von Dateien auf bestimmte Gruppen von Covata-Benutzer zu beschränken.) <br />
   **Hinweise:**

Ein Organisations-Administrator kann für Ihre aktuelle Organisation zum Beispiel die folgenden Klassifikationen konfiguriert haben: **Vertraulich**, **Beschränkt/geschützt** und **Keine Klassifikation**. Die Standardeinstellung **Keine Klassifikation** (die keinerlei Klassifikationen anwendet) ist bei der Freigabe von Dateien ebenfalls verfügbar.

Beachten Sie hierbei Folgendes: Ist ein vorhandener Mitwirkender der Datei nicht (aufgrund der von einem Organisations-Administrator definierten Zugehörigkeit zu einer Gruppe) mit der von Ihnen gewählten Klassifikation verknüpft, erhalten Sie eine entsprechende Warnung und können die betreffende Klassifikation nicht wählen.
10. ( *Optional und ebenfalls nur bei der Freigabe einer Datei* verfügbar) Definieren Sie, ab *wann* auf Ihre Datei zugegriffen werden kann:

    1. Klicken Sie hierzu auf den Link **Freigabezeitraum**, um die folgenden Optionen aufzurufen:

       ![Datums-/Zeit-Steuerelemente](/images/3344c07a726d-date-time-controls.png)
    2. Geben Sie dann folgendermaßen Datum und Zeit an:

       - Im Feld **Verfügbarkeit**, das festlegt, ab wann Ihre Mitwirkenden Zugriff auf Ihre Datei haben. Lassen Sie dieses Feld leer, um die Datei unmittelbar zur Verfügung zu stellen.
       - Im Feld **Ablaufdatum** (und -zeit), das festlegt, wann der Zugriff Ihrer Mitwirkenden auf Ihre Datei endet. Lassen Sie dieses Feld leer, um die Datei unbefristet zur Verfügung zu stellen.

       **Tipp:** Bei der Bearbeitung dieser Felder:

       - Klicken Sie zur Angabe des Datums in das Feld (oder das „Kalender“-Symbol).
       - Klicken Sie zur Angabe der Zeit auf das „Uhr“-Symbol.
       - Klicken Sie auf das **x**-Symbol, um die Inhalte des Felds zu löschen.
       - Möglicherweise bereits definierte Datums- und Zeitwerte werden beibehalten.
11. Klicken Sie auf **Freigeben/Aktualisieren**, um Ihr Element an Ihre Mitwirkenden freizugeben. Alle im Dialogfeld **Freigeben** *neu hinzugefügten* Mitwirkenden erhalten eine E-Mail-Benachrichtigung. <br />
    **Hinweise:**

      - „*Die Positivlisten-Funktion lässt Sie dieses Element nicht den folgenden Benutzern freigeben: ... Bitte wenden Sie sich an Ihren Administrator.*“ - Dies bedeutet, dass ein Safe Share-Organisations-Administrator Ihrer Organisation die Funktion Benutzer-Positivliste aktiviert hat, die den Kreis der (auf Ihre Organisation auf der Covata-Plattform zugriffsberechtigten) Personen auf diejenigen Benutzer beschränkt, deren E-Mail-Adressen (oder E-Mail-Domänen) der Positivliste hinzugefügt wurden. Sie müssen sich eventuell an einen Organisations-Administrator wenden um zu klären, welche E-Mail-Adressen und -Domänen auf der Positivliste stehen, und so sicherzustellen, dass nicht auf der Positivliste stehende Mitwirkende bei der Freigabe von Elementen (siehe oben) entweder entfernt oder Ihrer Liste von Mitwirkenden nicht hinzugefügt werden.
      - „*Die folgenden Benutzer haben keinen Zugriff auf mit KLASSIFIKATION markierte Dateien:*“ („KLASSIFIKATION“ ist hier der Name der von Ihnen [oben](/3.4/de/user/uploading-storing-and-sharing-content-securely#choosing-a-classification) gewählten Klassifikation) - Dies bedeutet, dass ein Safe Share-Organisations-Administrator Ihrer Organisation den in der Warnung aufgeführten Benutzern keinen Zugriff auf mit der betreffenden KLASSIFIKATION markierte Inhalte gewährt. Entfernen Sie entweder die Benutzer, die zum Zugriff auf Inhalte mit der betreffenden KLASSIFIKATION nicht berechtigt sind, oder wählen Sie eine andere Klassifikation.

    - Sie können die Freigabe Ihrer sicheren Inhalte auch aufheben (d. h. Mitwirkende von diesen Inhalten entfernen). Für weitere Informationen siehe [Aufhebung der Freigabe sicherer Inhalte](/3.4/de/user/managing-secure-content#unsharing-secure-content).

## Upload von Inhalten zur Freigabe über den Ordner eines anderen Benutzers <a id="uploading-content-to-share-through-another-users-folder" />

Wenn ein Covata-Benutzer, der [einen Ordner besitzt](/3.4/de/user/managing-secure-content#organising-content-with-folders):

- Ihnen als Mitwirkenden [diesen Ordner freigegeben hat](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) und
- Ihnen für den Zugriff auf diesen Ordner **Upload**-, **Änderungs**- oder **Verwaltungs**-[Berechtigung](/3.4/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) erteilt hat,

können Sie Inhalte in diesen Ordner des betreffenden Covata-Benutzers sicher hochladen und dort freigeben. Für alle Inhalte, die Sie in diesen Ordner hochladen, gilt Folgendes:

- Sie übernehmen implizit dieselben Berechtigungen, die Ihnen für den Ordner erteilt wurden.
- Sie werden für andere Covata-Benutzer verfügbar, die ebenfalls Mitwirkende des betreffenden Ordners sind (diese Mitwirkenden werden nach der Auswahl des Ordners im Abschnitt **Freigabe und Berechtigungen** im Register **Details** angezeigt).
- Sie werden Besitz des Benutzers, der Ihnen den Ordner freigegeben hat.

<Note>

Wie auch das Hochladen von Inhalten im persönlichen Besitz ([oben](/3.4/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content)) wird diese Funktion nur unterstützt, wenn Safe Share for Web auf einem Desktop- oder Laptop-Computer genutzt wird. Uploads über auf Tablets, Smartphones oder ähnlichen Geräten ausgeführte Webbrowser werden nicht unterstützt. (Bitte verwenden Sie zum Upload von Inhalten über derartige Geräte die eigenen Apps für die jeweiligen Geräte.)

</Note>

**Feststellung Ihrer Berechtigung, Inhalte in den Ordner eines anderen Benutzers hochzuladen (oder zusätzlich Inhalte dort zu verwalten):**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.4/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.4/de/user/uploading-storing-and-sharing-content-securely#filtering-for-items-shared-with-you) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.4/de/user/uploading-storing-and-sharing-content-securely#filtering-for-items-shared-with-you), um weiter mit Elementen dieser Organisation zu arbeiten, oder
   - Arbeit mit Elementen einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.4/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="filtering-for-items-shared-with-you" />Um im Elementebereich nur Elemente anzeigen zu lassen, die andere Covata-Benutzer Ihnen freigegeben haben, klicken Sie auf das Dropdown-Menü **Alle Dateien**/[Filter](/3.4/de/user/managing-secure-content#filtering-items) links oben in der Symbolleiste und vergewissern Sie sich, dass der Filter **Mir freigegeben** ausgewählt ist. <br />
   **Hinweis:** Das Dropdown-Menü **Alle Dateien**/[Filter](/3.4/de/user/managing-secure-content#filtering-items) (zum Filtern von Elementen) ist nicht verfügbar, wenn Ihrem Benutzer-Account nicht die **Ersteller**-Rolle zugewiesen ist.
4. Wählen Sie den Ordner im Elementebereich. Wenn der Wert im Feld **Zugriff** im Abschnitt **Ordnerdetails** im Register **Details** rechts vom Elementebereich **Upload**, **Änderung** oder **Verwaltung** anzeigt, hat der Besitzer des Ordners Ihnen für diesen Ordner die betreffenden Berechtigungen erteilt. Für diesen Ordner gilt Folgendes:

   - Die **Upload**-Berechtigung ermöglicht es Ihnen, Dateien (und neue Versionen von Dateien) in den Ordner selbst sowie seine Unterordner, für die Sie ebenfalls **Upload**-Berechtigung haben, *hochzuladen* und innerhalb dieser Ordner Unterordner *[zu erstellen](/3.4/de/user/managing-secure-content#organising-content-with-folders)*.
   - Die **Änderungs**-Berechtigung gibt Ihnen für den Ordner und seine Inhalte dieselben Berechtigungen wie die **Upload**-Berechtigung sowie zusätzlich die folgenden Möglichkeiten:

     - *[Umbenennen](/3.4/de/user/managing-secure-content#renaming-an-item)* und *[Entfernen](/3.4/de/user/managing-secure-content#removing-content-shared-through-another-users-folder)* von Elementen innerhalb des betreffenden Ordners sowie des Ordners selbst und aller Unterordner, für die Sie ebenfalls **Änderungs**-Berechtigung besitzen
     - *Verschieben* von Elementen zwischen Unterordnern innerhalb des betreffenden Ordners, für die Sie ebenfalls **Änderungs**-Berechtigung besitzen
   - Die **Verwaltungs**-Berechtigung gibt Ihnen für den Ordner und seine Inhalte dieselben Berechtigungen wie die **Änderungs**-Berechtigung sowie zusätzlich die Möglichkeit zur *[Freigabe](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)* des Ordners und aller seiner Elemente, für die Sie ebenfalls **Verwaltungs**-Berechtigung besitzen.

**Upload von Inhalten für die Freigabe über den Ordner eines dieser anderen Benutzer:**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet](/3.4/de/user/signing-in) sind, sich in der [gewünschten Organisation](/3.4/de/user/uploading-storing-and-sharing-content-securely#changing-organisations) befinden und den Ordner eines anderen Covata-Benutzers identifiziert haben, an dem Sie Mitwirkender sind und für den Sie Upload-Berechtigung haben.
2. Klicken Sie auf den Ordner dieses anderen Benutzers, um ihn zu öffnen.
3. Wählen Sie auf Ihrem Desktop-/Laptop-Computer eine oder mehrere Datei(en) und ziehen Sie sie in den Elementebereich auf der Safe Share-Hauptseite, ähnlich wie in [Schritt 3](/3.4/de/user/uploading-storing-and-sharing-content-securely#selecting-and-dragging-files) im Abschnitt [Upload und Speichern von Inhalten im persönlichen Besitz](/3.4/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) (oben) beschrieben. Über diesem Bereich erscheint eine Grafik mit der Meldung „*Dateien zum Upload hierher ziehen*“. Dies zeigt an, dass Safe Share for Web zum Upload der Datei(en) bereit ist. <br />
   **Tipps:**

   - Sobald Sie den Ordner des anderen Benutzers geöffnet haben, können Sie auch eine oder mehrere Datei(en) hochladen, indem Sie (links oben in der Symbolleiste) auf die Schaltfläche **Hochladen** klicken und anschließend die Datei(en) auf Ihrem Computer auswählen.
   - Sie sollten für alle Unterordner innerhalb des betreffenden Ordners (für die Sie auch die **Upload**-, **Änderungs**- oder **Verwaltungs**-Berechtigung haben) Datei/en einfach durch direktes Drag & Drop in den gewünschten Unterordner hochladen können. Ist dies nicht der Fall, hat der Besitzer wahrscheinlich Ihre Berechtigungen für die betreffenden Unterordner geändert, seit er Ihnen Berechtigungen am übergeordneten Ordner erteilt hat.
4. Das Symbol „Uploads im Gang“
   ![Symbol Uploads im Gang](/images/85e121d5519f-uploads-in-progress-icon.png)

    (in der Kopfleiste) zeigt die Zahl der Dateien an, die aktuell auf von der Covata-Plattform verwalteten Speicher hochgeladen werden. Beachten Sie, dass Dateien verschlüsselt werden, *bevor* sie gespeichert werden.

   - Während Dateien hochgeladen werden, können Sie Dateien, deren Uploads noch im Gang sind, folgendermaßen anzeigen und/oder ihren Upload abbrechen:

     1. Klicken Sie gegebenenfalls auf das Symbol „Uploads im Gang“ um die Dateien, die aktuell hochgeladen werden, anzuzeigen:

        ![Uploads im Gang](/images/fdcc983dd6c4-uploads-in-progress.png)
     2. Klicken Sie im Popup-Fenster neben den Dateien, deren Upload Sie abbrechen möchten, auf das **x** (oder klicken Sie auf **Alle abbrechen**, um den Upload aller im Popup-Fenster aufgeführten Dateien abzubrechen). <br />
        **Tipp:** Klicken Sie auf die Schaltfläche **Ausblenden** oder auf einen Punkt außerhalb des Popup-Fensters, um das Fenster zu schließen.

     **Hinweis:** Diese Funktion „Uploads/Downloads anzeigen und/oder abbrechen“ funktioniert am besten mit großen Dateien. Bei kleinen Dateien haben Sie eventuell nicht genügend Zeit, um diese Funktion zu nutzen.

   Inhalte werden in Safe Share innerhalb des Ordners des anderen Benutzers (in der aktuellen Organisation) sicher gespeichert, sobald der Upload-Vorgang abgeschlossen ist. <br />
   **Hinweise:**

   - Für diese Inhalte wird der Speicher des Covata-Benutzers beansprucht, in dessen Ordner Sie sie hochgeladen haben.
   - Alle (vom Besitzer des Ordners festgelegten) Mitwirkenden des Ordners erhalten auf die von Ihnen hochgeladenen Inhalte Zugriff, abhängig von den Berechtigungen der einzelnen Mitwirkenden hinsichtlich des Ordners.
   - Wenn Sie versuchen, eine Datei hochzuladen, deren Namen mit dem einer am jeweiligen Speicherort bereits vorhandenen Datei übereinstimmt (für die Sie **Änderungs**- oder **Verwaltungs**-Berechtigung innehaben), erhalten Sie die Meldung **Datei existiert bereits** mit der Aufforderung zu bestätigen, ob eine neue Version dieser Datei hochgeladen werden soll. Wenn Sie anschließend auf **Ja** klicken, wird die neue Version der Datei hochgeladen. Siehe [Verwaltung von Dateiversionen](/3.4/de/user/managing-file-versions) für weitere Informationen. <br />
     **Hinweise:**

     - Wenn die Datei, deren neue Version Sie hochladen, auf der Stammebene Ihrer Safe Share-Hauptseite gespeichert ist, können Sie diese Aktion nicht anhand von Drag & Drop ausführen. [Laden Sie eine neue Version dieser Datei](/3.4/de/user/managing-file-versions#uploading-a-new-version-of-a-file) stattdessen über die [Seite Versionsverwaltung](/3.4/de/user/managing-file-versions) der Datei hoch.
     - Wenn Sie in der Meldung **Datei existiert bereits** das Kontrollkästchen **Immer neue Version hochladen** aktivieren, ehe Sie auf **Ja** klicken, wird beim Drag & Drop einer neuen Datei mit demselben Namen wie eine bereits vorhandene Datei immer direkt die neue Version hochgeladen (ohne dass die Meldung angezeigt wird).
   - Wenn beim Upload einer oder mehrerer Dateien in den Ordner des anderen Benutzers eine (oder mehrere) dieser Dateien drei Mal nicht hochgeladen werden kann und Sie die Meldung „*Upload fehlgeschlagen*“ erhalten, ist am jeweiligen Speicherort bereits eine Datei mit demselben Namen vorhanden. Sie sehen diese Datei jedoch nicht, weil Sie aus einem der folgenden Gründe kein Mitwirkender daran sind:

     - Sie haben Ihren Zugriff auf eine Datei mit demselben Namen in diesem Ordner [entfernt](/3.4/de/user/managing-secure-content#removing-your-access-to-content-shared-with-you).
     - Sie wurden als Mitwirkender dieser Datei entfernt (für weitere Informationen siehe [Aufhebung der Freigabe sicherer Inhalte](/3.4/de/user/managing-secure-content#unsharing-secure-content)) oder
     - Die Datei wurde Ihnen nie freigegeben.

<Info>

**Zusätzlicher Tipp:** Sie können als Mitwirkender eines Elements (einschließlich Inhalte, die Sie in den Ordner eines anderen Benutzers hochgeladen haben) allen (oder bestimmten) aktuellen Mitwirkenden des Elements (einschließlich seines Besitzers) anhand der folgenden Optionen eine Safe Share-E-Mail-Benachrichtigung oder eine benutzerdefinierte E-Mail-Nachricht senden:

- Senden einer Safe Share-E-Mail-Benachrichtigung an alle/bestimmte aktuelle(n) Mitwirkende(n) eines Elements (sowie seinen Besitzer):

  1. Vergewissern Sie sich, dass das gewünschte Element auf der Safe Share-Hauptseite ausgewählt ist.
  2. Klicken Sie im Register **Details** im Abschnitt **Freigabe und Berechtigungen** (der nur verfügbar ist, wenn Sie für das Element über die **Upload**-, **Änderungs**- oder **Verwaltungs**-Berechtigung verfügen) auf das Symbol „Benachrichtigung“
     ![Symbol E-Mail-Benachrichtigung](/images/d110b1754834-email-notification-icon.png)

      neben:

     - **Mitwirkende benachrichtigen** <sup>(4)</sup>, um das Dialogfeld **Mitwirkende benachrichtigen** aufzurufen, in dem alle anderen aktuellen Mitwirkenden des Elements im Feld **Mitwirkende** aufgeführt sind, oder
     - der E-Mail-Adresse eines bestimmten Mitwirkenden, um das Dialogfeld **Mitwirkende benachrichtigen** mit lediglich der E-Mail-Adresse dieses Mitwirkenden im Feld **Mitwirkende** aufzurufen.

     Klicken Sie alternativ im Abschnitt **Besitzerdetails** auf das Symbol „Benachrichtigung“

     ![Symbol E-Mail-Benachrichtigung](/images/d110b1754834-email-notification-icon.png)

      um nur dem Besitzer des Elements eine E-Mail-Benachrichtigung zu senden. <br />
     **Hinweise:**

     - Dieses Dialogfeld enthält ein nicht bearbeitbares Feld **Link**, dessen Inhalt aus einer direkten URL zum betreffenden Element in Safe Share for Web besteht <sup>(5)</sup>. Dieser Link wird in die E-Mail-Benachrichtigung an die angegebenen Mitwirkenden aufgenommen.
     - Wenn Sie das Symbol „Benachrichtigung“ neben **Mitwirkende benachrichtigen** <sup>(4)</sup> angeklickt haben, können Sie einzelne Mitwirkende aus der Benachrichtigung entfernen, indem Sie das **x** neben den jeweiligen E-Mail-Adressen anklicken. (Das Dialogfeld schließt, sobald Sie die letzte E-Mail-Adresse entfernt haben.)
  3. Geben Sie im Feld **Nachricht (optional)** des Dialogfelds **Mitwirkende benachrichtigen** eine optionale Nachricht ein.
  4. Klicken Sie auf die Schaltfläche **Senden**, um die E-Mail-Benachrichtigung an alle gewählten Mitwirkenden zu senden. Diese Benachrichtigung enthält einen Link zum Element sowie Anweisungen über den Zugriff auf das Element.
- Senden einer benutzerdefinerten E-Mail-Benachrichtigung <sup>(4)</sup> an alle/bestimmte aktuelle(n) Mitwirkende(n) eines Elements anhand einer externen E-Mail-Client-Anwendung auf Ihrem Computer, z. B. Windows Live Mail, Apple Mail, Thunderbird usw.:

  1. Vergewissern Sie sich, dass das gewünschte Element auf der Safe Share-Hauptseite ausgewählt ist.
  2. Klicken Sie im Abschnitt **Freigabe und Berechtigungen** im Register **Details** auf das Symbol „E-Mail“
     ![Symbol E-Mail-Nachricht](/images/4123fb66d670-email-message-icon.png)

      um in der E-Mail-Client-Anwendung auf Ihrem Computer eine neue E-Mail mit den folgenden Parametern aufzurufen:

     - **An:** Dieses Feld ist bereits mit allen anderen aktuellen Mitwirkenden des betreffenden Elements aufgefüllt.
     - **Betreff:** Dieses Feld enthält den Namen des Elements.
     - Die erste Zeile im Text der E-Mail-Benachrichtigung enthält eine direkte URL zum betreffenden Element in Safe Share for Web <sup>(5)</sup> .

     Sie können einzelne E-Mail-Adressen aus dem Feld **An:** mithilfe der üblichen Bearbeitungsfunktionen Ihrer E-Mail-Client-Anwendung entfernen.

<sup>(4)</sup> Diese Funktionen sind nur für Elemente mit mindestens zwei Mitwirkenden verfügbar. <br />
<sup>(5)</sup> Für [vom Safe Share-Content-Viewer unterstützte Dateiformate](/3.4/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) öffnet diese URL das betreffende Element im [Content-Viewer](/3.4/de/user/accessing-secure-content#content-viewer) und nicht im Elementebereich der Safe Share-Hauptseite (in dem das Element aufgeführt ist).
