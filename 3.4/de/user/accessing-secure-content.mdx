---
title: "Zugriff auf sichere Inhalte"
---

Der Zugriff auf sichere Inhalte ist folgendermaßen möglich:

- [Anzeige, Ausdruck](/3.4/de/user/accessing-secure-content#viewing-and-printing-content) oder [Download](/3.4/de/user/accessing-secure-content#downloading-secure-content) von Dateien in Ihrem persönlichen Besitz, die Sie zuvor über [Safe Share for Web](/3.4/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content), einschließlich Safe Share for Windows, OS X, iOS und AndroidAnwendungen hochgeladen und sicher gespeichert haben. Diese Aktionen können auch mit Dateien ausgeführt werden, die ein anderer Benutzer zuvor anhand einer dieser Safe Share- Anwendungen in Ihren Ordner hochgeladen und freigegeben hat.
- [Anzeige](/3.4/de/user/accessing-secure-content#viewing-and-printing-content) von Dateien, die eine andere Person über [Safe Share for Web](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content), einschließlich Safe Share for Windows, OS X, iOS und Android-Anwendungen sicher gespeichert und Ihnen freigegeben hat. Sie können diese Dateien nur dann [ausdrucken](/3.4/de/user/accessing-secure-content#viewing-and-printing-content) oder [herunterladen](/3.4/de/user/accessing-secure-content#downloading-secure-content), wenn die Personen, die sie freigegeben haben, Ihnen die entsprechende Berechtigung erteilt haben. Diese Aktionen können auch mit Dateien ausgeführt werden, die Sie zuvor anhand einer dieser Safe Share- Anwendungen in den Ordner eines anderen Benutzers hochgeladen und freigegeben haben.

## Anzeige und Ausdruck von Inhalten <a id="viewing-and-printing-content" />

Safe Share for Web verfügt über einen [Content-Viewer](/3.4/de/user/accessing-secure-content#content-viewer), in dem Sie sichere Dateien, die Andere [Ihnen freigegeben haben](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content), sowie Dateien in Ihrem persönlichen Besitz, die [Sie](/3.4/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) oder [eine andere Person](/3.4/de/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) hochgeladen haben, anzeigen und ausdrucken können. (Für eine Liste der vom Content-Viewer unterstützten Dateitypen siehe [Vom Content-Viewer unterstützte Dateiformate](/3.4/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer).)

Wenn Ihnen Dateien freigegeben wurden, beruht Ihre Möglichkeit, diese anzuzeigen, auszudrucken und/oder herunterzuladen, auf den [Berechtigungen](/3.4/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set), die Ihnen als Mitwirkender an diesen Dateien gewährt wurden. Der Content-Viewer ist hilfreich, wenn der Besitzer einer Datei (oder ein Mitwirkender mit **Verwaltungs**-Berechtigung) den Inhalt der Datei freigeben möchte, ohne ihren Ausdruck oder ihr Download zu gestatten.

**Anzeige und Ausdruck sicherer Inhalte:**

Wenn Sie sich bei Safe Share for Web über einen Link in einer E-Mail-Benachrichtigung („Eine Datei wurde Ihnen freigegeben“) anmelden, werden Sie direkt zum [Content-Viewer](/3.4/de/user/accessing-secure-content#content-viewer) der Datei (siehe unten) geführt. Andernfalls:

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.4/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.4/de/user/accessing-secure-content#locating-your-item-to-view-and-print) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.4/de/user/accessing-secure-content#locating-your-item-to-view-and-print), um anschließend eine Datei dieser Organisation anzuzeigen/auszudrucken, oder
   - Anzeige/Ausdruck einer Datei einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.4/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="locating-your-item-to-view-and-print" />[Suchen Sie](/3.4/de/user/managing-secure-content#finding-secure-content) die anzuzeigende bzw. auszudruckende Datei.
4. Führen Sie zur Anzeige dieser Datei zunächst einen der folgenden Schritte aus:

   - *Klicken Sie mit der rechten Maustaste auf die Zeile der Datei* und wählen Sie aus dem Popup-Menü **Anzeigen**:

     ![Rechtsklick auf Datei als Mitwirkender mit Änderungs-Berechtigung - Kontextmenü](/images/6cbe6c7a2cd2-right-clicking-a-file-context-menu-collaborator-modify.png)

     <br />
     **Hinweis:** Diese Menüoption ist nicht verfügbar, wenn der betreffende Dateityp im Safe Share-Content-Viewer nicht angezeigt oder ausgedruckt werden kann. Für eine Liste der vom [Content-Viewer](/3.4/de/user/accessing-secure-content#content-viewer) unterstützten Dateitypen siehe [Vom Content-Viewer unterstützte Dateiformate](/3.4/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer). Stattdessen können Sie die Datei nur [herunterladen](/3.4/de/user/accessing-secure-content#downloading-secure-content), um auf ihre Inhalte zuzugreifen. Wenn die Datei (oder ein ihr übergeordneter Ordner) [Ihnen freigegeben ist](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content), können Sie sie nur herunterladen, wenn Ihnen eine andere Berechtigung als **Anzeige** gewährt wurde (da diese selbst nicht die individuelle Berechtigung zum *Download* beinhaltet). (Der Wert des Felds **Zugriff** innerhalb des Abschnitts **Dateidetails** im Register **Details** zeigt Ihre aktuellen Berechtigungen hinsichtlich der Datei.) <br />
     *ODER*

   1. *Fokussieren Sie* entweder das Element, indem Sie mit der Maus über die betreffende Zeile fahren, oder *wählen Sie* es aus, indem Sie auf seine Zeile klicken (bei Ordnern rechts vom Namen): <br />
      ![Auswahl eines Elements als Mitwirkender mit Änderungs-Berechtigung](/images/d708b351bee0-selecting-an-item-collaborator-modify.png)
   2. Wenn Sie:

      - das Element *fokussiert* haben, klicken Sie auf das Symbol „Anzeigen“
        ![Symbol Anzeigen](/images/2d867cdd824a-view-icon.png)

         in der betreffenden Zeile.
      - das Element *ausgewählt* haben, klicken Sie auf das Symbol „Anzeigen“
        ![Symbol Anzeigen](/images/2d867cdd824a-view-icon.png)

         in der betreffenden Zeile oder rechts in der Symbolleiste am oberen Seitenrand.

      Beachten Sie, dass das Symbol „Anzeigen“ nicht verfügbar ist, wenn die betreffende Datei im Content-Viewer nicht geöffnet werden kann. Sie können in diesem Fall nur auf den Inhalt der Datei zugreifen, indem Sie sie [herunterladen](/3.4/de/user/accessing-secure-content#downloading-secure-content). Für eine Liste der vom Content-Viewer unterstützten Dateitypen siehe [Vom Content-Viewer unterstützte Dateiformate](/3.4/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer).

   **Tipp:** Wenn Sie zu einer Datei in einem Ordner navigieren (indem Sie einen oder mehrere Ordnernamen durchklicken), können Sie im Breadcrumb (z. B.

   ![Breadcrumb](/images/435c751ef596-breadcrumb.png)

    ) am oberen Rand der Safe Share-Hauptseite Folgendes anklicken:

   - den verknüpften Namen Ihrer aktuellen Organisation, um zum Stammverzeichnis Ihres Dateibereichs zu wechseln
   - das Auslassungszeichen („...“), um die gesamte Ordnerhierarchie zu erweitern (d. h. um den **Freigegebenen Ordner** im Beispiel oben anzuzeigen), da nach jeder Änderung des Speicherorts eines Ordners nur die Stammebene und die aktuelle Ebene (d. h. **Sonstiges** im Beispiel oben) angezeigt werden
   - den Link zum Namen eines übergeordneten Ordners (d. h. **Freigegebener Ordner** in **Sonstiges** im Beispiel oben), um zum betreffenden Ordner zu wechseln

   <a id="content-viewer" /> Der Content-Viewer öffnet mit einer schreibgeschützten Anzeige der Inhalte Ihrer Datei:

   - Wenn es sich bei Ihrer Datei um eine Bilddatei handelt, sehen der Content-Viewer und seine Steuerelemente etwa folgendermaßen aus: <br />
     ![Content-Viewer für Bilddateien](/images/e365c494061c-content-viewer-image.jpg)
   - Wenn es sich bei Ihrer Datei um eine Dokumentdatei handelt (die z. B. mehr als eine Seite umfasst), sehen der Content-Viewer und seine Steuerelemente etwa folgendermaßen aus: <br />
     ![Content-Viewer für Dokumentdateien](/images/d11122b2834a-content-viewer-document.jpg)

   **Tipps zur Nutzung des Content-Viewer:**

   - Klicken Sie zum Ausdruck der Dateiinhalte im Content-Viewer auf das Symbol „Drucken“
     ![Symbol Drucken](/images/e875848c94db-content-viewer-print-icon.png)

     <br />
     **Hinweis:** Dieses Symbol ist deaktiviert, wenn Sie Mitwirkender der angezeigten Datei sind (siehe [Freigabe sicherer Inhalte](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)) *und* Ihnen für die betreffende Datei lediglich **Anzeige**-Berechtigung gewährt wurde, die eine individuelle Berechtigung zum direkten *Ausdruck* der Datei vom Content-Viewer aus nicht beinhaltet.
   - Klicken Sie zum Herunterladen der Dateiinhalte im Content-Viewer auf das Symbol „Herunterladen“
     ![Symbol Herunterladen](/images/0f12cf402ea9-content-viewer-download-icon.png)

      Downloads können auch von der [Safe Share-Hauptseite](/3.4/de/user/accessing-secure-content#downloading-secure-content) aus ausgeführt werden. <br />
     **Hinweis:** Dieses Symbol ist nicht verfügbar, wenn Sie Mitwirkender der angezeigten Datei sind *und* Ihnen für die betreffende Datei lediglich **Anzeige**-Berechtigung gewährt wurde, die eine individuelle Berechtigung zum *Download* der Datei vom Content-Viewer aus nicht beinhaltet.
   - Wenn Sie eine Bilddatei aufgerufen haben, klicken Sie im Content-Viewer auf das Symbol „Umschalten zwischen skalierter und tatsächlicher Bildgröße“
     ![Symbol Umschalten zwischen skalierter und tatsächlicher Bildgröße](/images/43764e011ef8-content-viewer-toggle-scaled-actual-size-icon.png)

      um zwischen der Anzeige des gesamten (skalierten) Bilds und der Anzeige in der tatsächlichen Originalgröße umzuschalten.
   - Die folgenden Funktionen sind nur bei der Anzeige von Dokumentdateien verfügbar:

     - Verwenden Sie die Symbole „Vergrößern“ (Plus) und „Verkleinern“ (Minus), um die Anzeige der Inhalte zu vergrößern oder verkleinern. Sie können auch im Dropdown-Menü daneben einen geeigneten Zoomfaktor wählen.
     - Klicken Sie auf das Symbol „In den Präsentationsmodus umschalten“
       ![Symbol Vollbild](/images/01ea2c7eafe6-content-viewer-presentation-mode-icon.png)

        um die Anzeige des Inhalts (mithilfe der Vollbild-Funktion des Webbrowsers) auf den gesamten Bildschirm zu vergrößern. <br />
       **Hinweis:** Manche Webbrowser unterstützen diese Funktion eventuell nicht (z. B. Safari). In diesem Fall bleibt das Anklicken dieses Symbols wirkungslos.
     - Wenn Ihr Inhalt mehrere Seiten umfasst, können Sie folgendermaßen zu verschiedenen Seiten navigieren:

       - Klicken Sie auf die Symbole „Nächste Seite“ (Pfeil nach unten) bzw. „Vorherige Seite“ (Pfeil nach oben), um seitenweise vor oder zurück zu blättern.
       - Klicken Sie auf das Symbol “Randleiste umschalten“
         ![Symbol Randleiste umschalten](/images/78354dc3e80a-content-viewer-toggle-sidebar-icon.png)

          um im Content-Viewer links die Randleiste zu öffnen, in der Sie bestimmte Seiten ansteuern können, indem Sie sie in der Miniaturansicht anklicken.
       - Geben Sie im Feld **Seite** eine Seitennummer ein (und drücken Sie dann die „Eingabe-/Return“-Taste.
     - Klicken Sie auf das Symbol „Tools“
       ![Symbol Tools](/images/b02486c7a3a6-content-viewer-tools-icon.png)

        um ein Dropdown-Menü mit weiteren Steuermöglichkeiten aufzurufen:

       - Wechseln Sie direkt zur ersten oder letzten Seite von (mehrseitigen) Inhalten.
       - Drehen Sie Inhalte im oder gegen den Uhrzeigersinn.
       - Aktivieren oder deaktivieren Sie das Hand-/Verschiebe-Tool.
   - Klicken Sie auf das **x** rechts oben im Content-Viewer, um zur Safe Share-Hauptseite zurückzukehren.

<Note>

- Sie können verschiedene Versionen einer Datei (für Einzelheiten siehe [Verwaltung von Dateiversionen](/3.4/de/user/managing-file-versions)) anzeigen und ausdrucken. Greifen Sie hierzu zunächst auf [die anderen Versionen der Datei zu](/3.4/de/user/managing-file-versions#accessing-other-versions-of-a-file). Von hier aus können Sie [die anderen Dateiversionen anzeigen und ausdrucken](/3.4/de/user/managing-file-versions#viewing-and-downloading-another-version-of-a-file).
- Wenn ein Safe Share-Organisations-Administrator Ihrer Organisation in den Safe Share-Organisationsverwaltung-Eigenschaften die Wasserzeichen-Funktion aktiviert hat, sehen Sie bei der Anzeige von Dateiinhalten im Content-Viewer (als Mitwirkender der betreffenden Datei) auf jeder Seite der Dateiinhalte ein Wasserzeichen. Für die Wasserzeichen-Funktion gilt Folgendes:

  - Diese Funktion soll Mitwirkende davon abhalten, Ansichten von Dateien auf andere Weisen zu kopieren (z. B. durch Erfassung von Screenshots usw.).
  - Sie deckt die Ansicht einer Datei mit großem, halb transparentem Text ab, der die folgenden Informationen zeigt: die E-Mail-Adresse des aktuell angemeldeten, die Datei ansehenden Mitwirkenden, die URL der Covata-Plattform, die ID der Datei/des sicheren Objekts, gegebenenfalls die vom Dateibesitzer auf die Datei angewendete Klassifikation sowie das Datum/die Zeit der Anzeige der Datei.

  Für weitere Informationen über diese Funktion und Eigenschaften der Safe Share-Safe Share-Organisationsverwaltung siehe [Konfiguration von Eigenschaften der Safe Share-Organisationsverwaltung](/3.4/de/admin-org/configuring-organisation-administration-properties) in der [Organisations-Administratorenanleitung](/3.4/de/admin-org/index).

</Note>

## Vom Content-Viewer unterstützte Dateiformate <a id="file-formats-supported-by-the-content-viewer" />

Der [Content-Viewer](/3.4/de/user/accessing-secure-content#content-viewer) in Safe Share for Web unterstützt die folgenden Dateiformate, die von ihren jeweiligen Erweiterungen bestimmt werden:

| Kategorie Dateityp | Unterstützte Dateiformate (Erweiterungen) |
| --- | --- |
| Bilddateien | bmp, gif, jpeg, jpg, png |
| Textverarbeitungs-/Textdokumente | doc, docx, html, mhtml, odt, ooxml, rtf, txt, xhtml, xml |
| Dokumente mit statischem Inhalt | pdf |
| Präsentationsdateien | odp, pot, potx, pps, ppsx, ppt, pptx |
| Tabellenkalkulations-/Datendateien | csv, ods, xls, xlsb, xlsm, xlsx, xltm, xltx, xlxm |

## Download sicherer Inhalte <a id="downloading-secure-content" />

Dieser Ablauf erklärt den Download der folgenden Inhalte:

- einzelner Dateien
- einer Auswahl von Dateien aus dem Elementebereich und
- einzelner Ordner und ihnen unmittelbar untergeordneter Elemente (d. h. ohne Inhalte, die in Unterordnern des betreffenden Ordners gespeichert sind)

<Note>

Diese Funktion ist nicht verfügbar, wenn Sie Mitwirkender der Datei sind (siehe [Freigabe sicherer Inhalte](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)) *und* Ihnen **Anzeige**-[Berechtigung](/3.4/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) gewährt wurde (die im Gegensatz zu den anderen Berechtigungen keine individuelle Berechtigung zum Download beinhaltet).

</Note>

**Download sicherer Inhalte:**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.4/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.4/de/user/accessing-secure-content#locating-your-item-to-download) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.4/de/user/accessing-secure-content#locating-your-item-to-download), um anschließend ein Element dieser Organisation herunterzuladen, oder
   - Download eines Elements einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.4/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="locating-your-item-to-download" />[Suchen Sie](/3.4/de/user/managing-secure-content#finding-secure-content) die Datei(en) bzw. den Ordner, die/den Sie herunterladen möchten.
4. Zum Download:

   - *einer einzelnen Datei oder eines einzelnen Ordners* führen Sie zunächst einen der folgenden Schritte aus:

     - *Klicken Sie mit der rechten Maustaste auf die Zeile der Datei* und wählen Sie aus dem Popup-Menü **Herunterladen**:

       ![Rechtsklick auf Datei als Besitzer - Kontextmenü](/images/6cde1cb4ccc3-right-clicking-a-file-context-menu-owner.png)

       <br />
       **Hinweis:** Wenn diese Menüoption nicht verfügbar ist, können Sie das betreffende Element nicht herunterladen, da Ihnen bei der [Freigabe](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) des Elements (bzw. eines übergeordneten Ordners) lediglich **Anzeige**-Berechtigung erteilt wurde. (Der Wert des Felds **Zugriff** innerhalb des Abschnitts **Dateidetails** im Register **Details** zeigt Ihre aktuellen Berechtigungen hinsichtlich des Elements.) <br />
       *ODER*

     1. *Fokussieren Sie* entweder das Element, indem Sie mit der Maus über die betreffende Zeile fahren, oder *wählen Sie* es aus, indem Sie auf seine Zeile klicken (bei Ordnern rechts vom Namen): <br />
        ![Auswahl eines Elements als Besitzer](/images/5de202e7ab6d-selecting-an-item-owner.png)
     2. Wenn Sie:

        - das Element *fokussiert* haben, klicken Sie auf das Symbol „Herunterladen“
          ![Symbol Herunterladen](/images/895e98c86ac0-download-icon.png)

           in der betreffenden Zeile.
        - das Element *ausgewählt* haben, klicken Sie auf das Symbol „Herunterladen“
          ![Symbol Herunterladen](/images/895e98c86ac0-download-icon.png)

           in der betreffenden Zeile oder rechts in der Symbolleiste am oberen Seitenrand.

        Beachten Sie bitte, dass diese Option nicht verfügbar ist, wenn Sie Mitwirkender des betreffenden Elements sind (siehe [Freigabe sicherer Inhalte](/3.4/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)) *und* Ihnen für das Element lediglich **Anzeige**-Berechtigung gewährt wurde.
   - *einer Auswahl von Dateien aus dem Elementebereich* wählen Sie im Elementebereich zwei oder mehr Dateien, die Sie herunterladen möchten (wie für den Download eines einzelnen Elements (siehe oben) - halten Sie zur Auswahl mehrerer Elemente jedoch die Umschalt-/Strg-/-Befehlstaste gedrückt), und klicken Sie auf das Symbol „Herunterladen“
     ![Symbol Herunterladen](/images/895e98c86ac0-download-icon.png)

      rechts in der Symbolleiste am oberen Seitenrand.

   Das Element wird über die übliche Download-Funktion Ihres Webbrowsers heruntergeladen. Wenn Sie mehrere Dateien auswählen (indem Sie aus dem Elementebereich einen Ordner oder eine Auswahl von Dateien herunterladen), werden diese in eine Datei mit demselben Namen wie der (übergeordnete) Ordner oder mit dem Namen „Home“ (beim Download einer Auswahl von Dateien von der Stammebene) gezippt. <br />
   **Tipps:**

   - Sie können den Inhalt einer Datei auch über den [Content-Viewer](/3.4/de/user/accessing-secure-content#content-viewer) herunterladen.
   - Zum Download der gesamten Inhalte eines Ordners einschließlich seiner Unterordner müssen Sie jeden Unterordner separat herunterladen. Beachten Sie, dass der Download eines Ordners nur den Download aller diesem Ordner unmittelbar untergeordneten Dateien beinhaltet. Dateien in Unterordnern des Ordners werden nicht heruntergeladen.
   - Sie können verschiedene Versionen einer Datei herunterladen (für Einzelheiten siehe [Verwaltung von Dateiversionen](/3.4/de/user/managing-file-versions)). Greifen Sie hierzu zunächst auf [die anderen Versionen der Datei zu](/3.4/de/user/managing-file-versions#accessing-other-versions-of-a-file). Von hier aus können Sie [die anderen Dateiversionen herunterladen](/3.4/de/user/managing-file-versions#viewing-and-downloading-another-version-of-a-file).
