The **Theme** page allows Covata Platform administrators to modify the:

- theme property values for [text and URLs](/3.4/admin/re-theming-the-application-and-administration#modifying-a-theme-property-value), which are used to customize:

  - the application and company names + support and help URLs for the:

    - [Safe Share web application](/3.4/user/index) (+ Covata Administration) and
    - Covata Notification email messages,

    as well as,
  - the copyright notice appearing at the base of Covata Notification email messages

  and
- [user interface logos](/3.4/admin/re-theming-the-application-and-administration#modifying-a-logo) of the Safe Share web application and Covata Administration, as well as the logo used for Covata Notification email messages.

![Theme page](/images/323d661132a0-theme-page.png)
## Modifying a theme property value

**To modify a theme property value:**

1. [Sign in](/3.4/admin/accessing-administration#signing-in) to Covata Administration.
2. Click the **Theme** option on the left of the [Covata Administration interface](/3.4/admin/accessing-administration#the-administration-interface) to open the **Theme** page.
3. Modify the values of the relevant properties below. <br />
   **Notes:**

   - After modifying a property's value, click its associated **Save** button (to save its value) before moving on to modify another property's value.
   - Clicking a property's **Reset** button sets the property back to its default value.

   | Property | Detailed description |
   | --- | --- |
   | Application Name | <a id="application-name" />The application name which appears to the right of the header logo of the [Safe Share web application](/3.4/user/index) (see [Safe Share web application logos, name and color](/3.4/admin/re-theming-the-application-and-administration#the-web-application-logos-name-and-color) for details) as well as throughout Covata Notification email messages. <br />**Note:** The default value of this property is 'Safe Share'.  |
   | Company Name | The company/organization name which appears throughout Covata Notification email messages. <br />**Note:** The default value of this property is 'Covata'.  |
   | Email Notification Copyright Notice | <a id="email-copyright" />The copyright notice which appears at the base of Covata Notification email messages. <br />**Note:** The default value of this property is '&lt;year&gt; Covata.'.  |
   | Support Link | The URL of the company's/organization's support page, which is accessible from the **Support** link in the footer of the [Safe Share web application](/3.4/user/index) and Covata Administration as well as from Covata Notification email messages. <br />**Note:** The default value of this property is the [Support page](https://support.covata.com) on the Covata web site.  |
   | Web application Help URL | The URL of the help documentation for the Covata Safe Share web application, which is accessible from the **Help** option/link available from the user's email address drop-down menu at the top-right of the Safe Share web application (and from the footer). <br />**Note:** The default value of this property is the [Safe Share User's Guide](/3.4/user/index) on the Covata web site.  |
   | Administration Help URL | The URL of the help documentation for Covata Administration, which is accessible from the **Help** option/link available from the email address drop-down menu of the Covata Platform administrator at the top-right of Covata Administration (and from the footer). <br />**Note:** The default value of this property is the Covata Platform Administrator's Guide (i.e. this guide) on the Covata web site.  |
   | Admin Email | The contact email address of the Covata Platform administrator, which is accessible from the **Need help? ...** link on the **Authentication code** entry page for two-factor authentication (2FA), whenever a Covata user (with [2FA enabled on their account](/3.4/admin/administering-users#enabling-2fa-on-a-user-account)) [signs in](/3.4/user/signing-in) through the Covata Sign-in page. <br />**Note:** The default value of this property is `admin@default.com`.  |
   | Legal URL | The URL of the company's/organization's legal page, which is accessible from the **Legal** link in the footer of the [Safe Share web application](/3.4/user/index) and Covata Administration. <br />**Note:** The default value of this property is the Covata End User License Agreement.  |
   | Version URL | An additional (custom) URL, which is accessible from the product version number link in the footer of the [Safe Share web application](/3.4/user/index) and Covata Administration. <br />**Note:** The default value of this property is the [Covata Product Release Notes](https://www.covata.com/product-releasenotes/) page on the Covata web site.  |
   | iPhone Authenticator URL | The URL of the authenticator application (app) for iOS-based devices, which is accessible from the **Install** link in **Step 1** of the instructions for a Covata user to [configure a mobile device for 2FA](/3.4/user/signing-in#configuring-a-mobile-device-for-2fa) once 2FA has been [enabled](/3.4/admin/administering-users#enabling-2fa-on-a-user-account) or [re-configured](/3.4/admin/administering-users#re-configuring-2fa-for-a-user-account) on this user's account. <br />**Note:** The default value of this property is the [Google Authenticator application for iOS](https://itunes.apple.com/au/app/google-authenticator/id388497605?mt=8) page on the iTunes web site.  |
   | Windows Phone Authenticator URL | The URL of the authenticator app for Windows mobile-based devices, which is accessible from the **Install** link in **Step 1** of the instructions for a Covata user to [configure a mobile device for 2FA](/3.4/user/signing-in#configuring-a-mobile-device-for-2fa) once 2FA has been [enabled](/3.4/admin/administering-users#enabling-2fa-on-a-user-account) or [re-configured](/3.4/admin/administering-users#re-configuring-2fa-for-a-user-account) on this user's account. <br />**Note:** The default value of this property is the [Authenticator application for Windows mobile devices](https://www.windowsphone.com/en-au/store/app/authenticator/021dd79f-0598-e011-986b-78e7d1fa76f8) page on the Microsoft web site.  |
   | Android Phone Authenticator URL | The URL of the authenticator app for Android-based devices, which is accessible from the **Install** link in **Step 1** of the instructions for a Covata user to [configure a mobile device for 2FA](/3.4/user/signing-in#configuring-a-mobile-device-for-2fa) once 2FA has been [enabled](/3.4/admin/administering-users#enabling-2fa-on-a-user-account) or [re-configured](/3.4/admin/administering-users#re-configuring-2fa-for-a-user-account) on this user's account. <br />**Note:** The default value of this property is the [Google Authenticator application for Android devices](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2) page on the Google play web site.  |
   | Header Primary Color | <a id="header-primary-color" />The background color used for the header of the [Safe Share web application](/3.4/user/index) and Covata Administration, as well as Covata Notification email messages. See [Safe Share web application logos, name and color](/3.4/admin/re-theming-the-application-and-administration#the-web-application-logos-name-and-color) for details. <br />**Note:** The default value of this property is a dark gray color.  |
   | Header Text Color | The text color used for the header of the [Safe Share web application](/3.4/user/index) and Covata Administration, as well as Covata Notification email messages. In the web application header, this option affects the color of the **Application Name** (above), as well as the email address drop-down menu and '[Uploads in progress](/3.4/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content)' icon at the top-right. See [Safe Share web application logos, name and color](/3.4/admin/re-theming-the-application-and-administration#the-web-application-logos-name-and-color) for details. <br />**Note:** The default value of this property is a white color.  |
   | Email Divider Color | The color of the dividing line between header and body of Covata Notification email messages. <br />**Note:** The default value of this property is a red color.  |

## Modifying a logo

**To modify a logo for the Safe Share web application/Covata Administration or Covata Notification email messages:**

1. [Sign in](/3.4/admin/accessing-administration#signing-in) to Covata Administration.
2. Click the **Theme** option on the left of the [Covata Administration interface](/3.4/admin/accessing-administration#the-administration-interface) to open the **Theme** page.
3. Click the appropriate **Upload Image** button to begin choosing an alternative logo for the Safe Share web application/Covata Administration user interface (i.e. the [Sign-in page](/3.4/admin/re-theming-the-application-and-administration#sign-in-page-logo) as well as [header and footer](/3.4/admin/re-theming-the-application-and-administration#the-web-application-logos-name-and-color)) and/or the Covata Notification email message (i.e. the **Email Logo**).
4. In the **Upload Image** dialog box, click **Choose a file** to upload a local image file. <br />
   **Note:** Take note of the maximum dimensions and file size. Uploading an image that exceeds these maximum values will fail.
5. Click **Close** and manually refresh the page. <br />
   **Notes:**

   - The logo is modified with immediate effect.
   - Clicking a logo's **Reset** button removes the uploaded custom image and sets the logo back to its default image, which are shown in the images below.
