## URL structure <a id="access-service-api-v1-config-theme-copyright-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/copyright
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-copyright-supported-methods-and-overview" />

- `PUT` - sets the **Email Notification Copyright Notice** property (accessible through the [System Details](/3.4/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the [Configuration](/3.4/admin-platform/configuring-platform-administration-properties) page of Safe Share Administration).

## Detailed description <a id="access-service-api-v1-config-theme-copyright-detailed-description" />

This API endpoint sets the **Email Notification Copyright Notice** property (accessible through the **System Details** section of the **Configuration** page of Safe Share Administration).

The current value of this property can be obtained using the [&lt;access-service&gt;/theme...](/3.4/api/access-service-theme) API endpoint.

## Supported roles <a id="access-service-api-v1-config-theme-copyright-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.4/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.4/admin-platform)):

- [Safe Share administrator](/3.4/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.4/api/access-service-api-v1-config-theme-copyright#access-service-api-v1-config-theme-copyright-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-config-theme-copyright-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer eyJhbGciOiJSUzI1NiJ9.eyJleHAiOjE0NjcwMTY2NjYsInVzZXJfbmFtZSI6ImFsZXgub...`

## Required body <a id="access-service-api-v1-config-theme-copyright-required-body" />

Specify the **Email Notification Copyright Notice** property value in the **body** of the request as **plain text**.

## Returns <a id="access-service-api-v1-config-theme-copyright-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
