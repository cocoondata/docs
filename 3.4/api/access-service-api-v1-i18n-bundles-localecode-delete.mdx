## URL structure <a id="access-service-api-v1-i18n-bundles-localecode-delete-url-structure" />

```text
https://access-service.xy-company.com/api/v1/i18n/bundles/{localeCode}/delete
```

where `{localeCode}` is a supported locale code.

## Supported methods and overview <a id="access-service-api-v1-i18n-bundles-localecode-delete-supported-methods-and-overview" />

- `DELETE` - deletes a custom internationalization (i18n) bundle (specified by `localeCode`) which had been uploaded to the Covata Platform's Access Service.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-i18n-bundles-localecode-delete-detailed-description" />

This API endpoint is used to delete a custom i18n bundle (specified by `{localCode}`) which had been uploaded to the Covata Platform's Access Service.

<Note>

- This endpoint can only be called on locales *without* existing i18n bundles that are built in to the Covata Platform.
- Any Covata users utilizing the locale of this custom i18n bundle (which they would have chosen through Safe Share) will automatically be reverted to use the [Safe Share administrator's default locale](/3.4/api/access-service-api-v1-i18n-adminpreference), when the bundle is deleted.

</Note>

## Supported roles <a id="access-service-api-v1-i18n-bundles-localecode-delete-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.4/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.4/admin-platform)):

- [Safe Share administrator](/3.4/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.4/api/access-service-api-v1-i18n-bundles-localecode-delete#access-service-api-v1-i18n-bundles-localecode-delete-required-headers) of requests to this endpoint.
