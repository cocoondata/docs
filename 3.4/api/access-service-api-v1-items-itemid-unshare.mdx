## URL structure <a id="access-service-api-v1-items-itemid-unshare-url-structure" />

```text
https://access-service.xy-company.com/api/v1/items/{itemId}/unshare
```

where `{itemId}` is the ID of a file object/Secure Object or folder/collection.

## Supported methods and overview <a id="access-service-api-v1-items-itemid-unshare-supported-methods-and-overview" />

- `PUT` - removes (i.e. 'unshares') all collaborators from a file object/[Secure Object](/3.4/api/working-with-files-and-folders-fundamentals#secure-object) or folder/[collection](/3.4/api/working-with-files-and-folders-fundamentals#collection) (i.e. [item](/3.4/api/working-with-files-and-folders-fundamentals#item)), specified by `itemId`.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-items-itemid-unshare-detailed-description" />

This API endpoint removes all collaborators from either a file object or folder (including the folder's contents), specified by `itemId`.

The item's ID can be obtained by calling the [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/items](/3.4/api/access-service-api-v1-organisations-orgid-items) API endpoint, which retrieves a list of information associated with file objects and folders that can be filtered using various 'search' criteria.

If the item's ID is a folder, then *all* collaborators will also be removed from *every* item contained within this folder; that is, any collaborators which had been set *explicitly* on any items contained within this folder are also removed.

## Supported roles and conditions <a id="access-service-api-v1-items-itemid-unshare-supported-roles-and-conditions" />

This API endpoint supports requests utilizing Covata user accounts with the following [roles](/3.4/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organization Administrator's Guide](/3.4/admin-org/index)):

- [Originator](/3.4/admin-org/administering-users-within-an-organisation#originator-role) - when this user owns the item whose ID is specified by `{itemId}` in the request's URL.
- **Originator**, [Collaborator](/3.4/admin-org/administering-users-within-an-organisation#collaborator-role) and [Ad hoc](/3.4/admin-org/administering-users-within-an-organisation#adhoc-role) - when this user is a collaborator with the **Share** [permission](/3.4/api/access-service-api-v1-permissions-sets) on the item whose ID is specified by `{itemId}` in the URL.

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token submitted in the [header](/3.4/api/access-service-api-v1-items-itemid-unshare#access-service-api-v1-items-itemid-unshare-required-headers) of requests to this endpoint.
