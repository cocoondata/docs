## URL structure <a id="access-service-api-v1-organisations-organisationid-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{organisationId}
```

where `{organisationId}` is the ID of an organization.

## Supported methods and overview <a id="access-service-api-v1-organisations-organisationid-supported-methods-and-overview" />

- `DELETE` - removes an organization (specified by `organisationId`) configured on the Covata Platform (available to Safe Share administrators only) on the proviso that this organization has an existing request for its removal (made by another Safe Share administrator).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-organisationid-detailed-description" />

This API endpoint removes an organization (specified by `organisationId`) configured on the Covata Platform by a Safe Share administrator.

For a request to this endpoint to succeed, a previous call to [&lt;access-service&gt;/api/v1/organisations/\{organisationId\}/removalRequest](/3.4/api/access-service-api-v1-organisations-organisationid-removalrequest) (i.e. to initiate a request to remove this organization) must have already been made by another Safe Share administrator whose [access token was submitted in the request to that API endpoint](/3.4/api/access-service-api-v1-organisations-organisationid-removalrequest#access-service-api-v1-organisations-organisationid-removalrequest-supported-roles).

<Tip>

To determine if an organization has an existing request for its removal, use the [&lt;access-service&gt;/api/v1/organisations](/3.4/api/access-service-api-v1-organisations) API endpoint to retrieve information about organizations configured on the Covata Platform and if the required organization's `organisationRemovalRequest` member is not `null` and contains sub-members, then the organization has an existing request for its removal.

</Tip>

## Supported roles and conditions <a id="access-service-api-v1-organisations-organisationid-supported-roles-and-conditions" />

This API endpoint supports the following Covata user [roles](/3.4/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.4/admin-platform)):

- [Safe Share administrator](/3.4/admin-platform/administering-platform-administrator-users#platform-administrator-role) - when this user is a different Safe Share administrator to the one who [initiated the request to remove this organization](/3.4/api/access-service-api-v1-organisations-organisationid-removalrequest).

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.4/api/access-service-api-v1-organisations-organisationid#access-service-api-v1-organisations-organisationid-required-headers) of requests to this endpoint.
