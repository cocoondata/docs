---
title: "Accessing secure content"
---

To access secure content, you can:

- [View, print, download/decrypt](/3.3/windows/accessing-secure-content#viewing-printing-downloading-your-own-content) and/or [edit](/3.3/windows/accessing-secure-content#editing-files) personally owned files you have previously uploaded and stored securely with [Safe Share for Windows](/3.3/windows/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content), including [Safe Share for Web](/3.3/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) as well as Safe Share for OS X, iOS and Android applications. These actions can also be performed on files that [another user uploaded to your folder](/3.3/windows/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) with any of these Safe Share applications.
- [View](/3.3/windows/accessing-secure-content#viewing-printing-downloading-content-shared-with-you) files which someone else has stored securely and shared with you using [Safe Share for Windows](/3.3/windows/uploading-storing-and-sharing-content-securely#sharing-secure-content), including [Safe Share for Web](/3.3/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) as well as Safe Share for OS X, iOS and Android applications. You can only [print, download/decrypt](/3.3/windows/accessing-secure-content#viewing-printing-downloading-content-shared-with-you) or [edit](/3.3/windows/accessing-secure-content#editing-files) these files if the people who shared the files have granted you permission to perform these actions. These actions can also be performed on files that [you uploaded to share through another user's folder](/3.3/windows/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) with any of these Safe Share applications.

## Viewing/printing/downloading your own content <a id="viewing-printing-downloading-your-own-content" />

**To view/print/download/decrypt securely stored content that you own:**

1. [Access](/3.3/windows/uploading-storing-and-sharing-content-securely#accessing-the-applications-folder) the `Safe Share` folder for your organization.
2. Within the `My Secured Files` subfolder, locate the file/s or folder/s whose content you wish to view/print/download/decrypt.
3. Do one of the following based on the action to be performed:

   - *To begin viewing/printing one or more of your own secure file/s*, select and right-click on the file/s and choose **Safe Share &gt; View**. A separate [Safe Share Content Viewer](/3.3/windows/accessing-secure-content#read-only-content-viewer) window opens for each viewable file of your selected content.

     ![Viewing my own files using the pop-up menu](/images/952bd39aa501-right-clicking-an-item-owner.png)

     <br />
     **Notes:**

     - If one of the files you selected is not viewable, a message is shown indicating that the file's type is not supported by the Safe Share Content Viewer. File types which are supported are [equivalent to those in Safe Share for Web's content viewer](/3.3/user/accessing-secure-content#file-formats-supported-by-the-content-viewer).
     - The **View** menu item is disabled if the selected items *only consist* of folders and/or non-viewable files. Although this menu option is available if one or more folders have been selected *in addition* to viewable files, any content within these folders is ignored (and not opened in the Safe Share Content Viewer).
   - *To begin downloading/decrypting your own secure content*, either:

     - Select the item/s and drag&drop/copy/move them to a location outside the `Safe Share` folder; for example, dragging and dropping them to your desktop: <br />
       ![Downloading my own files to desktop by drag and drop](/images/ca880cbed00c-downloading-my-own-files-to-desktop-by-drag-and-drop.jpg)
       <br />
       **Note:** Regardless of whether you copy or move items from `My Secured Files`, the secured items will remain in the `My Secured Files` subfolder. <br />
       *OR*
     - Alternatively, select and right-click on one or more file/s and/or folder/s and choose **Safe Share &gt; Download** from the pop-up menu:

       ![Downloading my own files to desktop using the pop-up menu](/images/952bd39aa501-right-clicking-an-item-owner.png)

       <br />
        The **Browse For Folder** dialog box opens, prompting you to specify a location where your selected content will be download.

     Safe Share for Windows downloads the content (decrypting it on your computer) at the target location (e.g. your desktop).

## Viewing/printing/downloading content (shared with you) <a id="viewing-printing-downloading-content-shared-with-you" />

If files have been [shared with you](/3.3/windows/uploading-storing-and-sharing-content-securely#sharing-secure-content), then your ability to view and/or print + download/decrypt these files is based on the [permissions](/3.3/windows/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) that were granted to you as a collaborator on these files. The content viewer is useful when the owner of a file (or a collaborator with **Manage** permissions on it) wants to share the file's content but not allow the content to be printed and downloaded.

**To view/print/download/decrypt securely stored content which someone else has shared with you:**

1. [Access](/3.3/windows/uploading-storing-and-sharing-content-securely#accessing-the-applications-folder) the `Safe Share` folder for your organization.
2. Within the `Shared With Me` subfolder, identify/locate the folder of the Covata user who shared content with you. <br />
   **Note:** You can only download/decrypt a file within these types of folders if you were granted **Download** permissions (or greater permissions that grant the individual *download* permission) when the file (or one of its ancestral folders) was [shared with you](/3.3/windows/uploading-storing-and-sharing-content-securely#sharing-secure-content). If you do not have the individual *download* permission on a file, then you can only view its content.
3. Within this other user's `Shared By ...` folder, locate the file/s or folder/s whose content you wish to view/print/download/decrypt. <br />
   **Note:** To determine if you can view or print the content of a file or folder (i.e. by having the individual *view* or *print* permissions respectively on the item), right-click the item and choose **Safe Share &gt; Show permissions** from the pop-up menu:

   ![Identifying a item's permissions](/images/44a0e62e1d4a-right-clicking-an-item-collaborator.png)
4. Do one of the following based on the action to be performed:

   - <a id="to-begin-viewing-printing-secure-content-shared-with-you" />*To begin viewing/printing one or more secure file/s which someone else has securely shared with you*, select and right-click on the file/s and choose **Safe Share &gt; View**. A separate [Safe Share Content Viewer](/3.3/windows/accessing-secure-content#read-only-content-viewer) window opens for each viewable item of your selected content. <br />
     **Notes:**

     - If one of the files you selected is not viewable, a message is shown indicating that the file's type is not supported by the Safe Share Content Viewer. File types which are supported are [equivalent to those in Safe Share for Web's content viewer](/3.3/user/accessing-secure-content#file-formats-supported-by-the-content-viewer).
     - The **View** menu item is disabled if the selected item/s *only consist* of folders and/or non-viewable files. Although this menu option is available if one or more folders have been selected *in addition* to viewable files, any content within these folders is ignored (and not opened in the Safe Share Content Viewer).
   - *To begin downloading/decrypting secure content which someone else has securely shared with you*, either:

     - Select the item/s and drag&drop/copy/move them to a location outside the `Safe Share` folder - e.g. dragging and dropping them to your desktop:

       ![Downloading a shared file to desktop by drag and drop](/images/5b3afb2741dc-downloading-a-shared-file-to-desktop-by-drag-and-drop.jpg)
       <br />
       **Note:** Regardless of whether you copy or move items from `Shared With Me`, the secured items will remain in the `Shared With Me` subfolder. <br />
       *OR*
     - Alternatively, select and right-click on one or more file/s and/or folder/s and choose a **Safe Share &gt; Download** option from the pop-up menu:

       ![Identifying a item's permissions](/images/44a0e62e1d4a-right-clicking-an-item-collaborator.png)

       <br />
        The **Browse For Folder** dialog box opens, prompting you to specify a location where your selected content will be download.

     Safe Share for Windows downloads the content (decrypting it on your computer) at the target location (e.g. your desktop).

<Note>

- If you downloaded a folder, either by dragging&dropping/copying/moving the folder to a location outside the `Safe Share` folder (or via the **Safe Share &gt; Download** right-click option), then all files within the folder (including its subfolders) are downloaded/decrypted, with the exception of subfolders on which you only have **View** permissions. If such a subfolder were to contain its own folder on which you had the individual *download* permission, then you would need to download this subfolder in a separate action.
- If files were *moved out* of any `Safe Share` folder to a network drive location, then these files will only reappear in the source `Safe Share` folder following a subsequent Safe Share for Windows synchronization event (with remote storage managed by the Covata Platform).
- If Safe Share for Windows experiences delays in network communication, you may notice the following behavior:

  1. The encrypted files are temporarily copied to their target location.
  2. Safe Share for Windows decrypts these files from their temporary copies (created in the previous step) and saves them to the same location as their temporary copies.
  3. The temporary copies are deleted.

</Note>

## Safe Share for Windows' read-only content viewer <a id="read-only-content-viewer" />

Safe Share for Windows' read-only content viewer (also known as the *Safe Share Content Viewer* within the application) and the [content viewer](/3.3/user/accessing-secure-content#content-viewer) of Safe Share for Web are equivalent features.

The Safe Share Content Viewer opens when you view [your own](/3.3/windows/accessing-secure-content#viewing-printing-downloading-your-own-content) or [someone else's](/3.3/windows/accessing-secure-content#viewing-printing-downloading-content-shared-with-you) file with Safe Share for Windows.

**Safe Share for Windows' content viewer for image files:**

![Safe Share for Windows' content viewer for image files](/images/3e208f686aa8-content-viewer-image.jpg)

**Safe Share for Windows' content viewer for document files:**

![Safe Share for Windows' content viewer for document files](/images/eb2e226cf6e2-content-viewer-document.png)

**Tips on using the Safe Share Content Viewer:**

- Click the 'Print' icon
  ![Print icon](/images/26ba53112420-content-viewer-print-icon.png)

   to print the file's content. <br />
  **Note:** This icon will not be available if you are a collaborator on the file being viewed (see [Sharing secure content](/3.3/windows/uploading-storing-and-sharing-content-securely#sharing-secure-content)) *and* you were only granted **View** permissions on the file, which does not grant the individual *print* permission that allows you to print it directly from the content viewer.
- If you are viewing an image file, click the 'Print preview' icon
  ![Print preview icon](/images/aedfe59120cd-content-viewer-print-preview-icon.png)

   to view a preview of the file's content (before printing it). <br />
  **Notes:**

  - Like the 'Print' icon, this icon will also not be available if you are a collaborator on the file being viewed *and* you were only granted **View** permissions.
  - The print preview feature has its own functional icons for printing and zooming.
  - Print previews can only be generated in portrait orientation. Landscape-oriented previews are not available through this feature.
- Click the 'Actual size'
  ![Actual size icon](/images/487e147b64ed-content-viewer-actual-size-icon.png)

   and 'Fit to viewer'

  ![Fit to viewer icon](/images/c6ed050d60e8-content-viewer-fit-to-viewer-icon.png)

   icons zoom to the native size of the content or the size that fits the viewer, respectively.
- Click the 'Zoom In'
  ![Zoom in icon](/images/5c80da4778f5-content-viewer-zoom-in-icon.png)

   and 'Zoom Out'

  ![Zoom out icon](/images/c98b1d333e2b-content-viewer-zoom-out-icon.png)

   icons to zoom in and out of the content view, respectively. The adjacent drop-down can also be used to select an appropriate zoom level.
- Click the 'Download' icon
  ![Download icon](/images/5e4b272e74f7-content-viewer-download-icon.png)

   on the content viewer to download the content of a file (belonging to [you](/3.3/windows/accessing-secure-content#viewing-printing-downloading-your-own-content) or [someone else](/3.3/windows/accessing-secure-content#viewing-printing-downloading-content-shared-with-you)). <br />
  **Note:** This icon will not be available if you are a collaborator on the file being viewed *and* you were only granted **View** permissions on the file, which does not grant the individual *download* permission that allows you to download the file's content.
- If you are the owner of the file you are currently viewing, click the 'Share' icon
  ![Share icon](/images/a66b740f9686-content-viewer-share-icon.png)

   to [open the 'Share' dialog box](/3.3/windows/uploading-storing-and-sharing-content-securely#share-dialog-box), which allows you to add new collaborators and/or modify existing collaborators (including their permissions) on this file. <br />
  **Note:** This icon will *also* be available if you are a collaborator on the file being viewed *and* you were granted **Manage** permissions on the file (which grants the individual *share* permission).
- If your content consists of multiple pages, you can navigate to different pages by:

  - Clicking the 'Next Page'
    ![Next page icon](/images/bb5aec5cf4d2-content-viewer-next-page-icon.png)

     and 'Previous Page'

    ![Previous page icon](/images/99da56fdf7eb-content-viewer-previous-page-icon.png)

     icons to respectively move forward and back one page at a time.
  - Clicking the 'First Page'
    ![First page icon](/images/323e3d5f5ee5-content-viewer-first-page-icon.png)

     and 'Last Page'

    ![Last page icon](/images/b4a096e1d1b9-content-viewer-last-page-icon.png)

     icons to respectively jump/go to the first and last pages of content.
  - Typing a page number in the 'Current Page' field (followed by the 'return/enter' key).

## Editing files

**To edit one or more securely stored files which you own (or someone else shared with you):**

1. [Access](/3.3/windows/uploading-storing-and-sharing-content-securely#accessing-the-applications-folder) the `Safe Share` folder for your organization.
2. Locate the file you wish to edit either within:

   - the `My Secured Files` subfolder for a file you own, or
   - another user's `Shared By ...` folder (within the `Shared With Me` subfolder) for a file that someone else has shared with you.
3. To begin editing:

   - *A single file*, double-click the file to open the file in its default Windows application. <br />
     *OR*
   - *One or more files*, select and right-click on the file/s and choose **Safe Share &gt; Edit** from the pop-up menu:

     ![Downloading my own files to desktop using the pop-up menu](/images/952bd39aa501-right-clicking-an-item-owner.png)

     <br />
      Each of the selected files opens in its own default Windows application window.

   Regardless of the application that opens the file/s, this action immediately sets the file/s into ['edit mode'](/3.3/windows/accessing-secure-content#accessing-files-in-edit-mode), where the number of files in edit mode is indicated under the **Sync now** link on the application pane:

   ![Files in 'edit mode'](/images/f633ce80a34a-application-pane-editing-files.png)

   <br />
   **Notes:**

   - The default Windows application is the application currently configured in Windows to open the file (based on its file name extension). <br />
      This behavior is equivalent to downloading and decrypting the file from a `Safe Share` folder to another location (using one of the procedures above) and then double-clicking the file to open it. However, opening the file after downloading/decrypting it outside the `Safe Share` folder, does not set the file into 'edit mode'.
   - Files in edit mode are stored by Safe Share for Windows in a local folder (managed by the application). Although these files are stored in a decrypted state, they are only intended to exist temporarily - see [below](/3.3/windows/accessing-secure-content#accessing-files-in-edit-mode) for more information.
   - Be aware that the default Windows application used to open your file may not be well-suited to editing this type of file, or this application may not be your preferred one for editing this file type. In such circumstances, either:

     - Download and decrypt the file to another location outside its `Safe Share` folder (using one of the procedures above) and then use Windows open the decrypted copy of this file in your application of choice.
     - Use Windows' own operating system features to change the default Windows application used to open the type of file you wish to edit. Doing so will allow you to set and access these types of files in [edit mode](/3.3/windows/accessing-secure-content#accessing-files-in-edit-mode).
4. If you edited the file outside its `Safe Share` folder, you can create a new version of the file by simply uploading the file (using drag&drop/copy/move) back to its original `Safe Share` folder (which either [you](/3.3/windows/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) or [another user](/3.3/windows/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) own/s). See [Managing file versions](/3.3/user/managing-file-versions) in the [Safe Share for Web](/3.3/user) User's Guide for more information.

<a id="accessing-files-in-edit-mode" />**To access files in 'edit mode':**

1. Ensure that Safe Share for Windows has been [started](/3.3/windows/starting-the-application-and-signing-in#starting-the-application), you are signed in and if your Covata user account is a member of multiple organizations, that your [current organization](/3.3/windows/uploading-storing-and-sharing-content-securely#changing-organisations) is the one through which you want to access files in edit mode.
2. Click the **Editing N files** link in the application pane, where 'N' represents the number of files you currently have open in edit mode, which opens the **Files open for editing** dialog box:

   ![Files open for editing dialog box](/images/0fd47bedb7c9-files-open-for-editing-dialog-box.png)

   <br />
    On this dialog box, you can click the following buttons on an individual file:

   - **Open** - to open this file in its default Windows application (for further editing). <br />
     **Note:** When saving any file in edit mode from its default Windows application, do so without changing the name and location of the file (which is a decrypted copy managed by Safe Share for Windows and is intended to exist only temporarily).
   - **Sync changes** - to save this file back to its original `Safe Share` folder, which uploads and stores the last edited/locally saved changes you made to this file back to its original location in Safe Share, thereby creating a new version of this file. See [Managing file versions](/3.3/user/managing-file-versions) in the [Safe Share for Web](/3.3/user) User's Guide for more information. <br />
     **Notes:**

     - If the folder containing this file was moved since the file entered edit mode, then Safe Share for Windows keeps track of the location of this folder and will automatically save the file back to the correct `Safe Share` folder. If, however, the folder containing this file was either removed or renamed (since the file entered edit mode), then Safe Share for Windows provides alternative options for handling your edited changes.
     - After clicking this button, this file entry is removed from the **Files open for editing** dialog box (and the locally decrypted copy of this file managed by Safe Share for Windows is removed).
   - **Discard changes** - to discard this file in edit mode. <br />
     **Note:** After clicking this button, this file entry is removed from the **Files open for editing** dialog box (and the locally decrypted copy of this file managed by Safe Share for Windows is removed). Be aware that you will lose any changes you made to this file since it entered edit mode.
   - **Save changes to desktop** - to save the last edited/locally saved changes you made to this file to the Windows desktop. After clicking this button, however, the locally decrypted copy of this file managed by Safe Share for Windows remains unaltered.

   You can also click the following buttons on this dialog box:

   - **Sync all changes** - to perform the same function as the **Sync changes** button (above) but for all files in edit mode listed on this dialog box.
   - **Discard all changes** - to perform the same function as the **Discard changes** button (above) but for all files in edit mode listed on this dialog box.
