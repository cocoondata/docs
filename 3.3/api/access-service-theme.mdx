## URL structure <a id="access-service-theme-url-structure" />

```text
https://access-service.xy-company.com/theme...
```

where `...` represents either nothing or any one of the following paths (appended to the URL [above](/3.3/api/access-service-theme#access-service-theme-url-structure)):

- `/adminEmail`
- `/adminHelpUrl`
- `/androidAuthenticatorUrl`
- `/applicationName`
- `/companyName`
- `/copyright`
- `/iphoneAuthenticatorUrl`
- `/legalUrl`
- `/orgAdminHelpUrl`
- `/privacyUrl`
- `/supportLink`
- `/versionUrl`
- `/webappHelpUrl`
- `/windowsAuthenticatorUrl`

## Supported methods and overview <a id="access-service-theme-supported-methods-and-overview" />

- `GET` - used to retrieve the current values for each (or all) theme-related Safe Share Administration properties, many of which can be [overridden through Organization Administration](/3.3/api/access-service-api-v1-organisations-orggroupid).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-theme-detailed-description" />

This API endpoint retrieves the current values for all theme-related Safe Share Administration properties (i.e. when nothing is appended to the URL [above](/3.3/api/access-service-theme#access-service-theme-url-structure)). Many of these properties can be [overridden through Organization Administration](/3.3/api/access-service-api-v1-organisations-orggroupid).

Each of the following paths (which can be appended to the URL above) relates to an individual property (accessible through the [System Details](/3.3/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the [Configuration](/3.3/admin-platform/configuring-platform-administration-properties) page of Safe Share Administration), such that making a `GET` request on that URL/path combination retrieves the value for that property only:

| Appended URL path | System Details property | Can be modified through this API endpoint |
| --- | --- | --- |
| /adminEmail | Admin Email | [&lt;access-service&gt;/api/v1/config/theme/adminEmail](/3.3/api/access-service-api-v1-config-theme-adminemail) |
| /adminHelpUrl | Safe Share Administration Help URL | [&lt;access-service&gt;/api/v1/config/theme/adminHelpUrl](/3.3/api/access-service-api-v1-config-theme-adminhelpurl) |
| /androidAuthenticatorUrl | Android Phone Authenticator URL | [&lt;access-service&gt;/api/v1/config/theme/androidAuthenticatorUrl](/3.3/api/access-service-api-v1-config-theme-androidauthenticatorurl) |
| /applicationName | Application Name | [&lt;access-service&gt;/api/v1/config/theme/applicationName](/3.3/api/access-service-api-v1-config-theme-applicationname) |
| /companyName | Company Name | [&lt;access-service&gt;/api/v1/config/theme/companyName](/3.3/api/access-service-api-v1-config-theme-companyname) |
| /copyright | Email Notification Copyright Notice | [&lt;access-service&gt;/api/v1/config/theme/copyright](/3.3/api/access-service-api-v1-config-theme-copyright) |
| /iphoneAuthenticatorUrl | iPhone Authenticator URL | [&lt;access-service&gt;/api/v1/config/theme/iphoneAuthenticatorUrl](/3.3/api/access-service-api-v1-config-theme-iphoneauthenticatorurl) |
| /legalUrl | Legal URL | [&lt;access-service&gt;/api/v1/config/theme/legalUrl](/3.3/api/access-service-api-v1-config-theme-legalurl) |
| /orgAdminHelpUrl | Organization Administration Help URL | [&lt;access-service&gt;/api/v1/config/theme/orgAdminHelpUrl](/3.3/api/access-service-api-v1-config-theme-orgadminhelpurl) |
| /privacyUrl | The URL of the privacy statement | [&lt;access-service&gt;/api/v1/config/theme/privacyUrl](/3.3/api/access-service-api-v1-config-theme-privacyurl) |
| /supportLink | Support URL | [&lt;access-service&gt;/api/v1/config/theme/supportLink](/3.3/api/access-service-api-v1-config-theme-supportlink) |
| /versionUrl | Version URL | [&lt;access-service&gt;/api/v1/config/theme/versionUrl](/3.3/api/access-service-api-v1-config-theme-versionurl) |
| /webappHelpUrl | Web Application Help URL | [&lt;access-service&gt;/api/v1/config/theme/webappHelpUrl](/3.3/api/access-service-api-v1-config-theme-webapphelpurl) |
| /windowsAuthenticatorUrl | Windows Phone Authenticator URL | [&lt;access-service&gt;/api/v1/config/theme/windowsAuthenticatorUrl](/3.3/api/access-service-api-v1-config-theme-windowsauthenticatorurl) |

## Supported roles <a id="access-service-theme-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.3/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.3/admin-platform/index)):

- [Safe Share administrator](/3.3/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.3/api/access-service-theme#access-service-theme-required-headers) of requests to this endpoint.

## Returns <a id="access-service-theme-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.

For successful requests only, a JSON-formatted response containing the following members is also returned:

- **property_name** - The name of the property, followed by its value. <br />
  **Notes:**

  - Most **property_name**s are similar to (but do not match) the URL path components [above](/3.3/api/access-service-theme#access-service-theme-detailed-description), which can be appended to this endpoint's URL. These names are hard-coded in the Covata Platform.
  - When a URL path component is appended to this endpoint's URL, the property name is returned as just **property**.
