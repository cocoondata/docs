## URL structure <a id="access-service-api-v1-config-theme-webapphelpurl-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/webappHelpUrl
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-webapphelpurl-supported-methods-and-overview" />

- `PUT` - used to set (or clear) the **Web Application Help URL** property (accessible through the [System Details](/3.3/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the [Configuration](/3.3/admin-platform/configuring-platform-administration-properties) page of Safe Share Administration).

## Detailed description <a id="access-service-api-v1-config-theme-webapphelpurl-detailed-description" />

This API endpoint sets (or clears) the **Web Application Help URL** property (accessible through the **System Details** section of the **Configuration** page of Safe Share Administration).

<Note>

This property can be overridden at the organization level using the [&lt;access-service&gt;/api/v1/organisations/\{orgGroupId\}](/3.3/api/access-service-api-v1-organisations-orggroupid) API endpoint.

</Note>

## Supported roles <a id="access-service-api-v1-config-theme-webapphelpurl-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.3/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.3/admin-platform)):

- [Safe Share administrator](/3.3/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-config-theme-webapphelpurl#access-service-api-v1-config-theme-webapphelpurl-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-config-theme-webapphelpurl-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

The following header is required if the body of the request has a JSON object:

- `Content-Type: application/json`

## Required body <a id="access-service-api-v1-config-theme-webapphelpurl-required-body" />

Specify the the **Web Application Help URL** property value (i.e. the full URL for this property) in the **body** of the request as **plain text**.

To clear this property's value, specify an empty **JSON object** in the **body** of the request:

- `{}`

## Returns <a id="access-service-api-v1-config-theme-webapphelpurl-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
