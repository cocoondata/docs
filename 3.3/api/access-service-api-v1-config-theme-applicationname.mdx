## URL structure <a id="access-service-api-v1-config-theme-applicationname-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/applicationName
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-applicationname-supported-methods-and-overview" />

- `PUT` - used to set the **Application Name** property (accessible through the [System Details](/3.3/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the [Configuration](/3.3/admin-platform/configuring-platform-administration-properties) page of Safe Share Administration).

## Detailed description <a id="access-service-api-v1-config-theme-applicationname-detailed-description" />

This API endpoint sets the **Application Name** property (accessible through the **System Details** section of the **Configuration** page of Safe Share Administration).

## Supported roles <a id="access-service-api-v1-config-theme-applicationname-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.3/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.3/admin-platform)):

- [Safe Share administrator](/3.3/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-config-theme-applicationname#access-service-api-v1-config-theme-applicationname-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-config-theme-applicationname-required-headers" />

The appropriate access token as the `Bearer` token:

## Required body <a id="access-service-api-v1-config-theme-applicationname-required-body" />

Specify the the **Application Name** property value in the **body** of the request as **plain text**.

## Returns <a id="access-service-api-v1-config-theme-applicationname-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
