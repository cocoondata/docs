## URL structure <a id="access-service-api-v1-i18n-bundles-url-structure" />

```text
https://access-service.xy-company.com/api/v1/i18n/bundles
```

## Supported methods and overview <a id="access-service-api-v1-i18n-bundles-supported-methods-and-overview" />

- `GET` - used to retrieve a list of internationalization (i18n) bundles which are currently available (i.e. 'supported') on the Covata Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-i18n-bundles-detailed-description" />

This API endpoint retrieves a list of i18n bundles which are currently available (i.e. 'supported') on the Covata Platform.

These are i18n bundles which either are built in or have been uploaded to the Covata Platform.

## Supported roles <a id="access-service-api-v1-i18n-bundles-supported-roles" />

This API endpoint supports requests utilizing Covata user accounts with the following roles (as described in the [Safe Share Administrator's](/3.3/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) and [Organization Administrator's](/3.3/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) Guides):

- [Originator](/3.3/admin-org/administering-users-within-an-organisation#originator-role)
- [Collaborator](/3.3/admin-org/administering-users-within-an-organisation#collaborator-role)
- [Ad hoc](/3.3/admin-org/administering-users-within-an-organisation#adhoc-role)
- [Safe Share administrator](/3.3/admin-platform/administering-platform-administrator-users#platform-administrator-role)
- [Organization administrator](/3.3/admin-org/administering-users-within-an-organisation#organisation-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-i18n-bundles#access-service-api-v1-i18n-bundles-required-headers) of requests to this endpoint.
