## URL structure <a id="access-service-api-v1-organisations-orggroupid-statistics-items-storage-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{orgGroupId}/statistics/items/storage
```

where `{orgGroupId}` is the ID of an organization.

## Supported methods and overview <a id="access-service-api-v1-organisations-orggroupid-statistics-items-storage-supported-methods-and-overview" />

- `GET` - used to retrieve a summary of information about storage requirements and usage for an organization (specified by `orgGroupId`).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-orggroupid-statistics-items-storage-detailed-description" />

This API endpoint retrieves a summary of information about storage requirements and usage for an organization (specified by `orgGroupId`).

The storage requirement information provided consists of the amount of:

- Storage space (in [mebibytes](http://physics.nist.gov/cuu/Units/binary.html)/MiB) currently allocated to this organization.
- Storage space required for [Covata users](/3.3/admin-org/administering-users-within-an-organisation) (also in MiB), which is based on the sum of all [quotas](/3.3/admin-org/managing-users-storage-quotas-through-plans) associated with all users in this organization who have the [Originator](/3.3/admin-org/administering-users-within-an-organisation#originator-role) role.

The storage space usage information provided is the amount (in bytes) currently consumed by Covata users (i.e. with the Originator role) in the organization.

The information returned by this API endpoint is utilized on the [Organization Administration dashboard](/3.3/admin-org/accessing-organisation-administration#the-organisation-administration-dashboard).

## Supported roles and conditions <a id="access-service-api-v1-organisations-orggroupid-statistics-items-storage-supported-roles-and-conditions" />

This API endpoint supports the following Covata user [roles](/3.3/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organization Administrator's Guide](/3.3/admin-org)):

- [Organization administrator](/3.3/admin-org/administering-users-within-an-organisation#organisation-administrator-role) - when this user is a member of the organization whose ID is specified by `{orgGroupId}` in the request's URL.

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-organisations-orggroupid-statistics-items-storage#access-service-api-v1-organisations-orggroupid-statistics-items-storage-required-headers) of requests to this endpoint.

## Returns <a id="access-service-api-v1-organisations-orggroupid-statistics-items-storage-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.

For successful requests only, a JSON-formatted response containing the following members is also returned:

- **organisationQuota** - The amount of storage space (in [MiB](http://physics.nist.gov/cuu/Units/binary.html)) currently allocated to the organization (specified by `{orgGroupId}` in the request's URL).
- **objectStorageRequired** - The amount of storage space required for Covata users (also in MiB), which is based on the sum of all [quotas](/3.3/admin-org/managing-users-storage-quotas-through-plans) associated with all users in the organization (specified by `orgGroupId`) who have the [Originator](/3.3/admin-org/administering-users-within-an-organisation#originator-role) role.
- **objectStorageUsed** - The amount of storage space (in bytes) currently consumed by Covata users (i.e. with the Originator role) in the organization (specified by `orgGroupId`). <br />
  **Example (response):**

  ```json
  {
      "organisationQuota": "4194304",
      "objectStorageRequired": "10240",
      "objectStorageUsed": "67026768"
  }
  ```
