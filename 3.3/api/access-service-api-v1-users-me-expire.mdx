## URL structure <a id="access-service-api-v1-users-me-expire-url-structure" />

```text
https://access-service.xy-company.com/api/v1/users/me/expire
```

## Supported methods and overview <a id="access-service-api-v1-users-me-expire-supported-methods-and-overview" />

- `PUT` - used to [invalidate all valid refresh tokens](/3.3/user/managing-your-account#terminating-your-user-accounts-sessions) associated with the [Covata user](/3.3/api/authentication-and-authorisation) whose [access token is submitted in the request](/3.3/api/access-service-api-v1-users-me-expire#access-service-api-v1-users-me-expire-supported-roles) to this endpoint.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-users-me-expire-detailed-description" />

This API endpoint invalidates all valid refresh tokens associated with the Covata user whose access token is submitted in the request to this endpoint.

If this request succeeds, all valid refresh tokens associated with this Covata user are invalidated. Every other active session this Covata user has with the Covata Platform will terminate once these sessions' access tokens expire.

Passing any invalidated access token in the header of requests to any Covata API endpoint will cause these requests to fail.

## Supported roles <a id="access-service-api-v1-users-me-expire-supported-roles" />

This API endpoint supports requests utilizing Covata user accounts with the following roles (as described in the [Safe Share Administrator's](/3.3/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) and [Organization Administrator's](/3.3/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) Guides):

- [Originator](/3.3/admin-org/administering-users-within-an-organisation#originator-role)
- [Collaborator](/3.3/admin-org/administering-users-within-an-organisation#collaborator-role)
- [Ad hoc](/3.3/admin-org/administering-users-within-an-organisation#adhoc-role)
- [Safe Share administrator](/3.3/admin-platform/administering-platform-administrator-users#platform-administrator-role)
- [Organization administrator](/3.3/admin-org/administering-users-within-an-organisation#organisation-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-users-me-expire#access-service-api-v1-users-me-expire-required-headers) of requests to this endpoint.
