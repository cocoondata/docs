## URL structure <a id="access-service-api-v1-organisations-orggroupid-objects-objectid-enable-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{orgGroupId}/objects/{objectId}/enable
```

where `{orgGroupId}` is the ID of an organization and `{objectId}` is the ID of a file object/Secure Object created within this organization.

## Supported methods and overview <a id="access-service-api-v1-organisations-orggroupid-objects-objectid-enable-supported-methods-and-overview" />

- `PUT` - used to [disable or (re-)enable](/3.3/admin-org/administering-files#disabling-or-re-enabling-a-file) a file object/[Secure Object](/3.3/api/working-with-files-and-folders-fundamentals#secure-object) (specified by `objectId`) within an organization (specified by `orgGroupId`).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-orggroupid-objects-objectid-enable-detailed-description" />

This API endpoint disables or (re-)enables a single file object (specified by `objectId`) within an organization (specified by `orgGroupId`).

Calling this endpoint on a given file object successively toggles between disabling or (re-)enabling this file object.

A file object's ID can be obtained using the [&lt;access-service&gt;/api/v1/organisations/\{orgGroupId\}/objects](/3.3/api/access-service-api-v1-organisations-orggroupid-objects) API endpoint, which retrieves a list of high-level information associated with file objects that can be filtered using a variety of search criteria.

## Supported roles and conditions <a id="access-service-api-v1-organisations-orggroupid-objects-objectid-enable-supported-roles-and-conditions" />

This API endpoint supports the following Covata user [roles](/3.3/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organization Administrator's Guide](/3.3/admin-org)):

- [Organization administrator](/3.3/admin-org/administering-users-within-an-organisation#organisation-administrator-role) - when this user is a member of the organization whose ID is specified by `{orgGroupId}` in the request's URL.

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-organisations-orggroupid-objects-objectid-enable#access-service-api-v1-organisations-orggroupid-objects-objectid-enable-required-headers) of requests to this endpoint.
