## URL structure <a id="access-service-api-v1-i18n-bundles-localecode-download-url-structure" />

```text
https://access-service.xy-company.com/api/v1/i18n/bundles/{localeCode}/download
```

where `{localeCode}` is a supported locale code.

## Supported methods and overview <a id="access-service-api-v1-i18n-bundles-localecode-download-supported-methods-and-overview" />

- `GET` - use to download the contents of an internationalization (i18n) bundle (specified by `{localCode}`) as key/value pairs in [JSON format](http://json.org/).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-i18n-bundles-localecode-download-detailed-description" />

This API endpoint downloads the contents of an i18n bundle (specified by `{localCode}`) as key/value pairs in JSON format.

## Supported roles <a id="access-service-api-v1-i18n-bundles-localecode-download-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.3/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.3/admin-platform)):

- [Safe Share administrator](/3.3/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-i18n-bundles-localecode-download#access-service-api-v1-i18n-bundles-localecode-download-required-headers) of requests to this endpoint.
