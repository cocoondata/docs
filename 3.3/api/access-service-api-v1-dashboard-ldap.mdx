## URL structure <a id="access-service-api-v1-dashboard-ldap-url-structure" />

```text
https://access-service.xy-company.com/api/v1/dashboard/ldap
```

## Supported methods and overview <a id="access-service-api-v1-dashboard-ldap-supported-methods-and-overview" />

- `GET` - used to retrieve the total number of currently enabled [LDAP connections](/3.3/admin-platform/configuring-ldap) on the Covata Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-dashboard-ldap-detailed-description" />

This API endpoint retrieves the total number of currently enabled LDAP connections on the Covata Platform.

This information is utilized on the [Safe Share Administration dashboard](/3.3/admin-platform/accessing-platform-administration#the-platform-administration-dashboard).

## Supported roles <a id="access-service-api-v1-dashboard-ldap-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.3/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.3/admin-platform/index)):

- [Safe Share administrator](/3.3/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-dashboard-ldap#access-service-api-v1-dashboard-ldap-required-headers) of requests to this endpoint.

## Returns <a id="access-service-api-v1-dashboard-ldap-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.

For successful requests only, a JSON-formatted response containing the following members is also returned:

- **totalLdapConnections** - The total number of currently enabled LDAP connections on the Covata Platform. Any LDAP connections which have already been configured on the Covata Platform but are disabled are not represented in this total. <br />
  **Example (response):**

  ```json
  {
      "totalLdapConnections": 1
  }
  ```
