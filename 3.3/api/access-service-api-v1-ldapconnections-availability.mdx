## Supported methods and overview <a id="access-service-api-v1-ldapconnections-availability-supported-methods-and-overview" />

- `POST` - used to verify the connection to an [LDAP user directory](/3.3/admin-platform/configuring-ldap).

## Detailed description <a id="access-service-api-v1-ldapconnections-availability-detailed-description" />

This API endpoint verifies the connection to an LDAP user directory.

With this request, a [core subset of LDAP connection parameters](/3.3/api/access-service-api-v1-ldapconnections-availability#access-service-api-v1-ldapconnections-availability-required-parameters) must be submitted, which includes the:

- address of the server running LDAP (along with the connection timeout duration),
- LDAP user directory's manager credentials (to perform LDAP authentication and synchronization),
- root node in LDAP from which the Covata Platform finds users and groups and
- LDAP field against which the Covata Platform matches the email address of a Covata user when they authenticate.

## Supported roles <a id="access-service-api-v1-ldapconnections-availability-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.3/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.3/admin-platform/index)):

- [Safe Share administrator](/3.3/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-ldapconnections-availability#access-service-api-v1-ldapconnections-availability-required-headers) of requests to this endpoint.
