## URL structure <a id="access-service-api-v1-organisations-orgid-groups-groupid-labels-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{orgId}/groups/{groupId}/labels
```

where `{orgId}` is the ID of an organization and `{groupId}` is the ID of one of this organization's groups.

## Supported methods and overview <a id="access-service-api-v1-organisations-orgid-groups-groupid-labels-supported-methods-and-overview" />

- `GET` - used to retrieve a list of information for all [classifications](/3.3/admin-org/managing-classifications) that are currently associated with a [group](/3.3/admin-org/managing-groups) (specified by `groupId`) in an organization (specified by `orgId`).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-orgid-groups-groupid-labels-detailed-description" />

This API endpoint retrieves a list of information for all classifications that are currently associated with a group (specified by `groupId`) in an organization (specified by `orgId`).

A group's ID can be obtained by calling the `GET` method of the [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/groups](/3.3/api/access-service-api-v1-organisations-orgid-groups) API endpoint, which retrieves a list of information for all groups in the organization (specified by `orgId`).

## Supported roles and conditions <a id="access-service-api-v1-organisations-groups-groupid-labels-supported-roles-and-conditions" />

This API endpoint supports requests utilizing Covata user accounts with the following [roles](/3.3/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organization Administrator's Guide](/3.3/admin-org)) and conditions:

- [Organization administrator](/3.3/admin-org/administering-users-within-an-organisation#organisation-administrator-role) - if this user is a member of the organization specified by `{orgId}` in the request's URL.

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token submitted in the [header](/3.3/api/access-service-api-v1-organisations-orgid-groups-groupid-labels#access-service-api-v1-organisations-orgid-groups-groupid-labels-required-headers) of requests to this endpoint.
