---
title: "User whitelist endpoints"
---

The endpoints in this section are used for handling an organization's user whitelists on the Covata Platform.

- [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/userwhitelist](/3.3/api/access-service-api-v1-organisations-orgid-userwhitelist)
- [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/userwhitelist/\{whitelistId\}](/3.3/api/access-service-api-v1-organisations-orgid-userwhitelist-whitelistid)
- [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/userwhitelist/check](/3.3/api/access-service-api-v1-organisations-orgid-userwhitelist-check)

The following user whitelist handling endpoints are deprecated:

- [&lt;access-service&gt;/api/v1/userwhitelist/\{objectId\}](/3.3/api/access-service-api-v1-userwhitelist-objectid) ( *Deprecated* )
- [&lt;access-service&gt;/api/v1/userwhitelist/bulk](/3.3/api/access-service-api-v1-userwhitelist-bulk) ( *Deprecated* )
