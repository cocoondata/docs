## Start von Safe Share for Windows <a id="starting-the-application" />

Safe Share for Windows startet automatisch, wenn Windows (neu) startet.

- Wenn Safe Share for Windows ausgeführt wird, erscheint das Symbol für die Anwendung im Infobereich der Taskleiste (entweder
  ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   oder

  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   ).

Nach dem Start fordert Safe Share for Windows Sie eventuell automatisch zur Anmeldung mit Ihrem Covata-Benutzer-Account auf, indem die Anwendung das [Dialogfeld „Anmeldung“](/3.3/de/windows/starting-the-application-and-signing-in#sign-in-dialog-box) öffnet, das normalerweise angezeigt wird, wenn Sie sich noch nie bei der Anwendung angemeldet oder Sie sich von einer früheren Sitzung mit Safe Share for Windows abgemeldet haben. Wenn Sie sich nicht von einer früheren Sitzung mit Safe Share for Windows [abgemeldet haben](/3.3/de/windows/starting-the-application-and-signing-in#signing-out), erhält Safe Share for Windows Ihre Sitzung aufrecht, wenn die Anwendung neu gestartet wird (und Sie müssen sich nicht nochmals anmelden).

Wenn Sie sich anmelden müssen, aber das Dialogfeld „Anmeldung“ nicht angezeigt wird, können Sie sich immer [manuell anmelden](/3.3/de/windows/starting-the-application-and-signing-in#signing-in-manually), um auf dieses Dialogfeld zuzugreifen.

Wenn Sie [Safe Share for Windows verlassen](/3.3/de/windows/starting-the-application-and-signing-in#exiting-the-application) oder die Anwendung nicht startet, nachdem Windows (neu) startet, können Sie Safe Share for Windows manuell starten.

<a id="starting-the-application-manually" />**Manueller Start von Safe Share for Windows:**

- Doppelklicken Sie auf das Symbol **Covata Safe Share** auf dem Desktop oder wählen Sie **Covata Safe Share** aus dem Windows-Startmenü. Wenn die Anwendung ausgeführt wird, erscheint ihr Symbol im Infobereich der Taskleiste (entweder
  ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   oder

  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   ).

## Manuelle Anmeldung <a id="signing-in-manually" />

Das Symbol Safe Share for Windows im Infobereich der Windows-Taskleiste zeigt Folgendes:

- ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   (d. h. ein graues Safe Share-Symbol mit einem roten **x**), wenn Sie bei der Anwendung *noch nicht* angemeldet sind
- ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   wenn Sie *bereits* angemeldet sind

Sobald Sie angemeldet sind, werden alle von Covata gesicherten, mit Ihrem Covata-Benutzer-Account verknüpften Dateien und Ordner im (von der Covata-Plattform verwalteten) Remotespeicher mit dem Dateisystem Ihres Computers synchronisiert und stehen lokal über den Windows Explorer zur Verfügung.

**Manuelle Anmeldung bei Safe Share for Windows:**

1. Vergewissern Sie sich, dass Safe Share for Windows [gestartet](/3.3/de/windows/starting-the-application-and-signing-in#starting-the-application) wurde.
2. Klicken Sie auf das Symbol
   ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

    der Anwendung im Infobereich der Taskleiste, um den *Anwendungsbereich* von Safe Share for Windows zu öffnen (der rechts unten auf dem Bilschirm erscheint). Klicken Sie dann auf den Link **Anmelden** in diesem Bereich:

   ![Anmeldung](/images/e5a470fdb5b0-application-pane-signed-out.png)

   <br />
   **Tipp:** Klicken Sie alternativ mit der rechten Maustaste auf das Symbol

   ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

    der Anwendung im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Anmelden**:

   ![Anmeldung](/images/5e5a9a69d7e1-taskbar-popup-menu-signed-out.png)
3. <a id="sign-in-dialog-box" />Geben Sie im Dialogfeld **Anmeldung - Safe Share** in den entsprechenden Feldern die **E-Mail-Adresse** und das **Passwort** für Ihren Covata-Benutzer-Account ein:

   ![Dialogfeld Anmeldung](/images/5d38b23dbcbb-signin-dialog-box.png)

   <br />
   **Hinweise:**

   - Das Feld **E-Mail-Adresse** wird automatisch mit der E -Mail-Adresse des letzten Covata-Benutzer-Accounts aufgefüllt, der sich bei Safe Share for Windows angemeldet hat.
   - Wenn Sie Ihr Passwort vergessen haben, lassen Sie das Feld **Passwort** leer, klicken Sie auf den Link **Passwort vergessen?** und folgen Sie den Anweisungen auf der nächsten Seite und anschließend in Ihrer E-Mail-Benachrichtigung, um Ihr Passwort zurückzusetzen.
4. Klicken Sie auf die Schaltfläche **ANMELDEN** (oder drücken Sie die Eingabe-/Return-Taste).

   - Wenn Sie im Dialogfeld **Anmeldung - Safe Share** aufgefordert werden, Ihren **Authentifizierungscode** einzugeben, haben entweder Sie selbst für Ihren Covata-Benutzer-Account (über die Funktion [Account-Management](/3.3/de/windows/managing-your-account)) Zwei-Faktor-Authentifizierung (2FA) konfiguriert oder mindestens einer Ihrer Safe Share -Organisations-Administratoren verlangt diese Funktion für Ihren Account.

     ![Safe Share 2FA-Authentifizierungscode](/images/ae353813e1a2-2fa-authentication-code.png)

     1. Wenn Sie für Ihren Covata-Benutzer-Account noch kein Mobilgerät für 2FA konfiguriert haben, lesen Sie die Hinweise zur [Konfiguration eines Mobilgeräts für Zwei-Faktor-Authentifizierung](/3.3/de/windows/starting-the-application-and-signing-in#configuring-a-mobile-device-for-two-factor-authentication) unten, ehe Sie den Vorgang fortsetzen.
     2. <a id="entering-your-authentication-code" />Öffnen Sie auf Ihrem Mobilgerät die Authentifizierungs-Anwendung.
     3. Geben Sie im Feld **Authentifizierungscode** den Code ein, den die Authentifizierungs-Anwendung für Ihren Covata-Benutzer-Account erzeugt hat.
     4. Klicken Sie auf die Schaltfläche **Authentifizieren**, um die Authentifizierung abzuschließen.

   Zur Bestätigung, dass Sie bei Safe Share for Windows angemeldet sind, wird nach Ihrer Anmeldung automatisch der Anwendungsbereich mit der E-Mail-Adresse Ihres Covata-Benutzer-Accounts oben angezeigt, und das Symbol der Anwendung im Infobereich der Taskleiste schaltet um auf

   ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

    .

   ![Überprüfung Ihres Anmeldestatus](/images/94fb0f60f5d3-application-pane-signed-in.png)

   <br />
   **Tipps:**

   - Wenn der Anwendungsbereich nicht angezeigt wird, klicken Sie auf das Symbol
     ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

      um darauf zuzugreifen.
   - Alternativ können Sie prüfen, ob Sie angemeldet sind, indem Sie mit der rechten Maustaste auf das Symbol
     ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

      klicken und die Anzeige im Popup-Menü lesen:

     - *„Sie sind als Ihre@email.adresse“* angemeldet oder
     - *„Sie sind nicht angemeldet“*
   - Sie können jederzeit, wenn Safe Share for Windows ausgeführt wird und Sie im Infobereich der Taskleiste mit der rechten Maustaste auf das Symbol
     ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

      oder

     ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

      der Anwendung klicken, aber der Anwendungsbereich nicht angezeigt wird, auf diesen Bereich schnell zugreifen, indem Sie im Popup-Menü **Erweitern** auswählen, z. B.

     ![Anmeldung](/images/e24b9c6e08e5-taskbar-popup-menu-signed-in.png)

<Note>

- Bei der ersten Anmeldung bei Safe Share for Windows nach der [Installation](/3.3/de/windows/installing-and-upgrading-the-application#installing) oder [Aktualisierung](/3.3/de/windows/installing-and-upgrading-the-application#upgrading) der Anwendung wird die Webseite **Herzlich willkommen bei Safe Share for Windows** angezeigt, auf der Sie eine Kurzanleitung zu den wichtigsten Funktionen finden.
- Wenn Sie sich bei Safe Share for Windows zum ersten Mal oder mit einem anderen Covata-Benutzer-Account als zuvor angemeldet haben, werden die folgenden [Safe Share-Ordner](/3.3/de/windows/uploading-storing-and-sharing-content-securely#accessing-the-applications-folder) im „Safe Share“-Ordner (der sich im Windows-Basisordner befindet) (neu) angelegt:

  - `Meine sicheren Dateien`
  - `Mir freigegeben`
- Erscheint der Ordner „Meine sicheren Dateien“ nicht, verfügt Ihr Account nicht über die **Ersteller**-Rolle. Diese Rolle kann Ihrem Account für Ihre jeweilige(n) Organisation(en) von Ihrem/Ihren Organisations-Administrator(en) zugeteilt werden.
- Bei jeder Anmeldung bei Safe Share for Windows als anderer Covata-Benutzer (am selben Computer) werden die Ordner „Meine sicheren Dateien“ und „Mir freigegeben“ des vorherigen Covata-Benutzers in den Papierkorb verschoben und die Inhalte der neu erstellten Ordner „Meine sicheren Dateien“ und „Mir freigegeben“ mit den jeweiligen Elementen des neuen Covata-Benutzers im Remotespeicher aktualisiert.
- Safe Share for Windows beginnt sofort nach Ihrer Anmeldung mit der Synchronisierung der Dateien und Ordner im Remotespeicher (Ihres Covata-Benutzer-Accounts, auf den über [Safe Share for Web](/3.3/de/user) zugegriffen werden kann) mit den Dateien und Ordnern in den Ordnern „Meine sicheren Dateien“ und „Mir freigegeben“. Die Inhalte der *von Covata gesicherten Dateien* innerhalb dieser Ordner werden mit einer Größe von 1 KB (oder weniger) und der Erweiterung „.covl“ angezeigt. Wenn die verschlüsselten Inhalte einer Datei jedoch anfänglich (vor der lokalen Entschlüsselung) heruntergeladen oder lokal vor dem Upload verschlüsselt werden, kann auch ein Exemplar der Datei mit der Erweiterung „.cov“ vorhanden sein. Diese Datei beinhaltet die lokal verschlüsselten Daten der Datei. Safe Share for Windows löscht solche Dateien jedoch automatisch, sobald der Download- bzw. Upload-Vorgang abgeschlossen ist.
- Verknüpfungen zum Unterordner „Meine sicheren Dateien“ (oben) sowie zum Start der Anwendung Safe Share for Windows selbst (d. h. *Covata Safe Share* werden auf Ihrem Desktop automatisch angelegt. Beachten Sie, dass die Verknüpfung „Meine sicheren Dateien“ nicht angelegt wird, wenn Sie ursprünglich als Covata-Benutzer ohne **Ersteller**-Rolle angemeldet waren.

</Note>

## Konfiguration eines Mobilgeräts für Zwei-Faktor-Authentifizierung <a id="configuring-a-mobile-device-for-two-factor-authentication" />

Wenn Sie oder einer Ihrer Organisations-Administratoren für Ihren Covata-Benutzer-Account Zwei-Faktor-Authentifizierung (2FA) konfiguriert hat, benötigen Sie ein Mobilgerät (d. h. ein Android- oder Microsoft Windows-basiertes Handy, ein iPhone, iPad oder iPod Touch), auf dem eine Authentifizierungsanwendung von Google oder Microsoft ausgeführt wird, um sich bei Safe Share for Windows anmelden zu können.

Die Authentifizierungsanwendung (Authenticator-App) auf Ihrem Mobilgerät erzeugt den zweiten Authentifizierungsfaktor für Ihren Account. Ihr Passwort ist Ihr erster Authentifizierungsfaktor.

**Konfiguration Ihres Mobilgeräts für 2FA Ihres Covata-Benutzer-Accounts:**

1. Öffnen Sie die E-Mail-Benachrichtigung von Covata mit dem Betreff „*Für Ihren Account wurde Zwei-Faktor-Authentifizierung aktiviert*“.
2. Befolgen Sie die Anweisungen in dieser E-Mail-Benachrichtigung, d. h. klicken Sie auf den Link, um die Konfigurationsseiten für Zwei-Faktor-Authentifizierung zu öffnen. <br />
    Befolgen Sie die weiteren Anweisungen auf diesen Seiten, um die Konfiguration Ihres Mobilgeräts abzuschließen. Geben Sie anschließend Ihren Authentifizierungscode (aus dem zweiten Schritt des [oben beschriebenen 2FA-Authentifizierungsverfahrens](/3.3/de/windows/starting-the-application-and-signing-in#entering-your-authentication-code) ein, um sich bei Safe Share for Windows anzumelden.

## Zugriff auf die Webanwendung <a id="accessing-the-web-application" />

Safe Share for Windows gibt Ihnen einfachen Zugriff auf [Safe Share for Web](/3.3/de/user), um eine möglichst gute Integration zwischen diesen beiden Produkten zu erzielen.

**Zugriff auf Safe Share for Web:**

1. Vergewissern Sie sich, dass Safe Share for Windows [gestartet](/3.3/de/windows/starting-the-application-and-signing-in#starting-the-application) wurde und Sie angemeldet sind.
2. Klicken Sie auf das Symbol
   ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

    der Anwendung im Infobereich der Taskleiste und anschließend auf das Symbol 'Safe Share Web'

   ![Safe Share Web öffnen](/images/1eaf20dfc4f4-application-pane-safe-share-web-icon.png)

    rechts unten im Anwendungsbereich:

   ![Öffnen der Webanwendung](/images/94fb0f60f5d3-application-pane-signed-in.png)

   <br />
    Nach der [Anmeldung](/3.3/de/user/signing-in) bei der Webanwendung (falls erforderlich) wird die Hauptseite für Safe Share von Safe Share for Web in Ihrem (in Windows konfigurierten) Standard-Webbrowser geöffnet.

<Note>

**Hinweise zur Nutzung dieser Funktion:**

- [Safe Share for Web](/3.3/de/user) ergänzt Safe Share for Windows. Zum Beispiel:

  - Safe Share for Web ermöglicht Ihnen die [Verwaltung Ihres Covata-Benutzer-Accounts](/3.3/de/windows/managing-your-account) über Safe Share for Windows und gibt Ihnen Zugriff auf bestimmte Informationsfunktionen für Dateien bzw. Ordner dieser Webanwendung, die über den Windows Explorer nicht verfügbar sind.
  - Microsoft gibt für die Datei- und Pfadlänge eine Obergrenze von 260 Zeichen vor. Wenn Sie daher in einer mehrfach vernesteten Ordnerhierarchie mit sicheren Inhalten arbeiten möchten, können Sie über Safe Share for Web auf solche Inhalte zugreifen.
- Wenn Sie vor dem Zugriff auf diese Funktion noch nicht angemeldet sind, wird die Anmeldeseite von Safe Share angezeigt. Beachten Sie jedoch, dass die Anmeldung über diese Seite und die Anmeldung bei Safe Share for Windows zwei unabhängige Abläufe sind, die voneinander unabhängige Sitzungen einleiten.
- Ihre Installation von Safe Share for Windows wurde eventuell (wahrscheinlich von einem Systemadministrator) so konfiguriert, dass das *Fenster Safe Share Web* geöffnet wird. Dieser integrierte Webbrowser ist im Wesentlichen eine Version von Safe Share for Web mit eingeschränkten Funktionen. Zum Beispiel:

  - Die **Download**-Funktion wird im Safe Share-Web-Fenster nicht unterstützt. Diese Funktion wird nur nativ unterstützt (d. h. mit einem kompatiblen Webbrowser), über [Safe Share for Web](/3.3/de/user).
  - Bei Verwendung des Safe Share Web-Fensters ist keine seitenweise Navigation vor oder zurück möglich. Sie können nur anhand der eigenen Navigationsfunktionen von Safe Share for Web navigieren.

</Note>

## Abmeldung <a id="signing-out" />

**Optionen für die Abmeldung von Safe Share for Windows:**

- Klicken Sie mit der rechten Maustaste auf das Symbol
  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   der Anwendung im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Abmelden**:

  ![Abmeldung](/images/e24b9c6e08e5-taskbar-popup-menu-signed-in.png)

  <br />
- Klicken Sie auf das Symbol
  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   der Anwendung im Infobereich der Taskleiste. Klicken Sie dann auf das Symbol Einstellungen

  ![Symbol Anwendungsbereich-Einstellungen](/images/5d9feb547c51-application-pane-settings-icon.png)

   rechts oben im Anwendungsbereich ... :

  ![Zugriff auf das Symbol Anwendungsbereich-Einstellungen](/images/94fb0f60f5d3-application-pane-signed-in.png)

  <br />
   und wählen Sie aus dem Popup-Menü dieses Symbols **Abmelden**.

<Note>

Nach Ihrer Abmeldung von Safe Share for Windows werden Dateien und Ordner in den Unterordnern „Meine sicheren Dateien“ und „Mir freigegeben“ im „Safe Share“-Ordner auf Ihrem Computer nicht mehr mit Elementen im von der Covata-Plattform verwalteten Remotespeicher synchronisiert.

</Note>

## Beenden von Safe Share for Windows <a id="exiting-the-application" />

Sie können Safe Share for Windows unabhängig davon beenden, ob Sie aktuell [bei der Anwendung angemeldet sind](/3.3/de/windows/starting-the-application-and-signing-in#signing-in-manually) oder nicht.

**Optionen für das Beenden von Safe Share for Windows:**

- Klicken Sie mit der rechten Maustaste auf das Symbol
  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   oder

  ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   der Anwendung im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Safe Share beenden**:

  ![Beenden von Safe Share](/images/5e5a9a69d7e1-taskbar-popup-menu-signed-out.png)

  <br />
- Klicken Sie auf das Symbol
  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   oder

  ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   der Anwendung im Infobereich der Taskleiste. Klicken Sie dann auf das Symbol Einstellungen

  ![Symbol Anwendungsbereich-Einstellungen](/images/5d9feb547c51-application-pane-settings-icon.png)

   rechts oben im Anwendungsbereich ... :

  ![Zugriff auf das Symbol Anwendungsbereich-Einstellungen](/images/e5a470fdb5b0-application-pane-signed-out.png)

  <br />
   und wählen Sie aus dem Popup-Menü dieses Symbols **Safe Share beenden**.

<Note>

Um sich wieder bei Safe Share for Windows anzumelden, [starten Sie die Anwendung erneut](/3.3/de/windows/starting-the-application-and-signing-in#starting-the-application) und [melden Sie sich manuell an](/3.3/de/windows/starting-the-application-and-signing-in#signing-in-manually), wenn Sie nicht automatisch angemeldet werden.

</Note>
