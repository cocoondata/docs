---
title: "Design der webbasierten Schnittstellen von Safe Share"
---

Designs ermöglichen die benutzerdefinierte Anpassung der innerhalb der Benutzeroberfläche von [Safe Share for Web](/3.3/de/user/index) verwendeten Farbkonzepte und Logos für individuelle [Organisationen](/3.3/de/user/index#organisations), sodass jede einzelne Organisation ihr jeweiliges Design erhält. (Für weitere Informationen über das Hinzufügen/die Konfiguration von Organisationen über die [Safe Share-Verwaltung](/3.3/de/admin-platform/index#platform-administration)siehe [Verwaltung von Organisationen](/3.3/de/admin-platform/administering-organisations).)

In dieser Version von Safe Share und der Covata-Plattform werden Designs anhand eines separaten Tools erstellt (des [Covata/WebApp Design-Builders](https://www.npmjs.com/package/covata-theme-builder)), das von Covata entwickelt wird und als lokal ausführbares [npm-Paket](https://www.npmjs.com/) verfügbar ist.

Diese benutzerdefinierten Anpassungen der Farbkonzepte und Logos werden auch auf den folgenden Oberflächen verwendet:

- [Organisationsverwaltung](/3.3/de/admin-platform/organisation-administration),
- [Safe Share-Verwaltung](/3.3/de/admin-platform/index#platform-administration) sowie
- in von der Covata-Plattform gesendeten E-Mail-Benachrichtigungen

Neu installierte Instanzen von Safe Share beinhalten das *Covata-Standarddesign*. Dieses Design wird zunächst für die Oberflächen von Safe Share for Web und der Organisationsverwaltung aller Organisationen, in E-Mail-Benachrichtigungen sowie für die Oberfläche der Safe Share-Verwaltung verwendet.

Mit dem WebApp Design-Builder können Sie für verschiedene Organisationen jeweils unterschiedliche Designs sowie Ihr eigenes Standarddesign (das so genannte „Systemdesign“) erstellen. Letzteres wird für Folgendes verwendet:

- alle Organisationen, für die kein Design definiert ist
- die Oberfläche der Safe Share-Verwaltung und
- die Funktion [Mein Account](/3.3/de/user/managing-your-account)

Besuchen Sie die Seite [covata-theme-builder](https://www.npmjs.com/package/covata-theme-builder) (auf der npm-Website nur in englischer Sprache verfügbar) für weitere Informationen, wie Sie den WebApp Design-Builder bekommen und nutzen und Designs auf einer Instanz der Covata-Plattform bereitstellen.

<Note>

Weitere Aspekte von Safe Share, die Sie benutzerdefiniert anpassen können, z. B. den Anwendungsnamen, die Firma und den Urheberrechtsvermerk in E-Mail-Benachrichtigungen, können anhand des Abschnitts [Eigenschaften der Systemdetails](/3.3/de/admin-platform/configuring-platform-administration-properties#system-details-properties) auf der **Konfigurations**-[Seite](/3.3/de/admin-platform/configuring-platform-administration-properties) der Safe Share-Verwaltung konfiguriert werden. Die Firma kann jedoch für die einzelnen Organisationen anhand der jeweiligen **Konfigurations**-[Seite](/3.3/de/admin-platform/configuring-organisation-administration-properties) der Organisationsverwaltung benutzerdefiniert angepasst werden.

</Note>

<Note>

Das Design von E-Mail-Benachrichtigungen richtet sich nach dem Safe Share-“Bereich“, auf den sich der Inhalt der Benachrichtigung bezieht. <br />
 Für E-Mail-Benachrichtigungen über verschiedene Aktivitäten gilt z. B. jeweils Folgendes:

- Für über die Safe Share-Verwaltung ausgeführte Aktivitäten, z. B. das Hinzufügen eines Safe Share-Administratoren-Accounts, wird das Systemdesign verwendet.
- Für über die Organisationsverwaltung ausgeführte Aktivitäten, z. B. das Entfernen eines Covata-Benutzer-Accounts von einer Organisation, wird das Organisationsdesign verwendet. <sup>&#42;</sup>
- Für über eine beliebige Safe Share-Anwendung ausgeführte Aktivitäten, z. B. die Freigabe eines Elements an eine andere Person, wird das Design der Standardorganisation des Empfängers verwendet. <sup>&#42;</sup> Dieses Prinzip gilt auch für auf der Covata-Plattform noch nicht registrierte Personen (d. h. Personen, deren Accounts erstellt und einer Organisation hinzugefügt werden, wenn ihnen ein vorhandener Covata-Benutzer in der betreffenden Organisation ein Element freigibt).

<sup>&#42;</sup> Wenn für eine Organisation kein Design definiert ist, wird für solche Benachrichtigungen stattdessen das Systemdesign verwendet.

</Note>
