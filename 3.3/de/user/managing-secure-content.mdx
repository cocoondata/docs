## Suchen sicherer Inhalte <a id="finding-secure-content" />

Safe Share for Web stellt für die Suche nach Dateien und Ordnern in Ihrer Organisation die folgenden Mechanismen bereit:

- [Suche nach (einem) bestimmten Element(en)](/3.3/de/user/managing-secure-content#searching-for-items) nach ihrem Namen oder ihrem/ihren Besitzer(n) und/oder
- [Filtern von Elementen](/3.3/de/user/managing-secure-content#filtering-items) anhand der Elementefilter links oben auf der Safe Share-Hauptseite

Diese Funktionen lassen sich zwar nur mit Elementen innerhalb Ihrer aktuellen Organisation ausführen, aber sie sind besonders hilfreich, wenn Ihrer Organisation/Ihren Organisationen (von Ihnen selbst oder von anderen Personen) mehr und mehr Elemente hinzugefügt bzw. freigegeben werden.

<a id="searching-for-items" />**Suche nach (einem) spezifischen Element(en):**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.3/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.3/de/user/managing-secure-content#beginning-your-search) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.3/de/user/managing-secure-content#beginning-your-search), um anschließend ein Element dieser Organisation zu suchen, oder
   - Suche nach einem Element einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.3/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="beginning-your-search" />Suchfeld rechts oben auf der Safe Share-Hauptseite:

   ![Suchfeld](/images/4ec5904de8ab-search-box.png)

   <br />
    Geben Sie hier eine Zeichenfolge ein, die in einem der folgenden Felder des betreffenden Elements enthalten ist:

   - **Name**
   - E-Mail-Adresse des **Besitzers**
   - Vor- oder Familienname des **Besitzers**
4. Drücken Sie die Eingabe-/Return-Taste oder klicken Sie auf das Suchsymbol (Vergrößerungsglas) rechts neben dem Suchfeld, und die Elementeliste in Ihrer Organisation wird nach denjenigen Elementen gefiltert, deren Name, E-Mail-Adresse des Besitzers oder Vor- bzw. Familienname des Besitzers der im Suchfeld eingegebenen Zeichenfolge entspricht. <br />
   **Tipps:**

   - Klicken Sie auf den Link **Suche löschen** links oben auf der Safe Share-Hauptseite, um Ihre Suchergebnisse zu löschen.
   - Sie können Elemente auch auf der Safe Share-Hauptseite sortieren, indem Sie auf den Namen (d. h. den Spaltenkopf) des betreffenden Felds klicken, nach dem Sie Ihre Elemente sortieren möchten (außer das Feld **Speicherort**). Mehrfaches Anklicken eines Feldnamens schaltet zwischen einer Sortierung der Elemente in aufsteigender und absteigender Reihenfolge (gemäß dem betreffenden Feld), gefolgt von natürlicher Sortierung (d. h. in absteigender Reihenfolge nach dem Feld **Namen** des Elements) um.

<a id="filtering-items" />**Filtern von Elementen:**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.3/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.3/de/user/managing-secure-content#beginning-your-filtering) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.3/de/user/managing-secure-content#beginning-your-filtering), um anschließend Elemente dieser Organisation zu filtern, oder
   - Filtern von Elementen einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.3/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="beginning-your-filtering" />Klicken Sie auf das Dropdown-Menü **Alle Dateien**/Filter (links von der Symbolleiste am oberen Seitenrand) und wählen Sie hier eine der folgenden Optionen:

   - **Meine Dateien**, um innerhalb Ihrer Organisation nach allen Elementen (in/ab der Stammebene Ihres Elementebereichs) in Ihrem Besitz zu filtern,
   - **Mir freigegeben**, um nach allen Ihnen als Mitwirkenden [von anderen Personen freigegebenen Elementen](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) zu filtern oder
   - **Freigeben**, um innerhalb Ihrer Organisation nach allen Elementen zu filtern, die Sie [anderen Personen freigegeben haben](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content).
   - **Papierkorb**, um auf den [Papierkorb zuzugreifen](/3.3/de/user/managing-secure-content#accessing-the-recycle-bin), der alle Ihre in den Papierkorb verschobenen Elemente enthält.

   Wählen Sie die Standardoption **Alle Dateien**, um alle Elemente innerhalb Ihrer Organisation anzuzeigen, auf die Sie von der Stammebene aus Zugriff haben.

<Note>

- Wenn Ihrem Benutzer-Account für Ihre (aktuelle) Organisation nicht die **Ersteller**-Rolle zugewiesen ist, ist das Dropdown-Menü **Alle Dateien** (oder andere Filter) nicht verfügbar, da Sie innerhalb der betreffenden Organisation nicht über Ihren eigenen Speicher verfügen, in den/dem Sie Inhalte in Ihrem persönlichen Besitz mittels Safe Share [hochladen, sicher speichern](/3.3/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) und [freigeben](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) können.
- Wenn Sie Dateien [hochladen und speichern](/3.3/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content), während die Safe Share-Hauptseite die Ergebnisse einer [Suche](/3.3/de/user/managing-secure-content#searching-for-items) oder eines [Filtervorgangs](/3.3/de/user/managing-secure-content#filtering-items) (siehe oben) anzeigt, werden Ihre Dateien auf die Stammebene hochgeladen.

</Note>

## Organisation von Inhalten in Ordnern <a id="organising-content-with-folders" />

Zur besseren Organisation von Dateien in Ihrer Organisation in (von der Covata-Plattform verwaltetem) Speicher können Sie Ordner anlegen, die Ihnen auch die Möglichkeit geben, [mehrere Elemente Ihrer sicher gespeicherten Inhalte](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) an eine Gruppe von Personen freizugeben.

**Erstellen eines neuen Ordners:**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.3/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.3/de/user/managing-secure-content#navigating-to-a-subfolder) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.3/de/user/managing-secure-content#navigating-to-a-subfolder), um anschließend innerhalb dieser Organisation einen Ordner zu erstellen, oder
   - Erstellen eines Ordners in einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.3/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="navigating-to-a-subfolder" />Wenn Sie in einem Ordner (auf der Stammebene Ihres Elementebereichs) einen Unterordner anlegen möchten, klicken Sie von der Safe Share-Hauptseite aus zum betreffenden Ordner, innerhalb dessen der Unterordner erstellt werden soll. <br />
    Beim übergeordneten Ordner kann es sich um einen Ordner in Ihrem eigenen Besitz handeln oder um einen Ordner, an dem Sie Mitwirkender mit **Upload**-, **Änderungs**- oder **Verwaltungs**-[Berechtigung](/3.3/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) sind. Sobald Sie einen oder mehrere Ordnernamen durchgeklickt haben, wird am oberen Seitenrand ein Breadcrumb angezeigt (z. B.
   ![Breadcrumb](/images/435c751ef596-breadcrumb.png)

    ), in dem Sie Folgendes anklicken können:

   - den verknüpften Namen Ihrer aktuellen Organisation, um zum Stammverzeichnis Ihres Elementebereichs zu wechseln
   - das Auslassungszeichen („...“), um die gesamte Ordnerhierarchie zu erweitern (d. h. um den **Freigegebenen Ordner** im Beispiel oben anzuzeigen), da nach jeder Änderung des Speicherorts eines Ordners nur die Stammebene und die aktuellen Speicherorte des Ordners (d. h. **Sonstiges** im Beispiel oben) angezeigt werden
   - den Link zum Namen eines übergeordneten Ordners (d. h. **Freigegebener Ordner** in **Sonstiges** im Beispiel oben), um zum betreffenden Ordner zu wechseln
4. Klicken Sie auf die Schaltfläche **Ordner** links von der Symbolleiste am oberen Seitenrand. <br />
   **Hinweis:** Diese Schaltfläche ist unter den folgenden Bedingungen nicht verfügbar:

   - Ihrem Covata-Benutzer-Account ist für Ihre Organisation nicht die **Ersteller**-Rolle zugewiesen oder
   - Sie befinden sich aktuell im Ordner eines anderen Benutzers, für den Sie keine **Upload**-, **Änderungs**- oder **Verwaltungs**-Berechtigung haben (die Ihnen wiederum die individuelle Berechtigung zur *Erstellung neuer Unterordner* erteilt).
5. Geben Sie im Dialogfeld **Neuen Ordner erstellen** den Namen des Ordners an.
6. ( *Optional, nur für Benutzer, die unmittelbar Besitzer des zu erstellenden Ordners werden* ) Sie können jetzt diesen Ordner an einen oder mehrere Mitwirkende freigeben, indem Sie den Link **Mitwirkende hinzufügen** anklicken. Damit greifen Sie auf den Abschnitt **Mitwirkende** des Dialogfelds **Freigeben** zu, wo Sie diese Festlegungen direkt für das Dialogfeld **Neuen Ordner erstellen** treffen können (d. h. ohne separat das [Dialogfeld „Freigeben“ aufrufen zu müssen](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)). Befolgen Sie [Schritte 5 bis 8](/3.3/de/user/uploading-storing-and-sharing-content-securely#share-dialog-box) des Ablaufs [Freigabe sicherer Inhalte](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content), um Ihre Mitwirkenden und deren Berechtigungen in diesem Dialogfeld **Neuen Ordner erstellen** zu ändern. <br />
   **Hinweise:**

   - Wenn Sie im Ordner eines anderen Benutzers einen neuen Ordner erstellen, ist der Link **Mitwirkende hinzufügen** nicht verfügbar, unabhängig von den Berechtigungen, die Sie als Mitwirkender an diesem Ordner des anderen Benutzers haben. Wenn Sie daher an einem Ordner eines anderen Benutzers **Verwaltungs**-Berechtigung haben, erstellen Sie zunächst den neuen Unterordner und [geben Sie ihn anschließend in einem separaten Schritt frei](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content).
   - Die Liste der **Aktuellen Mitwirkenden**, die Sie im [Dialogfeld „Freigeben“](/3.3/de/user/uploading-storing-and-sharing-content-securely#share-dialog-box) sehen, erscheint im Dialogfeld **Neuen Ordner erstellen** nicht. Aufgrund der impliziten Übernahme von Mitwirkenden und deren Berechtigungen innerhalb einer Ordnerhierarchie haben alle vorhandenen Mitwirkenden des übergeordneten Ordners Zugriff auf den neu erstellten Ordner. Wenn Sie diese Mitwirkenden identifizieren möchten, gehen Sie daher eine Ordnerebene höher und wählen Sie im Elementebereich den übergeordneten Ordner, um seine vorhandenen Mitwirkenden im Abschnitt **Freigabe und Berechtigungen** im Register **Details** rechts zu identifizieren.
7. Klicken Sie auf **Speichern**, um den Ordner zu erstellen. Der Ordner wird im aktuellen Elementebereich innerhalb Ihrer Organisation erstellt (und sofort an alle im vorherigen, optionalen Schritt definierten Personen freigegeben).

**Hinzufügen von Inhalten zu einem Ordner:**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet](/3.3/de/user/signing-in) sind und sich innerhalb der [gewünschten Organisation](/3.3/de/user/uploading-storing-and-sharing-content-securely#changing-organisations) befinden. Klicken Sie gegebenenfalls zum Ordner durch, dem Sie Inhalte hinzufügen möchten. (Dabei muss es sich um einen Ordner in Ihrem eigenen Besitz handeln oder um einen Ordner, an dem Sie Mitwirkender mit **Upload**-, **Änderungs**- oder **Verwaltungs**-[Berechtigung](/3.3/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) sind.)
2. Sie haben die folgenden Optionen:

   - Wenn im Elementebereich die Inhalte des Ordners angezeigt werden, dem Sie Inhalte hinzufügen möchten, ziehen Sie eine oder mehrere Datei(en) in den Elementebereich und legen Sie diese dort ab. Über diesem Bereich erscheint eine Grafik mit der Meldung „*Dateien zum Upload hierher ziehen*“ (falls diese nicht bereits angezeigt wird). Dies zeigt an, dass die Datei(en) zum Upload in den Speicher bereit ist/sind.
   - Wird der gewünschte Ordner im Elementebereich angezeigt, ziehen Sie eine oder mehrere Datei(en) in den Ordner, dem die Datei(en) hinzugefügt werden soll(en). Der Ordner wird in einer anderen Farbe hervorgehoben um anzuzeigen, dass die Datei(en) diesem Ordner hinzugefügt und dort gespeichert wird/werden statt dem aktuellen Speicherort im Elementebereich.

   Aufgrund der *impliziten* Übernahme von Mitwirkenden und ihren Berechtigungen an Elementen innerhalb einer Ordnerhierarchie können Sie diese Drag-and-Drop-Verfahren auch verwenden, um Dateien beliebigen Unterordnern hinzuzufügen, bei denen Sie Mitwirkender mit **Upload**-, **Änderungs**- oder **Verwaltungs**-Berechtigung sind. Für weitere Informationen über den Upload von Inhalten in Ihren Elementebereich siehe [Schritt 3](/3.3/de/user/uploading-storing-and-sharing-content-securely#selecting-and-dragging-files) in [Upload und Speichern von Inhalten im persönlichen Besitz](/3.3/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) sowie [Upload von Inhalten zur Freigabe über den Ordner eines anderen Benutzers](/3.3/de/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder).

<a id="folder-tips" />

<Tip>

- Wenn Sie Mitwirkender eines [Ordners](/3.3/de/user/managing-secure-content#organising-content-with-folders) einer anderen Person sind und für diesen Ordner lediglich die **Anzeige**- oder **Download**-[Berechtigung](/3.3/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) besitzen, können Sie in den betreffenden Ordner keine Dateien hochladen. Für weitere Informationen siehe [Freigabe sicherer Inhalte](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) und [Upload von Inhalten zur Freigabe über den Ordner eines anderen Benutzers](/3.3/de/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder).
- Sie können die Liste Ihrer Dateien und Ordner im Elementebereich filtern, um nur *Ihre* Elemente anzeigen zu lassen, die Sie hochgeladen und sicher gespeichert haben. Vergewissern Sie sich hierzu, dass im Dropdown-Menü **Alle Dateien**/[Filter](/3.3/de/user/managing-secure-content#filtering-items) (links oben in der Symbolleiste am oberen Seitenrand) **Meine Dateien** gewählt ist.

</Tip>

## Aufhebung der Freigabe sicherer Inhalte <a id="unsharing-secure-content" />

Die „Aufhebung“ der Freigabe eines Elements, das Sie besitzen oder an dem Sie Mitwirkender (mit **Verwaltungs**-[Berechtigung](/3.3/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set)) sind, entfernt alle oder nur bestimmte Mitwirkende vom betreffenden Element und seinen Inhalten.

Wenn die Safe Share-Funktion **Freigabe aufheben** auf einen Ordner angewendet wird, werden nicht nur alle Mitwirkenden des betreffenden Ordners, sondern auch alle Mitwirkenden aller Elemente innerhalb dieses Ordners (die *explizit* für diese Elemente festgelegt wurden) entfernt. Für weitere Informationen zur *expliziten* bzw. *impliziten* Freigabe siehe den **Hinweis** am Ende von [Schritt 6](/3.3/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) zur Auswahl von Berechtigungen für einen Mitwirkenden (im Ablauf [Freigabe sicherer Inhalte](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)).

**Aufhebung der Freigabe Ihrer sicher gespeicherten Inhalte:**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.3/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.3/de/user/managing-secure-content#locating-the-item-to-unshare) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.3/de/user/managing-secure-content#locating-the-item-to-unshare), um anschließend die Freigabe eines Elements dieser Organisation aufzuheben, oder
   - Aufhebung der Freigabe eines Elements einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.3/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="locating-the-item-to-unshare" />Aufhebung der Freigabe der folgenden Elemente:

   - *Inhalte in Ihrem persönlichen Besitz*: [Suchen Sie](/3.3/de/user/managing-secure-content#finding-secure-content) die Datei oder den Ordner (in Ihrem Besitz) in Ihrer aktuellen Organisation, deren/dessen Freigabe Sie aufheben möchten. <br />
     **Tipp:** Um sicherzustellen, dass Sie nur mit Ihren eigenen Elementen im Elementebereich arbeiten, klicken Sie auf das Dropdown/Menü**Alle Dateien**/[Filter](/3.3/de/user/managing-secure-content#filtering-items) links oben in der Symbolleiste und vergewissern Sie sich, dass der [Filter](/3.3/de/user/managing-secure-content#filtering-items) **Meine Dateien** ausgewählt ist.
   - *Inhalte im Besitz eines anderen Covata-Benutzers*: Suchen Sie die Datei oder den Ordner des betreffenden Benutzers in Ihrer aktuellen Organisation, deren/dessen Freigabe Sie aufheben möchten. <br />
     **Tipp:** Um sicherzustellen, dass Sie nur mit Elementen arbeiten, die andere Benutzer Ihnen als Mitwirkenden freigegeben haben, klicken Sie auf das Dropdown-Menü **Alle Dateien**/[Filter](/3.3/de/user/managing-secure-content#filtering-items) oben in der Symbolleiste und vergewissern Sie sich, dass der Filter **Mir freigegeben** ausgewählt ist.
4. Führen Sie zur Aufhebung der Freigabe dieses Elements zunächst einen der folgenden Schritte aus:

   - Entfernen *aller* Mitwirkenden der Datei oder des Ordners (einschließlich aller im Ordner enthaltenen Elemente):

     - *Klicken Sie mit der rechten Maustaste auf die Zeile des Elements* und wählen Sie aus dem Popup-Menü **Freigabe aufheben**:

       ![Rechtsklick auf Datei als Besitzer - Kontextmenü](/images/3777f181713e-right-clicking-a-shared-file-context-menu-owner.png)

       <br />
       *ODER*

     1. Klicken Sie auf die Zeile des Elements (bei Ordnern rechts vom Namen), um es *auszuwählen*: <br />
        ![Auswahl eines freigegebenen Elements als Besitzer](/images/d1d611c702b9-selecting-a-shared-item-owner.png)
     2. Klicken Sie rechts in der Symbolleiste am oberen Seitenrand auf das Dropdown-Menü **Mehr** und wählen Sie **Freigabe aufheben**.
   - Zum Entfernen *bestimmter* Mitwirkender vom betreffenden Element:

     1. *Wählen Sie* das Element.
     2. Suchen Sie im Abschnitt **Freigabe und Berechtigungen** im Register **Details** rechts die Namen/E-Mail-Adressen der betreffenden Mitwirkenden und wählen Sie in den jeweiligen Dropdown-Menüs **Berechtigung** **Benutzer entfernen**.

     *ODER*

     1. *Klicken Sie mit der rechten Maustaste auf die Zeile des Elements* und wählen Sie aus dem Popup-Menü **Freigeben**.
     2. Klicken Sie im Dialogfeld **Freigeben** auf den Link **Entfernen** neben dem/den betreffenden Mitwirkenden, den/die Sie von diesem Element entfernen möchten.
     3. Klicken Sie auf **Aktualisieren**, um die in diesem Dialogfeld vorgenommenen Änderungen zu übernehmen.

     Wenn es sich bei dem Element um einen Ordner handelt, werden nur diejenigen Mitwirkenden von diesem Ordner entfernt, die Sie entfernt haben. Alle *explizit* für andere Elemente im selben Ordner festgelegten Mitwirkenden bleiben unverändert.

<Note>

Wenn Sie die Freigabe von Inhalten im Besitz eines anderen Benutzers aufheben und *alle* Mitwirkenden (anhand der Menüoptionen für **Freigabe aufheben**) oder Ihren eigenen Covata-Benutzer-Account aus dem Abschnitt **Freigabe und Berechtigungen** im Register **Details** oder dem Dialogfeld **Freigeben** entfernen (was dazu führt, dass [Ihr Zugriff auf Ihnen freigegebene Inhalte entfernt wird](/3.3/de/user/managing-secure-content#removing-your-access-to-content-shared-with-you)), haben Sie anschließend für die betreffenden Inhalte keinen Zugriff mehr auf das Dialogfeld **Freigeben**. Um diese Möglichkeit wieder zu erhalten, müssen Sie den Besitzer der Inhalte (oder einen anderen Mitwirkenden mit **Verwaltungs**-Berechtigung) bitten, Ihnen diese Inhalte wieder (mit **Verwaltungs**-Berechtigung) freizugeben.

</Note>

## Umbenennung von Elementen <a id="renaming-an-item" />

Elemente können umbenannt werden, wenn:

- Sie Besitzer des Elements sind oder
- ein Covata-Benutzer Ihnen das Element (als Mitwirkenden) mit **Änderungs**- oder **Verwaltungs**-[Berechtigung](/3.3/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) [freigegeben](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) (und Ihnen so die individuelle Berechtigung zur *Umbenennung* des Elements erteilt) hat.

**Umbenennung von Elementen:**

1. Vergewissern Sie sich, dass Sie bei Safe Share for Web [angemeldet sind](/3.3/de/user/signing-in).
2. Wenn neben dem Home-Symbol links oben (vor dem Namen Ihrer aktuellen Organisation) kein Dropdown-Symbol erscheint, sind Sie nur Mitglied einer Organisation. Sie können daher direkt zum [nächsten Schritt](/3.3/de/user/managing-secure-content#locating-your-item-to-rename) weitergehen. <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.3/de/user/managing-secure-content#locating-your-item-to-rename), um anschließend ein Element dieser Organisation umzubenennen, oder
   - Umbenennung eines Elements einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.3/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="locating-your-item-to-rename" />[Suchen Sie](/3.3/de/user/managing-secure-content#finding-secure-content) das Element, das Sie umbenennen möchten.
4. Führen Sie zur Umbenennung dieses Elements zunächst einen der folgenden Schritte aus:

   - *Klicken Sie mit der rechten Maustaste auf die Zeile des Elements* und wählen Sie aus dem Popup-Menü **Umbenennen**.

     ![Rechtsklick auf Datei als Besitzer - Kontextmenü](/images/6cde1cb4ccc3-right-clicking-a-file-context-menu-owner.png)

     <br />

## Verschieben von Elementen <a id="moving-an-item" />

Dateien und Ordner (d. h. Elemente), auf die vom Elementebereich auf der Safe Share-Hauptseite (innerhalb Ihrer Organisation) zugegriffen werden kann, lassen sich zwischen Speicherorten verschieben.

Als Covata-Benutzer können Sie folgende Elemente verschieben:

- Elemente in Ihrem Besitz:

  - in einen anderen Ordner in Ihrem Besitz (oder ins Stammverzeichnis des Elementebereichs) oder
  - in einen Ihnen von einem anderen Covata-Benutzer [freigegebenen Ordner](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content), für den Sie die **Änderungs**- oder **Verwaltungs**-[Berechtigung](/3.3/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) besitzen. <br />
     (Diese Berechtigungen erteilen Ihnen aufgrund der *impliziten* Übernahme von Mitwirkenden und ihren Berechtigungen an Elementen innerhalb einer Ordnerhierarchie die individuelle Berechtigung zum *Verschieben* aller Elemente im betreffenden Ordner.)
- Elemente in einem Ihnen von einem anderen Benutzer freigegebenen Ordner (für den Sie **Änderungs**- oder **Verwaltungs**-Berechtigung besitzen) in beliebige Unterordner des betreffenden Ordners. Sie benötigen für das zu verschiebende Element *und* den Zielordner, in den Sie das Element verschieben, entweder **Änderungs**- oder **Verwaltungs**-Berechtigung, d. h. Ihre Berechtigungen dürfen weder für das zu verschiebende Element noch für den Zielordner unter diese Ebene heruntergestuft worden sein. <br />
  **Hinweis:** Ein Covata-Benutzer kann Ihnen zwar für zwei separate Ordnerhierarchien **Änderungs**- oder **Verwaltungs**-Berechtigung erteilt haben, aber Sie können Elemente nicht zwischen diesen beiden Ordnerhierarchien verschieben.

## Löschen und Wiederherstellen von Inhalten im Papierkorb <a id="deleting-and-restoring-content-in-the-recycle-bin" />

Löschen von Elementen im Papierkorb, die [Sie](/3.3/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) oder ein [Mitwirkender](/3.3/de/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) über eine beliebige Safe Share-Anwendung hochgeladen haben:

- löscht diese Elemente (einschließlich [aller Versionen](/3.3/de/user/managing-file-versions) jeder gelöschten Datei) aus von der Covata-Plattform verwaltetem Speicher und
- beendet dauerhaft den Zugriff anderer Personen, denen Sie diese Elemente freigegeben haben

Die Wiederherstellung eines Elements aus dem Papierkorb stellt das Element an seinem ursprünglichen Speicherort (von dem aus es in den Papierkorb verschoben wurde) zusammen mit seinen Mitwirkenden und Klassifikationen wieder her, so wie diese vor dem Verschieben in den Papierkorb definiert waren <sup>&#42;</sup> . Alle Mitwirkenden, denen das Element freigegeben war (ehe es in den Papierkorb verschoben wurde), erhalten wieder Zugriff auf das Element.

<Note>

Alle Elemente im Papierkorb werden automatisch nach 30 Tagen gelöscht.

</Note>

**Löschen von Elementen im Papierkorb:**

1. [Greifen Sie](/3.3/de/user/managing-secure-content#accessing-the-recycle-bin) auf die Seite Papierkorb zu.
2. Zum Löschen:

   - *nur eines Elements* führen Sie eine der folgenden Aktionen aus:

     - *Rechtsklicken Sie auf die Zeile des Elements* und wählen Sie aus dem Popup-Menü **Element löschen**. <br />
       *ODER*
     - *Fahren Sie den Cursor* über die Zeile des Elements (oder *wählen Sie* bzw. klicken Sie auf die Zeile) und klicken Sie auf das Symbol „Element löschen“
       ![Element löschen](/images/aaebcb8ba9e2-delete-icon.png)

        (für das jeweilige Element) in der betreffenden Zeile oder rechts in der Symbolleiste am oberen Seitenrand.
   - *von mehr als einem Element* wählen Sie zwei oder mehr Elemente, die Sie aus dem Papierkorb löschen möchten (wie für die Auswahl eines einzelnen Elements (siehe oben) - halten Sie zur Auswahl mehrerer Elemente jedoch die Umschalt-/Strg-/-Befehlstaste gedrückt), und klicken Sie auf das Symbol „Element löschen“
     ![Element löschen](/images/aaebcb8ba9e2-delete-icon.png)

      rechts in der Symbolleiste am oberen Seitenrand.
   - *aller Elemente* klicken Sie auf die Schaltfläche **Papierkorb leeren** links von der Symbolleiste am oberen Seitenrand.

   Safe Share for Web fordert Sie auf, den Löschvorgang zu bestätigen. Sobald Sie **Ja** anklicken, werden die gewählten Elemente (sowie [alle Versionen](/3.3/de/user/managing-file-versions) der einzelnen gelöschten Dateien) aus dem Speicher gelöscht. <br />
   **Hinweise:**

   - Dieser Vorgang setzt Speicherplatz frei, unabhängig, ob er manuell (siehe oben) oder automatisch nach 30 Tagen ausgeführt wird. Für weitere Informationen über die Nutzung Ihres Speicherplatzes siehe [Anzeige Ihrer Speichernutzung und Ihrer Speicherkontingente](/3.3/de/user/managing-your-account#viewing-your-storage-usages-and-quotas).
   - Die Seite Papierkorb ([oben](/3.3/de/user/managing-secure-content#recycle-bin-page)) zeigt in der Spalte **Zu löschen** das Datum an, an dem die einzelnen Elemente automatisch gelöscht werden, d. h. 30 Tage nachdem sie entfernt wurden.

**Wiederherstellen eines Elements aus dem Papierkorb:**

1. [Greifen Sie](/3.3/de/user/managing-secure-content#accessing-the-recycle-bin) auf die Seite Papierkorb zu.
2. Führen Sie zum Wiederherstellen eines Elements zunächst einen der folgenden Schritte aus:

   - *Klicken Sie mit der rechten Maustaste auf die Zeile des Elements* und wählen Sie aus dem Popup-Menü **Wiederherstellen**. <br />
     *ODER*
   - *Fahren Sie den Cursor* über die Zeile des Elements (oder *wählen Sie* bzw. klicken Sie auf die Zeile) und klicken Sie auf das Symbol „Element wiederherstellen“
     ![Element wiederherstellen](/images/881aff021339-restore-icon.png)

      (für das jeweilige Element) in der betreffenden Zeile oder rechts in der Symbolleiste am oberen Seitenrand.

   Safe Share for Web stellt das Element mit seinem gesamten Inhalt (sofern das Element ein Ordner war) an seinem ursprünglichen Speicherort wieder her, von dem aus es entfernt wurde. Wenn dem Element selbst oder einem seiner Inhalte Mitwirkende und/oder (für Dateien) Klassifikationen zugewiesen waren, ehe das Element in den Papierkorb verschoben wurde, werden auch diese Mitwirkenden und Klassifikationen wiederhergestellt <sup>&#42;</sup> , sodass alle Mitwirkenden, denen das Element [freigegeben war](/3.3/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) (ehe es in den Papierkorb verschoben wurde), wieder auf das Element Zugriff erhalten. <br />
   **Hinweise:**

   - Ist an dem Speicherort, an dem eine Datei oder ein Ordner wiederhergestellt werden soll, bereits eine Datei bzw. ein Ordner mit demselben Namen vorhanden, wird das Dialogfeld **Namenskonflikt** angezeigt, in dem Sie einen anderen Elementenamen angeben können, um das Element wiederherzustellen. Für Dateien kann im Dialogfeld **Namenskonflikt** wie auch beim [Umbenennen einer Datei](/3.3/de/user/managing-secure-content#renaming-an-item) die Dateierweiterung nicht geändert werden.
   - Wenn der Ordner, in dem das Element wiederhergestellt werden soll, entfernt oder gelöscht wurde, wird das Dialogfeld **Ordner fehlt** angezeigt, in dem Sie einen anderen Speicherort wählen oder einen neuen Ordner erstellen können, an/in dem das Element anschließend wiederhergestellt wird, um den Vorgang abzuschließen.

<sup>&#42;</sup> Wenn eine mit definierten **Datums-/Zeit-Steuerelementen** freigegebene, anschließend in den Papierkorb verschobene Datei wiederhergestellt werden soll, werden bei der Wiederherstellung alle Mitwirkenden und Klassifikationen entfernt. Dies ist auch der Fall, wenn sich die Datei in einem Ordner befindet, der in den Papierkorb verschoben wurde und wiederhergestellt wird.
