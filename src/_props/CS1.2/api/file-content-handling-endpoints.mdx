---
title: "File content handling endpoints"
---

The endpoints in this section are used for handling the content of files (i.e. [Secure Objects](/CS1.2/api/working-with-files-and-folders-fundamentals#secure-object)) on the Cocoon Data Platform, including file versions.

### File object content handling (new file objects and active file versions)

* **Content upload and download**

  * [\<content-service>/api/v1/objects/\{objectId}/contents](/CS1.2/api/content-service-api-v1-objects-objectid-contents)
* **'Read-only view' download and regeneration**

  * [\<content-service>/api/v1/objects/\{objectId}/view](/CS1.2/api/content-service-api-v1-objects-objectid-view)

### File version content handling

* **File version creation and content upload**

  * [\<content-service>/api/v1/objects/\{objectId}/versions](/CS1.2/api/content-service-api-v1-objects-objectid-versions)
* **Content download**

  * [\<content-service>/api/v1/versions/\{versionId}/contents](/CS1.2/api/content-service-api-v1-versions-versionid-contents)
* **'Read-only view' download**

  * [\<content-service>/api/v1/versions/\{versionId}/view](/CS1.2/api/content-service-api-v1-versions-versionid-view)
