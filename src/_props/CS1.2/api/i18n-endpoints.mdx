The endpoints in this section are used for handling internationalization/language bundles on the Cocoon Data Platform.

* [\<access-service>/api/v1/i18n/adminpreference](/CS1.2/api/access-service-api-v1-i18n-adminpreference)
* [\<access-service>/api/v1/i18n/bundles/\{localeCode}](/CS1.2/api/access-service-api-v1-i18n-bundles-localecode)
* [\<access-service>/api/v1/i18n/bundles/\{localeCode}/delete](/CS1.2/api/access-service-api-v1-i18n-bundles-localecode-delete)
* [\<access-service>/api/v1/i18n/bundles/\{localeCode}/download](/CS1.2/api/access-service-api-v1-i18n-bundles-localecode-download)
* [\<access-service>/api/v1/i18n/bundles/\{localeCode}/reset](/CS1.2/api/access-service-api-v1-i18n-bundles-localecode-reset)
* [\<access-service>/api/v1/i18n/localedetails](/CS1.2/api/access-service-api-v1-i18n-localedetails)
* [\<access-service>/api/v1/i18n/reload](/CS1.2/api/access-service-api-v1-i18n-reload)

### I18n endpoints accessible publicly (without authentication)

* [\<access-service>/api/v1/i18n/bundles](/CS1.2/api/access-service-api-v1-i18n-bundles) (use this endpoint to reveal information about the current values for the properties above)
