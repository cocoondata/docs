---
title: "Folder handling endpoints"
---

The endpoints in this section are used for handling folders (i.e. [collections](/CS1.2/api/working-with-files-and-folders-fundamentals#collection)) on the Cocoon Data Platform.

### Folder creation

* [\<access-service>/api/v1/organisations/\{orgId}/collections](/CS1.2/api/access-service-api-v1-organisations-orgid-collections)

### Folder property retrieval and update, including folder removal and list retrieval

* [\<access-service>/api/v1/collections/\{collectionId}](/CS1.2/api/access-service-api-v1-collections-collectionid)
* [\<access-service>/api/v1/collections/\{collectionId}/collections](/CS1.2/api/access-service-api-v1-collections-collectionid-collections)
