## Overview of SafeShare and the Covata Platform

Covata provides a complete solution and platform for securely protecting and sharing encrypted files and folders which can be stored and accessed anywhere (within an organisation, outside the domain and from mobile devices).

Covata's technologies provide this solution through the *Covata Platform* (upon which SafeShare is built), whose *Access Service* centrally manages cryptographic *keys* (used to encrypt/decrypt content) and *access controls* (which define who can access/decrypt content and when).

The Covata Platform's Access Service handles its *key* management and *access controls* separately from cryptography and user content. This separation helps ensure that encrypted content is only able to be decrypted by the people it's intended for.

Users of *Covata technologies*<sup>\*</sup> can share their secured content with others through Covata's SafeShare applications, which integrate with the Covata Platform to ensure that critical key management and access controls are adhered to.

The Covata Platform provides an application programming interface (API), which allows integrators to develop their own applications that leverage Covata's powerful data-centric security features.

## SafeShare Administration

*SafeShare Administration* is a web-based interface for administering organisations on a Covata Platform instance. This interface also provides access to a number of configurable features of Covata technologies<sup>\*</sup> that apply to all organisations configured on the Covata Platform.

![Dashboard page](/images/ffa5fccb2ddc-platform-administration-dashboard-page.png)
*SafeShare administrators* are users who, once [signed in](/CS1.0/admin-platform/accessing-platform-administration#signing-in-to-platform-administration) to SafeShare Administration, can access its [dashboard](/CS1.0/admin-platform/accessing-platform-administration#the-platform-administration-dashboard) (depicted above) and have the ability to perform the following administration activities on their Covata Platform instance:

* Administer all [SafeShare administrator users](/CS1.0/admin-platform/administering-platform-administrator-users) on the Covata Platform. <br />
  **Note:** Any user who has an account registered on the Covata Platform is known as a Covata user. A SafeShare administrator is one type of Covata user. For more information about other types of Covata users, please refer to [Administering users within an organisation](/CS1.0/admin-platform/administering-users-within-an-organisation) in the [Organisation Administration](/CS1.0/admin-platform/organisation-administration) section of this guide.
* Administer all [organisations](/CS1.0/admin-platform/administering-organisations) on the Covata Platform.
* Configure single sign-on (SSO) using a [SAML](/CS1.0/admin-platform/configuring-single-sign-on-using-an-idp)-based Identity Provider (IdP).
* Register [client apps](/CS1.0/admin-platform/configuring-client-applications), which are integrator-developed applications that utilise any aspect of Covata technologies made available through the Covata Platform's API.
* Change aspects of SafeShare's behavior by modifying SafeShare Administration [configuration](/CS1.0/admin-platform/configuring-platform-administration-properties) properties.
* Adjust the user interface languages of SafeShare Administration, Organisation Administration and the default used for SafeShare for Web, as well as upload/delete language bundles using [internationalisation](/CS1.0/admin-platform/managing-internationalisation).

<sup>\*</sup> *Covata technologies* refers to all features and functionality provided by (and made available through) the Covata Platform, including Covata's SafeShare applications, the Covata Platform's API and the Covata Platform itself.
