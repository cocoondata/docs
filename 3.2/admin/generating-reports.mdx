---
title: "Generating reports"
---

A key security feature of Covata technology is the ability to audit all actions taken by users in the creation and dissemination of Secure Objects. When data is leaked from an organization as a Secure Object, then an auditor must have a tool to identify the person responsible.

The Reports page allows Administrators to access a detailed audit log. Reports can be run on the following:

- Keys created and retrieved for objects
- Secure Objects created and retrieved
- Secure Objects updated
- Notifications created and retrieved

Although this feature is intended mainly for API Clients, who will develop their own applications using Covata technology, it can be used by all Administrators.

## View a report <a id="view-reports" />

The Reports page will automatically display the last 25 API actions by default.

To review further pages of the report click on the page numbers displayed above the list.

You also have the option to export the report as a PDF or CSV file. Select the **PDF** or **CSV** icon to download the report.

## Report parameters

To generate a specific report there are a number of possible parameters you can set. The table below outlines these:

| Field | Description |
| --- | --- |
| Start Date | A start date can be set for any report |
| End Date | An end date can be set for any report |
| Client ID | A unique identifier for each client application. Allows an Administrator to run reports on specific clients |
| Email | A registered email address. Allows an Administrator to run reports on specific users, such as Originators |
| Resource | There are three resources available for reporting. Choose an option from the drop down menu:  <br />•  Notifications <br />•  Objects <br />•  Keys  |
| Action | There are three actions available for reporting. Choose an option from the drop down menu:  <br />•  Created <br />•  Retrieved <br />•  Updated  |

To run a specific report set the parameters you need and click **View**.

To refine a report you can alter or add a new parameters and click **View** again. The new results will then display on screen for you.

You then have the option to export the report as a PDF or CSV file. Select the **PDF** or **CSV** icon to download the report generated.
