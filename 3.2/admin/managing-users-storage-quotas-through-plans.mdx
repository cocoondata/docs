---
title: "Managing users' storage quotas through plans"
---

The **Plans** page allows Covata Platform administrators to define storage quotas, which are used to limit the amount of storage (managed by the Covata Platform's Content Service) available to Covata user accounts accessed through either:

- Covata Safe Share applications, or
- Other client applications that utilize the Covata Platform's API.

A storage quota is defined by a *plan*, which in turn can be applied to a Covata user account with the [Originator role](/3.2/admin/administering-users#originator-role) (through the **Users** [page](/3.2/admin/administering-users)) when the account is either [created](/3.2/admin/administering-users#adding-a-new-user) or [edited](/3.2/admin/administering-users#editing-an-existing-user).

## Adding a new plan

**To add a new plan to the Covata Platform:**

1. [Sign in](/3.2/admin/accessing-administration#signing-in) to Covata Administration.
2. Click the **Plans** option on the left of the [Covata Administration interface](/3.2/admin/accessing-administration#the-administration-interface) to open the **Plan Management** page.
3. Click the **Add New** button.
4. In the **Add new** dialog box, specify the:

   - **Name** - The value of this field is the name of the plan shown in the list of available plans when a Covata user with the [Originator role](/3.2/admin/administering-users#originator-role) is [created](/3.2/admin/administering-users#adding-a-new-user) or [edited](/3.2/admin/administering-users#editing-an-existing-user) through the **Users** [page](/3.2/admin/administering-users).
   - **Description** - A longer description to provide more information about the plan, such as the plan's purpose or which type of Covata users the plan is intended for. The value of this field is only visible to Covata Platform administrators on this **Plan Management** page.
   - **Quota (MB)** - The value of the quota (in megabytes) that this plan defines.
5. ( *Optional* ) Select the **Default plan** check box to ensure that *this* plan (you are about to add) is selected by default when a Covata user with the [Originator role](/3.2/admin/administering-users#originator-role) is either [created](/3.2/admin/administering-users#adding-a-new-user) or [edited](/3.2/admin/administering-users#editing-an-existing-user).
6. Click **Save** and the new plan is added and will appear as a new entry on the **Plan Management** page. <br />
   **Note:** If the **Default plan** check box was selected, the **default** indicator on the **Plan Management** page switches to this plan you just added.

## Editing an existing plan

Editing an existing plan allows modification of all of its fields. This is useful when it is necessary to modify the plan's quota or change this plan to the **default** one.

<Note>

It is not possible to edit the plan marked **default**. To edit such a plan, see the **Tip** below.

</Note>

**To edit an existing plan:**

1. [Sign in](/3.2/admin/accessing-administration#signing-in) to Covata Administration.
2. Click the **Plans** option on the left of the [Covata Administration interface](/3.2/admin/accessing-administration#the-administration-interface) to open the **Plan Management** page.
3. Locate/scroll to the relevant plan and click its **Edit** link.
4. In the **Edit plan** dialog box, modify the:

   - **Name** - The value of this field is the name of the plan shown in the list of available plans when a Covata user with the [Originator role](/3.2/admin/administering-users#originator-role) is [created](/3.2/admin/administering-users#adding-a-new-user) or [edited](/3.2/admin/administering-users#editing-an-existing-user) through the **Users** [page](/3.2/admin/administering-users).
   - **Description** - A longer description to provide more information about the plan, such as the plan's purpose or which type of Covata users the plan is intended for. The value of this field is only visible to Covata Platform administrators on this **Plan Management** page.
   - **Quota (MB)** - The value of the quota (in megabytes) that this plan defines.
5. ( *Optional* ) Select the **Default plan** check box to ensure that *this* plan (you are editing) is selected by default when a Covata user with the [Originator role](/3.2/admin/administering-users#originator-role) is either [created](/3.2/admin/administering-users#adding-a-new-user) or [edited](/3.2/admin/administering-users#editing-an-existing-user).
6. Click **Save** and the plan's fields are updated accordingly. <br />
   **Note:** If the **Default plan** check box was selected, the **default** indicator on the **Plan Management** page switches to this plan you just edited.

<Tip>

To edit a plan marked **default**, edit another plan first and choose its **Default plan** check box (then **Save**), which switches the **default** indicator away from the plan you intend to edit.

</Tip>

## Deleting an existing plan

Deleting an existing plan prevents this plan from being selected when [creating](/3.2/admin/administering-users#adding-a-new-user) or [editing](/3.2/admin/administering-users#editing-an-existing-user) a Covata user through the **Users** [page](/3.2/admin/administering-users).

When a plan is deleted, any users who were assigned this plan are automatically switched over to the **default** plan. Be aware that if this **default** plan has a quota which is lower than the amount of Content Service-managed storage utilized by any of these users, then these users will no longer be able to upload any data through Safe Share (until their storage utilization drops below the **default** plan's quota).

<Note>

It is not possible to delete the plan marked **default**. To delete a plan marked **default**, [edit another plan](/3.2/admin/managing-users-storage-quotas-through-plans#editing-an-existing-plan) first and choose its **Default plan** check box (then **Save**), which switches the **default** indicator away from the plan you intend to delete.

</Note>

**To delete an existing plan:**

1. [Sign in](/3.2/admin/accessing-administration#signing-in) to Covata Administration.
2. Click the **Plans** option on the left of the [Covata Administration interface](/3.2/admin/accessing-administration#the-administration-interface) to open the **Plan Management** page.
3. Locate/scroll to the relevant group and click its **Delete** link.
4. On the **Delete** message box, click **Yes** to proceed with the plan's deletion.
