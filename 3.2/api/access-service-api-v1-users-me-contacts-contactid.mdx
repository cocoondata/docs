## URL structure <a id="access-service-api-v1-users-me-contacts-contactid-url-structure" />

```text
https://access-service.xy-company.com/api/v1/users/me/contacts/{contactId}
```

where `{contactId}` is the ID of a Covata user's contact.

## Supported methods and overview <a id="access-service-api-v1-users-me-contacts-contactid-supported-methods-and-overview" />

- `PUT` - used to modify the fields of an existing contact that belongs to the currently authenticated Covata user<sup>&#42;</sup>, based on the contact's ID.
- `DELETE` - used to remove an existing contact belonging to the currently authenticated Covata user.

<Note>

The `DELETE` method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-users-me-contacts-contactid-detailed-description" />

This API endpoint serves a number of purposes:

- Modifies the fields (i.e. the email address, first name and/or last name) of an existing contact that belongs to the currently authenticated Covata user<sup>&#42;</sup>, based on the contact's ID. <br />
   A contact's ID is obtained by calling the `GET` method of the [&lt;access-service&gt;/api/v1/users/me/contacts](/3.2/api/access-service-api-v1-users-me-contacts) API endpoint, which retrieves a list of field information for all contacts of the currently authenticated Covata user. <br />
  **Note:** A contact's email address can be modified to one which does not match a registered Covata user account. However, as to whether or not sharing the currently authenticated Covata user's content with this modified contact will succeed, ultimately depends on the contact's email address complying with a rule of an enabled user whitelist on the Covata Platform. If this content is successfully shared with this contact, then a new Covata user account is automatically created for this contact (with the [Ad hoc role](/3.2/admin-org/administering-users-within-an-organisation#adhoc-role)).
- Removes an existing contact belonging to the currently authenticated Covata user, based on the contact's ID.

## Supported roles <a id="access-service-api-users-me-contacts-contactid-supported-roles" />

This API endpoint supports the following Covata user roles (as described in the [Covata Platform Administrator's Guide](/3.2/admin)):

- [Originator](/3.2/admin-org/administering-users-within-an-organisation#originator-role)
