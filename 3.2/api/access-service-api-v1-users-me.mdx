## URL structure <a id="access-service-api-v1-users-me-url-structure" />

```text
https://access-service.xy-company.com/api/v1/users/me
```

## Supported methods and overview <a id="access-service-api-v1-users-me-supported-methods-and-overview" />

- `GET` - used to retrieve information about the currently authenticated Covata user<sup>&#42;</sup>.
- `PUT` - used to modify the account details of the currently authenticated Covata user.

<Note>

The `GET` method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-users-me-detailed-description" />

This API endpoint serves a number of purposes:

- Retrieves a detailed set of information about the currently authenticated Covata user<sup>&#42;</sup>.
- Modifies the account details of the currently authenticated Covata user. <br />
  **Note:** These account details can also be modified through the [My Account](/3.2/user/managing-your-account#updating-your-account-details) feature of the [Safe Share web application](/3.2/user).

## Supported roles and conditions <a id="access-service-api-v1-users-me-supported-roles-and-conditions" />

This API endpoint supports the following Covata user roles (as described in the [Covata Platform Administrator's Guide](/3.2/admin)) and conditions:

- [Originator](/3.2/admin-org/administering-users-within-an-organisation#originator-role)
- [Collaborator](/3.2/admin-org/administering-users-within-an-organisation#collaborator-role)
- [Ad hoc](/3.2/admin-org/administering-users-within-an-organisation#adhoc-role) - a Covata user with this role can call the `GET` method only.
- System administrator
- User administrator

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.2/api/access-service-api-v1-users-me#access-service-api-v1-users-me-required-headers) of requests to this endpoint.
