## URL structure <a id="access-service-api-v1-dashboard-ldap-url-structure" />

```text
https://access-service.xy-company.com/api/v1/dashboard/ldap
```

## Supported methods and overview <a id="access-service-api-v1-dashboard-ldap-supported-methods-and-overview" />

- `GET` - used to retrieve the total number of currently enabled [LDAP connections](/3.2/admin-platform/configuring-ldap) on the Covata Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-dashboard-ldap-detailed-description" />

This API endpoint retrieves the total number of currently enabled LDAP connections on the Covata Platform.

## Supported roles <a id="access-service-api-v1-dashboard-ldap-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [Safe Share Administrator's Guide](/3.2/admin-platform)):

- [Safe Share administrator](/3.2/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.2/api/access-service-api-v1-dashboard-ldap#access-service-api-v1-dashboard-ldap-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-dashboard-ldap-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Returns <a id="access-service-api-v1-dashboard-ldap-returns" />

A JSON-formatted response containing the following members:

- **totalLdapConnections** - The total number of currently enabled LDAP connections on the Covata Platform. Any LDAP connections which have already been configured on the Covata Platform but are disabled are not represented in this total.

  **Example:**

  ```json
  {
    "totalLdapConnections": 1
  }
  ```
