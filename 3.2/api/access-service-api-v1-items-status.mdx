## URL structure <a id="access-service-api-v1-items-status-url-structure" />

```text
https://access-service.xy-company.com/api/v1/items/status
```

## Supported methods and overview <a id="access-service-api-v1-items-status-supported-methods-and-overview" />

- `POST` - used to retrieve information about the current status of one or more [Secure Objects](/3.2/api/creating-files-and-folders#secure-object) (i.e. *Incomplete*, *Created* or *Deleted*) as well as one or more [collections](/3.2/api/creating-files-and-folders#collection).

## Detailed description <a id="access-service-api-v1-items-status-detailed-description" />

This API endpoint retrieves information about the current status of one or more Secure Objects (i.e. *Incomplete*, *Created* or *Deleted*) as well as one or more collections, based on their IDs.

Collections can have one of two statuses - *Created* or *Deleted*. However, *Deleted* collections are not returned in responses from requests to this endpoint.

Also returned in responses are details about the Covata user who owns each item returned in the response.

## Supported roles <a id="access-service-api-items-status-supported-roles" />

This API endpoint supports the following Covata user roles (as described in the [Covata Platform Administrator's Guide](/3.2/admin/index)):

- [Originator](/3.2/admin-org/administering-users-within-an-organisation#originator-role)
- [Collaborator](/3.2/admin-org/administering-users-within-an-organisation#collaborator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.2/api/access-service-api-v1-items-status#access-service-api-v1-items-status-required-headers) of requests to this endpoint.
