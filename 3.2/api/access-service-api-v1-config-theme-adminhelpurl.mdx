## URL structure <a id="access-service-api-v1-config-theme-adminhelpurl-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/adminHelpUrl
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-adminhelpurl-supported-methods-and-overview" />

- `PUT` - used to set a new help URL for documentation relating to Covata Administration.
- `DELETE` - see [&lt;access-service&gt;/api/v1/config/theme/...](/3.2/api/access-service-api-v1-config-theme-reset) for more information.

## Detailed description <a id="access-service-api-v1-config-theme-adminhelpurl-detailed-description" />

This API endpoint sets a new help URL for documentation relating to Covata Administration.

To reset this URL back to its default value, see [&lt;access-service&gt;/api/v1/config/theme/...](/3.2/api/access-service-api-v1-config-theme-reset) for more information.

## Supported roles <a id="access-service-api-v1-config-theme-adminhelpurl-supported-roles" />

This API endpoint supports the following Covata user roles (as described in the [Covata Platform Administrator's Guide](/3.2/admin/index)):

- System administrator

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.2/api/access-service-api-v1-config-theme-adminhelpurl#access-service-api-v1-config-theme-adminhelpurl-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-config-theme-adminhelpurl-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Required body <a id="access-service-api-v1-config-theme-adminhelpurl-required-body" />

Specify the new help URL for documentation relating to Covata Administration in the body of the request as plain text.

## Returns <a id="access-service-api-v1-config-theme-adminhelpurl-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
