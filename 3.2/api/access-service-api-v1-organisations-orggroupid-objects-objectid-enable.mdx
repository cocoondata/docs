## URL structure <a id="access-service-api-v1-organisations-orggroupid-objects-objectid-enable-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{orgGroupId}/objects/{objectId}/enable
```

where `{orgGroupId}` is the ID of an organization and `{objectId}` is the ID of a file object created within this organization.

## Supported methods and overview <a id="access-service-api-v1-organisations-orggroupid-objects-objectid-enable-supported-methods-and-overview" />

- `PUT` - used to [disable or (re-)enable](/3.2/admin-org/administering-files#disabling-or-re-enabling-secure-objects) a file object/[Secure Object](/3.2/api/creating-files-and-folders#secure-object), based on its ID.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-orggroupid-objects-objectid-enable-detailed-description" />

This API endpoint disables or (re-)enables a single file object, using the file object's ID.

Calling this endpoint on a given file object successively toggles between disabling or (re-)enabling this file object.

A file object's ID can be obtained by calling the GET method on the [&lt;access-service&gt;/api/v1/organisations/\{orgGroupId\}/objects](/3.2/api/access-service-api-v1-organisations-orggroupid-objects) API endpoint, which retrieves a list of high-level information associated with file objects that can be filtered using various 'search' criteria.

It is also possible to disable or (re-)enable one or more file objects in a single action by calling the [&lt;access-service&gt;/api/v1/objects/bulk](/3.2/api/access-service-api-v1-objects-bulk) API endpoint.

- [Organization administrator](/3.2/admin-org/administering-users-within-an-organisation#organisation-administrator-role)
