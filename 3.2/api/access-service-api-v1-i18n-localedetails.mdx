## Supported methods and overview <a id="access-service-api-v1-i18n-localedetails-supported-methods-and-overview" />

- `GET` - used to retrieve a list of field information for all supported locales on the Covata Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-i18n-localedetails-detailed-description" />

This API endpoint retrieves a list of field information for all supported locales on the Covata Platform.

## Supported roles <a id="access-service-api-v1-i18n-localedetails-supported-roles" />

This API endpoint supports the following Covata user roles (as described in the [Covata Platform Administrator's Guide](/3.2/admin/index)):

- System administrator

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.2/api/access-service-api-v1-i18n-localedetails#access-service-api-v1-i18n-localedetails-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-i18n-localedetails-required-headers" />
