## URL structure <a id="access-service-api-v1-organisations-orgid-items-transfer-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{orgId}/items/transfer
```

where `{orgId}` is the ID of an organization.

## Supported methods and overview <a id="access-service-api-v1-organisations-orgid-items-transfer-supported-methods-and-overview" />

- `POST` - used to transfer the ownership of all file objects and folders from one Covata user to another Covata user.

## Detailed description <a id="access-service-api-v1-organisations-orgid-items-transfer-detailed-description" />

This API endpoint transfers the ownership of all files/[Secure Objects](/3.2/api/creating-files-and-folders#secure-object) and folders/[collections](/3.2/api/creating-files-and-folders#collection) (in which these files are contained) from one Covata user to another Covata user, within the organization specified by the `{orgId}` of the request's URL.

<Note>

- When using [Organization Administration](/3.2/admin-org) to transfer item ownership from one Covata user to another, this process must be done as part of [removing a user account from an organization](/3.2/admin-org/administering-users-within-an-organisation#removing-a-user-account-from-your-organisation).
- However, when using the Covata API, transferring item ownership from a Covata user can be accomplished without having to remove this user from the organization.

</Note>

## Supported roles and conditions <a id="access-service-api-v1-organisations-orgid-items-transfer-supported-roles-and-conditions" />

This API endpoint supports requests utilizing Covata user accounts with the following [roles](/3.2/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organization Administrator's Guide](/3.2/admin-org)) and conditions:

- [Organization administrator](/3.2/admin-org/administering-users-within-an-organisation#organisation-administrator-role) - if this user is a member of the organization specified by the `{orgId}` of the request's URL.

The Covata Platform's resources available to Covata users meeting this criteria is determined by the access token passed in the [header](/3.2/api/access-service-api-v1-organisations-orgid-items-transfer#access-service-api-v1-organisations-orgid-items-transfer-required-headers) of requests to this endpoint.

- **from** - The ID of a Covata user (with the [Originator role](/3.2/admin-org/administering-users-within-an-organisation#originator-role)), whose items will be transferred to another Covata user.
- **to** - The ID of another Covata user (with the **Originator** role) to whom these items will be transferred.
