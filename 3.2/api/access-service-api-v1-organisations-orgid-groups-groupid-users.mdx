## URL structure <a id="access-service-api-v1-organisations-orgid-groups-groupid-users-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{orgId}/groups/{groupId}/users
```

where `{orgId}` is the ID of an organization and `{groupId}` is the ID of one of this organization's groups.

## Supported methods and overview <a id="access-service-api-v1-organisations-orgid-groups-groupid-users-supported-methods-and-overview" />

- `GET` - used to retrieve a list of information for all of an organization's [Covata users](/3.2/admin-org/administering-users-within-an-organisation) who are members of a [group](/3.2/admin-org/managing-groups), based on the group's ID.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-orgid-groups-groupid-users-detailed-description" />

This API endpoint retrieves a list of information for all of an organization's Covata users who are members of the group whose ID is specified in the URL of this endpoint.

A group's ID can be obtained by calling the `GET` method of the [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/groups](/3.2/api/access-service-api-v1-organisations-orgid-groups) API endpoint, which retrieves a list of information for all groups in an organization.

## Supported roles <a id="access-service-api-groups-groupid-users-supported-roles" />

This API endpoint supports requests utilizing Covata user accounts with the following [roles](/3.2/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organization Administrator's Guide](/3.2/admin-org)) and conditions:

- [Organization administrator](/3.2/admin-org/administering-users-within-an-organisation#organisation-administrator-role) - if this user is a member of the organization specified by the `{orgId}` of the request's URL.

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.2/api/access-service-api-v1-organisations-orgid-groups-groupid-users#access-service-api-v1-organisations-orgid-groups-groupid-users-required-headers) of requests to this endpoint.
