## URL structure <a id="access-service-api-v1-i18n-bundles-localecode-download-url-structure" />

```text
https://access-service.xy-company.com/api/v1/i18n/bundles/{localeCode}/download
```

where `{localeCode}` is a supported locale code.

## Supported methods and overview <a id="access-service-api-v1-i18n-bundles-localecode-download-supported-methods-and-overview" />

- `GET` - use to download the contents of an internationalization (i18n) bundle as key/value pairs in [JSON format](http://json.org/).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-i18n-bundles-localecode-download-detailed-description" />

This API endpoint downloads the contents of an i18n bundle (specified by `{localCode}`) as key/value pairs in JSON format.

## Supported roles <a id="access-service-api-v1-i18n-bundles-localecode-download-supported-roles" />

This API endpoint supports the following Covata user roles (as described in the [Covata Platform Administrator's Guide](/3.2/admin)):

- System administrator

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.2/api/access-service-api-v1-i18n-bundles-localecode-download#access-service-api-v1-i18n-bundles-localecode-download-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-i18n-bundles-localecode-download-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Returns <a id="access-service-api-v1-i18n-bundles-localecode-download-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
