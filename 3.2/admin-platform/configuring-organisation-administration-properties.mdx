title: "Configuring Safe Share Organization Administration properties"
---

The **Configuration** page allows Organization administrators to [modify](/3.2/admin-platform/configuring-organisation-administration-properties#modifying-an-organisation-administration-property-value) a restricted set of organization-specific properties that tweak the specific functional aspects and the behavior of their organization on the Covata Platform.

![Configuration/Properties page](/images/30d8dd220b84-organisation-administration-property-configuration-page.png)
## Modifying a Safe Share Organization Administration property value <a id="modifying-an-organisation-administration-property-value" />

**To modify a Safe Share Organization Administration property value:**

1. [Sign in](/3.2/admin-platform/accessing-organisation-administration#signing-in-to-organisation-administration) to Safe Share Organization Administration.
2. Click the **Configuration** option on the left of the [Safe Share Organization Administration interface](/3.2/admin-platform/accessing-organisation-administration#the-organisation-administration-interface) to open the **Configuration** page.
3. Click the **Edit** link to the right of the relevant [Safe Share Organization Administration property](/3.2/admin-platform/configuring-organisation-administration-properties#organisation-administration-properties).
4. In the **Edit Config Property** dialog box, update the **Property value** field as required.
5. Click **Save** and the value of the Safe Share Organization Administration property is modified with immediate effect. <br />
   **Notes:**

   - For properties whose value consists of a simple `true` or `false`, the **Edit Config Property** dialog box has a **Property Value** check box, which should be selected for `true` or cleared for `false`.
   - It is not possible to modify the names of Safe Share Organization Administration properties, since these are fixed.

## Safe Share Organization Administration properties <a id="organisation-administration-properties" />

The following Safe Share Organization Administration properties are available:

| Property | Detailed description |
| --- | --- |
| Organization Admin Email | <a id="org-admin-email" />The contact email address, typically for an [Organization administrator](/3.2/admin-platform/administering-users-within-an-organisation#organisation-administrator-role), which is:  <br />•  used in Covata Notification email messages and <br />•  is accessible from the **Need help? ...** link on the **Authentication code** entry page for two-factor authentication (2FA) whenever a [Covata user with 2FA enabled](/3.2/admin-platform/administering-users-within-an-organisation#enabling-or-disabling-2fa-on-organisation-user-accounts) on their account [signs in](/3.2/user/signing-in) through the Covata Sign-in page. <br />If a Covata user cannot successfully sign in (typically due to the user losing the ability to generate authentication codes for their 2nd authentication factor), the user can click this **Need help? ...** link to begin emailing their Organization administrator a request to [re-configure 2FA for their user account](/3.2/admin-platform/administering-users-within-an-organisation#re-configuring-2fa-for-an-organisation-user-account). <br />  See [Administering users within an organization](/3.2/admin-platform/administering-users-within-an-organisation) in the [Safe Share Organization Administration](/3.2/admin-platform/organisation-administration) section of this guide for more information. <br /> **Notes:**  <br />•  This property's default value is empty. In such circumstances, the [Admin Email](/3.2/admin-platform/configuring-platform-administration-properties#platform-admin-email) property's value (defined through [System details properties](/3.2/admin-platform/configuring-platform-administration-properties#system-details-properties) - see [Configuring Safe Share Administration properties](/3.2/admin-platform/configuring-platform-administration-properties) for more information), is used as the fallback. <br />•  Two-factor authentication is enabled by the user themselves for their own account through the [Safe Share web application](/3.2/user/managing-your-account#enabling-or-disabling-2fa-for-your-account), [Organization Administration](/3.2/admin-platform/administering-users-within-an-organisation#enabling-or-disabling-2fa-on-organisation-user-accounts) or Safe Share Administration interfaces, by a Safe Share administrator for [any Safe Share administrator's account](/3.2/admin-platform/administering-platform-administrator-users#enabling-or-disabling-2fa-for-a-platform-administrator), or by an Organization administrator for [all members of their organization](/3.2/admin-platform/configuring-organisation-administration-properties#enforce-2fa-for-organisation-members).  |
| Is the address book feature enabled? | <a id="address-book-feature" />Determines whether (i.e. `true`) or not (i.e. `false`) the organization's address book feature is enabled. <br />  The address book feature allows a user to discover (through autocompletion) other Covata user members within their organization by the user typing the first few characters of a member account's email address, when sharing an item. If this property's value is:  <br />•  `true`, this discovery feature will be scoped to all Covata user accounts that are members of the organization, as well as all of the user's own contacts. <br />•  `false`, this discovery feature will be scoped only to all of the user's own contacts.  |
| A brief description of the organization. | As the name of this property indicates. This field's purpose is only to provide Organization administrators with additional information about their organization. Be aware that this description:  <br />•  is not displayed anywhere else throughout the interfaces of Safe Share Administration, Organization Administration and Safe Share applications, and <br />•  cannot be cleared once it has been set.  |
| The email address of the organization's contact person. | <a id="organisations-contact-person" />As the name of this property indicates. This property's purpose is to provide Safe Share administrators with the email address of the organization's contact person, which appears in the **Contact Person** column on the [Organizations](/3.2/admin-platform/administering-organisations) page of [Safe Share Administration](/3.2/admin-platform/index#platform-administration). Be aware that this contact person:  <br />•  is initially the email address of the Organization administrator set when a Safe Share administrator added the organization to the Covata Platform, <br />•  is not displayed anywhere else throughout the interfaces of Organization Administration and Safe Share applications, and <br />•  cannot be cleared. <br />**Notes:**  <br />•  This property is useful for allowing Safe Share administrators of your Covata Platform instance to contact (by email) the appropriate person responsible for administering your organization. <br />•  This property is unrelated to the [Organization Admin Email](/3.2/admin-platform/configuring-organisation-administration-properties#org-admin-email) property (above), whose value is accessible to Covata users from Covata Notification email messages and the **Need help? ...** link on the **Authentication code** entry page for two-factor authentication (2FA). <br />•  For more information about how organizations are added to the Covata Platform, see [Adding a new organization](/3.2/admin-platform/administering-organisations#adding-a-new-organisation) in [Administering organizations](/3.2/admin-platform/administering-organisations).  |
| Is watermarking of viewed files enabled? | Determines whether (i.e. `true`) or not (i.e. `false`) the watermarking feature is enabled for all viewable files/Secure Objects created within your organization. <br />  The watermarking feature:  <br />•  Only applies to collaborators viewing files that have been shared with them. This feature is intended to discourage collaborators from copying file views by other means (e.g. using screenshot capturing tools, etc). <br />•  Covers a file's view with large semi-transparent text that consists of the email address of the currently signed-in collaborator viewing the file, the Covata Platform's URL, the ID of the file/Secure Object, the classification applied to the file by its owner (if applicable) and the date/time when the file was viewed.  |
| Default i18n setting for new users and email notifications. | <a id="default-i18n-setting-for-organisation" />The default language for all new Covata user accounts created on the Covata Platform <sup>&#42;</sup> as a result of the users' accounts being [added to the organization](/3.2/admin-platform/administering-users-within-an-organisation#adding-an-organisation-user-account).  <br />•  This setting overrides the **System Default** language setting set by a Safe Share administrator for their Covata Platform instance. <br />•  This property's initial value is the current **System Default** language setting <br />**Note:** Users can always choose/set their own account's language settings through their own account editing features in the [Safe Share web application](/3.2/user/managing-your-account#updating-your-account-details) (or [Organization Administration](/3.2/admin-platform/administering-users-within-an-organisation#editing-your-organisation-administrator-account)). <br /> <sup>&#42;</sup> These new user accounts are created because the user's email address has not yet been registered on the the Covata Platform. |
| Enforce two-factor authentication for organization members. | <a id="enforce-2fa-for-organisation-members" />Determines whether (i.e. `true`) or not (i.e. `false`) the two-factor authentication (2FA) feature is enforced for all Covata users who are members of your organization. This includes your own Organization administrator account. <br /> **Note:** Take caution before setting this value to `true`. If any members of your organization (including yourself) are not prepared to configure 2FA on their account, they may be unable to sign in successfully through the Covata Sign-in page, thereby preventing these users' access to:  <br />•  all organizations on the Covata Platform for which these users are members and/or <br />•  Safe Share Organization Administration for all organizations of which these users are [Organization administrators](/3.2/admin-platform/administering-users-within-an-organisation#organisation-administrator-role). <br />For more information about 2FA, see [Enabling or disabling 2FA on Organization user accounts](/3.2/admin-platform/administering-users-within-an-organisation#enabling-or-disabling-2fa-on-organisation-user-accounts). |
| An item which will appear in a new users' file list when they sign in. | <a id="user-adoption-content" />A file/Secure Object or folder/collection that an Organization administrator can choose to be automatically shared with Covata users in the organization who acquire the [Originator role](/3.2/admin-platform/administering-users-within-an-organisation#originator-role). <br />  When an Organization administrator chooses one of their items through this property, this feature becomes active, which results in any users within the organization who subsequently acquire the Originator role being automatically shared this chosen item. A user's account acquires the Originator role when this account is either:  <br />•  [added to the organization](/3.2/admin-platform/administering-users-within-an-organisation#adding-an-organisation-user-account) with the Originator role, or <br />•  an existing organization member that is subsequently [edited](/3.2/admin-platform/administering-users-within-an-organisation#editing-an-organisation-user-account) to grant it/upgrade it to the Originator role. <br />The purpose of this feature is to provide users (who acquire the Originator role) with immediate access to an item/content that provides information about adopting the use of Safe Share products to share data securely. However, any item/content can be chosen for this property. <br />  Be aware that this feature has the following requirements and characteristics:  <br />•  A Covata user account with the Organization administrator role must *also* have the Originator role as the item chosen by the Organization administrator must be one they own. <br />•  All items shared automatically through this feature (regardless of whether the item is a file or a folder) are done so with *Download* permissions. <br />•  This property's current item can be changed by any Organization administrator, regardless of the item's ownership. However, the Organization administrator (modifying this property) can only choose an item they own. <br />•  Once this feature becomes active, existing Covata users in the organization who have the Originator role are not automatically shared this property's current item. However, if one of these users' accounts is [removed](/3.2/admin-platform/administering-users-within-an-organisation#removing-a-user-account-from-your-organisation) from the organization and subsequently added again (with the Originator role), the user's re-added account is automatically shared this property's current item. <br />•  If this property's item is actually located within a folder, then the item will appear at the root level of the items area for users who subsequently acquire the Originator role in the organization. <br />**Notes (and idiosyncrasies) about this feature:**  <br />•  Take caution before setting this item. Once an item has been chosen, this feature becomes permanently 'active' and from this point on, it is no longer possible to deactivate this feature. <br />•  If an Organization administrator chooses a folder for this property, then only the folder itself (i.e. none of its existing content) is automatically shared with users in the organization who subsequently acquire the Originator role. However, if this Organization administrator then adds new items to this folder, the accounts of any users who had previously been shared this folder (automatically through this property/feature) are also be shared these newly added items. This behavior will be reviewed for a future Covata Platform release. <br />•  If this property's item is set to a folder and you wish to remove this particular folder (through a Safe Share product or other client application), change this property to a different item *before* removing this folder. Otherwise, the folder will not be completely removed from Safe Share. This issue will be resolved in a future Covata Platform release.  |
