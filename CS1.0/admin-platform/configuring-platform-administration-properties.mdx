---
title: "Configuring SafeShare Administration properties"
---

The **Configuration** page allows SafeShare administrators to [modify](/CS1.0/admin-platform/configuring-platform-administration-properties#modifying-a-platform-administration-property-value) a restricted set of properties on their Covata Platform instance, which are used to tweak specific functional aspects and the behavior of their Covata Platform instance.

Modifying these properties affects the behavior of SafeShare across all organisations configured on the Covata Platform.

<Note>

Other properties in configuration files can be modified by systems administrator/s responsible for setting up on-site deployments of the Covata Platform.

</Note>

![Configuration/Properties page](/images/c741c6ef94a1-platform-administration-property-configuration-page.png)
## Modifying a SafeShare Administration property value <a id="modifying-a-platform-administration-property-value" />

**To modify a SafeShare Administration property value:**

1. Ensure you are [signed in](/CS1.0/admin-platform/accessing-platform-administration#signing-in-to-platform-administration) to SafeShare Administration.
2. Click the **Configuration** option on the left of the [SafeShare Administration interface](/CS1.0/admin-platform/accessing-platform-administration#the-platform-administration-interface) to open the **Configuration** page.
3. Click the **Edit** link to the right of the relevant [SafeShare Administration property](/CS1.0/admin-platform/configuring-platform-administration-properties#platform-administration-properties).
4. In the **Edit Configuration** dialog box, update the **Property value** field as required.
5. Click **Save** and the value of the SafeShare Administration property is modified with immediate effect. <br />
   **Notes:**

   - For properties whose value consists of a simple `true` or `false`, the **Edit Configuration** dialog box has a **Property Value** check box, which should be selected for `true` or cleared for `false`.
   - It is not possible to modify the names of SafeShare Administration properties, since these are fixed.

## SafeShare Administration properties <a id="platform-administration-properties" />

The following SafeShare Administration properties are available in the following categories.

### User authentication properties

The **User Authentication** properties section allows the configuration of factors that affect how users sign in to SafeShare.

See [Modifying a SafeShare Administration property value](/CS1.0/admin-platform/configuring-platform-administration-properties#modifying-a-platform-administration-property-value) above for instructions on how to modify these properties' values.

| Property | Detailed description |
| --- | --- |
| Minimum password length | The minimum number of characters required for a [Local](/CS1.0/admin-platform/administering-users-within-an-organisation#account-type) user's password. This property has no affect on [LDAP](/CS1.0/admin-platform/administering-users-within-an-organisation#account-type) user's password since the authentication of LDAP users is delegated to their respective LDAP server. |
| Temporary password expiry time in hours | When a new [Local](/CS1.0/admin-platform/administering-users-within-an-organisation#account-type) Covata user account is created, the user receives an email notification containing a temporary password (generated by the Covata Platform), which the user requires to set their own password for their user account. Hence, the value of this property defines the validity of this temporary password. <br />**Note:** If this temporary password expires, the user can still set their password through the Covata Sign-in page by clicking either the **Don't have a password?** or **Forgot your password** button and following the instructions in the resulting email notification sent to their email address.  |
| Maximum number of password retries | <a id="maximum-number-of-password-retries" />The maximum number of incorrect sign-in attempts permitted by a Covata user mistyping their password before the user account becomes locked. The user will need to do one of the following to unlock their account:  <br />•  Follow the instructions in the email notification which is sent to the user after their account is locked. The email notification contains a link to unlock the user's account. The validity of this link is equivalent to the **Account lockout time in minutes** (below). <br />•  Wait until their account is unlocked; the duration of this period is defined by the **Account lockout time in minutes** (below). <br />•  Reset their password by clicking either **Don't have a password?** or **Forgot your password** on the Covata Sign-in page.  |
| Account lockout time in minutes | The amount of time that a Covata user needs to wait before their user account (which was locked as a result of the user mistyping their password beyond the **Maximum number of password retries** above, during sign-in) is automatically unlocked by the Covata Platform. This amount of time also defines the period for which the link to unlock a user's account (contained in the email notification sent to the user) is valid. <br />**Important:** Ensure this value is positive and do not set it to `0` (zero). Setting this value to `0` locks a user account indefinitely (as a result of the user mistyping their password beyond the **Maximum number of password retries** above) and as a SafeShare administrator, increases the risk of you locking yourself out of SafeShare Administration if you mistype your password. If this value was `0` following a Covata Platform upgrade, then change it to a positive value.  |
| Maximum number of email my password retries | <a id="maximum-number-of-email-my-password-retries" />The maximum number of times that a Covata user can click either **Don't have a password?** or **Forgot your password**, be sent an email notification containing either a one-time access link/password or password reset instructions *and* fail to successfully sign in, before their account is locked. <br /> **Notes:**  <br />•  Ensure that this value is positive and do not set it to `0` (zero). Doing so increases your risk (as a SafeShare administrator) of locking yourself out of SafeShare Administration in the event that you mistype your password. <br />•  Although a Covata user may click either **Don't have a password?** or **Forgot your password** successively, an email notification from this action is only sent out at a rate of once every five minutes. This default value is defined by a property that can be modified by system administrators responsible for setting up on-site deployments of the Covata Platform.  |
| Number of character type categories that must appear in a password | <a id="number-of-character-type-categories-that-must-appear-in-a-password" />There are four *categories* of *character types* that can be used in a password:  <br />•  Lower case letters <br />•  Uppercase letters <br />•  Numerals <br />•  Special characters <br />The value of this property determines how many of these four character type categories must be present in a password (whenever it is set) for this password to be valid. For instance:  <br />•  Specifying `1` means that the characters in a password only need to derive from one of the categories above. <br />•  Specifying `2` means that the characters in a password must derive from at least two of these categories, etc.  |
| Two-factor authentication configuration link expiry time in days | When two-factor authentication (2FA) has been enabled on a Covata user account (by the user themselves through [SafeShare for Web](/CS1.0/user/managing-your-account#enabling-or-disabling-2fa-for-your-account), [Organisation Administration](/CS1.0/admin-platform/administering-users-within-an-organisation#enabling-or-disabling-2fa-on-organisation-user-accounts) or SafeShare Administration, by a SafeShare administrator on [any SafeShare administrator's account](/CS1.0/admin-platform/administering-platform-administrator-users#enabling-or-disabling-2fa-for-a-platform-administrator), or by an Organisation administrator for [all members of their organisation](/CS1.0/admin-platform/configuring-organisation-administration-properties#enforce-2fa-for-organisation-members)) the user receives an email notification informing them about this. This email notification contains a time-limited configuration link, which leads to step-by-step instructions for the user to:  <br />•  configure their mobile device with an appropriate authenticator application (aka authenticator app), as well as <br />•  configure the authenticator app with the Covata user account (thereby allowing the app to generate appropriate authentication codes). <br />Hence, the value of this property defines the validity of this configuration link. |
| Allow organisation users to enable Two-factor Authentication | Prevents any Covata user from being able to set 2FA on their account (see the ['My Account' feature of the SafeShare for Web User's Guide](/CS1.0/user/managing-your-account#enabling-or-disabling-2fa-for-your-account) for more information). This also prevents the ability for Organisation administrators to set 2FA for [all members of their organisation](/CS1.0/admin-platform/configuring-organisation-administration-properties#enforce-2fa-for-organisation-members) through Organisation Administration, as well as SafeShare administrators to set 2FA on [any SafeShare administrator's account](/CS1.0/admin-platform/administering-platform-administrator-users#enabling-or-disabling-2fa-for-a-platform-administrator) through SafeShare Administration. |
| Password validity in days | The number of days from the time when a Covata user last changes their password until this user is required to change their password again. <br /> **Note:** For this SafeShare Administration property to take effect, the **Password expiration enabled** property (below) must be set to `true`. |
| Password expiration enabled | Determines whether (i.e. `true`) or not (i.e. `false`) the Covata Platform enforces every Covata user (whose account is registered on the system) to change their password after their **Password validity in days** period has passed. <br /> **Note:** When a Covata user changes their password, the Covata Platform checks to ensure that the user does not specify the same password utilised when last changing their password. However, the Covata Platform neither keeps nor acts upon an historical record of previously used passwords. |

### Analytics properties

The **Analytics** properties section allows the configuration of Google Analytics properties, which collect data on visitor traffic through [SafeShare for Web](/CS1.0/user/index), [Organisation Administration](/CS1.0/admin-platform/organisation-administration) and SafeShare Administration.

See [Modifying a SafeShare Administration property value](/CS1.0/admin-platform/configuring-platform-administration-properties#modifying-a-platform-administration-property-value) above for instructions on how to modify these properties' values.

| Property | Detailed description |
| --- | --- |
| The tracking code used for Google Analytics | The tracking code given to you when you sign up for Google Analytics. <br />**Note:** For Google Analytics to work with your Covata Platform instance, this value must be used in conjunction with **The tracking domain used for Google Analytics** (below).  |
| The tracking domain used for Google Analytics | The domain of your Covata Platform's web server. <br />**Note:** For Google Analytics to work with your Covata Platform instance, this value must be used in conjunction with **The tracking code used for Google Analytics** (above).  |

### Application links properties

The **Application Links** properties section allows the configuration (i.e. exposure) of links to SafeShare client applications, which are better designed for the platform on which the user is currently accessing SafeShare.

See [Modifying a SafeShare Administration property value](/CS1.0/admin-platform/configuring-platform-administration-properties#modifying-a-platform-administration-property-value) above for instructions on how to modify these properties' values.

| Property | Detailed description |
| --- | --- |
| Show smart banner on iOS devices linking to the native iOS client | Sets a 'flag' on the Covata Platform which results in a smart banner appearing at the top of [SafeShare for Web](/CS1.0/user/index) pages whenever it is accessed through Safari on iOS devices. This encourages users of iOS devices who have clicked a direct URL to an item from '*New items have been shared with you*' email notification (which opens the item in SafeShare for Web) to access the item in SafeShare for iOS instead (by clicking the link in the smart banner). |

### Notifications properties

The **Notifications** properties section allows the configuration of the types and behavior of email notifications sent by the Covata Platform.

See [Modifying a SafeShare Administration property value](/CS1.0/admin-platform/configuring-platform-administration-properties#modifying-a-platform-administration-property-value) above for instructions on how to modify these properties' values.

| Property | Detailed description |
| --- | --- |
| Item shared notification frequency in minutes | The time interval defining the frequency with which email notifications for shared items (i.e. '*New items have been shared with you*') are sent by the Covata Platform. <br />**Note:** If any given Covata user has multiple items shared with them during one of these time intervals, the user will receive a single email notification (at the end of the interval) listing all the items that were shared with them since the previous interval/notification they received.  |
| User adoption notification reminder frequency in days | The number of days between each of a series of user adoption email notifications being sent out to [new Covata users](/CS1.0/admin-platform/administering-users-within-an-organisation#adding-an-organisation-user-account) with the [Originator role](/CS1.0/admin-platform/administering-users-within-an-organisation#originator-role). See the **User adoption notification reminder enabled** property's description (below) for more information about these types of email notifications. <br />**Notes:** For this SafeShare Administration property to take effect, the **User adoption notification reminder enabled** property (below) must be set to `true`.  |
| User adoption notification reminder enabled | Determines whether (i.e. `true`) or not (i.e. `false`) the Covata Platform sends a series of user adoption email notifications to [new Covata users](/CS1.0/admin-platform/administering-users-within-an-organisation#adding-an-organisation-user-account) with the [Originator role](/CS1.0/admin-platform/administering-users-within-an-organisation#originator-role). Each of these email notifications contain tips and information to encourage these new Covata users to use SafeShare applications (for example, how to share data using these applications). <br /> **Notes:**  <br />•  There are a series of four user adoption email notifications which are sent out at a frequency defined by the **User adoption notification reminder frequency in days** property (above). The *user adoption email notification period* is defined as the number of different user adoption email notifications (four) multiplied by the **User adoption notification reminder frequency in days** property value (15 days by default), which is a default of 60 days. <br />•  User adoption email notifications are only sent out to new Covata user accounts *from the time their account is first created* (either through [SafeShare Administration](/CS1.0/admin-platform/administering-platform-administrator-users#adding-a-platform-administrator-account) or [Organisation Administration](/CS1.0/admin-platform/administering-users-within-an-organisation#adding-an-organisation-user-account)). If a Covata user with an existing account is added to a new/different organisation (even with the [Originator role](/CS1.0/admin-platform/administering-users-within-an-organisation#originator-role)), they do not receive any user adoption email notifications. <br />•  If an existing Covata user is granted the Originator role for the first time (within any organisation), they do not receive any user adoption email notifications unless their user account was granted the Originator role within the *user adoption email notification period* of their account's creation date. If so, such a user would receive user adoption email notifications for the trailing part of this period.  |
| Registered user summary enabled | Determines whether (i.e. `true`) or not (i.e. `false`) the Covata Platform sends a 'snapshot' summary of users (on the 1st of each month) to the email addresses specified in the **Registered user summary email addresses (comma separated)** property below. This summary is useful for billing purposes and consists of the following information *for each organisation* on the Covata Platform:  <br />•  The total number of Covata user accounts (in the organisation). <br />•  The total number of Covata user accounts with the [Originator](/CS1.0/admin-platform/administering-users-within-an-organisation#originator-role), [Collaborator](/CS1.0/admin-platform/administering-users-within-an-organisation#collaborator-role) and [Ad hoc](/CS1.0/admin-platform/administering-users-within-an-organisation#adhoc-role) roles. Users with the Collaborator role are separated into the two [Account Type](/CS1.0/admin-platform/administering-users-within-an-organisation#account-type) categories **Local** and **External**. <br />•  The 'total quota', which is the amount of storage currently allocated to users with the Originator role in the organisation (i.e. the sum of all these users' quotas, based on the users' plans). <br />•  The total 'used quota', which is the total amount of storage currently utilised by Covata users in the organisation. <br />**Notes:**  <br />•  For this SafeShare Administration property to take effect, the **Registered user summary email addresses (comma separated)** property (below) must contain at least one email address. <br />•  By default, this user summary is configured to be sent on the 1st of each month. The frequency with which this email is sent can be changed through a configuration file property (by the systems administrator/s who set up your on-site deployment of the Covata Platform instance).  |
| Registered user summary email addresses (comma separated) | One or more email addresses to which the user summary (activated through the **Registered user summary enabled** property above) is sent by the Covata Platform. Separate multiple email addresses using a comma only. <br />**Notes:** <br />•  For this SafeShare Administration property to take effect, the **Registered user summary enabled** property (above) must be set to `true`. <br />•  Any email address specified in this property *does not need to correspond* to a registered Covata user account on the Covata Platform.  |

### System details properties

The **System Details** section allows the configuration of text and URLs, which are used to customise:

- the application and company names + support and help URLs for:

  - [SafeShare for Web](/CS1.0/user/index) (+ SafeShare Administration and Organisation Administration) and
  - Covata Notification email messages,

  as well as,
- the copyright notice appearing at the base of Covata Notification email messages

See [Modifying a SafeShare Administration property value](/CS1.0/admin-platform/configuring-platform-administration-properties#modifying-a-platform-administration-property-value) above for instructions on how to modify these properties' values.

<Note>

- Please be aware that any modifications to any of these properties apply to *all organisations* configured on the Covata Platform.
- For more information about customising the appearance of SafeShare, refer to [Theming SafeShare's web-based interfaces](/CS1.0/admin-platform/theming-the-applications-web-based-interfaces) in the [Appendix](/CS1.0/admin-platform/appendix) of this guide.
