---
title: "Accessing secure content"
---

To access secure content, you can:

- [View, print](/3.5/user/accessing-secure-content#viewing-and-printing-content) or [download](/3.5/user/accessing-secure-content#downloading-secure-content) personally owned files which you had previously uploaded and stored securely with [SafeShare for Web](/3.5/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content), including SafeShare for [Windows](/3.5/windows/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content), OS X, iOS and Android applications. These actions can also be performed on files that another user uploaded to your folder with any of these SafeShare applications.
- [View](/3.5/user/accessing-secure-content#viewing-and-printing-content) files which someone else has stored securely and shared with you using [SafeShare for Web](/3.5/user/uploading-storing-and-sharing-content-securely#sharing-secure-content), including SafeShare for [Windows](/3.5/windows/uploading-storing-and-sharing-content-securely#sharing-secure-content), OS X, iOS and Android applications. You can only [print](/3.5/user/accessing-secure-content#viewing-and-printing-content) or [download](/3.5/user/accessing-secure-content#downloading-secure-content) these files if the people who shared the files have granted you permission to perform these actions. These actions can also be performed on files that you uploaded to share through another user's folder with any of these SafeShare applications.

## Viewing and printing content

SafeShare for Web has a [content viewer](/3.5/user/accessing-secure-content#content-viewer) which allows you to view and optionally print secured files that other people have [shared with you](/3.5/user/uploading-storing-and-sharing-content-securely#sharing-secure-content), as well as personally owned files which [you](/3.5/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) or [someone else](/3.5/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) had previously uploaded. (See [File formats supported by the content viewer](/3.5/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) for a list of file types that the content viewer supports.)

If files have been shared with you, then your ability to view and/or print + download these files is based on the [permissions](/3.5/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) that were granted to you as a collaborator on these files. The content viewer is useful when the owner of a file (or a collaborator with **Co-Owner** permissions on it) wants to share the file's content but not allow the content to be printed and downloaded.

**To view and print secure content:**

If you sign in to SafeShare for Web via a link provided in a 'file has been shared with you' email message, you are taken directly to the file's [content viewer](/3.5/user/accessing-secure-content#content-viewer) (below). Otherwise...

1. Ensure you are [signed in](/3.5/user/signing-in) to SafeShare for Web.
2. If the Home icon at the top-left (followed by your current organisation's name) has no drop-down icon indicated, then you are a member of only one organisation. Therefore, you can skip to the [next step](/3.5/user/accessing-secure-content#locating-your-item-to-view-and-print). <br />
   *Otherwise*, the name of your current organisation is indicated, from which you can either:

   - skip to the [next step](/3.5/user/accessing-secure-content#locating-your-item-to-view-and-print) to continue with viewing/printing a file from this organisation, or
   - view/print a file from a different organisation (you are a member of) by [changing your organisation](/3.5/user/uploading-storing-and-sharing-content-securely#changing-organisations) before continuing on.
3. <a id="locating-your-item-to-view-and-print" />[Locate](/3.5/user/managing-secure-content#finding-secure-content) the file to view/print.
4. Do one of the following to begin viewing this file:

   - *Right-click on the file's row* and choose **View** from the pop-up menu:

     ![Right-clicking a file as a collaborator with Manage permissions - context menu](/images/a969e2e03c28-right-clicking-a-file-context-menu-collaborator-modify.png)

     <br />
     **Note:** This menu option will not be available if it is not possible to view/print this type of file from a SafeShare content viewer. See [File formats supported by the content viewer](/3.5/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) for a list of file types that the [content viewer](/3.5/user/accessing-secure-content#content-viewer) supports. Instead, you will only be able to [download](/3.5/user/accessing-secure-content#downloading-secure-content) the file to access its content. If the file (or one of its ancestral folders) has been [shared with you](/3.5/user/uploading-storing-and-sharing-content-securely#sharing-secure-content), then you can only download the file if you were granted any permissions other than **View** (which in itself does not grant the individual *download* permission). (The **Access** field's value within the **File Details** section of the **Details** tab shows your current permissions on the file.) <br />
     *OR*

   1. Either *focus* on the item, by hovering your mouse pointer over the item's row, or *select* the item, by clicking on the item's row (to the right of its name if a folder): <br />
      ![Selecting an item as a collaborator with Manage permissions](/images/8d1a85af1dc1-selecting-an-item-collaborator-modify.png)
   2. If you:

      - *Focussed* on the item, click the 'View' icon
        ![View icon](/images/2d867cdd824a-view-icon.png)

         in its row.
      - *Selected* the item, click the 'View' icon
        ![View icon](/images/2d867cdd824a-view-icon.png)

         either in its row or the right-side of the toolbar near the top of the page.

      Note that the View icons will not be available if it is not possible to open this file in the content viewer; [downloading](/3.5/user/accessing-secure-content#downloading-secure-content) this file is your only option to access the file's content. (See also [File formats supported by the content viewer](/3.5/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) for a list of file types that the content viewer supports.)

   **Tip:** If navigating to a file in a folder (by having clicked through one or more folder names), then in the breadcrumb (e.g.

   ![Breadcrumb](/images/d379d8b652db-breadcrumb.png)

    ) near the top of the main SafeShare page, you can click the:

   - The linked name of your current organisation to go to the root location of your file area.
   - Ellipsis symbol ('...') to expand the entire folder hierarchy (i.e. to reveal **Shared Folder** in the example above), since only the root and current (i.e. **Other** above) folder locations are indicated after each change in folder location.
   - Link of a parent folder's name (i.e. **Shared Folder** from **Other** above) to go to that folder's location.

   <a id="content-viewer" /> The content viewer opens, showing a read-only view of your file's content:

   - If your file is an image, the content viewer and its controls will look similar to this: <br />
     ![Content viewer for image files](/images/873008625675-content-viewer-image.jpg)
   - If your file is a document-like file (i.e. which may contain more than one page), the content viewer and its controls will look similar to this: <br />
     ![Content viewer for document files](/images/d28487aa868b-content-viewer-document.jpg)

   **Tips on using the content viewer:**

   - Click the 'Print' icon
     ![Print icon](/images/e875848c94db-content-viewer-print-icon.png)

      on the content viewer to print the file's content. <br />
     **Note:** This icon will be disabled if you are a collaborator on the file being viewed (see [Sharing secure content](/3.5/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)) *and* you were only granted **View** permissions on the file, which does not grant the individual *print* permission that allows you to print it directly from the content viewer.
   - Click the 'Download' icon
     ![Download icon](/images/0f12cf402ea9-content-viewer-download-icon.png)

      on the content viewer to download the file's content, which can also be performed from the [main SafeShare page](/3.5/user/accessing-secure-content#downloading-secure-content). <br />
     **Note:** This icon will not be available if you are a collaborator on the file being viewed *and* you were only granted **View** permissions on the file, which also does not grant the individual *download* permission that allows you to download the file's content.
   - If you are viewing an image file, click the 'Toggle scaled or actual size of image' icon
     ![Toggle between scaled and actual size icon](/images/43764e011ef8-content-viewer-toggle-scaled-actual-size-icon.png)

      on the content viewer to switch between viewing the image in its entirety (i.e. scaled) or at its actual/original size.
   - The following features are only available when viewing document-like files:

     - Use the 'Zoom In' (plus) and 'Zoom Out' (minus) icons to zoom in and out of the content view. The adjacent drop-down can also be used to select an appropriate zoom level.
     - Click the 'Switch To Presentation Mode' icon
       ![Full screen icon](/images/01ea2c7eafe6-content-viewer-presentation-mode-icon.png)

        to expand the size of the content to fill the entire screen (using the web browser's own 'full screen' feature). <br />
       **Note:** Some web browsers may not support this feature (e.g. Safari) and therefore, clicking this icon has no effect.
     - If your content consists of multiple pages, you can navigate to different pages by:

       - Clicking the 'Next page' (down arrow) and 'Previous Page' (up arrow) icons to respectively move forward and back one page at a time.
       - Clicking the 'Toggle sidebar' icon
         ![Toggle sidebar icon](/images/78354dc3e80a-content-viewer-toggle-sidebar-icon.png)

          to open the sidebar on the left of the content viewer and in this sidebar, scrolling to and clicking the corresponding thumbnails for specific pages.
       - Typing a page number in the **Page** field (followed by the 'return/enter' key).
     - Click the 'Tools' icon
       ![Tools icon](/images/b02486c7a3a6-content-viewer-tools-icon.png)

        to open a drop-down menu of additional controls:

       - Jump/go to the first and last pages of content (consisting of multiple pages).
       - Rotate content clockwise and counterclockwise.
       - Enable/disable the hand/move tool.
   - To go back to the main SafeShare page, click the **x** at the top-right of the content viewer.

<Note>

- You can view and print different versions of a file (see [Managing file versions](/3.5/user/managing-file-versions) for details). To do so, [access the other versions of a file](/3.5/user/managing-file-versions#accessing-other-versions-of-a-file) first, from which you can then [view and print the file's other versions](/3.5/user/managing-file-versions#viewing-and-downloading-another-version-of-a-file).
- If (one of) your organisation's SafeShare Organisation administrator/s has enabled the watermarking feature through SafeShare Organisation Administration properties, then when you view a file's content (as a collaborator on this file) through the content viewer, you will observe a watermark covering (each page of) the file's content. The watermarking feature:

  - Is intended to discourage collaborators from copying file views by other means (e.g. using screenshot capturing tools, etc).
  - Covers a file's view with large semi-transparent text that consists of the email address of the currently signed-in collaborator viewing the file, the Covata Platform's URL, the ID of the file/Secure Object, the classification applied to the file by its owner (if applicable) and the date/time when the file was viewed.

  For more information about this feature and SafeShare SafeShare Organisation Administration properties, see [Configuring SafeShare Organisation Administration properties](/3.5/admin-org/configuring-organisation-administration-properties) in the [Organisation Administrator's Guide](/3.5/admin-org/index).

</Note>

## File formats supported by the content viewer

The SafeShare for Web [content viewer](/3.5/user/accessing-secure-content#content-viewer) supports the following file formats, which are determined by file name extensions:

| File-type category | Supported file formats (file name extensions) |
| --- | --- |
| Image files | bmp, gif, jpeg, jpg, png |
| Word processing/text documents | doc, docx, html, mhtml, odt, ooxml, rtf, txt, xhtml, xml |
| Documents with static content | pdf |
| Presentation files | odp, pot, potx, pps, ppsx, ppt, pptx |
| Spreadhsheet/data files | csv, ods, xls, xlsb, xlsm, xlsx, xltm, xltx, xlxm |

## Downloading secure content

This procedure explains how to download:

- a single file,
- a selection of files from the items area, as well as
- a single folder and its immediate child items (i.e. excluding the contents of any subfolders within this folder).

<Note>

This feature is not available if you are a collaborator on the file (see [Sharing secure content](/3.5/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)) *and* you have been granted **View** [permissions](/3.5/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) (which, unlike the other permissions, does not grant you the individual *download* permission).

</Note>

**To download secure content:**

1. Ensure you are [signed in](/3.5/user/signing-in) to SafeShare for Web.
2. If the Home icon at the top-left (followed by your current organisation's name) has no drop-down icon indicated, then you are a member of only one organisation. Therefore, you can skip to the [next step](/3.5/user/accessing-secure-content#locating-your-item-to-download). <br />
   *Otherwise*, the name of your current organisation is indicated, from which you can either:

   - skip to the [next step](/3.5/user/accessing-secure-content#locating-your-item-to-download) to continue with downloading an item from this organisation, or
   - download an item from a different organisation (you are a member of) by [changing your organisation](/3.5/user/uploading-storing-and-sharing-content-securely#changing-organisations) before continuing on.
3. <a id="locating-your-item-to-download" />[Locate](/3.5/user/managing-secure-content#finding-secure-content) the file/s or folder to download.
4. If downloading:

   - *Either a single file or a single folder*, do one of the following to begin downloading this item:

     - *Right-click on the file's row* and choose **Download** from the pop-up menu:

       ![Right-clicking a file as an owner - context menu](/images/1cdc599f411b-right-clicking-a-file-context-menu-owner.png)

       <br />
       **Note:** If this menu option is not available, then it is not possible to download this item since you were only granted **View** permissions when the item (or one of its ancestral folders) was [shared with you](/3.5/user/uploading-storing-and-sharing-content-securely#sharing-secure-content). (The **Access** field's value within the **File Details** section of the **Details** tab shows your current permissions on the item.) <br />
       *OR*

     1. Either *focus* on the item, by hovering your mouse pointer over the item's row, or *select* the item, by clicking on the item's row (to the right of its name if a folder): <br />
        ![Selecting an item as its owner](/images/706a7373e68e-selecting-an-item-owner.png)
     2. If you:

        - *Focussed* on the item, click the 'Download' icon
          ![Download icon](/images/895e98c86ac0-download-icon.png)

           in its row.
        - *Selected* the item, click the 'Download' icon
          ![Download icon](/images/895e98c86ac0-download-icon.png)

           either in its row or the right-side of the toolbar near the top of the page.

        Note that this option will not be available if you are a collaborator on the item (see [Sharing secure content](/3.5/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)) *and* you were only granted **View** permissions on the item.
   - *A selection of files from the items area,* select two or more files to download from the items area (as you would for a single item above although hold down the 'shift'/'control'/'command' key to allow the selection of multiple items) and click the 'Download' icon
     ![Download icon](/images/895e98c86ac0-download-icon.png)

      (right-side of the toolbar near the top of the page).

   The item is downloaded through your web browser's usual download feature. If you chose multiple files (by downloading either a folder or a selection of files from the items area), then the files are zipped to a file whose name is that of the (parent) folder itself, or simply 'Home' (if a selection of files at the root level were downloaded). <br />
   **Tips:**

   - You can also download a file's content through the [content viewer](/3.5/user/accessing-secure-content#content-viewer).
   - To download the entire contents of a folder, including its subfolders, you need to download each subfolder in a separate action. Be aware that downloading a folder only includes all immediate files within that folder - files within any subfolders of this folder are not included.
   - You can download different versions of a file (see [Managing file versions](/3.5/user/managing-file-versions) for details). To do so, [access the other versions of a file](/3.5/user/managing-file-versions#accessing-other-versions-of-a-file) first, from which you can then [download the file's other versions](/3.5/user/managing-file-versions#viewing-and-downloading-another-version-of-a-file).
