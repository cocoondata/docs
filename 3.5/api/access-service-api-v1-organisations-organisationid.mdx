## URL structure <a id="access-service-api-v1-organisations-organisationid-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{organisationId}
```

where `{organisationId}` is the ID of an organisation.

## Supported methods and overview <a id="access-service-api-v1-organisations-organisationid-supported-methods-and-overview" />

- `DELETE` - removes an organisation (specified by `organisationId`) configured on the Covata Platform (available to SafeShare administrators only) on the proviso that this organisation has an existing request for its removal (made by another SafeShare administrator).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-organisationid-detailed-description" />

This API endpoint removes an organisation (specified by `organisationId`) configured on the Covata Platform by a SafeShare administrator.

For a request to this endpoint to succeed, a previous call to [&lt;access-service&gt;/api/v1/organisations/\{organisationId\}/removalRequest](/3.5/api/access-service-api-v1-organisations-organisationid-removalrequest) (i.e. to initiate a request to remove this organisation) must have already been made by another SafeShare administrator whose [access token was submitted in the request to that API endpoint](/3.5/api/access-service-api-v1-organisations-organisationid-removalrequest#access-service-api-v1-organisations-organisationid-removalrequest-supported-roles).

<Tip>

To determine if an organisation has an existing request for its removal, use the [&lt;access-service&gt;/api/v1/organisations](/3.5/api/access-service-api-v1-organisations) API endpoint to retrieve information about organisations configured on the Covata Platform and if the required organisation's `organisationRemovalRequest` member is not `null` and contains sub-members, then the organisation has an existing request for its removal.

</Tip>

## Supported roles and conditions <a id="access-service-api-v1-organisations-organisationid-supported-roles-and-conditions" />

This API endpoint supports the following Covata user [roles](/3.5/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [SafeShare Administrator's Guide](/3.5/admin-platform/index)):

- [SafeShare administrator](/3.5/admin-platform/administering-platform-administrator-users#platform-administrator-role) - when this user is a different SafeShare administrator to the one who [initiated the request to remove this organisation](/3.5/api/access-service-api-v1-organisations-organisationid-removalrequest).

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.5/api/access-service-api-v1-organisations-organisationid#access-service-api-v1-organisations-organisationid-required-headers) of requests to this endpoint.
