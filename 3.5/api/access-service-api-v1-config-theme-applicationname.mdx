## URL structure <a id="access-service-api-v1-config-theme-applicationname-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/applicationName
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-applicationname-supported-methods-and-overview" />

- `PUT` - sets the **Application Name** property (accessible through the [System Details](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the [Configuration](/3.5/admin-platform/configuring-platform-administration-properties) page of SafeShare Administration).

## Detailed description <a id="access-service-api-v1-config-theme-applicationname-detailed-description" />

This API endpoint sets the **Application Name** property (accessible through the **System Details** section of the **Configuration** page of SafeShare Administration).

The current value of this property can be obtained using the [&lt;access-service&gt;/theme...](/3.5/api/access-service-theme) API endpoint.

## Supported roles <a id="access-service-api-v1-config-theme-applicationname-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.5/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [SafeShare Administrator's Guide](/3.5/admin-platform/index)):

- [SafeShare administrator](/3.5/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.5/api/access-service-api-v1-config-theme-applicationname#access-service-api-v1-config-theme-applicationname-required-headers) of requests to this endpoint.

## Required body <a id="access-service-api-v1-config-theme-applicationname-required-body" />

Specify the **Application Name** property value in the **body** of the request as **plain text**.

## Returns <a id="access-service-api-v1-config-theme-applicationname-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
