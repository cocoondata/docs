---
title: "File content handling endpoints"
---

The endpoints in this section are used for handling the content of files (i.e. [Secure Objects](/3.5/api/working-with-files-and-folders-fundamentals#secure-object)) on the Covata Platform, including file versions.

### File object content handling (new file objects and active file versions)

- **Content upload and download**

  - [&lt;content-service&gt;/api/v1/objects/\{objectId\}/contents](/3.5/api/content-service-api-v1-objects-objectid-contents)
- **'Read-only view' download and regeneration**

  - [&lt;content-service&gt;/api/v1/objects/\{objectId\}/view](/3.5/api/content-service-api-v1-objects-objectid-view)

### File version content handling

- **File version creation and content upload**

  - [&lt;content-service&gt;/api/v1/objects/\{objectId\}/versions](/3.5/api/content-service-api-v1-objects-objectid-versions)
- **Content download**

  - [&lt;content-service&gt;/api/v1/versions/\{versionId\}/contents](/3.5/api/content-service-api-v1-versions-versionid-contents)
- **'Read-only view' download**

  - [&lt;content-service&gt;/api/v1/versions/\{versionId\}/view](/3.5/api/content-service-api-v1-versions-versionid-view)
