## URL structure <a id="access-service-api-v1-objects-objectid-versions-versionid-url-structure" />

```text
https://access-service.xy-company.com/api/v1/objects/{objectId}/versions/{versionId}
```

where `{objectId}` is the ID of a file object/Secure Object and `{versionId}` is the ID of one of its versions.

## Supported methods and overview <a id="access-service-api-v1-objects-objectid-versions-versionid-supported-methods-and-overview" />

- `PUT` - sets the active version (specified by `versionId`) of a file object/[Secure Object](/3.5/api/working-with-files-and-folders-fundamentals#secure-object) (specified by `objectId`).
- `DELETE` - deletes a version (specified by `versionId`) of a file object (specified by `objectId`), permanently.

<Note>

Both of these methods take no other parameters.

</Note>

## Detailed description <a id="access-service-api-v1-objects-objectid-versions-versionid-detailed-description" />

This API endpoint serves a number of purposes:

- Sets the active version (specified by `versionId`) of a file object (specified by `objectId`).
- Deletes a version (specified by `versionId`) of a file object (specified by `objectId`), permanently. <br />
  **Note:** A successful request using this method also deletes this version's content (via the Covata Platform's Content Service) automatically.

## Supported roles and conditions <a id="access-service-api-v1-objects-objectid-versions-versionid-supported-roles-and-conditions" />

This API endpoint supports requests utilising Covata user accounts with the following [roles](/3.5/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organisation Administrator's Guide](/3.5/admin-org/index)) and conditions:

- [Originator](/3.5/admin-org/administering-users-within-an-organisation#originator-role) - when this user owns the file object whose ID is specified by `{itemId}` in the request's URL.
- **Originator**, [Collaborator](/3.5/admin-org/administering-users-within-an-organisation#collaborator-role) and [Ad hoc](/3.5/admin-org/administering-users-within-an-organisation#adhoc-role) - when this user is a collaborator with the **Rename** [permission](/3.5/api/access-service-api-v1-permissions-sets) on the file object whose ID is specified by `{itemId}` in the URL. (The **Rename** permission restricts access to collaborators who have been applied either the **Modify** or **Manage** *permission set* on this file object.)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.5/api/access-service-api-v1-objects-objectid-versions-versionid#access-service-api-v1-objects-objectid-versions-versionid-required-headers) of requests to this endpoint.
