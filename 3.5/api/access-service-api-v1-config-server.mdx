## URL structure <a id="access-service-api-v1-config-server-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/server
```

## Supported methods and overview <a id="access-service-api-v1-config-server-supported-methods-and-overview" />

- `GET` - retrieves a list of information for all configurable [SafeShare Administration-only properties](/3.5/admin-platform/configuring-platform-administration-properties) (not related to theming SafeShare's interfaces).

## Detailed description <a id="access-service-api-v1-config-server-detailed-description" />

This API endpoint retrieves a list of information for all configurable properties SafeShare Administration-only properties which are not related to theming SafeShare's interfaces.

<Note>

- For properties related to theming SafeShare's interfaces, see [&lt;access-service&gt;/theme...](/3.5/api/access-service-theme).
- From a security perspective, with the exception of the current values of the following few Covata Administration properties returned by this API endpoint's [response](/3.5/api/access-service-api-v1-config-server#access-service-api-v1-config-server-returns), no information about any of the other properties (returned in this response) are contained within the [&lt;access-service&gt;/api/v1/config](/3.5/api/access-service-api-v1-config) endpoint's [response](/3.5/api/access-service-api-v1-config#access-service-api-v1-config-returns):

  - **analytics.google.trackingCode**
  - **analytics.google.trackingDomain**
  - **require.login.on.launch**

</Note>

## Supported roles <a id="access-service-api-config-server-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.5/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [SafeShare Administrator's Guide](/3.5/admin-platform/index)):

- [SafeShare administrator](/3.5/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Covata Platform's resources available to a Covata user meeting the criteria above is determined by the access token submitted in the [header](/3.5/api/access-service-api-v1-config-server#access-service-api-v1-config-server-required-headers) of requests to this endpoint.

## Optional parameters <a id="access-service-api-v1-config-server-optional-parameters" />

The following optional parameters can be sent in the **URL** of the GET request:

- **limit** - An integer value from `0` to `100`, representing the maximum number of items to be returned in the response from the Covata Platform, where an individual item is information about a configurable SafeShare Administration-only property (not related to theming SafeShare's interfaces). If this parameter is omitted, then its value is `0` by default.
- **offset** - A value representing the count order of all retrievable items (i.e. configurable SafeShare Administration-only properties) from the Covata Platform returned in the response. Calls to this API endpoint may amount to potentially large numbers of items being returned from the Covata Platform. This **offset** parameter provides pagination for items returned in responses, allowing items to be retrieved from any count greater than `0` (i.e. the first item returned in a response). If this parameter is omitted, then its value is `0` by default. <br />
  **Example (request):**

  ```text
  https://access-service.xy-company.com/api/v1/config/server
  ```
