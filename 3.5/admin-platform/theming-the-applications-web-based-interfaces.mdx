---
title: "Theming SafeShare's web-based interfaces"
---

Themes allow the color schemes and logos utilised throughout [SafeShare for Web](/3.5/user) user interface to be customised for individual [organisations](/3.5/user#organisations), where each individual organisation is associated with its own theme. (For more information about adding/configuring organisations through [SafeShare Administration](/3.5/admin-platform#platform-administration), see [Administering organisations](/3.5/admin-platform/administering-organisations).)

In this version of SafeShare and the Covata Platform, themes are generated using an separate tool (the [Covata/WebApp Theme Builder](https://www.npmjs.com/package/covata-theme-builder)), which is developed by Covata and is available as a locally executable [npm package](https://www.npmjs.com/).

These color scheme and logo customisations are also utilised throughout:

- the [Organisation Administration](/3.5/admin-platform/organisation-administration) interface,
- the [SafeShare Administration](/3.5/admin-platform#platform-administration) interface, as well as
- email notifications sent out by the Covata Platform.

Newly installed instances of SafeShare are pre-packaged with the *Covata default theme*. This theme is initially used for all organisations' SafeShare for Web and Organisation Administration interfaces, email notifications, as well as the SafeShare Administration interface.

Using the WebApp Theme Builder tool, you can generate different themes - one for each organisation - as well as your own default theme (aka the 'system' theme), which is used for:

- any organisation that does not have a theme defined for it,
- the SafeShare Administration interface and
- the [My Account](/3.5/user/managing-your-account) feature.

Visit the [covata-theme-builder page](https://www.npmjs.com/package/covata-theme-builder) (on the npm web site) for more information about obtaining and using the WebApp Theme Builder tool, as well as deploying themes to a Covata Platform instance.

<Note>

Other customisable aspects of SafeShare, such as the Application Name, as well as the Company Name and Copyright Notice that appear in email notifications, are configurable through the [System details properties](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the **Configuration** [page](/3.5/admin-platform/configuring-platform-administration-properties) of SafeShare Administration. However, the Company Name can be customised for each organisation (through the **Configuration** [page](/3.5/admin-platform/configuring-organisation-administration-properties) of Organisation Administration).

</Note>

<Note>

Email notifications are themed according to the SafeShare 'area' to which the notification's content is related. <br />
 For example, email notifications about activities conducted through:

- SafeShare Administration, such as the addition of a SafeShare administrator user account, use the system theme.
- Organisation Administration, such as the removal of a Covata user account from an organisation, use the organisation's theme. <sup>&#42;</sup>
- Activities conducted through any SafeShare application, such as sharing an item with another person, use the theme of the recipient's home/default organisation. <sup>&#42;</sup> This principle also applies to a person who is not yet registered on the Covata Platform (i.e. this person's account is created and added to an organisation as a result of them being shared an item by an existing Covata user in that organisation).

<sup>&#42;</sup> If an organisation's theme were not defined, then such notifications would instead use the system theme.

</Note>
