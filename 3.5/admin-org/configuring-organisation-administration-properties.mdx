---
title: "Configuring SafeShare Organisation Administration properties"
---

The **Configuration** page allows Organisation administrators to [modify](/3.5/admin-org/configuring-organisation-administration-properties#modifying-an-organisation-administration-property-value) a restricted set of organisation-specific properties that tweak the specific functional aspects and the behavior of their organisation on the Covata Platform.

![Configuration/Properties page](/images/bab05926d539-organisation-administration-property-configuration-page.png)
## Modifying a SafeShare Organisation Administration property value <a id="modifying-an-organisation-administration-property-value" />

**To modify a SafeShare Organisation Administration property value:**

1. Ensure you are [signed in](/3.5/admin-org/accessing-organisation-administration#signing-in-to-organisation-administration) to SafeShare Organisation Administration.
2. Click the **Configuration** option on the left of the [SafeShare Organisation Administration interface](/3.5/admin-org/accessing-organisation-administration#the-organisation-administration-interface) to open the **Configuration** page.
3. Click the **Edit** link to the right of the relevant [SafeShare Organisation Administration property](/3.5/admin-org/configuring-organisation-administration-properties#organisation-administration-properties).
4. In the **Edit Config Property** dialog box, update the **Property value** field as required.
5. Click **Save** and the value of the SafeShare Organisation Administration property is modified with immediate effect. <br />
   **Notes:**

   - For properties whose value consists of a simple `true` or `false`, the **Edit Config Property** dialog box has a **Property Value** check box, which should be selected for `true` or cleared for `false`.
   - It is not possible to modify the names of SafeShare Organisation Administration properties, since these are fixed.

## SafeShare Organisation Administration properties <a id="organisation-administration-properties" />

The following SafeShare Organisation Administration properties are available:

| Property | Detailed description |
| --- | --- |
| Organisation Admin Email | <a id="org-admin-email" />The contact email address, typically for an [Organisation administrator](/3.5/admin-org/administering-users-within-an-organisation#organisation-administrator-role), which is:  <br />•  used in Covata Notification email messages and <br />•  is accessible from the **Need help? ...** link on the **Authentication code** entry page for two-factor authentication (2FA) whenever a [Covata user with 2FA enabled](/3.5/admin-org/administering-users-within-an-organisation#enabling-or-disabling-2fa-on-organisation-user-accounts) on their account [signs in](/3.5/user/signing-in) through the Covata Sign-in page. <br />If a Covata user cannot successfully sign in (typically due to the user losing the ability to generate authentication codes for their 2nd authentication factor), the user can click this **Need help? ...** link to begin emailing their Organisation administrator a request to [re-configure 2FA for their user account](/3.5/admin-org/administering-users-within-an-organisation#re-configuring-2fa-for-an-organisation-user-account). <br />  See [Administering users within an organisation](/3.5/admin-org/administering-users-within-an-organisation) for more information. <br /> **Notes:**  <br />•  This property's default value is empty. In such circumstances, the **Admin Email** property's value (defined through [System details properties](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) - see [Configuring SafeShare Administration properties](/3.5/admin-platform/configuring-platform-administration-properties) in the [SafeShare Administrator's Guide](/3.5/admin-platform) for more information), is used as the fallback. <br />•  2FA is enabled by the user themselves for their own account through [SafeShare for Web](/3.5/user/managing-your-account#enabling-or-disabling-2fa-for-your-account), [Organisation Administration](/3.5/admin-org/administering-users-within-an-organisation#enabling-or-disabling-2fa-on-organisation-user-accounts) or SafeShare Administration interfaces, or by an Organisation administrator for [all members of their organisation](/3.5/admin-org/configuring-organisation-administration-properties#enforce-2fa-for-organisation-members).  |
| Is the address book feature enabled? | <a id="address-book-feature" />Determines whether (i.e. `true`) or not (i.e. `false`) the organisation's address book feature is enabled. <br />  The address book feature allows a user to discover (through autocompletion) other Covata user members within their organisation by the user typing the first few characters of a member account's email address, when sharing an item. If this property's value is:  <br />•  `true`, this discovery feature will be scoped to all Covata user accounts that are members of the organisation, as well as all of the user's own contacts. <br />•  `false`, this discovery feature will be scoped only to all of the user's own contacts.  |
| A brief description of the organisation | As the name of this property indicates. This field's purpose is only to provide Organisation administrators with additional information about their organisation. Be aware that this description is not displayed anywhere else throughout the interfaces of Organisation Administration and SafeShare applications (including SafeShare Administration). |
| The email address of the organisation's contact person | <a id="organisations-contact-person" />As the name of this property indicates. This property's purpose is to provide SafeShare administrators with the email address of the organisation's contact person, which appears in the **Contact Person** column on the **Organisations** page of [SafeShare Administration](/3.5/admin-platform). Be aware that this contact person:  <br />•  is initially the email address of the Organisation administrator set when a SafeShare administrator added the organisation to the Covata Platform, <br />•  is not displayed anywhere else throughout the interfaces of Organisation Administration and SafeShare applications, and <br />•  cannot be cleared. <br />**Notes:**  <br />•  This property is useful for allowing SafeShare administrators of your Covata Platform instance to contact (by email) the appropriate person responsible for administering your organisation. <br />•  This property is unrelated to the [Organisation Admin Email](/3.5/admin-org/configuring-organisation-administration-properties#org-admin-email) property (above), whose value is accessible to Covata users from Covata Notification email messages and the **Need help? ...** link on the **Authentication code** entry page for two-factor authentication (2FA). <br />•  For more information about how organisations are added to the Covata Platform, see [Administering organisations](/3.5/admin-platform/administering-organisations) in the [SafeShare Administrator's Guide](/3.5/admin-platform).  |
| Is watermarking of viewed files enabled? | Determines whether (i.e. `true`) or not (i.e. `false`) the watermarking feature is enabled for all viewable files created within your organisation. <br />  The watermarking feature:  <br />•  Only applies to collaborators viewing files that have been shared with them. This feature is intended to discourage collaborators from copying file views by other means (e.g. using screenshot capturing tools, etc). <br />•  Covers a file's view with large semi-transparent text that consists of the email address of the currently signed-in collaborator viewing the file, the Covata Platform's URL, the ID of the file, the classification applied to the file by its owner (if applicable) and the date/time when the file was viewed.  |
| Default i18n setting for new users and email notifications | <a id="default-i18n-setting-for-organisation" />The default language for all new Covata user accounts created on the Covata Platform <sup>&#42;</sup> as a result of the users' accounts being [added to the organisation](/3.5/admin-org/administering-users-within-an-organisation#adding-an-organisation-user-account).  <br />•  This setting overrides the **System Default** language setting set by a SafeShare administrator for their Covata Platform instance. <br />•  This property's initial value is the current **System Default** language setting <br />**Note:** Users can always choose/set their own account's language settings through their own account editing features in [SafeShare for Web](/3.5/user/managing-your-account#updating-your-account-details) (or [Organisation Administration](/3.5/admin-org/administering-users-within-an-organisation#editing-your-organisation-administrator-account)). <br /> <sup>&#42;</sup> These new user accounts are created because the user's email address has not yet been registered on the Covata Platform. |
| Enforce two-factor authentication for organisation members | <a id="enforce-2fa-for-organisation-members" />Determines whether (i.e. `true`) or not (i.e. `false`) the two-factor authentication (2FA) feature is enforced for all Covata users who are members of your organisation. This includes your own Organisation administrator account. <br /> **Note:** Take caution before setting this value to `true`. If any members of your organisation (including yourself) are not prepared to configure 2FA on their account, they may be unable to sign in successfully through the Covata Sign-in page, thereby preventing these users' access to:  <br />•  all organisations on the Covata Platform for which these users are members and/or <br />•  SafeShare Organisation Administration for all organisations of which these users are [Organisation administrators](/3.5/admin-org/administering-users-within-an-organisation#organisation-administrator-role). <br />For more information about 2FA, see [Enabling or disabling 2FA on Organisation user accounts](/3.5/admin-org/administering-users-within-an-organisation#enabling-or-disabling-2fa-on-organisation-user-accounts). |
| Onboarding materials to appear in a user's file list when the user acquires the Originator role | <a id="user-adoption-content" />A file or folder (typically containing onboarding materials) that an Organisation administrator can choose to be automatically shared with Covata users in the organisation who acquire the [Originator role](/3.5/admin-org/administering-users-within-an-organisation#originator-role). <br />  When an Organisation administrator chooses one of their items through this property, this feature becomes active, which results in any users within the organisation who subsequently acquire the Originator role being automatically shared this chosen item. A user's account acquires the Originator role when this account is either:  <br />•  [added to the organisation](/3.5/admin-org/administering-users-within-an-organisation#adding-an-organisation-user-account) with the Originator role, or <br />•  an existing organisation member that is subsequently [edited](/3.5/admin-org/administering-users-within-an-organisation#editing-an-organisation-user-account) to grant it/upgrade it to the Originator role. <br />The purpose of this feature is to provide users (who acquire the Originator role) with immediate access to an item of materials that provides information about adopting the use of SafeShare products to share data securely. However, any item/content can be chosen for this property. <br />  Be aware that this feature has the following requirements and characteristics:  <br />•  A Covata user account with the Organisation administrator role must *also* have the Originator role as the item chosen by the Organisation administrator must be one they own. <br />•  All items shared automatically through this feature (regardless of whether the item is a file or a folder) are done so with *Download* permissions. <br />•  This property's current item can be changed by any Organisation administrator, regardless of the item's ownership. However, the Organisation administrator (modifying this property) can only choose an item they own. <br />•  Once this feature becomes active, existing Covata users in the organisation who have the Originator role are not automatically shared this property's current item. However, if one of these users' accounts is [removed](/3.5/admin-org/administering-users-within-an-organisation#removing-a-user-account-from-your-organisation) from the organisation and subsequently added again (with the Originator role), the user's re-added account is automatically shared this property's current item. <br />•  If this property's item is actually located within a folder, then the item will appear at the root level of the items area for users who subsequently acquire the Originator role in the organisation. <br />**Notes (and idiosyncrasies) about this feature:**  <br />•  If an Organisation administrator chooses a folder for this property, then only the folder itself (i.e. none of its existing content) is automatically shared with users in the organisation who subsequently acquire the Originator role. However, if this Organisation administrator then adds new items to this folder, the accounts of any users who had previously been shared this folder (automatically through this property/feature) are also be shared these newly added items. This behavior will be reviewed for a future Covata Platform release. <br />•  If this property's item is set to a folder and you wish to remove this particular folder (through a SafeShare product or other client application), change this property to a different item *before* removing this folder. Otherwise, the folder will not be completely removed from SafeShare. This issue will be resolved in a future Covata Platform release.  |
| Support URL | <a id="org-support-url" />The URL of the company's/organisation's support page, which is accessible from the **Support** link in the footer of [SafeShare for Web](/3.5/user) and Organisation Administration as well as from Covata Notification email messages. <br />**Note:** This property's default value is empty. In such circumstances, the **Support URL** property's value (defined through [System details properties](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) - see [Configuring SafeShare Administration properties](/3.5/admin-platform/configuring-platform-administration-properties) in the [SafeShare Administrator's Guide](/3.5/admin-platform) for more information), is used as the fallback, which by default is the [Support page](https://support.covata.com) on the Covata web site.  |
| Company Name | <a id="org-company-name" />The company/organisation name which appears throughout Covata Notification email messages. <br />**Note:** This property's default value is empty. In such circumstances, the **Company Name** property's value (defined through [System details properties](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) - see [Configuring SafeShare Administration properties](/3.5/admin-platform/configuring-platform-administration-properties) in the [SafeShare Administrator's Guide](/3.5/admin-platform) for more information), is used as the fallback, which by default is 'Covata'.  |
| Legal URL | <a id="org-legal-url" />The URL of the company's/organisation's legal page, which is accessible from the **Legal** link in the footer of [SafeShare for Web](/3.5/user) and Organisation Administration. <br />**Note:** This property's default value is empty. In such circumstances, the **Legal URL** property's value (defined through [System details properties](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) - see [Configuring SafeShare Administration properties](/3.5/admin-platform/configuring-platform-administration-properties) in the [SafeShare Administrator's Guide](/3.5/admin-platform) for more information), is used as the fallback, which by default is the Covata End User License Agreement.  |
| Web Application Help URL | <a id="org-web-application-help-url" />The URL of the help documentation for the Covata SafeShare for Web application, which is accessible from the **Help** option/link available from the user's email address drop-down menu at the top-right of SafeShare for Web (and from the footer). <br />**Note:** This property's default value is empty. In such circumstances, the **Web Application Help URL** property's value (defined through [System details properties](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) - see [Configuring SafeShare Administration properties](/3.5/admin-platform/configuring-platform-administration-properties) in the [SafeShare Administrator's Guide](/3.5/admin-platform) for more information), is used as the fallback, which by default is the [SafeShare for Web User's Guide](/3.5/user) on the Covata documentation web site.  |
| Organisation Administration Help URL | <a id="org-organisation-administration-help-url" />The URL of the help documentation for SafeShare Organisation Administration, which is accessible from the **Help** option/link available from the email address drop-down menu at the top-right of SafeShare Organisation Administration (and from the footer). <br />**Note:** This property's default value is empty. In such circumstances, the **Organisation Administration Help URL** property's value (defined through [System details properties](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) - see [Configuring SafeShare Administration properties](/3.5/admin-platform/configuring-platform-administration-properties) in the [SafeShare Administrator's Guide](/3.5/admin-platform) for more information), is used as the fallback, which by default is the [Organisation Administrator's Guide](/3.5/admin-org) on the Covata documentation web site.  |
| The URL of the privacy statement | <a id="org-privacy-statement-url" />An additional (custom) URL for the company's/organisation's privacy statement page, which is accessible from the **Privacy**:  <br />•  link in the footer of [SafeShare for Web](/3.5/user) and Organisation Administration, <br />•  options in the taskbar notification area pop-up menu and application pane of [SafeShare for Windows](/3.5/windows) and <br />•  link in the sign-in dialog box and **Help &gt; Privacy** option from the SafeShare menu bar of SafeShare for OS X. <br />**Note:** This property's default value is empty. In such circumstances, the **URL of the privacy statement** property's value (defined through [System details properties](/3.5/admin-platform/configuring-platform-administration-properties#system-details-properties) - see [Configuring SafeShare Administration properties](/3.5/admin-platform/configuring-platform-administration-properties) in the [SafeShare Administrator's Guide](/3.5/admin-platform) for more information), is used as the fallback, which by default is also empty, resulting in these links/options not being available. |
| Custom message to appear on the 'Share' dialog box | A custom message (typically a warning) that will be shown at the base of the 'Share' dialog box (near the **Share** button). <br /> **Note:** The default value of this property is empty. Be aware that once this property's value has been set, it can also be cleared when edited (by clearing its value before saving). |
| Restrict sharing to existing members of this organisation only | <a id="restrict-sharing-to-existing-members-of-this-organisation-only" />Determines whether (i.e. `false`) or not (i.e. `true`) Covata users in the organisation are allowed to share items with people who are not already members of the organisation. <br />  If this value is set to `true`, the Covata Platform will only permit items in the organisation being shared with Covata users whose accounts are existing members of the organisation. |
