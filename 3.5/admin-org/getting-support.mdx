---
title: "Getting Support"
---

If you have any issues with the Covata Platform or other Covata technologies, please consult the relevant system administrator(s) who installed and configured the Covata Platform within your organisation.

Otherwise, if you are using a hosted instance of the Covata Platform or if you wish to report a bug, please visit the customer support web page at:

`[https://support.covata.com](https://support.covata.com)`
