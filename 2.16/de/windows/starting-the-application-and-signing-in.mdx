## Start von Safe Share for Windows <a id="starting-the-application" />

Safe Share for Windows startet automatisch, wenn Windows (neu) startet.

- Wenn Safe Share for Windows ausgeführt wird, erscheint das Symbol für die Anwendung im Infobereich der Taskleiste (entweder
  ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   oder

  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   ).

Nach dem Start öffnet Safe Share for Windows automatisch das [Dialogfeld Anmeldung](/2.16/de/windows/starting-the-application-and-signing-in#sign-in-dialog-box), um Sie zur Anmeldung aufzufordern. Sie können sich alternativ auch [manuell anmelden](/2.16/de/windows/starting-the-application-and-signing-in#signing-in-manually).

<a id="starting-the-application-manually" />**Manueller Start von Safe Share for Windows:**

- Wenn Sie [Safe Share for Windows verlassen](/2.16/de/windows/starting-the-application-and-signing-in#exiting-the-application) oder die Anwendung nicht startet, nachdem Windows (neu) startet, können Sie Safe Share for Windows manuell starten, indem Sie auf das **Covata Safe Share**-Symbol auf dem Desktop doppelklicken oder im Windows-Startmenü **Covata Safe Share** wählen. Wenn die Anwendung ausgeführt wird, erscheint ihr Symbol im Infobereich der Taskleiste (entweder
  ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   oder

  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   ).

## Manuelle Anmeldung <a id="signing-in-manually" />

Wenn Sie:

- *noch nicht* bei Safe Share for Windows angemeldet sind, erscheint das Symbol im Infobereich der Taskleiste als
  ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   - d. h. ein graues Safe Share-Symbol mit einem roten **x**.
- *bereits* bei Safe Share for Windows angemeldet sind, erscheint das Symbol in der Taskleiste als
  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

Sobald Sie angemeldet sind, werden alle von Covata gesicherten, mit Ihrem Covata-Benutzer-Account verknüpften Dateien und Ordner im (von der Covata-Plattform verwalteten) Remotespeicher mit Ihrem Computer synchronisiert und stehen lokal zur Verfügung.

**Manuelle Anmeldung bei Safe Share for Windows:**

1. Vergewissern Sie sich, dass Safe Share for Windows [gestartet](/2.16/de/windows/starting-the-application-and-signing-in#starting-the-application) wurde.
2. Klicken Sie mit der rechten Maustaste auf das Symbol
   ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

    im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Anmelden**:

   ![Anmeldung](/images/75c7c95add89-taskbar-popup-menu-signed-out.jpg)
3. <a id="sign-in-dialog-box" />Geben Sie im Dialogfeld **Anmeldung bei Safe Share** in den entsprechenden Feldern Ihre **E-Mail-Adresse** und **Ihr Passwort** ein:

   ![Dialogfeld Anmeldung](/images/0d715704cdeb-signin-dialog-box.jpg)

   <br />
   **Passwort vergessen?** Wenn ja, dann:

   1. Schließen Sie das Dialogfeld **Anmeldung bei Safe Share**.
   2. Klicken Sie mit der rechten Maustaste auf das Symbol
      ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

       im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Safe Share Web öffnen**:
   3. Klicken Sie auf die Schaltfläche **Passwort vergessen?**, sobald die Anmeldeseite für die Safe Share-Webanwendung geöffnet ist, und folgen Sie den Anweisungen in Ihrer E-Mail-Benachrichtigung, um Ihr Passwort zurückzusetzen. <br />
      **Hinweis:** Wenn Ihre Installation von Safe Share for Windows so konfiguriert ist, dass sie den eigenen, integrierten Webbrowser der Anwendung verwendet (für weitere Informationen über diese Funktion siehe [Zugriff auf die Webanwendung](/2.16/de/windows/starting-the-application-and-signing-in#accessing-the-web-application)), wird die eigene Anmeldeseite von Safe Share for Windows gezeigt (über die Ihr Passwort nicht zurückgesetzt werden kann). Wenn dies der Fall ist, öffnen Sie die [Safe Share-Webanwendung](/2.16/de/user/index) unabhängig von Ihrem eigenen Webbrowser aus, klicken Sie auf die Schaltfläche **Passwort vergessen?** und folgen Sie den Anweisungen in Ihrer E-Mail-Benachrichtigung, um Ihr Passwort zurückzusetzen. Wenn Sie die URL der Safe Share-Webanwendung nicht kennen: Sie ist identisch mit der URL für die Covata-Plattform, die Sie eventuell nach der Installation von Safe Share for Windows konfiguriert haben. Sie erhalten diese URL, indem Sie die unter [Änderung der URL der Covata-Plattform](/2.16/de/windows/installing-and-upgrading-the-application#modifying-the-server-url) beschriebenen Schritte ausführen (ohne den Wert des Registrierungsschlüssels zu ändern). Alternativ erhalten Sie diese Angaben auch von Ihrem Administrator.
4. Klicken Sie auf die Schaltfläche **Anmelden** (oder drücken Sie die Eingabe-/Return-Taste).

   - Wenn Sie im Dialogfeld **Anmeldung bei Safe Share** aufgefordert werden, Ihren **Authentifizierungscode** einzugeben, hat Ihr Covata-Plattform-Administrator für Ihren Covata-Benutzer-Account Zwei-Faktor-Authentifizierung (2FA) konfiguriert.

     ![Safe Share 2FA-Authentifizierungscode](/images/cf81d75965b4-2fa-authentication-code.png)

     1. Wenn Sie für Ihren Covata-Benutzer-Account noch kein Mobilgerät für 2FA konfiguriert haben, lesen Sie die Hinweise zur [Konfiguration eines Mobilgeräts für 2FA](/2.16/de/windows/starting-the-application-and-signing-in#configuring-a-mobile-device-for-2fa) unten, ehe Sie den Vorgang fortsetzen.
     2. <a id="entering-your-authentication-code" />Öffnen Sie auf Ihrem Mobilgerät die Authentifizierungs-Anwendung.
     3. Geben Sie im Feld **Authentifizierungscode** den Code ein, den die Authentifizierungs-Anwendung für Ihren Covata-Benutzer-Account erzeugt hat.
     4. Klicken Sie auf die Schaltfläche **Authentifizieren**, um die Authentifizierung abzuschließen.

   Zur Bestätigung, dass Sie bei Safe Share for Windows angemeldet sind, wird zunächst eine entsprechende Sprechblaseninfo angezeigt, und der Infobereich der Taskleiste schaltet um auf

   ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

    . Ein Rechtsklick auf dieses Symbol zeigt den aktuell angemeldeten Benutzer:

   ![Überprüfung Ihres Anmeldestatus](/images/a79c2609c5b8-taskbar-popup-menu-signed-in.jpg)

<Note>

- Nach der ersten Anmeldung bei Safe Share for Windows nach der [Installation](/2.16/de/windows/installing-and-upgrading-the-application#installing) oder [Aktualisierung](/2.16/de/windows/installing-and-upgrading-the-application#upgrading) der Anwendung wird die Webseite **Herzlich willkommen bei Safe Share for Windows** angezeigt, auf der Sie eine Kurzanleitung zu den wichtigsten Funktionen finden.
- Wenn Sie sich bei Safe Share for Windows zum ersten Mal oder mit einem anderen Covata-Benutzer-Account als zuvor angemeldet haben, werden die folgenden [Safe Share-Ordner](/2.16/de/windows/storing-and-sharing-content-securely#accessing-the-applications-folder) im „`Safe Share`“-Ordner (der sich im Windows-Basisordner befindet) (neu) angelegt:

  - `Meine sicheren Dateien`
  - `Mir freigegeben`
- Erscheint der Ordner „`Meine sicheren Dateien`“ nicht, verfügt Ihr Account nicht über die **Ersteller**-Rolle. Diese Rolle kann Ihrem Account von Ihrem Covata-Plattform-Administrator zugeteilt werden.
- Bei jeder Anmeldung bei Safe Share for Windows als anderer Covata-Benutzer (am selben Computer) werden die Ordner „`Meine sicheren Dateien`“ und „`Mir freigegeben`“ des vorherigen Covata-Benutzers in den Papierkorb verschoben und die Inhalte der neu erstellten Ordner „`Meine sicheren Dateien`“ und „`Mir freigegeben`“ mit den jeweiligen Elementen des neuen Covata-Benutzers im Remotespeicher aktualisiert.
- Safe Share for Windows beginnt sofort nach Ihrer Anmeldung mit der Synchronisierung der Dateien und Ordner im Remotespeicher (Ihres Covata-Benutzer-Accounts, auf den über die [Safe Share-Webanwendung](/2.16/de/user/index) zugegriffen werden kann) mit den Dateien und Ordnern in den Ordnern „`Meine sicheren Dateien`“ und „`Mir freigegeben`“. Die Inhalte der *von Covata gesicherten Dateien* innerhalb dieser Ordner, die mit einer Größe von 1 KB (oder weniger) und der Erweiterung „`.covl`“ statt „`.cov`“ angezeigt werden, sind nicht im Zwischenspeicher abgelegt. Für weitere Informationen über die Speicherung von Dateien im Zwischenspeicher siehe [Verwaltung der Einstellungen für die Cache-Richtlinien](/2.16/de/windows/managing-cache-policy-settings).
- Verknüpfungen zum Unterordner „`Meine sicheren Dateien`“ (oben) sowie zum Start der Anwendung Safe Share for Windows selbst (d. h. *Covata Safe Share* werden auf Ihrem Desktop automatisch angelegt. Beachten Sie, dass die Verknüpfung „`Meine sicheren Dateien`“ nicht angelegt wird, wenn Sie ursprünglich als Covata-Benutzer ohne **Ersteller**-Rolle angemeldet waren.

</Note>

## Konfiguration eines Mobilgeräts für 2FA <a id="configuring-a-mobile-device-for-2fa" />

Wenn Ihr Covata-Plattform-Administrator für Ihren Covata-Benutzer-Account Zwei-Faktor-Authentifizierung (2FA) konfiguriert hat, benötigen Sie ein Mobilgerät (d. h. ein Android- oder Microsoft Windows-basiertes Mobiltelefon, ein iPhone, iPad oder iPod Touch), auf dem eine Authentifizierungsanwendung von Google oder Microsoft ausgeführt wird, um sich bei Safe Share for Windows anmelden zu können.

Die Authentifizierungsanwendung (Authenticator-App) auf Ihrem Mobilgerät erzeugt den zweiten Authentifizierungsfaktor für Ihren Account. Ihr Passwort ist Ihr erster Authentifizierungsfaktor.

**Konfiguration Ihres Mobilgeräts für Zwei-Faktor-Authentifizierung Ihres Covata-Benutzer-Accounts:**

1. Öffnen Sie die E-Mail-Benachrichtigung von Covata mit dem Betreff „*Für Ihren Account wurde Zwei-Faktor-Authentifizierung aktiviert*“.
2. Befolgen Sie die Anweisungen in dieser E-Mail-Benachrichtigung, d. h. klicken Sie auf den Link, um die Konfigurationsseiten für Zwei-Faktor-Authentifizierung zu öffnen. <br />
    Befolgen Sie die weiteren Anweisungen auf diesen Seiten, um die Konfiguration Ihres Mobilgeräts abzuschließen. Melden Sie sich anschließend durch [Eingabe Ihres Authentifizierungscodes](/2.16/de/windows/starting-the-application-and-signing-in#entering-your-authentication-code) bei Safe Share for Windows an.

## Zugriff auf die Webanwendung <a id="accessing-the-web-application" />

Safe Share for Windows gibt Ihnen einfachen Zugriff auf die [Safe Share-Webanwendung](/2.16/de/user/index), um eine möglichst gute Integration zwischen diesen beiden Produkten zu erzielen.

**Zugriff auf die Safe Share-Webanwendung:**

1. Vergewissern Sie sich, dass Safe Share for Windows [gestartet](/2.16/de/windows/starting-the-application-and-signing-in#starting-the-application) wurde und Sie angemeldet sind.
2. Klicken Sie mit der rechten Maustaste auf das Symbol
   ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

    oder

   ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

    im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Safe Share Web öffnen**:

   ![Öffnen der Webanwendung](/images/a79c2609c5b8-taskbar-popup-menu-signed-in.jpg)

   <br />
    Die Safe Share-Webanwendung wird mit der Hauptseite von Safe Share in Ihrem (in Windows konfigurierten) Standard-Webbrowser für den Covata-Benutzer geöffnet, mit dem Sie bei Safe Share for Windows angemeldet sind.

<Note>

**Hinweise zur Nutzung dieser Funktion:**

- Die [Safe Share-Webanwendung](/2.16/de/user/index) ergänzt Safe Share for Windows. Zum Beispiel:

  - Die Safe Share-Webanwendung ermöglicht Ihnen die [Verwaltung Ihres Covata-Benutzer-Accounts](/2.16/de/windows/managing-your-account) über Safe Share for Windows und gibt Ihnen über diese Webanwendung Zugriff auf bestimmte Informationen über Dateien bzw. Ordner, die über den Windows Explorer nicht verfügbar sind.
  - Microsoft gibt für die Datei- und Pfadlänge eine Obergrenze von 260 Zeichen vor. Wenn Sie daher in einer mehrfach vernesteten Ordnerhierarchie mit sicheren Inhalten arbeiten möchten, können Sie über die Safe Share-Webanwendung auf solche Inhalte zugreifen.
- Wenn Sie vor dem Zugriff auf diese Funktion noch nicht angemeldet sind, wird die Anmeldeseite von Safe Share angezeigt. Beachten Sie jedoch, dass die Anmeldung über diese Seite Sie nicht auch bei Safe Share for Windows anmeldet.
- Ihre Instanz der Covata-Plattform kann so konfiguriert sein, dass sie ältere Webbrowser wie Internet Explorer 9 unterstützt. Wenn dies der Fall ist, wird beim Zugriff auf die Safe Share-Webanwendung (über diese Funktion von Safe Share for Windows) die *Safe Share-Webanwendung im Kompatibilitätsmodus* geöffnet. Für weitere Informationen über die Nutzung dieser eingeschränkten Version der Webanwendung siehe die [Benutzeranleitung zur Safe Share-Webanwendung im Kompatibilitätsmodus](/2.16/compatweb/index).
- Ihre Installation von Safe Share for Windows wurde eventuell (wahrscheinlich von einem Systemadministrator) so konfiguriert, dass das *Fenster Safe Share Web* geöffnet wird. Dieser integrierte Webbrowser gibt Zugriff auf eine Version der Safe Share-Webanwendung mit eingeschränkten Funktionen. Zum Beispiel:

  - Die **Download**-Funktion wird im Safe Share-Web-Fenster nicht unterstützt. Diese Funktion wird nur nativ unterstützt (d. h. mit einem kompatiblen Webbrowser), entweder über die [Safe Share-Webanwendung](/2.16/de/user/index) oder die [Webanwendung im Kompatibilitätsmodus](/2.16/compatweb/index).
  - Bei Verwendung des Safe Share Web-Fensters ist keine seitenweise Navigation vor oder zurück möglich. Sie können nur anhand der eigenen Navigationsfunktionen der Safe Share-Webanwendung navigieren.

</Note>

## Abmeldung <a id="signing-out" />

**Abmeldung von Safe Share for Windows:**

- Klicken Sie mit der rechten Maustaste auf das Symbol
  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Abmelden**:

  ![Abmeldung](/images/a79c2609c5b8-taskbar-popup-menu-signed-in.jpg)

<Note>

Nach Ihrer Abmeldung von Safe Share for Windows werden Dateien und Ordner in den Unterordnern „`Meine sicheren Dateien`“ und „`Mir freigegeben`“ im „`Safe Share`“-Ordner auf Ihrem Computer nicht mehr mit Elementen im von der Covata-Plattform verwalteten Remotespeicher synchronisiert.

</Note>

## Verlassen von Safe Share for Windows <a id="exiting-the-application" />

**Verlassen von Safe Share for Windows:**

- Klicken Sie mit der rechten Maustaste auf das Symbol
  ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

   oder

  ![Safe Share for Windows - Abgemeldet](/images/4565af3abf9f-taskbar-icon-signed-out.png)

   im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Safe Share verlassen**:

  ![Safe Share verlassen](/images/75c7c95add89-taskbar-popup-menu-signed-out.jpg)

<Note>

Um sich wieder bei Safe Share for Windows anzumelden, [starten Sie die Anwendung erneut](/2.16/de/windows/starting-the-application-and-signing-in#starting-the-application) und [melden Sie sich manuell an](/2.16/de/windows/starting-the-application-and-signing-in#signing-in-manually), wenn Sie nicht automatisch angemeldet werden.

</Note>
