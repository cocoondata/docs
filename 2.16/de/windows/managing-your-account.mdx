**Verwaltung Ihres Covata-Benutzer-Accounts über „Safe Share for Windows“:**

1. Vergewissern Sie sich, dass Safe Share for Windows [gestartet](/2.16/de/windows/starting-the-application-and-signing-in#starting-the-application) wurde und Sie angemeldet sind.
2. Klicken Sie mit der rechten Maustaste auf das Symbol
   ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

    im Infobereich der Taskleiste und wählen Sie aus dem Popup-Menü **Account verwalten**:

   ![Verwaltung Ihres Covata-Benutzer-Accounts](/images/a79c2609c5b8-taskbar-popup-menu-signed-in.jpg)

   <br />
    Die Safe Share-Webanwendung wird geöffnet (wie beim [Zugriff auf die Webanwendung](/2.16/de/windows/starting-the-application-and-signing-in#accessing-the-web-application)) und zeigt die Funktion [Mein Account](/2.16/de/user/managing-your-account) der [Safe Share-Webanwendung](/2.16/de/user/index).

Über die Funktion **Mein Account** der Safe Share-Webanwendung können Sie die folgenden Aspekte Ihres Covata-Benutzer-Accounts verwalten:

- [Account-Details](/2.16/de/user/managing-your-account#updating-your-account-details-from-windows) wie Ihren Vor- und Familiennamen, sonstige Namen und Ihre Mobiltelefonnummer.
- Änderung Ihres bestehenden [Passworts](/2.16/de/user/managing-your-account#changing-your-password-from-windows).
- Anzeige von [Informationen über Ihre Nutzung des Remotespeichers und Ihr Kontingent](/2.16/de/user/managing-your-account#viewing-your-storage-usage-and-quota-from-windows).
- Anzeige von [Informationen über Ihre letzte Anmeldung](/2.16/de/user/managing-your-account#viewing-your-last-sign-in-details-from-windows) bei der Covata-Plattform.
- Änderung Ihrer [Einstellungen für E-Mail-Benachrichtigungen](/2.16/de/user/managing-your-account#modifying-your-email-notification-preferences-from-windows).
- Widerruf der Berechtigung, die Sie [Client-Anwendungen](/2.16/de/user/managing-your-account#revoking-client-applications) ursprünglich über Ihren Covata-Benutzer-Account zum Zugriff auf Ressourcen der Covata-Plattform erteilt haben.

## Verwaltung Ihrer Kontakte <a id="managing-your-contacts" />

Jedesmal, wenn Sie anderen Personen [Inhalte in Ihrem persönlichen Besitz freigeben](/2.16/de/windows/storing-and-sharing-content-securely#sharing-secure-content), werden deren E-Mail-Adressen automatisch Ihrer Liste von **Kontakten** hinzugefügt. Dies vereinfacht es, diese Personen das nächste Mal als Mitwirkende anzugeben, wenn Sie ihnen Inhalte freigeben möchten.

Mithilfe der **Kontakte**-Funktion von Safe Share for Windows können Sie solche persönlichen Kontakte auch manuell hinzufügen, bearbeiten oder löschen.

**Zugriff auf die Funktion „Kontakte“:**

1. Vergewissern Sie sich, dass Safe Share for Windows [gestartet](/2.16/de/windows/starting-the-application-and-signing-in#starting-the-application) ist.
2. Öffnen Sie das **Sicher freigeben**-Dialogfeld, indem Sie mit der rechten Maustaste auf eine Datei oder einen Ordner auf Ihrem Desktop oder anderswo im Windows Explorer klicken und aus dem Popup-Menü **Sicher freigeben...** auswählen:

   ![Freigabe einer Datei vom Desktop](/images/72a2cfa3fb45-sharing-a-file-from-desktop.jpg)
3. Klicken Sie im Dialogfeld **Sicher freigeben** auf die Schaltfläche **Kontakte**, um das Dialogfeld **Kontakte** zu öffnen.

   ![Dialogfeld Kontakte](/images/3bd678713eaf-contacts-dialog-box.png)

**Manuelles Hinzufügen eines neuen „Kontakts“:**

1. Greifen Sie auf die Funktion **Kontakte** zu.
2. Klicken Sie im Dialogfeld **Kontakte** auf die Schaltfläche **Neu**.
3. Geben Sie im nächsten Dialogfeld **Neuer Kontakt** optional einen **Vornamen** und **Familiennamen** an und füllen Sie das Pflichtfeld **E-Mail-Adresse** aus.
4. Klicken Sie in diesem Dialogfeld auf **Speichern**, um Ihren neuen **Kontakt** hinzuzufügen.

**Bearbeitung eines bestehenden „Kontakts“:**

1. Greifen Sie auf die Funktion **Kontakte** zu.
2. Wählen Sie im Dialogfeld **Kontakte** die E-Mail-Adresse des **Kontakts** und klicken Sie auf die Schaltfläche **Bearbeiten**.
3. Bearbeiten Sie im nächsten Dialogfeld **Kontakt bearbeiten** nach Bedarf optional den **Vornamen** und **Familiennamen** sowie das Pflichtfeld **E-Mail-Adresse**.
4. Klicken Sie in diesem Dialogfeld auf **Speichern**, um Ihren bestehenden **Kontakt** zu aktualisieren.

**Löschung eines bestehenden „Kontakts“:**

1. Greifen Sie auf die Funktion **Kontakte** zu.
2. Wählen Sie im Dialogfeld **Kontakte** die E-Mail-Adresse(n) des zu löschenden Kontakts/der zu löschenden **Kontakte** und klicken Sie auf die Schaltfläche **Löschen**.
3. Bestätigen Sie die Löschung in der Meldung **Kontakte löschen**. <br />
    Die E-Mail-Adresse des betreffenden Kontakts steht dann nicht mehr zur Auswahl zur Verfügung, wenn Sie [Ihre Inhalte freigeben](/2.16/de/windows/storing-and-sharing-content-securely#sharing-secure-content).

<a id="adding-multiple-contacts-from-the-contacts-dialog-box" />**Hinzufügen mehrerer Kontakte zum Dialogfeld „Sicher freigeben“ über das Dialogfeld „Kontakte“:**

1. Greifen Sie auf die Funktion **Kontakte** zu.
2. Wählen Sie im Dialogfeld **Kontakte** die E-Mail-Adresse(n) des Kontakts/der **Kontakte**, der/die dem Dialogfeld **Sicher freigeben** hinzugefügt werden soll(en).
3. Klicken Sie auf die Schaltfläche **Auswahl übernehmen**. Dies schließt das Dialogfeld **Kontakte** und führt Sie zurück zum Dialogfeld **Sicher freigeben**, wo die betreffenden Kontakte nun hinzugefügt sind. <br />
   **Hinweis:** [Legen Sie nun die Berechtigungen fest](/2.16/de/windows/storing-and-sharing-content-securely#selecting-a-permission-set), die diese Kontakte für das von Ihnen freizugebende Element haben sollen.
