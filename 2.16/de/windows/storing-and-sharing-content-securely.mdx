title: "Sichere Speicherung und Freigabe von Inhalten"
---

Die sichere Speicherung und Freigabe von Inhalten mit Safe Share for Windows wird direkt über den „Safe Share“-Ordner vorgenommen, auf den Sie bequem über den Windows Explorer (in Ihrem Windows-Basisordner) zugreifen können.

## Zugriff auf den „Safe Share“-Ordner <a id="accessing-the-applications-folder" />

**Zugriff auf den „`Safe Share`“-Ordner:**

1. Vergewissern Sie sich, dass Safe Share for Windows [gestartet](/2.16/de/windows/starting-the-application-and-signing-in#starting-the-application) wurde und Sie angemeldet sind.
2. Klicken Sie auf das Symbol
   ![Safe Share for Windows - Angemeldet](/images/91b3a11c5563-taskbar-icon-signed-in.png)

    im Infobereich der Taskleiste.

   - Klicken Sie alternativ mit der rechten Maustaste auf dieses Symbol und wählen Sie aus dem Popup-Menü **Safe Share-Ordner öffnen**.

     ![Öffnen Ihres Safe Share-Ordners](/images/a79c2609c5b8-taskbar-popup-menu-signed-in.jpg)

   Der Windows Explorer öffnet mit dem „`Safe Share`“-Ordner in Ihrem Windows-Basisordner und zeigt die beiden Unterordner:

   - `Meine sicheren Dateien` - mit allen Elementen in Ihrem Besitz. (Beachten Sie, dass dieser Ordner nicht erscheint, wenn Ihrem Account nicht die **Ersteller**-Rolle zugewiesen ist.)
   - `Mir freigegeben` - mit allen Elementen, die Andere Ihnen als Mitwirkenden freigegeben haben.

   ![Safe Share-Ordner im Windows Explorer](/images/d63e5466e8ea-windows-explorer.png)

<Note>

- Safe Share for Windows beginnt nach der erfolgreichen Anmeldung mit der Synchronisierung aller Dateien und Ordner, die:

  - im Remotespeicher kürzlich über Ihren Covata-Benutzer-Account (anhand der [Safe Share-Webanwendung](/2.16/de/user/index) oder Safe Share for iOS) geändert wurden, mit den Dateien und Ordnern in Ihrem lokalen Ordner „`Meine sicheren Dateien`“.
  - andere Covata-Benutzer Ihnen kürzlich freigegeben haben, mit den Dateien und Ordnern in Ihrem lokalen Ordner „`Mir freigegeben`".
- Wenn auf Ihrem Computer Drittanwendungen ausgeführt werden, die so konfiguriert sind, dass sie verschlüsselte Inhalte im „`Safe Share`“-Ordner kopieren und anderswo speichern (z. B. Anwendungen zur Datensicherung), kann dies dazu führen, dass entschlüsselte Kopien der betreffenden Inhalte von solchen Anwendungen an ihren jeweiligen Ziel-Speicherorten gespeichert werden. Beachten Sie, dass Safe Share for Windows verschlüsselte Inhalte automatisch (im „`Safe Share`“-Ordner) im Remotespeicher synchronisiert und speichert. Wenn Sie daher nicht wünschen, dass Drittanwendungen zusätzliche Kopien dieser Inhalte (in entschlüsselter Form) anfertigen, stellen Sie sicher, dass diese Anwendungen so konfiguriert sind, dass sie Inhalte der „`Safe Share`“-Ordner nicht kopieren bzw. sichern.

</Note>

## Speicherung von Inhalten im persönlichen Besitz <a id="storing-personally-owned-content-securely" />

<Tip>

Sie können Inhalte in Ihrem persönlichen Besitz auch in nur einem Schritt sicher speichern und [freigeben (siehe unten)](/2.16/de/windows/storing-and-sharing-content-securely#sharing-secure-content). Siehe [Sichere Speicherung und Freigabe von Inhalten in einem Schritt](/2.16/de/windows/storing-and-sharing-content-securely#storing-content-securely-and-sharing-it-in-one-go) für weitere Informationen.

</Tip>

**Sichere Speicherung von Inhalten im persönlichen Besitz über Safe Share for Windows:**

1. [Greifen Sie](/2.16/de/windows/storing-and-sharing-content-securely#accessing-the-applications-folder) auf den „`Safe Share`“-Ordner zu.
2. Wählen Sie eine(n) oder mehrere Datei(en) und/oder Ordner auf Ihrem Computer und kopieren oder verschieben Sie sie in den Unterordner „`Meine sicheren Dateien`“ (wie Sie dies normalerweise im Windows Explorer tun würden) oder in einen beliebigen anderen Ordner in „`Meine sicheren Dateien`“. Ziehen Sie Ihr(e) Element(e) zum Beispiel direkt in den Unterordner „`Meine sicheren Dateien`“:

   ![Sicherung einer Datei durch Drag&Drop](/images/fbf763a6b728-dragging-a-file-to-secure-by-moving.png)

   <br />
    Ihre Elemente werden von Safe Share for Windows im Ordner „`Meine sicheren Dateien`“ lokal verschlüsselt und anschließend sicher in den von der Covata-Plattform verwalteten Remotespeicher hochgeladen. Ihre ursprünglichen Inhalte können an ihrem ursprünglichen Speicherort verbleiben, unabhängig davon, ob Sie Ihre Elemente kopiert oder verschoben haben. Siehe die [Hinweise](/2.16/de/windows/storing-and-sharing-content-securely#item-storing-behavior) unten für weitere Informationen über dieses Verhalten. <br />
   **Tipp:** Sie können Inhalte auch sicher speichern, indem Sie auf Ihrem Computer eine(n) oder mehrere Datei(en) oder Ordner auswählen und anschließend einen der folgenden Schritte ausführen:

   - Direktes Verschieben in den „`Safe Share`“-Ordner. Dies ist mit dem direkten Kopieren oder Verschieben dieser Elemente in den Ordner „`Meine sicheren Dateien`“ identisch. Beachten Sie, dass direktes Kopieren von Elementen in den „`Safe Share`“-Ordner nicht unterstützt wird.
   - Kopieren oder Verschieben in die Verknüpfung „`Meine sicheren Dateien`“ auf Ihrem Desktop (sofern vorhanden).

   **Hinweise:**

   - Die maximale unterstützte Dateigröße hängt von einem in der Covata-Plattform konfigurierten Parameter ab. Ihr Covata-Plattform-Administrator kann Ihnen den Wert dieses Parameters mitteilen. Safe Share for Windows definiert standardmäßig eine maximale Dateigröße von 20 GB. Dieser Standardwert kann jedoch (nur für Uploads) anhand einer Einstellung in der Windows-Registrierung überschrieben werden.
   - Beim Kopieren (nicht Verschieben) einer großen Datei (im Allgemeinen mit mehreren hundert MB) kann Safe Share for Windows die Sprechblaseninfo „*Verschlüsselung ist nicht möglich - Windows hat den Zugriff auf dieses Element verhindert.*“ ausgeben. Safe Share for Windows beginnt jedoch automatisch mit der Verschlüsselung dieses Inhalts, sobald der Kopiervorgang abgeschlossen ist. Sie können diese Meldung in diesem Szenario daher ignorieren.
   - Safe Share for Windows unterstützt das Kopieren von Dateien zwischen Ordnern innerhalb des „`Safe Share`“-Ordners nicht, auch nicht zwischen Ordnern in „`Meine sicheren Dateien`“. Alle kopierten Dateien werden nach der nächsten Synchronisierung (mit von der Covata-Plattform verwaltetem Remotespeicher) automatisch gelöscht.

## Freigabe sicherer Inhalte <a id="sharing-secure-content" />

Die folgenden Hinweise erläutern, wie Sie sichere (zuvor [gespeicherte](/2.16/de/windows/storing-and-sharing-content-securely#storing-personally-owned-content-securely)) Inhalte in Ihrem persönlichen Besitz anderen Personen freigeben sowie die auf diese Inhalte zugriffsberechtigten Covata-Benutzer und/oder die Zugriffsberechtigungen dieser Benutzer ändern können.

<Note>

**Hinweise und Tipps:**

- Sie können nur *Inhalte in Ihrem Besitz* an andere Personen freigeben.
- Diese Hinweise beschreiben den Freigabevorgang für Inhalte in Ihrem Besitz, aber derselbe Vorgang gilt auch für die Freigabe von Inhalten, die Andere [in Ihren Ordner hochgeladen und dort gespeichert haben](/2.16/de/windows/storing-and-sharing-content-securely#storing-content-to-share-through-another-users-folder), wenn Sie diesen Personen für den betreffenden Ordner **Upload**- oder **Verwaltungs**-Berechtigung erteilt haben. Die Erteilung von Berechtigungen für Ihre Ordner ist [unten](/2.16/de/windows/storing-and-sharing-content-securely#selecting-a-permission-set) detaillierter beschrieben.
- Sie können Inhalte auch in nur einem Schritt sicher speichern und freigeben. Siehe [Sichere Speicherung und Freigabe von Inhalten in einem Schritt](/2.16/de/windows/storing-and-sharing-content-securely#storing-content-securely-and-sharing-it-in-one-go) für weitere Informationen.

</Note>

**Freigabe Ihrer sicher gespeicherten Inhalte an andere Personen (oder Änderung vorhandener Freigaben dieser Inhalte):**

1. [Greifen Sie](/2.16/de/windows/storing-and-sharing-content-securely#accessing-the-applications-folder) auf den „`Safe Share`“-Ordner zu.
2. Klicken Sie mit der rechten Maustaste im Unterordner „`Meine sicheren Dateien`“ auf die Datei oder den Ordner, die/den Sie einer oder mehreren Personen freigeben oder deren/dessen vorhandene Mitwirkende Sie ändern möchten, und wählen Sie aus dem Popup-Menü **Sicher freigeben...**, um das **Sicher freigeben**-Dialogfeld zu öffnen:

   ![Freigabe einer Datei](/images/066462bf6e70-right-clicking-an-item-owner.png)
3. <a id="share-dialog-box" />Geben Sie im Dialogfeld **Sicher freigeben** im Textfeld **Freigabe an** die E-Mail-Adresse der Person (des „Mitwirkenden“) ein, der Sie das Element freigeben möchten. <br />
   **Hinweise:**

   - Wenn Sie lediglich die Berechtigungen eines oder mehrerer vorhandener Mitwirkender am betreffenden Element ändern möchten, suchen Sie die E-Mail-Adressen dieser Mitwirkenden in der Liste der Mitwirkenden (in diesem Dialogfeld) und gehen Sie direkt zum nächsten Schritt zur [Auswahl der Berechtigungen für Mitwirkende](/2.16/de/windows/storing-and-sharing-content-securely#selecting-a-permission-set).
   - Wenn Sie Mitwirkende des Elements entfernen, mehrere Mitwirkende in einem Schritt hinzufügen oder mehrere Elemente in einem Schritt freigeben möchten, siehe die **Tipps** am Ende des Schritts [Hinzufügen eines Mitwirkenden zur Liste](/2.16/de/windows/storing-and-sharing-content-securely#adding-collaborator-to-list).

   ![Sicher freigeben-Dialogfeld](/images/adf44eb4893c-share-dialog-box.png)

   <br />
   **Hinweise:**

   - Wenn die gewünschte E-Mail-Adresse in der Dropdown-Liste zur Auswahl angezeigt wird, ehe Sie sie fertig eingegeben haben:

     - haben Sie die E-Mail-Adresse bereits verwendet, um Elemente freizugeben (und die Adresse wurde Ihrer Kontaktliste bereits hinzugefügt - für weitere Informationen siehe [Verwaltung Ihrer Kontakte](/2.16/de/windows/managing-your-account#managing-your-contacts)) <br />
        oder
     - haben Sie die E-Mail-Adresse Ihren Kontakten bereits manuell hinzugefügt.
   - Sie können Mitwirkende auch anhand des [Dialogfelds „Kontakte“](/2.16/de/windows/managing-your-account#adding-multiple-contacts-from-the-contacts-dialog-box) hinzufügen.
   - Wenn Sie einen Ordner freigeben, erscheint ein etwas anderes Dialogfeld. (Die Unterschiede sind unten erläutert.)
4. <a id="selecting-a-permission-set" />Wählen Sie aus der Dropdown-Liste **Berechtigungen** eine der folgenden Berechtigungen aus, um den Zugriff des betreffenden Mitwirkenden auf das Element zu definieren:

   - **Anzeigen** - gewährt die Berechtigung zur Anzeige der Datei (aus dem [schreibgeschützten Content-Viewer in Safe Share for Windows](/2.16/de/windows/accessing-secure-content#read-only-content-viewer) heraus, der auch als *Safe Share-Content-Viewer* bezeichnet wird) bzw., wenn es sich um einen Ordner handelt, die Berechtigung zur Anzeige aller Dateien im betreffenden Ordner. <br />
     **Tipps:**

     - Der Safe Share-Content-Viewer unterstützt dieselben Dateitypen wie der [Content-Viewer](/2.16/de/user/accessing-secure-content#content-viewer) der Safe Share-Webanwendung. Für weitere Informationen siehe [Vom Content-Viewer unterstützte Dateiformate](/2.16/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) in der [Safe Share-Benutzeranleitung für die Webanwendung](/2.16/de/user/index).
     - Wird für ein Element die **Anzeige**-Berechtigung gewährt, kann der Inhalt des Elements im schreibgeschützten Content-Viewer der [Safe Share-Webanwendung](/2.16/de/user/accessing-secure-content#content-viewer) sowie Safe Share for iOS angezeigt werden.
   - **Herunterladen** - gewährt die Berechtigung zur Anzeige und zum Ausdruck der Datei (auch aus dem Safe Share-Content-Viewer heraus) sowie zu ihrem Download bzw., wenn es sich um einen Ordner handelt, die entsprechende Berechtigung für alle Dateien im betreffenden Ordner. <br />
     **Tipp:** Wird für ein Element die **Download**-Berechtigung gewährt, kann der Inhalt des Elements über den schreibgeschützten Content-Viewer der [Safe Share-Webanwendung](/2.16/de/user/accessing-secure-content#content-viewer) sowie Safe Share for iOS auch ausgedruckt werden.
   - **Hochladen** ( *nur verfügbar, wenn das Element ein Ordner ist* ) - gewährt die Berechtigung zur Anzeige, zum Ausdruck und zum Download vorhandener Dateien sowie zum Upload neuer Dateien innerhalb des betreffenden Ordners.
   - **Verwalten** - gewährt die Berechtigung zur Anzeige, zum Ausdruck, zum Download, zur Umbenennung und zur Löschung der betreffenden Datei. Wenn es sich um einen Ordner handelt, gilt die entsprechende Berechtigung für alle Dateien im betreffenden Ordner, einschließlich der Berechtigung zum Upload neuer Dateien, zur Erstellung neuer Unterordner und zur Löschung vorhandener Unterordner (innerhalb des betreffenden Ordners). <br />
     **Hinweis:** Die Erteilung einer **Verwaltungs**-Berechtigung für einen Ordner ermöglicht es dem Mitwirkenden, den betreffenden Ordner zu löschen.

   **Tipp:** Bei der Freigabe eines Ordners gilt Folgendes:

   - Mitwirkende und ihre Berechtigungen (zum Zugriff auf Inhalte innerhalb des Ordners) werden *implizit* an alle im betreffenden Ordner enthaltenen Elemente weitergegeben (d. h. auf sie angewendet).
   - Wenn Mitwirkende an einem Unterordner (in diesem Ordner) und/oder ihre Berechtigungen geändert werden, werden diese Änderungen *explizit* für den betreffenden Unterordner festgelegt und von dort aus *implizit* über die Elementehierarchie des betreffenden Unterordners weitergegeben.
   - Die Berechtigungen eines Mitwirkenden, die *explizit* für diesen Unterordner vorgegeben wurden, haben Vorrang gegenüber Berechtigungen, die der Mitwirkende (dieses Unterordners) eventuell *implizit* von einem übergeordneten Ordner übernommen hat.
5. <a id="adding-collaborator-to-list" />Wenn die E-Mail-Adresse des Mitwirkenden (in diesem Dialogfeld) nicht in der Liste der Mitwirkenden erscheint, klicken Sie auf die Plus-Schaltfläche (**+**) rechts oben, und die E-Mail-Adresse und gewählten Berechtigungen des Mitwirkenden werden der Liste der Mitwirkenden hinzugefügt:

   ![Sicher freigeben-Dialogfeld](/images/04464ca65e29-added-collaborator.png)

   <br />
    (Wiederholen Sie die Schritte ab Schritt 3 [oben](/2.16/de/windows/storing-and-sharing-content-securely#share-dialog-box), um der Liste weitere Mitwirkende hinzuzufügen.) <br />
   **Tipps:**

   - Sie können im Textfeld **Freigabe an** auch mehrere E-Mail-Adressen/Mitwirkende eingeben und diese in einem Zug hinzufügen. Dies geschieht folgendermaßen:

     - Geben Sie nach der E-Mail-Adresse jedes Mitwirkenden ein Komma (,) ein. Damit ist die aktuelle E-Mail-Adresse abgeschlossen, und Sie können im Textfeld weitere Adressen eingeben. Alle eingegebenen E-Mail-Adressen werden der Liste Ihrer Mitwirkenden hinzugefügt, wenn Sie die Plus-Schaltfläche (**+**) anklicken.
     - Kopieren Sie eine mit Trennzeichen strukturierte Zeichenfolge von E-Mail-Adressen Ihrer Mitwirkenden und fügen Sie sie in dieses Textfeld ein (ohne Leerzeichen). Safe Share for Windows erkennt die einzelnen E-Mail-Adressen im Textfeld automatisch und fügt der Liste Ihrer Mitwirkenden alle Adressen hinzu, wenn Sie die Plus-Schaltfläche (**+**) anklicken.

     Beachten Sie, dass bei beiden Methoden die in der daneben gezeigten Dropdown-Liste **Berechtigungen** aktuell gewählte Berechtigung auf alle hinzugefügten Mitwirkenden angewendet wird.
   - Klicken Sie auf die Schaltfläche **x** neben der betreffenden E-Mail-Adresse, um einen Mitwirkenden aus der Liste zu entfernen.
   - Um mehrere Dateien (in einem Schritt und/oder künftig) einer Gruppe von Personen freizugeben, [erstellen Sie einen Ordner](/2.16/de/windows/managing-secure-content#organizing-content-with-folders) im Unterordner „`Meine sicheren Dateien`“ und geben Sie diesen anhand dieses Verfahrens an einen oder mehrere Mitwirkende frei. Alle Elemente, die Sie (oder ein Mitwirkender mit **Verwaltungs**-Berechtigung für den betreffenden Ordner) anschließend in diesen Ordner (von außerhalb des „`Safe Share`“-Ordnerbereichs) kopieren oder verschieben, werden sofort an alle aktuellen Mitwirkenden des Ordners freigegeben. Mitwirkenden mit **Verwaltungs**-Berechtigung für diesen Ordner wird der betreffende Ordner in ihrem Unterordner „`Mir freigegeben`“ angezeigt.
6. ( *Optional, nur bei der Freigabe einer Datei verfügbar und nur, wenn Ihr Covata-Plattform-Administrator Bezeichnungen konfiguriert hat* ) Wählen Sie aus der Dropdown-Liste „Bezeichnungen“ eine vordefinierte Bezeichnung aus (die Standardauswahl lautet **Keine Bezeichnung**). Bezeichnungen verhalten sich wie „Geheimhaltungsstufen“, anhand deren Sie die Möglichkeit der Freigabe von Dateien auf eine bestimmte Gruppe von Covata-Benutzer beschränken können. <br />
   **Hinweise:**

   - Wenn die Richtlinien Ihrer Organisation es verlangen, dass Sie bei der Freigabe einer Datei eine bestimmte Bezeichnung zuweisen, wählen Sie die für die freizugebenden Inhalte geeignete Bezeichnung. Ihr Covata-Plattform-Administrator kann zum Beispiel die Bezeichnungen **Vertraulich**, **Beschränkter Zugang/Geschützt** und **Nicht geheim** konfiguriert haben (sowie die Standardoption **Keine Bezeichnung**, die bedeutet, dass bei der Freigabe keine Bezeichnung angewendet wird). Weitere Informationen über Bezeichnungen und Gruppen finden Sie im [Covata-Plattform-Administratorenhandbuch](/2.16/de/admin/index).
7. ( *Optional und ebenfalls nur bei der Freigabe einer Datei verfügbar* ) Definieren Sie, ab *wann* auf Ihre Datei zugegriffen werden kann:

   - Aktivieren Sie hierzu das Kontrollkästchen **Zugriff ermöglichen ab** und legen Sie in den Feldern rechts das Datum und den Zeitpunkt fest, ab dem Ihre Mitwirkenden auf die Datei zugreifen können. Lassen Sie das Kästchen leer, um die Datei unmittelbar zur Verfügung zu stellen.
   - Aktivieren Sie das Kontrollkästchen **Zugriff widerrufen nach** und legen Sie in den Feldern rechts das Datum und den Zeitpunkt fest, ab dem Ihre Mitwirkenden nicht mehr auf die Datei zugreifen können. Lassen Sie das Kästchen leer, um die Datei unbefristet zur Verfügung zu stellen.

   ![Datums-/Zeit-Steuerelemente](/images/3bea82c81014-date-time-controls.png)
8. ( *Optional und nur verfügbar, wenn mindestens ein neuer Mitwirkender hinzugefügt wird* ) Schreiben Sie im Textfeld **Optionalen Hinweis für neue Mitwirkende hinzufügen** einen benutzerdefinierten Hinweis, den neue Mitwirkende in ihrer E-Mail-Benachrichtigung erhalten.

   ![Optionaler Hinweis](/images/a6d6251b61ea-optional-note.png)
9. Klicken Sie auf **Speichern** oder drücken Sie die „Eingabe-/Return“-Taste, um Ihr Element an Ihre Mitwirkenden freizugeben und das **Sicher freigeben**-Dialogfeld zu schließen. Alle in diesem Dialogfeld *neu hinzugefügten* Mitwirkenden erhalten eine E-Mail-Benachrichtigung. <br />
   **Hinweise:**

   - Wenn Sie Ihr Element aufgrund einer der folgenden Warnungen nicht freigeben können:

     - „*Die Positivlistenfunktion verweigert Ihnen die Freigabe dieses Elements an eine oder mehrere der gewählten Personen. Bitte wenden Sie sich an Ihren Administrator.*“ - Ihr Covata-Plattform-Administrator hat die Funktion Benutzer-Positivliste in der Covata-Plattform aktiviert, die den Kreis der (auf die Covata-Plattform zugriffsberechtigten) Personen auf diejenigen Benutzer beschränkt, deren E-Mail-Adressen (oder E-Mail-Domänen) der Positivliste hinzugefügt wurden. Sie müssen sich eventuell an Ihren Covata-Plattform-Administrator wenden um zu klären, welche E-Mail-Adressen und -Domänen auf der Positivliste stehen, und so sicherzustellen, dass nicht auf der Positivliste stehende Mitwirkende bei der Freigabe von Elementen (siehe oben) entweder entfernt oder Ihrer Liste von Mitwirkenden nicht hinzugefügt werden.
     - „*Die folgenden Benutzer haben keinen Zugriff auf mit BEZEICHNUNG markierte Dateien:*“ („BEZEICHNUNG“ ist hier der Name der von Ihnen oben gewählten Bezeichnung) - Ihr Covata-Plattform-Administrator gewährt den in der Meldung aufgeführten Benutzern keinen Zugriff auf mit der betreffenden BEZEICHNUNG markierte Inhalte. Entfernen Sie entweder die Benutzer, die zum Zugriff auf Inhalte mit der betreffenden BEZEICHNUNG nicht berechtigt sind, oder wählen Sie eine andere Bezeichnung.

     Klicken Sie in beiden Fällen auf die Nachricht selbst, um zum Dialogfeld **Sicher freigeben** zurückzukehren.
   - Weitere Informationen über die Benutzer-Positivliste und Bezeichnungen (und Gruppen) finden Sie im [Covata-Plattform-Administratorenhandbuch](/2.16/de/admin/index).

<Tip>

**Tipps und Hinweise:**

- Sie können eine URL für den direkten Zugriff auf Ihre Datei oder Ihren Ordner über die Safe Share-Webanwendung erhalten, die Sie dann Ihren Mitwirkenden, denen Sie das Element freigegeben haben, senden können. Sie erhalten diese Direkt-URL folgendermaßen:

  1. Öffnen Sie das Dialogfeld **Sicher freigeben** zum betreffenden Element (siehe Beschreibung am Anfang dieses Ablaufs [oben](/2.16/de/windows/storing-and-sharing-content-securely#sharing-secure-content)).
  2. Klicken Sie im Dialogfeld **Sicher freigeben** auf die Schaltfläche **Freigabe-Link abrufen**, um den Link in Ihre Zwischenablage zu kopieren. Diese Schaltfläche ist nur verfügbar, wenn das Element mindestens einen Mitwirkenden hat. <br />
      Für Dateiformate, die vom [Content-Viewer einer Safe Share-Anwendung unterstützt werden](/2.16/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer), öffnet diese URL das Element im [Content-Viewer](/2.16/de/user/accessing-secure-content#content-viewer) der Safe Share -Webanwendung und nicht auf der Hauptseite von Safe Share, auf der das Element aufgeführt ist.
- Wenn Sie Elemente von einem Unterordner in einen anderen innerhalb von „`Meine sicheren Dateien`“ verschieben, werden die betreffenden Elemente allen Mitwirkenden zugänglich gemacht, denen der betreffende Unterordner bereits *explizit* freigegeben wurde. Dieser Zugriff gilt auch für Mitwirkende, die *explizit* für übergeordnete Ordner (innerhalb des Ordners „`Meine sicheren Dateien`“) eingerichtet sind; diese erhalten dann *implizit* Zugriff auf diese verschobenen Elemente (an ihrem neuen Speicherort). Der Zugriff jedes dieser Mitwirkenden auf die verschobenen Elemente hängt von den Berechtigungen ab, die für den betreffenden übergeordneten Ordner der Elemente vorgegeben wurden. Beachten Sie jedoch, dass (solche) Mitwirkende für Elemente, die in einen Ordner verschoben wurden, auf den sie bereits Zugriff haben, keine E-Mail-Benachrichtigung erhalten.
- Wenn Sie ein Element einem oder mehreren Mitwirkenden freigeben *und* das Element in einem Ordner gespeichert ist, der den betreffenden Mitwirkenden nicht freigegeben ist, können die Mitwirkenden bei ihrer Anmeldung:

  - bei Safe Share for Windows auf das Element vom Stamm des Unterordners „`Freigegeben von`“ Ihres Covata-Benutzer-Accounts (in ihrem Unterordner „`Mir freigegeben`“) zugreifen. Für weitere Informationen über „`Freigegeben von`“-Unterordner siehe [Entschlüsselung oder Anzeige/Ausdruck sicherer (Ihnen freigegebener) Inhalte](/2.16/de/windows/accessing-secure-content#decrypting-or-viewing-printing-secure-content-shared-with-you).
  - bei der [Safe Share-Webanwendung](/2.16/de/user/index) auf das Element vom Stammspeicherort ihrer Safe Share-Hauptseite zugreifen.

</Tip>

## Sichere Speicherung und Freigabe von Inhalten in einem Schritt <a id="storing-content-securely-and-sharing-it-in-one-go" />

**Sichere Speicherung und Freigabe Ihrer Inhalte an andere Personen in einem Schritt (von allen über den Windows Explorer zugänglichen Speicherorten):**

1. Vergewissern Sie sich, dass Safe Share for Windows [gestartet](/2.16/de/windows/starting-the-application-and-signing-in#starting-the-application) ist.
2. Klicken Sie mit der rechten Maustaste auf eine Datei oder einen Ordner auf Ihrem Desktop oder anderswo im Windows Explorer und wählen Sie aus dem Popup-Menü **Sicher freigeben...**:

   ![Freigabe einer Datei vom Desktop](/images/72a2cfa3fb45-sharing-a-file-from-desktop.jpg)

   <br />
    Safe Share for Windows beginnt, den Inhalt Ihres Elements zu verschlüsseln:

   ![Verschlüsselungsmeldung](/images/6569c05253e2-encrypting-message.png)

   <br />
   **Hinweise:**

   - Wenn Sie nicht angemeldet sind, öffnet Safe Share for Windows das [Dialogfeld Anmeldung](/2.16/de/windows/starting-the-application-and-signing-in#sign-in-dialog-box), um Sie zur Anmeldung aufzufordern.
   - Wenn Sie eine große Datenmenge sicher speichern, kann die Verschlüsselung etwas Zeit in Anspruch nehmen. Sie können daher in der Verschlüsselungsmeldung (oben) auf die Schaltfläche **Ausblenden** klicken, um die Meldung zu schließen und die Verschlüsselung im Hintergrund fortzusetzen.
   - Die maximale unterstützte Dateigröße hängt von einem in der Covata-Plattform konfigurierten Parameter ab. Ihr Covata-Plattform-Administrator kann Ihnen den Wert dieses Parameters mitteilen. Safe Share for Windows definiert standardmäßig eine maximale Dateigröße von 20 GB. Dieser Standardwert kann jedoch (nur für Uploads) anhand einer Einstellung in der Windows-Registrierung überschrieben werden.
3. Sobald die Verschlüsselung abgeschlossen ist, wird das **Sicher freigeben**-Dialogfeld geöffnet. Setzen Sie den Vorgang ab [Schritt 3 in „Freigabe sicherer Inhalte“](/2.16/de/windows/storing-and-sharing-content-securely#share-dialog-box) oben fort.

## Speicherung von Inhalten zur Freigabe über den Ordner eines anderen Benutzers <a id="storing-content-to-share-through-another-users-folder" />

Wenn ein Covata-Benutzer, der [einen Ordner besitzt](/2.16/de/windows/managing-secure-content#organizing-content-with-folders):

- Ihnen als Mitwirkenden [diesen Ordner freigegeben hat](/2.16/de/windows/storing-and-sharing-content-securely#sharing-secure-content) und
- Ihnen für den Zugriff auf diesen Ordner entweder **Upload**- oder **Verwaltungs**-Berechtigung erteilt hat,

können Sie Inhalte über diesen Ordner des anderen Covata-Benutzers (als Mitwirkender an diesem Ordner) sicher speichern und freigeben. Sobald der Inhalt verschlüsselt ist, wird er in von der Covata-Plattform verwalteten Remotespeicher hochgeladen. Alle Inhalte, die Sie in diesem Ordner speichern, werden für andere Covata-Benutzer verfügbar, die Mitwirkende des betreffenden Ordners sind.

<a id="determining-folder-permissions" />**Feststellung Ihrer Berechtigung, Inhalte im Ordner eines anderen Benutzers zu speichern (d. h. sie hochzuladen) (oder Inhalte dort zu verwalten):**

1. [Greifen Sie](/2.16/de/windows/storing-and-sharing-content-securely#accessing-the-applications-folder) auf den „`Safe Share`“-Ordner zu.
2. Klicken Sie in einem Unterordner „`Freigegeben von...`“ im Ordner „`Mir freigegeben`“ mit der rechten Maustaste auf einen Unterordner und wählen Sie aus dem Popup-Menü **Berechtigungen anzeigen**:

   ![Feststellung der Berechtigungen an einem Ordner](/images/86bf11ac8124-right-clicking-an-item-collaborator.png)

   <br />
    Im Infobereich der Taskleiste (standardmäßig rechts unten auf dem Bildschirm) wird eine Meldung mit den einzelnen **Berechtigungen**, die Sie für den betreffenden Ordner haben, angezeigt. Enthält diese Meldung:

   - die Berechtigung **Datei hochladen**, hat Ihnen der Besitzer des Ordners für den Ordner **Upload**-Berechtigung erteilt.
   - die Berechtigungen **Entfernen**, **Verschieben**, **Umbenennen** und **Datei hochladen**, hat Ihnen der Besitzer des Ordners für den Ordner **Verwaltungs**-Berechtigung erteilt.

**Feststellung der Mitwirkenden des Ordners dieses anderen Benutzers:**

Als Mitwirkender mit **Upload**- oder **Verwaltungs**-Berechtigung für den Ordner eines anderen Benutzers möchten Sie vielleicht feststellen, welche anderen Personen Mitwirkende des betreffenden Ordners sind, ehe Sie Dateien in diesen Ordner hochladen und Inhalte freigeben.

Über den Windows Explorer können Sie nur den Besitzer des Ordners feststellen, nicht aber die anderen Mitwirkenden. Die einzelnen Mitwirkenden des Ordners lassen sich jedoch anhand der Safe Share-Webfunktion feststellen.

1. [Greifen Sie](/2.16/de/windows/starting-the-application-and-signing-in#accessing-the-web-application) auf Safe Share Web zu.
2. Suchen Sie in Safe Share Web den Ordner (eines anderen Benutzers), für den Sie **Upload**- oder **Verwaltungs**-Berechtigung haben. Für weitere Informationen siehe [Suchen sicherer Inhalte](/2.16/de/user/managing-secure-content#finding-secure-content) und [Upload von Inhalten zur Freigabe über den Ordner eines anderen Benutzers](/2.16/de/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) in der Safe Share-Benutzeranleitung für die Webanwendung. <br />
    Im Bereich **Freigabe** des Registers **Details** werden alle anderen Covata-Benutzer, die aktuell Mitwirkende des Ordners sind, angezeigt (einschließlich des Besitzers aber ausschließlich Ihrer selbst).

**Upload von Inhalten für die Freigabe über den Ordner eines dieser anderen Benutzer:**

1. [Greifen Sie](/2.16/de/windows/storing-and-sharing-content-securely#accessing-the-applications-folder) auf den „`Safe Share`“-Ordner zu und identifizieren Sie den Ordner eines anderen Covata-Benutzers, für den Sie Mitwirkender sind und in den Sie Inhalte hochladen dürfen (siehe Beschreibung [oben](/2.16/de/windows/storing-and-sharing-content-securely#determining-folder-permissions)).
2. Wählen Sie eine(n) oder mehrere Datei(en) und/oder Ordner auf Ihrem Computer und kopieren oder verschieben Sie sie in diesen Ordner (wie Sie dies normalerweise im Windows Explorer tun würden). <br />
    Ihre Elemente werden von Safe Share for Windows in diesem Ordner lokal verschlüsselt und anschließend sicher in den von der Covata-Plattform verwalteten Remotespeicher hochgeladen. <br />
   **Hinweis:** Beachten Sie bitte Folgendes:

   - Diese Inhalte werden nach ihrem Upload im Remotespeicher des Covata-Benutzers gespeichert, in dessen Ordner Sie Inhalte kopiert/verschoben haben.
   - Der Besitzer dieses Ordners wird der Besitzer der von Ihnen hochgeladenen Inhalte. Diese Inhalte erscheinen daher im Ordner „`Meine sicheren Dateien`“ des Besitzers, wenn sich dieser das nächste Mal bei Safe Share for Windows anmeldet oder die Elemente im betreffenden Ordner aufruft.
   - Alle (vom Besitzer des Ordners festgelegten) Mitwirkenden des Ordners erhalten auf die von Ihnen hochgeladenen Inhalte Zugriff, abhängig von den Berechtigungen der einzelnen Mitwirkenden hinsichtlich des Ordners.
   - Wenn Sie die Meldung „*Aktion konnte nicht ausgeführt werden - Das Element existiert im Ordner oder Remotespeicher bereits.*“ erhalten, existiert im Ordner des Benutzers bereits mindestens ein Element mit demselben Namen. Sie sind jedoch eventuell aus den folgenden Gründen kein Mitwirkender dieser Elemente:

     - Sie haben [Ihren Zugriff auf diese Elemente](/2.16/de/windows/managing-secure-content#removing-your-access-to-secure-content-shared-with-you) entfernt.
     - Der Besitzer hat Sie als Mitwirkender der Elemente entfernt. Für weitere Informationen siehe [Aufhebung der Freigabe sicherer Inhalte](/2.16/de/windows/managing-secure-content#unsharing-secure-content) oder
     - Die Elemente wurden Ihnen nie freigegeben.
