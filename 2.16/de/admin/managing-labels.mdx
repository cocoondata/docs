---
title: "Verwaltung von Bezeichnungen"
---

Die Seite **Bezeichnungen** ermöglicht es Covata-Plattform-Administratoren, eine Reihe von Bezeichnungen zu definieren, aus denen [Covata-Benutzer](/2.16/de/admin/administering-users) wählen können, wenn sie anderen Personen über Safe Share-Anwendungen, einschließlich andere Client-Anwendungen, die mit der API der Covata-Plattform arbeiten, Dateien freigeben.

Anhand von Bezeichnungen können Covata-Benutzer die Möglichkeit der Freigabe von Dateien auf eine bestimmte [Gruppe der Covata-Benutzer](/2.16/de/admin/managing-groups) beschränken. Ist eine Bezeichnung einem Covata-Benutzer nicht zugewiesen (d. h. die Bezeichnung ist keiner [Gruppe](/2.16/de/admin/managing-groups) zugewiesen, der der betreffende Benutzer angehört), kann eine Datei mit der betreffenden Bezeichnung an diesen Benutzer nicht freigegeben werden.**

![Seite Bezeichnungen](/images/3c15e800863e-labels-page.png)
** „Dateien“ können sich in diesem Kontext auch auf sichere Objekte beziehen.

## Hinzufügen einer neuen Bezeichnung <a id="adding-a-new-label" />

**Hinzufügen einer neuen Bezeichnung zur Covata-Plattform:**

1. [Melden Sie sich](/2.16/de/admin/accessing-administration#signing-in) bei der Covata-Verwaltung an.
2. Klicken Sie auf die Option **Bezeichnungen** links auf der [Covata-Verwaltung-Oberfläche](/2.16/de/admin/accessing-administration#the-administration-interface), um die Seite **Bezeichnungen** aufzurufen.
3. Klicken Sie auf die Schaltfläche **Neue hinzufügen**.
4. Geben Sie im Dialogfeld **Neue hinzufügen** Folgendes an:

   - **Name** - der Wert dieses Felds ist der Name der Bezeichnung, den Covata-Benutzer von Safe Share-Anwendungen, einschließlich Client-Anwendungen, die mit der API der Covata-Plattform arbeiten, (bei der Freigabe eines Elements) sehen.
   - **Beschreibung ( *Optional* )** - eine längere Beschreibung für mehr Informationen über die Bezeichnung, z. B. ihren Zweck oder die beabsichtigte Zielgruppe. Der Wert dieses Felds ist nur für Covata-Plattform-Administratoren auf dieser Seite **Bezeichnungen** sichtbar.

   **Hinweis:** Bitte vergewissern Sie sich, dass Sie mit den obigen Werten zufrieden sind, ehe Sie den Vorgang fortsetzen, da es konzeptionsgemäß sowie aus Sicherheitsgründen nicht möglich ist, jegliche Aspekte einer Bezeichnung zu bearbeiten, nachdem sie erstellt wurde.
5. Klicken Sie auf **Speichern**, und die neue Bezeichnung erscheint als neue Eintragung auf der Seite **Bezeichnungen**. <br />
   **Hinweise:**

   - Siehe [Verwaltung von Gruppen](/2.16/de/admin/managing-groups), um diese Bezeichnung einem Covata-Benutzer oder mehreren (als Gruppe) zuzuweisen. Dieser Vorgang ermöglicht es, die Freigabe von Dateien anhand der Bezeichnung auf die betreffenden Benutzer zu beschränken.
   - Es wird empfohlen, alle neu hinzugefügten Bezeichnungen baldmöglichst mindestens einer [Gruppe Covata-Benutzer zuzuweisen](/2.16/de/admin/managing-groups), da die Auswahl einer noch keiner Gruppe oder keinen Benutzern zugewiesenen Bezeichnung bei der Freigabe von Dateien/sicheren Objekten verhindert, dass diese tatsächlich freigegeben werden können.

## Löschen einer bestehenden Bezeichnung <a id="deleting-an-existing-label" />

Löschen einer Bezeichnung entfernt einerseits die betreffende Bezeichnung von allen Dateien, denen sie bei ihrer Freigabe zugewiesen wurde, und andererseits alle Mitwirkenden von den betreffenden Dateien.

**Löschen einer bestehenden Bezeichnung von der Covata-Plattform:**

1. [Melden Sie sich](/2.16/de/admin/accessing-administration#signing-in) bei der Covata-Verwaltung an.
2. Klicken Sie auf die Option **Bezeichnungen** links auf der [Covata-Verwaltung-Oberfläche](/2.16/de/admin/accessing-administration#the-administration-interface), um die Seite **Bezeichnungen** aufzurufen.
3. Suchen Sie die betreffende Bezeichnung bzw. blättern Sie zu ihr und klicken Sie auf den Link **Löschen**.
4. Eine Meldung **Löschen** wird aufgerufen, die Sie warnt, dass die Löschung der Bezeichnung diese von allen Dateien entfernt, denen sie bei der Freigabe zugewiesen wurde. <br />
   **Hinweis:** Beachten Sie, dass diese Aktion auch alle Mitwirkenden von den betreffenden Dateien entfernt, ehe Sie den Vorgang fortsetzen.
5. Klicken Sie in dieser Meldung auf **Ja**, um die Bezeichnung zu löschen.
