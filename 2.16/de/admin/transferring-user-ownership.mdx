---
title: "Übertragung des Besitzes von Benutzern"
---

Mithilfe der Seite **Besitz übertragen** können [Benutzer-Administratoren](/2.16/de/admin/administering-users#user-administrator-role) den Besitz an den *gesamten gesicherten Inhalten* eines Benutzers an einen anderen Benutzer übertragen.

Bei der Übertragung des Besitzes beinhalten die *gesamten gesicherten Inhalte* eines Benutzers seine kompletten gesicherten Objekte und Sammlungen.

<Note>

Der Besitz kann nur von einem Benutzer, dessen Account [deaktiviert](/2.16/de/admin/administering-users#disabling-or-re-enabling-users) ist, an einen Benutzer, dessen Account [aktiviert](/2.16/de/admin/administering-users#disabling-or-re-enabling-users) ist, übertragen werden.

</Note>

## Übertragung des Besitzes von einem Benutzer auf einen anderen <a id="transferring-ownership-from-one-user-to-another" />

**Übertragung des Besitzes an sicheren Objekten und Sammlungen von einem Benutzer auf einen anderen:**

1. [Melden Sie sich](/2.16/de/admin/accessing-administration#signing-in) bei der Covata-Verwaltung (als Covata-Benutzer mit der Rolle [Benutzer-Administrator](/2.16/de/admin/administering-users#user-administrator-role)) an und vergewissern Sie sich, dass auf der [Covata-Verwaltung-Oberfläche](/2.16/de/admin/accessing-administration#the-administration-interface) die Seite **Besitz übertragen** angezeigt wird.
2. Suchen Sie den [deaktivierten](/2.16/de/admin/administering-users#disabling-or-re-enabling-users) Benutzer-Account, dessen sämtlichen gesicherten Inhalte auf einen anderen Benutzer-Account übertragen werden sollen. <br />
   **Tipps:**

   - Wenn die Liste deaktivierter Benutzer-Accounts mehr als eine Seite lang ist, können Sie bestimmte Benutzer-Accounts (oder Gruppen bestimmter Accounts) anhand der folgenden Funktionen suchen:

     - *Benutzer-Accounts filtern* - fangen Sie im Feld **Suche nach...** (rechts auf der Seite **Benutzer**) an, eine Reihe von Zeichen einzugeben, die in den [Feldern](/2.16/de/admin/administering-users#a-users-fields) **E-Mail**, **Vorname** oder **Familienname** des/der Benutzer enthalten sind. Dies filtert die Liste der Benutzer der Covata-Plattform nach denen, deren E-Mail-Adresse, Vorname oder Familienname die im Feld **Suche nach...** eingegebene Zeichenfolge enthält. <br />
        Standardmäßig werden für den Filter die Felder **E-Mail**, **Vorname** oder **Familienname** verwendet (d. h. **Alle**), aber Sie können den Filter anhand des Dropdown-Menüs auch auf eines dieser Felder beschränken.
     - *Zu spezifischen Benutzer-Accounts navigieren* - verwenden Sie die Schaltflächen zur Seitennavigation (rechts unten auf der Seite **Benutzer**), die Sie zusammen mit dem Dropdown-Menü **25/50/75/100 Elemente** (d. h. Benutzer-Accounts) pro Seite einsetzen können.
   - Sie können Benutzer-Accounts auch auf der Seite **Benutzer** sortieren, indem Sie auf den verknüpften Namen (im Spaltenkopf) des betreffenden Felds klicken, nach dem Sie Ihre Benutzer sortieren möchten:

     - Mehrfaches Anklicken eines verknüpften Feldnamens schaltet zwischen einer Sortierung der Benutzer in aufsteigender und absteigender Reihenfolge (gemäß dem betreffenden Feld) um.
     - Aktualisieren Sie einfach die Seite, um zur normalen Sortierung der Benutzer in der Liste zurückzukehren.
3. Klicken Sie auf den Link **Übertragen** rechts neben dem betreffenden Benutzer-Account.
4. Wählen Sie im Dialogfeld **Übertragen an...** den [aktivierten](/2.16/de/admin/administering-users#disabling-or-re-enabling-users) Benutzer-Account, dem der Besitz an den gesicherten Inhalten des gewählten, deaktivierten Benutzers (siehe oben) übertragen werden soll.
5. Klicken Sie auf **Fortsetzen**, und der aktivierte (im vorherigen Schritt ausgewählte) Benutzer wird der neue Besitzer der gesicherten Inhalte. Damit wird die gesamte Hierarchie an Dateien (d. h. gesicherten Inhalten) und Ordnern (Sammlungen) des deaktivierten Benutzers auf das Stammverzeichnis des aktivierten Benutzers übertragen und dort in einem Ordner mit dem Namen „Übertragen von...“ gespeichert.
