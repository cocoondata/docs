---
title: "Erzeugung von Berichten"
---

Eine wichtige Sicherheitsfunktion der Covata-Technologie ist die Fähigkeit, alle von Benutzern bei der Erstellung und Verbreitung sicherer Objekte ausgeführten Aktionen prüfen zu können. Wenn Daten von einer Organisation als sicheres Objekt in Form eines Datenlecks offen gelegt werden, müssen Auditoren Instrumente in der Hand haben, um die verantwortliche Person identifizieren zu können.

Die Seite Berichte gibt Administratoren Zugriff auf ein detailliertes Überwachungsprotokoll. Berichte können zu Folgendem erstellt werden:

- für Objekte erstellte und abgerufene Schlüssel
- erstellte und abgerufene sichere Objekte
- aktualisierte sichere Objekte
- erstellte und abgerufene Benachrichtigungen

Diese Funktion ist zwar hauptsächlich für API-Clients gedacht, die anhand von Covata-Technologie ihre eigenen Anwendungen entwickeln, aber sie steht allen Administratoren zur Verfügung.

## Anzeige eines Berichts <a id="view-reports" />

Die Seite Berichte zeigt standardmäßig automatisch die letzten 25 API-Aktionen an.

Wenn Sie weitere Seiten des Berichts aufrufen möchten, klicken Sie auf die Seitenzahlen oberhalb der Liste.

Sie können den Bericht auch als PDF- oder CSV-Datei exportieren. Wählen Sie das Symbol **PDF** oder **CSV**, um den Bericht herunterzuladen.

## Berichtsparameter <a id="report-parameters" />

Für die Erstellung spezifischer Berichte können Sie eine Reihe möglicher Parameter setzen. Diese sind in der folgenden Tabelle dargestellt:

| Feld | Beschreibung |
| --- | --- |
| Anfangsdatum | Ein Anfangsdatum kann für jeden Bericht festgelegt werden. |
| Enddatum | Ein Enddatum kann für jeden Bericht festgelegt werden. |
| Client-ID | Ein eindeutiger Identifikator für jede Client-Anwendung. Diese ID ermöglicht es Administratoren, Berichte über spezifische Clients auszuführen. |
| E-Mail | Eine registrierte E-Mail-Adresse. Diese ermöglicht es Administratoren, Berichte über spezifische Benutzer, z. B. Ersteller, auszuführen. |
| Ressource | Für die Erstellung von Berichten sind drei Ressourcen verfügbar. Wählen Sie aus dem Dropdown-Menü eine Option.  <br />•  Benachrichtigungen <br />•  Objekte <br />•  Schlüssel  |
| Aktion | Für die Erstellung von Berichten sind drei Aktionen verfügbar. Wählen Sie aus dem Dropdown-Menü eine Option.  <br />•  Erstellt <br />•  Abgerufen <br />•  Aktualisiert  |

Setzen Sie die gewünschten Parameter und klicken Sie auf **Anzeigen**, um einen spezifischen Bericht zu erstellen.

Falls Sie den Bericht verfeinern möchten, ändern Sie Parameter oder fügen Sie neue hinzu und klicken Sie erneut auf **Anzeigen**. Die neuen Ergebnisse werden dann auf dem Bildschirm dargestellt.

Sie können den Bericht anschließend als PDF- oder CSV-Datei exportieren. Wählen Sie das Symbol **PDF** oder **CSV**, um den erstellten Bericht herunterzuladen.
