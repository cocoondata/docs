## Upload und Speichern von Inhalten im persönlichen Besitz <a id="uploading-and-storing-personally-owned-content" />

<Note>

Diese Funktion wird nur unterstützt, wenn die Safe Share-Webanwendung auf einem Desktop- oder Laptop-Computer genutzt wird. Von Tablets, Mobiltelefonen oder ähnlichen Geräten werden Uploads über Webbrowser nicht unterstützt. Wenn Sie ein iOS-Gerät nutzen, beachten Sie jedoch bitte, dass Covata für diese Plattform eine eigene App zur Verfügung stellt ([Safe Share für iOS](https://itunes.apple.com/au/app/safe-share/id874127973)).

</Note>

**Sicheres Hochladen und Speichern von Inhalten im persönlichen Besitz:**

1. [Melden Sie sich](/2.16/de/user/signing-in) bei der Safe Share-Webanwendung an.
2. <a id="selecting-and-dragging-files" />Wählen Sie auf Ihrem Desktop-/Laptop-Computer eine oder mehrere Datei(en) und ziehen Sie sie in die Elementeliste auf der Safe Share-Hauptseite: <br />
   ![Datei-Upload durch Drag&Drop](/images/851945183a54-dragging-a-file-to-upload.png)
   <br />
   **Tipps:**

   - Sobald Sie eine oder mehrere Datei(en) in diesen Bereich ziehen, erscheint oben eine Meldung, dass die Safe Share-Webanwendung zum Upload Ihrer Datei(en) bereit ist.
   - Sie können auch eine oder mehrere Datei(en) hochladen, indem Sie links oben auf die Schaltfläche **Hochladen** klicken und anschließend die Datei(en) auf Ihrem Computer auswählen.
   - Sie können auch eine oder mehrere Datei(en) in einen vorhandenen Ordner hochladen, indem Sie sie auf der Safe Share-Hauptseite über diesen Ordner ziehen. Der Ordner wird in einer anderen Farbe hervorgehoben um anzuzeigen, dass die Dateien in diesen Ordner hochgeladen werden. Für weitere Informationen siehe [Organisation von Inhalten in Ordnern](/2.16/de/user/managing-secure-content#organizing-content-with-folders).
   - Klicken Sie auf den [Filter](/2.16/de/user/managing-secure-content#filtering-items) **Meine Dateien** links auf der Safe Share-Hauptseite um sicherzustellen, dass Sie in der Elementeliste nur mit Ihren eigenen Elementen arbeiten.

   **Hinweise:**

   - Wenn Sie keine Dateien hochladen können:

     - ist Ihrem Account eventuell keine **Ersteller**-Rolle zugewiesen. Wenden Sie sich an Ihren Covata-Plattform-Administrator, um Ihrem Benutzer-Account diese Rolle zuweisen zu lassen und dieses Problem zu beheben.
     - sind Sie eventuell nicht berechtigt, an den aktuellen Speicherort im Dateienbereich Daten hochzuladen. Für Einzelheiten siehe die [Tipps](/2.16/de/user/managing-secure-content#folder-tips) in [Organisation von Inhalten in Ordnern](/2.16/de/user/managing-secure-content#organizing-content-with-folders).
   - Die maximale unterstützte Dateigröße hängt von einem in der Covata-Plattform konfigurierten Parameter ab. Ihr Covata-Plattform-Administrator kann Ihnen den Wert dieses Parameters mitteilen.
3. Das Symbol „Uploads im Gang“
   ![Symbol Uploads im Gang](/images/950e0d70a85f-uploads-in-progress-icon.png)

    (in der Kopfleiste) zeigt die Zahl der Dateien an, die aktuell auf von der Covata-Plattform verwalteten Speicher hochgeladen werden. Beachten Sie, dass Dateien verschlüsselt werden, *bevor* sie gespeichert werden.

   - Während Dateien hochgeladen werden, können Sie Dateien, deren Uploads noch im Gang sind, folgendermaßen anzeigen und/oder ihren Upload abbrechen:

     1. Klicken Sie auf das Symbol „Uploads im Gang“ um die Dateien, die aktuell hochgeladen werden, anzuzeigen:

        ![Uploads im Gang](/images/5d0e14846ee0-uploads-in-progress.png)
     2. Klicken Sie im Popup-Fenster neben den Dateien, deren Upload Sie abbrechen möchten, auf **Abbrechen**. <br />
        **Tipp:** Klicken Sie zum Schließen dieses Popup-Fensters auf das Symbol
        ![Popup schließen](/images/6c0b4557a1b6-no-entry-icon.png)

         oder auf einen Bereich außerhalb des Popup-Fensters.

     **Hinweis:** Diese Funktion „Anzeigen und/oder abbrechen“ funktioniert am besten mit großen Dateien. Bei kleinen Dateien haben Sie eventuell nicht genügend Zeit, um ihren Upload anzeigen zu lassen und/oder abzubrechen.

   Nach Abschluss des Upload-Vorgangs werden Ihre Inhalte in Safe Share (am angegebenen Speicherort) sicher gespeichert.

<Tip>

**Tipps und Hinweise:**

- Sobald ein Element hervorgehoben wird, werden seine **Details**- und **Elementeverlauf**-Register rechts vom Elementebereich angezeigt.

  - Wenn Sie das hervorgehobene Element hochgeladen und [es einer oder mehreren Personen freigegeben](/2.16/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) haben, wird (im Abschnitt **Datei-/Ordner-Details** im Register **Details**) ein **Freigabe**-Abschnitt angezeigt, in dem die Covata-Benutzer aufgeführt sind, denen Sie das Element aktuell freigegeben haben.
  - Wenn ein anderer Benutzer das hervorgehobene Element erstellt hat, wird (im Abschnitt **Datei-/Ordner-Details** im Register **Details**) ein **Besitzerdetails**-Abschnitt angezeigt. Wenn dieser Besitzer Ihnen (als Mitwirkenden am betreffenden Element) **Verwaltungs**- oder **Upload**-Berechtigung erteilt hat (dies geschieht anhand des [Dialogfelds Freigeben](/2.16/de/user/uploading-storing-and-sharing-content-securely#share-dialog-box) (für weitere Informationen siehe [Freigabe sicherer Inhalte](/2.16/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) unten), erscheint auch der **Freigabe**-Abschnitt (unter **Besitzerdetails**) mit den Benutzern, denen das Element aktuell freigegeben ist.
- *Drag & Drop von Ordnern in den Dateibereich auf der Safe Share-Hauptseite wird nicht unterstützt*, da verschiedene Browser diesen Vorgang unterschiedlich handhaben. Zum Beispiel:

  - Bei manchen Browsern (darunter Chrome) werden nur die Dateien im gezogenen Ordner zum (von der Covata-Plattform verwalteten) Speicher im aktuellen, in der Elementeliste gezeigten Speicherort hochgeladen.
  - Bei anderen Browsern (darunter Firefox) werden der gezogene Ordner und seine Inhalte nicht auf den Speicher hochgeladen.

</Tip>

## Freigabe sicherer Inhalte <a id="sharing-secure-content" />

Die folgenden Hinweise erläutern, wie Sie sichere, (zuvor [hochgeladene](/2.16/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content)) Inhalte in Ihrem persönlichen Besitz anderen Personen freigeben sowie die auf diese Inhalte zugriffsberechtigten Covata-Benutzer und/oder die Zugriffsberechtigungen dieser Benutzer ändern können.

<Note>

- Sie können nur *Inhalte in Ihrem Besitz* an andere Personen freigeben.
- Diese Hinweise beschreiben den Freigabevorgang für Inhalte in Ihrem Besitz, aber derselbe Vorgang gilt auch für die Freigabe von Inhalten, die Andere [auf Ihren Ordner hochgeladen haben](/2.16/de/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder), wenn Sie diesen Personen für den betreffenden Ordner **Upload**- oder **Verwaltungs**-Berechtigung erteilt haben. Die Erteilung von Berechtigungen für Ihre Ordner ist [unten](/2.16/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) detaillierter beschrieben.

</Note>

**Freigabe Ihrer sicher gespeicherten Inhalte an andere Personen (oder Änderung vorhandener Freigaben dieser Inhalte):**

1. [Melden Sie sich](/2.16/de/user/signing-in) bei der Safe Share-Webanwendung an. <br />
   **Tipp:** Klicken Sie auf den [Filter](/2.16/de/user/managing-secure-content#filtering-items) **Meine Dateien** links auf der Safe Share-Hauptseite um sicherzustellen, dass Sie in der Elementeliste nur mit Ihren eigenen Elementen arbeiten.
2. [Suchen Sie](/2.16/de/user/managing-secure-content#finding-secure-content) Ihre Datei/Ihren Ordner, die/den Sie einer oder mehreren Anderen freigeben möchten.
3. <a id="opening-the-share-dialog-box" />Öffnen Sie für die Freigabe dieses Elements zunächst das Dialogfeld **Freigeben** auf eine der folgenden Weisen:

   - Klicken Sie mit der rechten Maustaste auf die Zeile des Elements und wählen Sie aus dem Popup-Menü **Freigeben**:

     ![Rechtsklick auf Datei als Besitzer - Kontextmenü](/images/683e6822585d-right-clicking-a-file-context-menu-owner.png)

     <br />
     **Hinweis:** Wenn diese Menüoption nicht verfügbar ist und der (nach dem Namen des Elements gezeigte) **Besitzer** nicht Ihr Benutzer-Account ist, können Sie das Element nicht freigeben, da Sie es nicht besitzen; d. h. Sie können keine Elemente freigeben, die andere Covata-Benutzer besitzen und Ihnen freigegeben haben. <br />
     *ODER*

   1. Klicken Sie auf die Zeile des Elements (rechts von seinem Namen), um es *hervorzuheben*: <br />
      ![Hervorhebung eines Elements als Besitzer](/images/ef1c604beb34-highlighting-an-item-owner.png)
   2. Klicken Sie in der Symbolleiste über der Elementeliste auf die Schaltfläche **Freigeben**. Beachten Sie, dass diese Schaltfläche nur verfügbar ist, wenn Sie der Besitzer des hervorgehobenen Elements sind.
4. <a id="share-dialog-box" />Geben Sie im Dialogfeld **Freigeben** die E-Mail-Adresse der Person (des „Mitwirkenden“) ein, der Sie das Element freigeben möchten. <br />
   **Hinweise:**

   - Wenn Sie lediglich die Berechtigungen eines vorhandenen Mitwirkenden am betreffenden Element ändern möchten, suchen Sie die E-Mail-Adresse dieses Mitwirkenden in der Liste der Mitwirkenden (in diesem Dialogfeld) und gehen Sie direkt zum nächsten Schritt zur [Auswahl der Berechtigungen für Mitwirkende](/2.16/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set).
   - Sie können auf dieses Dialogfeld auch über den [Content-Viewer](/2.16/de/user/accessing-secure-content#content-viewer) zugreifen.

   ![Freigabe-Dialogfeld](/images/7ebc13f8c596-share-dialog-box.png)

   <br />
   **Weitere Hinweise:**

   - Wenn die gewünschte E-Mail-Adresse in der Dropdown-Liste zur Auswahl angezeigt wird, ehe Sie sie fertig eingegeben haben:

     - haben Sie die E-Mail-Adresse bereits verwendet, um Elemente freizugeben, oder
     - haben Sie die E-Mail-Adresse Ihren Kontakten bereits hinzugefügt. Für weitere Informationen siehe [Verwaltung Ihrer Kontakte](/2.16/de/user/managing-your-account#managing-your-contacts).
   - Wenn Sie einen Ordner freigeben, erscheint ein etwas anderes Dialogfeld. (Die Unterschiede sind unten erläutert.)
   - Wenn Ihr Covata-Plattform-Administrator auf dem System keine Bezeichnungen konfiguriert hat, fehlt der Abschnitt **Bezeichnungen** im Dialogfeld **Freigeben**. Weitere Informationen über Bezeichnungen finden Sie im [Covata-Plattform-Administratorenhandbuch](/2.16/de/admin).
5. <a id="selecting-a-permission-set" />Wählen Sie aus der Dropdown-Liste eine der folgenden Berechtigungen aus, um den Zugriff des betreffenden Mitwirkenden auf das Element zu definieren:

   - **Anzeigen** - gewährt die Berechtigung zur Anzeige der Datei (aus dem schreibgeschützten Safe Share-[Content-Viewer](/2.16/de/user/accessing-secure-content#content-viewer) heraus) bzw., wenn es sich um einen Ordner handelt, die Berechtigung zur Anzeige aller Dateien im betreffenden Ordner. Für eine Liste der vom Content-Viewer unterstützten Dateitypen siehe [Vom Content-Viewer unterstützte Dateiformate](/2.16/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer).
   - **Herunterladen** - gewährt die Berechtigung zur Anzeige und zum Ausdruck der Datei (ebenfalls aus dem schreibgeschützten Safe Share-Content-Viewer heraus) sowie zu ihrem Download bzw., wenn es sich um einen Ordner handelt, die entsprechende Berechtigung für alle Dateien im betreffenden Ordner.
   - **Hochladen** ( *nur verfügbar, wenn das Element ein Ordner ist*  ) - gewährt die Berechtigung zur Anzeige, zum Ausdruck und zum Download vorhandener Dateien sowie zum Upload neuer Dateien und zur Erstellung neuer Unterordner innerhalb des betreffenden Ordners.
   - **Verwalten** - gewährt die Berechtigung zur Anzeige, zum Ausdruck, zum Download, zur Umbenennung und zur Löschung der betreffenden Datei. Wenn es sich um einen Ordner handelt, gilt die entsprechende Berechtigung für alle Dateien im betreffenden Ordner, einschließlich der Berechtigung zum Upload neuer Dateien, zur Erstellung neuer Unterordner und zur Löschung vorhandener Unterordner (innerhalb des betreffenden Ordners). <br />
     **Hinweis:** Die Erteilung einer **Verwaltungs**-Berechtigung für einen Ordner ermöglicht es dem Mitwirkenden, den betreffenden Ordner zu löschen.

   **Tipp:** Bei der Freigabe eines Ordners gilt Folgendes:

   - Mitwirkende und ihre Berechtigungen (zum Zugriff auf Inhalte innerhalb des Ordners) werden *implizit* an alle im betreffenden Ordner enthaltenen Elemente weitergegeben (d. h. auf sie angewendet).
   - Wenn Mitwirkende an einem Unterordner (in diesem Ordner) und/oder ihre Berechtigungen geändert werden, werden diese Änderungen *explizit* für den betreffenden Unterordner festgelegt und von dort aus *implizit* über die Elementehierarchie des betreffenden Unterordners weitergegeben.
   - Die Berechtigungen eines Mitwirkenden, die *explizit* für diesen Unterordner vorgegeben wurden, haben Vorrang gegenüber Berechtigungen, die der Mitwirkende (dieses Unterordners) eventuell *implizit* von einem übergeordneten Ordner übernommen hat.
6. Wenn die E-Mail-Adresse des Mitwirkenden (in diesem Dialogfeld) nicht in der Liste der Mitwirkenden erscheint, klicken Sie auf die Schaltfläche **Hinzufügen** (oder drücken Sie zur Auswahl der standardmäßigen **Anzeige**-Berechtigung nach der Eingabe der E-Mail-Adresse einfach die Eingabe-/Return-Taste), und die E-Mail-Adresse und gewählten Zugriffsberechtigungen des Mitwirkenden werden der Liste der Mitwirkenden hinzugefügt.

   ![Hinzugefügter Mitwirkender](/images/267cef3dbbb2-added-collaborator.png)

   <br />
   **Tipps:**

   - Wiederholen Sie diesen Vorgang ab Schritt 4 ([oben](/2.16/de/user/uploading-storing-and-sharing-content-securely#share-dialog-box)), um dieser Liste weitere Mitwirkende hinzuzufügen oder die Berechtigungen vorhandener Mitwirkender zu ändern.
   - Sie können in diesem Textfeld auch mehrere E-Mail-Adressen/Mitwirkende eingeben und diese gleichzeitig hinzufügen. Dies geschieht folgendermaßen:

     - Geben Sie nach jeder E-Mail-Adresse ein Trennzeichen (z. B. Leerstelle oder Komma) ein - die E-Mail-Adresse wird nach der Eingabe jedes Trennzeichens automatisch zur Liste hinzugefügt.
     - Kopieren Sie eine mit Trennzeichen strukturierte „Zeichenfolge“ von E-Mail-Adressen und fügen Sie sie in dieses Feld ein - die Safe Share-Webanwendung identifiziert automatisch die einzelnen E-Mail-Adressen in der Zeichenfolge und fügt sie der Liste hinzu.

     Beachten Sie, dass bei beiden Methoden die in der daneben gezeigten Dropdown-Liste aktuell gewählte Berechtigung auf alle hinzugefügten Mitwirkenden angewendet wird.
   - Klicken Sie auf das **x** neben der betreffenden E-Mail-Adresse, um einen Mitwirkenden (mit den entsprechenden Berechtigungen) aus der Liste zu entfernen.
   - Um mehrere Dateien (in einem Schritt und/oder künftig) einer Gruppe von Personen freizugeben, [erstellen Sie einen Ordner](/2.16/de/user/managing-secure-content#organizing-content-with-folders) und geben Sie ihn anhand dieses Verfahrens an einen oder mehrere Mitwirkende frei. Alle Elemente, die Sie (oder ein Mitwirkender mit **Verwaltungs**-Berechtigung für den betreffenden Ordner) anschließend auf diesen Ordner hochladen, werden sofort an alle aktuellen Mitwirkenden des Ordners freigegeben. Wenn Sie jedoch die Mitwirkenden und Berechtigungen eines beliebigen Unterordners dieses Ordners ändern, haben diese Änderungen **Vorrang** gegenüber den Mitwirkenden und Berechtigungen, die für den ursprünglichen Ordner festgelegt waren.
7. <a id="choosing-a-label" />( *Optional, nur bei der Freigabe einer Datei verfügbar und nur, wenn Ihr Covata-Plattform-Administrator Bezeichnungen konfiguriert hat* ) Wählen Sie aus dem Feld **Bezeichnungen** eine vordefinierte Bezeichnung aus. Bezeichnungen verhalten sich wie „Geheimhaltungsstufen“, anhand deren Sie die Möglichkeit der Freigabe von Dateien auf eine bestimmte Gruppe von Covata-Benutzer beschränken können. <br />
   **Hinweise:**

   - Wenn die Richtlinien Ihrer Organisation es verlangen, dass Sie bei der Freigabe einer Datei eine bestimmte Bezeichnung zuweisen, wählen Sie die für die freizugebenden Inhalte geeignete Bezeichnung. Ihr Covata-Plattform-Administrator hat z. B. möglicherweise die folgenden Bezeichnungen konfiguriert: **Vertraulich**, **Geschützt** und **Nicht klassifiziert** (sowie die Standardoption **Keine Bezeichnung**, bei der die Freigabe ohne Bezeichnung erfolgt). Weitere Informationen über Bezeichnungen und Gruppen finden Sie im [Covata-Plattform-Administratorenhandbuch](/2.16/de/admin).
8. ( *Optional und ebenfalls nur bei der Freigabe einer Datei* verfügbar) Definieren Sie, ab *wann* auf Ihre Datei zugegriffen werden kann:

   1. Klicken Sie hierzu auf den Link **Datums-/Zeit-Steuerelemente festlegen**, um folgende Optionen aufzurufen:

      ![Datums-/Zeit-Steuerelemente](/images/1aea588d5e7a-date-time-controls.png)
   2. Geben Sie dann folgendermaßen Datum und Zeit an:

      - Im Feld **Verfügbarkeit**, das festlegt, ab wann Ihre Mitwirkenden Zugriff auf Ihre Datei haben. Lassen Sie dieses Feld leer, um die Datei unmittelbar zur Verfügung zu stellen.
      - Im Feld **Ablaufdatum** (und -zeit), das festlegt, wann der Zugriff Ihrer Mitwirkenden auf Ihre Datei endet. Lassen Sie dieses Feld leer, um die Datei unbefristet zur Verfügung zu stellen.

      **Tipp:** Bei der Bearbeitung dieser Felder:

      - Klicken Sie zur Angabe des Datums in das Feld (oder das „Kalender“-Symbol). Ein möglicherweise bereits definierter Zeitwert wird beibehalten.
      - Klicken Sie zur Angabe der Zeit auf das „Uhr“-Symbol. Wird kein Datum angegeben, geht die Anwendung vom aktuellen Datum aus.
      - Klicken Sie auf das **x**-Symbol, um die Inhalte des Felds zu löschen.
9. ( *Optional und nur verfügbar, wenn mindestens ein neuer Mitwirkender hinzugefügt wird* ) Klicken Sie auf den Link **Hinweis**, um einen benutzerdefinierten Hinweis zu schreiben, den neue Mitwirkende in ihrer E-Mail-Benachrichtigung erhalten. Dies öffnet ein Textfeld für den Inhalt Ihres Hinweises.

   ![Optionaler Hinweis](/images/2a62bce47ad8-optional-note.png)
10. Klicken Sie auf **Speichern**, um Ihr Element an Ihre Mitwirkenden freizugeben. Alle im Dialogfeld **Freigeben** *neu hinzugefügten* Mitwirkenden erhalten eine E-Mail-Benachrichtigung. <br />
    **Hinweise:**

    - Wenn Sie Ihr Element aufgrund einer der folgenden Warnungen nicht freigeben können:

      - „*Die Positivlisten-Funktion lässt Sie dieses Element nicht den folgenden Benutzern freigeben: ... Bitte wenden Sie sich an Ihren Administrator.*“ - Ihr Covata-Plattform-Administrator hat die Funktion Benutzer-Positivliste in der Covata-Plattform aktiviert, die den Kreis der (auf die Covata-Plattform zugriffsberechtigten) Personen auf diejenigen Benutzer beschränkt, deren E-Mail-Adressen (oder E-Mail-Domänen) der Positivliste hinzugefügt wurden. Sie müssen sich eventuell an Ihren Covata-Plattform-Administrator wenden um zu klären, welche E-Mail-Adressen und -Domänen auf der Positivliste stehen, und so sicherzustellen, dass nicht auf der Positivliste stehende Mitwirkende bei der Freigabe von Elementen (siehe oben) entweder entfernt oder Ihrer Liste von Mitwirkenden nicht hinzugefügt werden.
      - „*Die folgenden Benutzer haben keinen Zugriff auf mit BEZEICHNUNG markierte Dateien:*“ („BEZEICHNUNG“ ist hier der Name der von Ihnen [oben](/2.16/de/user/uploading-storing-and-sharing-content-securely#choosing-a-label) gewählten Bezeichnung) - Ihr Covata-Plattform-Administrator gewährt den in der Warnung aufgeführten Benutzern keinen Zugriff auf mit der betreffenden BEZEICHNUNG markierte Inhalte. Entfernen Sie entweder die Benutzer, die zum Zugriff auf Inhalte mit der betreffenden BEZEICHNUNG nicht berechtigt sind, oder wählen Sie eine andere Bezeichnung.
    - Weitere Informationen über die Benutzer-Positivliste und Bezeichnungen (und Gruppen) finden Sie im [Covata-Plattform-Administratorenhandbuch](/2.16/de/admin).
    - Sie können die Freigabe Ihrer sicheren Inhalte auch aufheben (d. h. Mitwirkende von diesen Inhalten entfernen). Für weitere Informationen siehe [Aufhebung der Freigabe sicherer Inhalte](/2.16/de/user/managing-secure-content#unsharing-secure-content).

<Tip>

Sie können anhand der folgenden Mechanismen Informationen zu Ihren Elementen kommunizieren:

- Um allen aktuellen Mitwirkenden eines Elements E-Mail-Kommunikationen zu senden:

  1. Vergewissern Sie sich, dass das gewünschte Element ausgewählt ist.
  2. Klicken Sie im Abschnitt **Freigabe** im Register **Details** auf das Symbol
     ![Email-Symbol](/images/abcb5e1ee267-email-icon.png)

      um auf Ihrem Computer die E-Mail-Client-Anwendung mit einer neuen E-Mail zu öffnen:

     - **An:** Dieses Feld ist bereits mit den aktuellen Mitwirkenden des betreffenden Elements aufgefüllt.
     - **Betreff:** Dieses Feld enthält den Namen der Datei.
     - Der Nachrichtentext enthält eine direkte URL zum betreffenden Element in der Safe Share-Webanwendung.
- Um eine direkte URL zum betreffenden Element in der Safe Share-Webanwendung zu erhalten:

  1. Vergewissern Sie sich, dass das gewünschte Element ausgewählt ist.
  2. Kopieren Sie im Abschnitt **Freigabe** im Register **Details** die URL aus dem Textfeld **Link**. <br />
      Für [vom Safe Share-Content-Viewer unterstützte Dateiformate](/2.16/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) öffnet diese URL das betreffende Element im [Content-Viewer](/2.16/de/user/accessing-secure-content#content-viewer) und nicht in der Listenansicht auf der Safe Share-Hauptseite.

</Tip>

## Upload von Inhalten zur Freigabe über den Ordner eines anderen Benutzers <a id="uploading-content-to-share-through-another-users-folder" />

Wenn ein Covata-Benutzer, der [einen Ordner besitzt](/2.16/de/user/managing-secure-content#organizing-content-with-folders):

- Ihnen als Mitwirkenden [diesen Ordner freigegeben hat](/2.16/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) und
- Ihnen für den Zugriff auf diesen Ordner entweder **Upload**- oder **Verwaltungs**-Berechtigung erteilt hat,

können Sie Inhalte in diesen Ordner des anderen Covata-Benutzers sicher hochladen und (als Mitwirkender an diesem Ordner) freigeben. Alle von Ihnen in den betreffenden Ordner hochgeladenen Inhalte werden an die anderen Covata-Benutzer freigegeben, deren E-Mail-Adressen im Abschnitt **Freigabe** im Register **Details** aufgeführt sind (dieses wird angezeigt, sobald der Ordner hervorgehoben wird).

<Note>

Wie auch das Hochladen von Inhalten im persönlichen Besitz ([oben](/2.16/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content)) wird diese Funktion nur unterstützt, wenn die Safe Share-Webanwendung auf einem Desktop- oder Laptop-Computer genutzt wird. Von Tablets, Mobiltelefonen oder ähnlichen Geräten werden Uploads über Webbrowser nicht unterstützt.

</Note>

**Feststellung Ihrer Berechtigung, Inhalte in den Ordner eines anderen Benutzers hochzuladen (oder Inhalte dort zu verwalten):**

1. [Melden Sie sich](/2.16/de/user/signing-in) bei der Safe Share-Webanwendung an.
2. Klicken Sie auf den [Filter](/2.16/de/user/managing-secure-content#filtering-items) **Mir freigegeben** links auf der Safe Share-Hauptseite (falls verfügbar), um in der Elementeliste nur diejenigen Elemente anzuzeigen, die andere Covata-Benutzer Ihnen freigegeben haben. <br />
   **Hinweis:** Wenn Ihrem Benutzer-Account nicht die **Ersteller**-Rolle zugewiesen ist, wird nur der [Filter](/2.16/de/user/managing-secure-content#filtering-items) **Alle Dateien** gezeigt, der in der Elementeliste nur Elemente anzeigt, die andere Covata-Benutzer Ihnen freigegeben haben.
3. Greifen Sie in der Elementeliste auf einen Ordner zu. Erscheint links oben die Schaltfläche **Hochladen**, hat Ihnen der andere Benutzer (d. h. der Besitzer des Ordners) **Upload**-Berechtigung erteilt und Sie können Inhalte in diesen Ordner hochladen. Erscheint die Schaltfläche **Hochladen** nicht, können Sie keine Inhalte in diesen Ordner hochladen oder in ihm erstellen. <br />
   **Hinweis:** Wenn Sie nach dem Zugriff auf den Ordner *auch* eine Schaltfläche **Erstellen** sehen (d. h. zur [Erstellung von Unterordnern](/2.16/de/user/managing-secure-content#organizing-content-with-folders) innerhalb dieses Ordners), hat der Besitzer des Ordners Ihnen für den betreffenden Ordner **Verwaltungs**-Berechtigung erteilt.

**Hochladen von Inhalten für die Freigabe über den Ordner eines anderen Benutzers:**

1. Vergewissern Sie sich, dass Sie bei der Safe Share-Webanwendung [angemeldet](/2.16/de/user/signing-in) sind und den Ordner eines anderen Covata-Benutzer identifiziert haben, an dem Sie Mitwirkender sind und für den Sie Upload-Berechtigung haben.
2. Wählen Sie auf Ihrem Desktop-/Laptop-Computer eine oder mehrere Datei(en) aus. Anschließend:

   - Wenn Sie auf der Startseite oder im Stammverzeichnis der Safe Share-Hauptseite sind und/oder den Ordner des anderen Benutzers, in den Sie Inhalte hochladen möchten, in Ihrer Elementeliste sehen, ziehen Sie die Datei(en) auf diesen Ordner. Der Ordner wird mit einer anderen Farbe hinterlegt, und es erscheint oben eine Meldung, dass die Safe Share-Webanwendung zum Upload Ihrer Datei(en) in diesen Ordner bereit ist. Für weitere Informationen über Ordner siehe [Organisation von Inhalten in Ordnern](/2.16/de/user/managing-secure-content#organizing-content-with-folders).
   - Wenn Sie den Ordner des anderen Benutzers angeklickt und geöffnet haben, ziehen Sie Ihre Datei(en) in die Elementeliste auf der Safe Share-Hauptseite, ähnlich wie in [Schritt 2](/2.16/de/user/uploading-storing-and-sharing-content-securely#selecting-and-dragging-files), [Upload und Speichern von Inhalten im persönlichen Besitz](/2.16/de/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) (oben) beschrieben. Sobald Sie eine oder mehrere Datei(en) in diesen Bereich ziehen, erscheint oben eine Meldung, dass die Datei(en) zum Upload bereit steht/stehen. <br />
     **Tipps:** Wenn Sie den Ordner des anderen Benutzers geöffnet haben, können Sie Dateien auch folgendermaßen hochladen:

     - Klicken Sie auf die Schaltfläche **Hochladen** links oben und wählen Sie anschließend die gewünschte(n) Datei(en) auf Ihrem Computer aus.
     - Um die Datei(en) in einen Unterordner (des betreffenden Ordners dieses Benutzers) hochzuladen, ziehen Sie die Datei(en) über diesen Unterordner oder öffnen Sie den Unterordner und ziehen Sie die Datei(en) in die Elementeliste. Für weitere Informationen siehe [Organisation von Inhalten in Ordnern](/2.16/de/user/managing-secure-content#organizing-content-with-folders).
3. Das Symbol „Uploads im Gang“
   ![Symbol Uploads im Gang](/images/950e0d70a85f-uploads-in-progress-icon.png)

    (in der Kopfleiste) zeigt die Zahl der Dateien an, die aktuell auf von der Covata-Plattform verwalteten Speicher hochgeladen werden. Beachten Sie, dass Dateien verschlüsselt werden, *bevor* sie gespeichert werden.

   - Während Dateien hochgeladen werden, können Sie Dateien, deren Uploads noch im Gang sind, folgendermaßen anzeigen und/oder ihren Upload abbrechen:

     1. Klicken Sie auf das Symbol „Uploads im Gang“ um die Dateien, die aktuell hochgeladen werden, anzuzeigen:

        ![Uploads im Gang](/images/5d0e14846ee0-uploads-in-progress.png)
     2. Klicken Sie im Popup-Fenster neben den Dateien, deren Upload Sie abbrechen möchten, auf **Abbrechen**. <br />
        **Tipp:** Klicken Sie zum Schließen dieses Popup-Fensters auf das Symbol
        ![Popup schließen](/images/6c0b4557a1b6-no-entry-icon.png)

         oder auf einen Bereich außerhalb des Popup-Fensters.

     **Hinweis:** Diese Funktion „Anzeigen und/oder abbrechen“ funktioniert am besten mit großen Dateien. Bei kleinen Dateien haben Sie eventuell nicht genügend Zeit, um ihren Upload anzeigen zu lassen und/oder abzubrechen.

   Inhalte werden in Safe Share innerhalb des Ordners des anderen Benutzers sicher gespeichert, sobald der Upload-Vorgang abgeschlossen ist. <br />
   **Hinweis:** Beachten Sie bitte Folgendes:

   - Diese hochgeladenen Inhalte werden dem Speicherkontingent des Covata-Benutzer angerechnet, der den Ordner besitzt, in den Sie Ihre Inhalte hochgeladen haben.
   - Der Besitzer dieses Ordners wird der Besitzer der von Ihnen hochgeladenen Inhalte.

<a id="advertising-communicating-about-an-item" />

<Tip>

Anhand der folgenden Mechanismen können Sie Informationen über Elemente kommunizieren, die Sie über den Ordner eines anderen Benutzers freigegeben haben (oder die eine andere Person Ihnen freigegeben hat):

- Um eine direkte URL zu einem Element (in der Safe Share-Webanwendung) zu erhalten, für das Sie **Verwaltungs**- oder **Upload**-Berechtigung haben:

  1. Vergewissern Sie sich, dass das gewünschte Element ausgewählt ist.
  2. Kopieren Sie im Abschnitt **Freigabe** im Register **Details** die URL aus dem Textfeld **Link**. <br />
      Für [vom Safe Share-Content-Viewer unterstützte Dateiformate](/2.16/de/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) öffnet diese URL das betreffende Element im [Content-Viewer](/2.16/de/user/accessing-secure-content#content-viewer) und nicht in der Listenansicht auf der Safe Share-Hauptseite.
- Um allen aktuellen Mitwirkenden (einschließlich dem Besitzer) eines Elements, für das Sie **Verwaltungs**- oder **Upload**-Berechtigung haben, oder nur dem Besitzer eines Elements, für das Sie **Download**- oder **Anzeige**-Berechtigung haben, E-Mail-Kommunikationen zu senden:

  1. Vergewissern Sie sich, dass das gewünschte Element ausgewählt ist.
  2. Klicken Sie im Abschnitt **Freigabe** im Register **Details** auf das Symbol
     ![Email-Symbol](/images/abcb5e1ee267-email-icon.png)

      um auf Ihrem Computer die E-Mail-Client-Anwendung mit einer neuen E-Mail zu öffnen:

     - **An:** Dieses Feld ist bereits mit dem Besitzer und/oder den aktuellen Mitwirkenden des betreffenden Elements aufgefüllt.
     - **Betreff:** Dieses Feld enthält den Namen der Datei.
     - Der Nachrichtentext enthält eine direkte URL zum betreffenden Element in der Safe Share-Webanwendung.

</Tip>
