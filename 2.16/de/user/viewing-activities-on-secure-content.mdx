---
title: "Anzeige der an sicheren Inhalten ausgeführten Aktivitäten"
---

Benutzer der Safe Share-Webanwendung können einen Verlauf [bestimmter Aktivitäten](/2.16/de/user/viewing-activities-on-secure-content#types-of-activities-indicated) aufrufen, die an einer Datei oder einem Ordner ausgeführt wurden.

**Anzeige der an einer Datei oder einem Ordner ausgeführten Aktivitäten:**

1. [Melden Sie sich](/2.16/de/user/signing-in) bei der Safe Share-Webanwendung an.
2. [Suchen Sie](/2.16/de/user/managing-secure-content#finding-secure-content) die Datei oder den Ordner, deren/dessen Verlauf Sie aufrufen möchten.
3. Vergewissern Sie sich, dass der Bereich **Details/Elementeverlauf** am rechten Seitenrand angezeigt wird. Klicken Sie hierzu auf die Umschaltfläche „Rechte Randleiste ein-/ausblenden“
   ![Rechte Randleiste umschalten](/images/1d277479aeed-right-panel-toggle-icon.png)

    (in der Kopfleiste).
4. Klicken Sie auf die Zeile des Elements (rechts von seinem Namen), um es *hervorzuheben*: <br />
   ![Hervorhebung eines freigegebenen Elements als Besitzer](/images/0323aaf80412-highlighting-a-shared-item-owner.png)
5. Klicken Sie auf das Register **Elementeverlauf**, um den Verlauf der am Element ausgeführten Aktivitäten in umgekehrter chronologischer Abfolge darzustellen: <br />
   ![Aktivitätsfeed als Besitzer](/images/d838e5cb3383-activity-feed-owner.png)

## Arten der angezeigten Aktivitäten <a id="types-of-activities-indicated" />

Die Arten der angezeigten, an einer Datei oder einem Ordner (d. h. Element) ausgeführten Aktivitäten hängen von den folgenden Bedingungen ab:

- Für die folgenden Rollen:

  - *Besitzer* eines Elements,
  - *Mitwirkender*<sup>1</sup> mit **Verwaltungs**[-Berechtigung](/2.16/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) für ein Element oder
  - *Mitwirkender* mit **Upload**-Berechtigung für ein von Ihnen erstelltes Element<sup>2</sup>,

  zeigt das Register **Elementeverlauf** an, wann (und von wem) das Element erstellt wurde, sowie jede der folgenden Aktivitäten Zugriffsberechtiger:

  - [Anzeige](/2.16/de/user/accessing-secure-content#viewing-and-printing-secure-content) oder [Download](/2.16/de/user/accessing-secure-content#downloading-secure-content) des Elements (wenn es sich um eine Datei handelt),
  - Änderung:

    - des Namens des Elements oder
    - des Speicherorts des Elements.
  - Nur für Besitzer des Elements auch Änderungen:

    - der [Freigabe](/2.16/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) des Elements oder
    - der [Berechtigung von Mitwirkenden](/2.16/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) des Elements (bei seiner [Freigabe](/2.16/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content)).
- Für *Mitwirkende* mit **Download**- oder **Anzeige**-Berechtigung an einer Datei, die sie *nicht* erstellt haben, zeigt das Register **Elementeverlauf** die einzelnen [Anzeigen](/2.16/de/user/accessing-secure-content#viewing-and-printing-secure-content) und [Downloads](/2.16/de/user/accessing-secure-content#downloading-secure-content) der betreffenden Datei an.
- Für *Mitwirkende* mit **Upload**-, **Download**- oder **Anzeige**-Berechtigung an einem Ordner, den sie *nicht* erstellt haben, zeigt das Register **Elementeverlauf** keine Aktivitäten an.

<sup>1</sup> *Mitwirkende* eines Elements sind Personen mit Zugriffsberechtigung auf das betreffende Element. Mitwirkende besitzen das Element jedoch nicht, da es sich in einem Ordner eines anderen Besitzers befindet. <br />
<sup>2</sup> *Mitwirkende* sind in diesem Kontext Sie selbst, wenn Sie in einem Ordner eines anderen Besitzers einen Ordner erstellt oder in einen solchen Ordner eine Datei hochgeladen haben. Handelt es sich bei dem betreffenden Element um eine Datei, stuft Safe Share seine Berechtigungen automatisch von **Upload** auf **Download** herunter, da es praktisch nicht möglich ist, Inhalte auf eine Datei hochzuladen.
