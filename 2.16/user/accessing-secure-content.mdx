To access secure content, you can:

- [View, print](/2.16/user/accessing-secure-content#viewing-and-printing-secure-content) or [download](/2.16/user/accessing-secure-content#downloading-secure-content) personally owned files which you had previously uploaded and stored securely with the [Safe Share web application](/2.16/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) or [Safe Share for Windows](/2.16/windows/storing-and-sharing-content-securely#storing-personally-owned-content-securely). These actions can also be performed on files that you had uploaded to share through another user's folder with the Safe Share [web](/2.16/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) or [Windows](/2.16/windows/storing-and-sharing-content-securely#storing-content-to-share-through-another-users-folder) applications.
- [View](/2.16/user/accessing-secure-content#viewing-and-printing-secure-content) files which someone else has stored securely and shared with you using the Safe Share [web](/2.16/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) or [Windows](/2.16/windows/storing-and-sharing-content-securely#sharing-secure-content) applications. You can only [print](/2.16/user/accessing-secure-content#viewing-and-printing-secure-content) or [download](/2.16/user/accessing-secure-content#downloading-secure-content) these files if the owners who shared the files have granted you permission to perform these actions.

## Viewing and printing secure content

The Safe Share web application has a [content viewer](/2.16/user/accessing-secure-content#content-viewer) which allows you to view and optionally print files that other people have shared with you (including [personally owned files which you had previously uploaded](/2.16/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content)). (See [File formats supported by the content viewer](/2.16/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) for a list of file types that the content viewer supports.)

The ability to view or print + download files is based on the permissions that the owners of these files granted their collaborators (i.e. you) when the files were [shared](/2.16/user/uploading-storing-and-sharing-content-securely#sharing-secure-content). The content viewer is useful when the owner of a file wants to share the file's content but not allow the content to be printed and downloaded.

**To view and print secure content:**

If you [Sign in](/2.16/user/signing-in) to the Safe Share web application via a link provided in a 'file has been shared with you' email message, you are taken directly to the file's [content viewer](/2.16/user/accessing-secure-content#content-viewer) (below). Otherwise...

1. [Sign in](/2.16/user/signing-in) to the Safe Share web application.
2. [Locate](/2.16/user/managing-secure-content#finding-secure-content) the file to be viewed/printed.
3. Do one of the following to begin viewing this file:

   - Click the linked name of the file. <br />
     **Note:** If the file's name is not linked, then it is not possible to view or print this file in Safe Share. See [File formats supported by the content viewer](/2.16/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) for a list of file types that the [content viewer](/2.16/user/accessing-secure-content#content-viewer) supports. Instead, you will only be able to [download](/2.16/user/accessing-secure-content#downloading-secure-content) the file to access its content, on the proviso that the owner of this file has granted you (as a collaborator) **Download** permissions on the file. <br />
     *OR*
   - Right-click on the file's row and choose **View** from the pop-up menu:

     ![Right-clicking a file as a collaborator with Manage permissions - context menu](/images/4486e86e5250-right-clicking-a-file-context-menu-collaborator-manage.png)

     <br />
     **Note:** This menu option will not be available if it is not possible to view or print this file in Safe Share. [Downloading](/2.16/user/accessing-secure-content#downloading-secure-content) this file is your only option to access the file's content. <br />
     *OR*

   1. *Highlight* the file, by clicking on the file's row (to the right of its name): <br />
      ![Highlighting an item as a collaborator with Manage permissions](/images/9d70c5a626d2-highlighting-an-item-collaborator-manage.png)
   2. In the toolbar above the list of items, click the **More** menu button and choose the **View** option. Again, this option will not be available if it is not possible to view or print this file in Safe Share; [downloading](/2.16/user/accessing-secure-content#downloading-secure-content) this file is your only option to access the file's content.

   **Tip:** If navigating to a file in a folder (by having clicked through one or more folder names), then in the breadcrumb (e.g.

   ![Breadcrumb](/images/0d2c6014f6e6-breadcrumb.png)

    ) near the top of the main Safe Share page, you can click the:

   - Link of a parent folder's name (e.g. **Shared Folder** in the example above) to go to that folder's location.
   - **Home** link to go to the root location of your file area.

   <a id="content-viewer" /> The content viewer opens, showing a read-only view of your file's content:

   - If your file is an image, the content viewer and its controls will look similar to this: <br />
     ![Content viewer for image files](/images/2cd3dd51b5ab-content-viewer-image.jpg)
   - If your file is a document-like file (i.e. which may contain more than one page), the content viewer and its controls will look similar to this: <br />
     ![Content viewer for document files](/images/5fcefc3893fa-content-viewer-document.jpg)

   **Tips on using the content viewer:**

   - Click the
     ![Print button](/images/e875848c94db-print-button.png)

      (Print) button on the content viewer to print the file's content. <br />
     **Note:** This feature will be disabled if the file you are viewing was [shared with you](/2.16/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) *and* the owner of that file did not grant you (as a collaborator) **Download** permissions, which in addition to [downloading the file's content](/2.16/user/accessing-secure-content#downloading-secure-content), allows you to print it directly from the content viewer.
   - Click the
     ![Download button](/images/c6f8114c7564-download-button.png)

      (Download) button on the content viewer to download the file's content, which can also be performed from the [main Safe Share page](/2.16/user/accessing-secure-content#downloading-secure-content). <br />
     **Note:** This button will not be visible if the file you are viewing was [shared with you](/2.16/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) *and* the owner of that file did not grant you (as a collaborator) **Download** permissions.
   - If you are the owner of the file you are currently viewing, click the
     ![Share button](/images/f3f819964901-share-button.png)

      (Share) button to [open the 'Share' dialog box](/2.16/user/uploading-storing-and-sharing-content-securely#share-dialog-box), which allows you to add new collaborators and/or modify existing collaborators (including their permissions) on this file. <br />
     **Note:** This button will not be visible if you are not the owner of this file.
   - If you are viewing an image file, click the
     ![Toggle between scaled and actual size button](/images/43764e011ef8-toggle-scaled-actual-size-button.png)

      (Toggle between scaled and actual size) button on the content viewer to switch between viewing the image in its entirety (i.e. scaled) or at its actual/original size.
   - The following features are only available when viewing document-like files:

     - Use the '+' (plus) and '-' (minus) buttons to zoom in and out of the content view. The adjacent drop-down can also be used to select an appropriate zoom level.
     - Click the
       ![Full screen button](/images/01ea2c7eafe6-full-screen-button.png)

        (full screen button) to expand the size of the content to fill the entire screen (using the web browser's own 'full screen' feature). <br />
       **Note:** Some web browsers may not support this feature (e.g. Safari) and therefore, clicking this button has no effect.
     - If your content consists of multiple pages, you can navigate to different pages by:

       - Using the 'down' (forward) and 'up' (back) arrow buttons to move forward and back one page at a time.
       - Clicking the
         ![Preview panel button](/images/78354dc3e80a-preview-panel-button.png)

          (show/hide preview panel button) to open the preview panel on the left and in this panel, scrolling to and clicking the corresponding thumbnails for specific pages.
       - Typing a page number in the **Page** field (followed by the 'return/enter' key).
     - Click the
       ![More options button](/images/b02486c7a3a6-more-options-button.png)

        (more options button) to open a drop-down menu of additional controls:

       - Jump to the first and last pages of content (consisting of multiple pages).
       - Rotate content clockwise and counterclockwise.
       - Enable/disable the hand 'move' tool.

<Tip>

To go back to the main Safe Share page, click the **x** at the top-right of the content viewer.

</Tip>

## File formats supported by the content viewer

The [content viewer](/2.16/user/accessing-secure-content#content-viewer) supports the following file formats, which are determined by file name extensions:

| File-type category | Supported file formats (file name extensions) |
| --- | --- |
| Image files | bmp, gif, jpeg, jpg, png |
| Word processing/text documents | doc, docx, html, mhtml, odt, ooxml, rtf, txt, xhtml, xml |
| Documents with static content | pdf |
| Presentation files | odp, pot, potx, pps, ppsx, ppt, pptx |
| Spreadhsheet/data files | csv, ods, xls, xlsb, xlsm, xlsx, xltm, xltx, xlxm |

## Downloading secure content

<Note>

This feature is not available if a file you can [view](/2.16/user/accessing-secure-content#viewing-and-printing-secure-content) was [shared with you](/2.16/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) *and* the owner of that file did not allow their collaborators to download the file's content.

</Note>

**To download secure content:**

1. [Sign in](/2.16/user/signing-in) to the Safe Share web application.
2. [Locate](/2.16/user/managing-secure-content#finding-secure-content) the file to be downloaded.
3. Do one of the following to begin downloading this file:

   - Right-click on the file's row and choose **Download** from the pop-up menu:

     ![Right-clicking a file as an owner - context menu](/images/646aa13cf8ce-right-clicking-a-file-context-menu-owner.png)

     <br />
     **Note:** If this menu option is not available, then it is not possible to download this file since its owner did not grant **Download** permissions when they [shared the file](/2.16/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) with you. <br />
     *OR*

   1. *Highlight* the file, by clicking on the file's row (to the right of its name): <br />
      ![Highlighting an item as an owner](/images/aff771317e1d-highlighting-an-item-owner.png)
   2. In the toolbar above the list of items, click the **Download** button. Note that this option will not be available if the owner did not grant **Download** permissions when they [shared the file (or one of its ancestral folders)](/2.16/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) with you.

   The file is downloaded through your web browser's usual download feature. <br />
   **Tip:** You can also download a file's content through the [content viewer](/2.16/user/accessing-secure-content#content-viewer).
