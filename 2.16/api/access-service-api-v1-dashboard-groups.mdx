## URL structure <a id="access-service-api-v1-dashboard-groups-url-structure" />

```text
https://access-service.xy-company.com/api/v1/dashboard/groups
```

## Supported methods and overview <a id="access-service-api-v1-dashboard-groups-supported-methods-and-overview" />

- `GET` - used to retrieve a summary of information about [Covata user](/2.16/admin/administering-users) membership for all existing [groups](/2.16/admin/managing-groups) on the Covata Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-dashboard-groups-detailed-description" />

This API endpoint retrieves a summary of information about the numbers and percentages of Covata users who are members of each existing group on the Covata Platform.

All [existing groups](/2.16/api/access-service-api-v1-groups) on the Covata Platform are returned in the [response](/2.16/api/access-service-api-v1-dashboard-groups#access-service-api-v1-dashboard-groups-returns) to this API endpoint.

## Supported roles <a id="access-service-api-v1-dashboard-groups-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)):

- [System administrator](/2.16/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-dashboard-groups#access-service-api-v1-dashboard-groups-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-dashboard-groups-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`
