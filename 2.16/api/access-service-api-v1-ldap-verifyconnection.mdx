## Supported methods and overview <a id="access-service-api-v1-ldap-verifyconnection-supported-methods-and-overview" />

- `POST` - used to verify the connection to an [LDAP user directory](/2.16/admin/configuring-ldap).

## Detailed description <a id="access-service-api-v1-ldap-verifyconnection-detailed-description" />

This API endpoint verifies the connection to an LDAP user directory.

With this request, a core [subset of LDAP connection parameters must be submitted](/2.16/api/access-service-api-v1-ldap-verifyconnection#access-service-api-v1-ldap-verifyconnection-required-parameters), which includes the:

- address of the server running LDAP (along with the connection timeout duration),
- LDAP user directory's manager credentials (to perform LDAP authentication and synchronization),
- root node in LDAP from which the Covata Platform finds users and groups and
- LDAP field against which the Covata Platform matches the email address of a Covata user when they authenticate.

## Supported roles <a id="access-service-api-v1-ldap-verifyconnection-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin/index)):

- [System administrator](/2.16/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-ldap-verifyconnection#access-service-api-v1-ldap-verifyconnection-required-headers) of requests to this endpoint.
