## URL structure <a id="access-service-api-v1-users-me-contacts-url-structure" />

```text
https://access-service.xy-company.com/api/v1/users/me/contacts
```

## Supported methods and overview <a id="access-service-api-v1-users-me-contacts-supported-methods-and-overview" />

- `POST` - used to create a new contact for the currently authenticated [Covata user](/2.16/admin/administering-users)<sup>&#42;</sup>.
- `GET` - used to retrieve a list of field information for all contacts of the currently authenticated Covata user.

## Detailed description <a id="access-service-api-v1-users-me-contacts-detailed-description" />

This API endpoint serves a number of purposes:

- Creates a new contact for the currently authenticated Covata user<sup>&#42;</sup>. This contact consists of a mandatory email address as well as optional first and last names. <br />
  **Note:** A contact can be created for any person who does not have a registered Covata user account. However, as to whether or not sharing the currently authenticated Covata user's content with this contact will succeed, ultimately depends on the contact's email address complying with a rule of an enabled user whitelist on the Covata Platform. If this content is successfully shared with this contact, then a new Covata user account is automatically created for this contact (with the [Ad hoc role](/2.16/admin/administering-users#adhoc-role)).
- Retrieves a list of field information for all contacts of the currently authenticated Covata user. The list of contacts returned in the [response](/2.16/api/access-service-api-v1-users-me-contacts#access-service-api-v1-users-me-contacts-returns) can be filtered according to contacts whose email address, first name or last name contains the string specified in the request.

## Supported roles <a id="access-service-api-users-me-contacts-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)):

- [Originator](/2.16/admin/administering-users#originator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-users-me-contacts#access-service-api-v1-users-me-contacts-required-headers) of requests to this endpoint.
