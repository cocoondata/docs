## URL structure <a id="access-service-api-v1-users-url-structure" />

```text
https://access-service.xy-company.com/api/v1/users
```

## Supported methods and overview <a id="access-service-api-v1-users-supported-methods-and-overview" />

- `POST` - used to add a new [Covata user](/2.16/admin/administering-users).
- `GET` - used to [retrieve a list of field information for all existing users](/2.16/admin/administering-users#finding-existing-users) on the Covata Platform.

## Detailed description <a id="access-service-api-v1-users-detailed-description" />

This API endpoint serves a number of purposes:

- Adds a new Covata user to the Covata Platform. <br />
  **Note:** Use this endpoint to add a new Covata user with any valid (combination of) [role(s)](/2.16/admin/administering-users#a-users-roles), with the exception of Covata users with the [Ad hoc role](/2.16/admin/administering-users#adhoc-role) (whose accounts are created when a user with the [Originator role](/2.16/admin/administering-users#originator-role) shares their content with someone whose email address has not yet been registered with an existing user account on the Covata Platform).
- Retrieves a list of field information for all existing users on the Covata Platform. The list of users returned in the [response](/2.16/api/access-service-api-v1-users#access-service-api-v1-users-returns-from-a-POST-request) can be filtered according to users:

  - whose email address, first name or last name contains the string specified in the request,
  - with a specific role, and/or
  - whose accounts are either enabled or disabled.

## Supported roles and conditions <a id="access-service-api-v1-users-supported-roles-and-conditions" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)) and conditions:

- [System administrator](/2.16/admin/administering-users#system-administrator-role)
- [User administrator](/2.16/admin/administering-users#user-administrator-role) - a Covata user with this role can call the `GET` method only.

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-users#access-service-api-v1-users-required-headers) of requests to this endpoint.

## Optional parameters on GET <a id="access-service-api-v1-users-optional-parameters-on-GET" />

The following optional parameters can be sent in the URL of the GET request:

- **enabled** - true or false.
- **limit** - 0 to 100 (default is 10).
- **offset** - default is 0.
- **orderBy** - `ASC` or `DESC` (default is `ASC`).
- **searchColumn** - all, email, firstName, lastName, roles or admin.
- **searchText** - when searchColumn is admin, specify yes or no. Otherwise, search on any text value in the column(s) specified by searchColumn.
- **sortBy** - default is userId.
