## URL structure <a id="content-service-api-v1-users-me-url-structure" />

```text
https://content-service.xy-company.com/api/v1/users/me
```

## Supported methods and overview <a id="content-service-api-v1-users-me-supported-methods-and-overview" />

- `GET` - used to retrieve the total storage (managed by the Covata Platform's Content Service) which has been utilized by the currently authenticated [Covata user](/2.16/admin/administering-users)<sup>&#42;</sup>.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="content-service-api-v1-users-me-detailed-description" />

This API endpoint retrieves the total number of bytes of storage (managed by the Covata Platform's Content Service) which has been utilized by the currently authenticated Covata user<sup>&#42;</sup>.

This total consists of the encrypted data of the Covata user's [Secure Objects](/2.16/api/creating-secure-objects-and-collections#secure-object), as well as all *read-only view* data for this user's Secure Objects, whose file types (determined by file name extension) support the generation of read-only views.

## Supported roles <a id="content-service-api-v1-users-me-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)):

- [Originator](/2.16/admin/administering-users#originator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/content-service-api-v1-users-me#content-service-api-v1-users-me-required-headers) of requests to this endpoint.

## Required headers <a id="content-service-api-v1-users-me-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Returns <a id="content-service-api-v1-users-me-returns" />

A JSON-formatted response containing the following members:

- **diskStorage** - A member containing information about the total storage (managed by the Covata Platform's Content Service) which has been utilized by the currently authenticated Covata user. This member contains the following sub-member:

  - **total** - The total amount of space (in bytes) of all Secure Objects' encrypted data in storage (managed by the Content Service).

  **Example:**

  ```json
  {
    "diskStorage": {
      "total": "549744"
    }
  }
  ```

<sup>&#42;</sup> The currently authenticated user is determined by the access token passed in the [header](/2.16/api/content-service-api-v1-users-me#content-service-api-v1-users-me-required-headers) of requests to this endpoint.
