## URL structure <a id="content-service-api-v1-items-transfer-url-structure" />

```text
https://content-service.xy-company.com/api/v1/items/transfer
```

## Supported methods and overview <a id="content-service-api-v1-items-transfer-supported-methods-and-overview" />

- `POST` - used to [transfer ownership](/2.16/admin/transferring-user-ownership) of all [Secure Objects](/2.16/api/creating-secure-objects-and-collections#secure-object) and [collections](/2.16/api/creating-secure-objects-and-collections#collection) (i.e. [items](/2.16/api/creating-secure-objects-and-collections#item)) from one Covata user to another Covata user.

## Supported roles <a id="content-service-api-items-transfer-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin/index)):

- [User administrator](/2.16/admin/administering-users#user-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/content-service-api-v1-items-transfer#content-service-api-v1-items-transfer-required-headers) of requests to this endpoint.

## Required headers <a id="content-service-api-v1-items-transfer-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

- `Content-Type: application/json`
