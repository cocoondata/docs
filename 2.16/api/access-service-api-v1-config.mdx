## URL structure <a id="access-service-api-v1-config-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config
```

## Supported methods and overview <a id="access-service-api-v1-config-supported-methods-and-overview" />

- `GET` - used to retrieve a list of 'public' properties (and their values) about the Covata Platform's Access Service for consumption by client applications.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-config-detailed-description" />

This API endpoint retrieves a list of public properties (and their values) from the Covata Platform's Access Service for consumption by client applications.

While the response from this endpoint returns an extensive list of properties, only a subset of these properties (most likely to be used) are described in the [Returns](/2.16/api/access-service-api-v1-config#access-service-api-v1-config-returns) section below.

## Supported roles <a id="access-service-api-config-supported-roles" />

This request does not require any [authentication or authorization](/2.16/api/authentication-and-authorization) through a Covata user account. Therefore, Covata user account [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)) are not relevant to this request.

## Required headers <a id="access-service-api-v1-config-required-headers" />

No additional headers are required for submission with this request. This request does not require an access (i.e. `Bearer`) token.

## Returns <a id="access-service-api-v1-config-returns" />

A JSON-formatted response containing numerous properties (each as individual members of this response) for consumption by the client application. Some useful properties include the following members:

- **require.login.on.launch** - The current value of the **Require user authentication when client application launches** [Covata Administration property](/2.16/api/access-service-api-v1-config-server). See [&lt;access-service&gt;/api/v1/config/server](/2.16/api/access-service-api-v1-config-server) for more information.
- **googleAnalyticsDomain** - The current value of the **The tracking domain used for Google Analytics** Covata Administration property. <br />
  **Note:** Be aware that the [&lt;access-service&gt;/api/v1/config/server](/2.16/api/access-service-api-v1-config-server) API endpoint returns this member as **analytics.google.trackingDomain**.
- **googleAnalyticsTrackingCode** - The current value of the **The tracking code used for Google Analytics** Covata Administration property. <br />
  **Note:** Be aware that the [&lt;access-service&gt;/api/v1/config/server](/2.16/api/access-service-api-v1-config-server) API endpoint returns this member as **analytics.google.trackingCode**.
