## URL structure <a id="access-service-api-v1-items-delta-url-structure" />

```text
https://access-service.xy-company.com/api/v1/items/delta
```

## Supported methods and overview <a id="access-service-api-v1-items-delta-supported-methods-and-overview" />

- `GET` - used to retrieve lists of changes to the currently authenticated [Covata user](/2.16/admin/administering-users)'s<sup>&#42;</sup> [Secure Objects](/2.16/api/creating-secure-objects-and-collections#secure-object) and [collections](/2.16/api/creating-secure-objects-and-collections#collection) (i.e. [items](/2.16/api/creating-secure-objects-and-collections#item)).

## Detailed description <a id="access-service-api-v1-items-delta-detailed-description" />

This API endpoint retrieves lists of changes to the currently authenticated Covata user's<sup>&#42;</sup> Secure Objects and collections from a given point in time, which includes separate lists for:

- New items (added),
- Deleted items (removed) and
- Modified items.

## Supported roles <a id="access-service-api-items-delta-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)):

- [Originator](/2.16/admin/administering-users#originator-role)
- [Collaborator](/2.16/admin/administering-users#collaborator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-items-delta#access-service-api-v1-items-delta-required-headers) of requests to this endpoint.
