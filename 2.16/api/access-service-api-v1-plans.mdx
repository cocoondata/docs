## URL structure <a id="access-service-api-v1-plans-url-structure" />

```text
https://access-service.xy-company.com/api/v1/plans
```

## Supported methods and overview <a id="access-service-api-v1-plans-supported-methods-and-overview" />

- `POST` - used to add a new [plan](/2.16/admin/managing-users-storage-quotas-through-plans).
- `GET` - used to retrieve a list of field information for all current plans on the Covata Platform.

<Note>

The `GET` method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-plans-detailed-description" />

This API endpoint serves a number of purposes:

- Adds a new plan to the Covata Platform.
- Retrieves a list of field information for all current plans on the Covata Platform.

## Supported roles <a id="access-service-api-plans-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)):

- [System administrator](/2.16/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-plans#access-service-api-v1-plans-required-headers) of requests to this endpoint.
