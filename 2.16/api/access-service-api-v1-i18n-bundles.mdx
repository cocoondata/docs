## URL structure <a id="access-service-api-v1-i18n-bundles-url-structure" />

```text
https://access-service.xy-company.com/api/v1/i18n/bundles
```

## Supported methods and overview <a id="access-service-api-v1-i18n-bundles-supported-methods-and-overview" />

- `GET` - used to retrieve a list of internationalization (i18n) bundles which are currently available on the Covata Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-i18n-bundles-detailed-description" />

This API endpoint retrieves a list of i18n bundles which are currently available on the Covata Platform.

These are i18n bundles which either are built in or have been uploaded to the Covata Platform.

## Supported roles <a id="access-service-api-v1-i18n-bundles-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)):

- [Originator](/2.16/admin/administering-users#originator-role)
- [Collaborator](/2.16/admin/administering-users#collaborator-role)
- [Ad hoc](/2.16/admin/administering-users#adhoc-role)
- [System administrator](/2.16/admin/administering-users#system-administrator-role)
- [User administrator](/2.16/admin/administering-users#user-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-i18n-bundles#access-service-api-v1-i18n-bundles-required-headers) of requests to this endpoint.
