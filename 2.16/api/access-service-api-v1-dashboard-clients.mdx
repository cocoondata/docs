## URL structure <a id="access-service-api-v1-dashboard-clients-url-structure" />

```text
https://access-service.xy-company.com/api/v1/dashboard/clients
```

## Supported methods and overview <a id="access-service-api-v1-dashboard-clients-supported-methods-and-overview" />

- `GET` - used to retrieve the number of [client applications](/2.16/admin/configuring-client-applications) currently registered on the Covata Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-dashboard-clients-detailed-description" />

This API endpoint retrieves the number of [client applications currently registered](/2.16/api/access-service-api-v1-clientapps) on the Covata Platform.

## Supported roles <a id="access-service-api-v1-dashboard-clients-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin/index)):

- [System administrator](/2.16/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-dashboard-clients#access-service-api-v1-dashboard-clients-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-dashboard-clients-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Returns <a id="access-service-api-v1-dashboard-clients-returns" />

A JSON-formatted response containing the following members:

- **totalClientApps** - The total number of client applications currently registered on the Covata Platform.

  **Example:**

  ```json
  {
    "totalClientApps": 4
  }
  ```
