## URL structure <a id="access-service-api-v1-labels-labelid-priority-url-structure" />

```text
https://access-service.xy-company.com/api/v1/labels/{labelId}/priority
```

where `{labelId}` is the ID of a label.

## Supported methods and overview <a id="access-service-api-v1-labels-labelid-priority-supported-methods-and-overview" />

- `PUT` - used to shift the priority of a [label](/2.16/admin/managing-labels) either up or down, based on that label's ID.

## Detailed description <a id="access-service-api-v1-labels-labelid-priority-detailed-description" />

This API endpoint shifts the priority of a label either up or down, using that label's ID. The label's ID can be obtained by calling the `GET` method of the [&lt;access-service&gt;/api/v1/labels](/2.16/api/access-service-api-v1-labels) API endpoint, which retrieves a list of field information for all existing labels on the Covata Platform.

A priority is defined by a series of consecutive positive integer numbers called *priority integer values*. These values are used for sorting labels from the highest priority (i.e. a priority integer value of `1`) through to the lowest priority (i.e. the highest priority integer value, which equals the total number of all existing labels on the Covata Platform).

When a new label is [added](/2.16/api/access-service-api-v1-labels), it is automatically given the lowest priority (i.e. the highest priority integer number). When any label (except for the label with the lowest priority) is [deleted](/2.16/api/access-service-api-v1-labels-labelid), then the priority integer numbers of all other labels with a lower priority are automatically decreased by a value of `1`.

When a label's priority is shifted:

- `up` - then the priority integer values of this label and its neighboring label (i.e. with the next lowest priority integer value) switch their priority values.
- `down` - then the priority integer values of this label and its neighboring label (i.e. with the next highest priority integer value) switch their priority values.

## Supported roles <a id="access-service-api-labels-labelid-priority-supported-roles" />

This API endpoint supports the following Covata user [roles](/2.16/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/2.16/admin)):

- [System administrator](/2.16/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/2.16/api/access-service-api-v1-labels-labelid-priority#access-service-api-v1-labels-labelid-priority-required-headers) of requests to this endpoint.
