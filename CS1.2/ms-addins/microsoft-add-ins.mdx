**What is a Microsoft Add-in?**

A Microsoft (MS) Add-in, allows you to extend your web application functionality into the Office environment, thereby allowing users to access your web application functions without having to leave the Office tool they are in. Think of it as a “light-weight” browser within your Office tools.

<a id="how-to-install-a-ms-addin" />**How to install a Microsoft Add-in?**

For more information on how to install a Microsoft add-in, please visit the official Microsoft sites below:

```text
* <code><a href="Get an Office Add-in for Outlook" target="_blank">https://support.office.com/en-us/article/get-an-office-add-in-for-outlook-1ee261f9-49bf-4ba6-b3e2-2ba7bcab64c8</a></code>

```

**Benefits of a SafeShare Microsoft Add-in**

```text
* Reduces the likelihood of accidental sharing of files within Outlook.
* Allows users to revoke access to files in real-time.
* Full audit trail of all actions performed by all authorised users on a file.
* Manage your SafeShare data from within the MS productivity tools.
```

## Using the Microsoft Office Add-in <a id="using-the-ms-office-addin" />

1. Search for SafeShare for Office and Install the add-in from the Microsoft Store by following the steps mentioned under [How to install a Microsoft Add-in?](/CS1.2/ms-addins/microsoft-add-ins#how-to-install-a-ms-addin). Once installed, it should appear on the ribbon bar.

   ![SafeShare for Office Add-in](/images/8ba7d9affaf7-office-addin-on-ribbon-bar.png)

   <br />
2. Click on the icon and the add-in should open as below:

   ![SafeShare Office Add-in Login Page](/images/4cb638f20998-office-addin-login-page.png)

   <br />
3. Check the “Service address setup” link and make sure this points to your unique instance id of SafeShare as below:

   ![SafeShare Service Address Setup](/images/20151c6d7c1d-service-address-setup.png)

   <br />
4. Enter your SafeShare login details and click “Sign In”. If you have Multi-Factor Authentication (MFA) enabled, you will be presented with the below screen:

   ![SafeShare MFA enabled](/images/ac1f5bd58325-mfa-enabled.png)

   <br />
5. Enter your MFA details and click “Authenticate” and you should be taken to the Homepage:

   ![SafeShare Office Add-in Home Page](/images/46bbcfc462a2-homepage-after-successful-login.png)

   <br />
6. Click on Secure, to securely upload the current open Word, Excel or PowerPoint document that you have open.
7. Pick a location within SafeShare, give it a Filename and click the “Secure” button to securely upload the document as below:

   ![Secure files with Office Add-in](/images/a12327d8fd46-securing-files-with-office-addin.png)

   <br />
8. Click OK once the file has been securely uploaded as below:

   ![File Secured Successfully](/images/6d13030dfe95-file-secured-successfully.png)

   <br />
9. You will then be taken back to the Homepage. Click on Open to browse your existing secured documents as below:

   ![SafeShare Office Add-in Home Page](/images/dc4486c15afb-homepage-after-successful-upload.png)

   <br />
10. You should see all your folders/files, including the newly secured file/s you just uploaded. If you highlight a file you can either click on the 3 dots (…) or right-click on the file to see further options as below:

    ![Right-Click a file for Options](/images/e0d3cf6d06a9-right-click-a-file-for-options.png)

    <br />
11. If you click on “View”, a browser window will open and show the file. <sup>(&#42;)</sup>
12. If you click “Download”, a browser window will open and download the file. <sup>(&#42;)</sup>
13. If you click “Edit in Office Online”, a browser window will open, and you will be able to Edit the file with Microsoft Online. <sup>(&#42;)</sup>

<sup>(&#42;)</sup> *Please note that you will be prompted to login again if there is no active browser session for SafeShare.*

1. If you click on Share you will be able to edit the sharing permissions for a file as below:

   ![Sharing a file using the Office Add-in](/images/3195802f3afa-sharing-a-file-using-office-addin.png)

   <br />
2. You can do everything you would normally do in the browser version of SafeShare such as: add Collaborators with individual sharing permissions, set the classification of the file and add a sharing period.
3. When you are done, click “Share” and the permissions will be updated, and you will be taken back to your Homepage.
4. For Settings, click on the Settings wheel in the top right as below:

   ![Office Add-in Settings](/images/4e3e72646cd0-office-addin-settings.png)

   <br />
5. Here you will be able to switch between different organisations that you may belong to:

   ![Switch Organisations](/images/6733b8b03272-switch-organisations.png)

   <br />
6. And “Sign out” as below:

   ![Sign-Out from SafeShare Office Add-in](/images/219d0372d32f-signout-from-office-addin.png)

   <br />
7. Lastly on the Homepage there are two links at the bottom, one for support which open a browser window and take you to our support portal and a legal link which opens a browser windows and takes you to our license agreement.

   ![Leal Document for SafeShare Office Add-in](/images/68f5ac9e0eb7-legal-document-link.png)

## Using the Microsoft Outlook Add-in <a id="using-the-ms-outlook-addin" />

This section is split into two, one for composing a new email and the other for securely uploading an attachment from an existing email within outlook.

<a id="composing-new-emails" />Composing new E-mails:

1. Search for SafeShare for Outlook and Install the add-in from the Microsoft Store by following the steps mentioned under [How to install a Microsoft Add-in?](/CS1.2/ms-addins/microsoft-add-ins#how-to-install-a-ms-addin). Once installed, it should appear on the ribbon bar.

   ![SafeShare for Outlook Add-in](/images/e3c50d202086-outlook-addin-on-ribbon-bar.png)

   <br />
2. Click on the icon and the add-in should open and display a login page as below:

   ![SafeShare for Outlook Add-in Login Page](/images/02cfa7814030-outlook-addin-login-page.png)

   <br />
3. Check the “Service address setup” link and make sure this points to your unique instance id of SafeShare as below:

   ![SafeShare Service Address Setup](/images/86633d8344a9-service-address-setup-outlook.png)

   <br />
4. Enter your SafeShare login details and click “Sign In”. If you have Multi-Factor Authentication (MFA) enabled, you will be presented with the below screen:

   ![SafeShare MFA enabled](/images/e335d44160e6-mfa-enabled-outlook.png)

   <br />
5. Enter your MFA details and click “Authenticate” and you should be taken to the Homepage:

   ![SafeShare Outlook Add-in Home Page](/images/a16eed1aeeff-homepage-after-successful-login-outlook.png)

   <br />
6. Once logged in you will be able to browse your existing SafeShare directory for a file you want to securely attach.
7. To attach a file securely, first compose a new email and then click on the SafeShare icon again to open the add-in. Once you have found a file, right click and select Attach or double click on the file.
8. This will open the “Sharing screen” and automatically insert any TO, CC and BCC email addresses that you are addressing the email too.

   ![Sharing a file using the Outlook Add-in](/images/9153d3eea30d-sharing-a-file-using-outlook-addin-email-fields.png)

   ![Sharing a file using the Outlook Add-in](/images/e68130ebee35-sharing-a-file-using-outlook-addin.png)

   <br />
9. When you click Attach, a link is inserted into the body of the email where your cursor is as below:

   ![Insert link to a file using the Outlook Add-in](/images/6ac636b04dd4-insert-link-using-outlook-addin.png)

   <br />
10. All users on the email will then be able to click on the link and access the file via SafeShare. Permissions depend on what you have specified in Step 8. In this case “View only” permission was given.
11. Please note, if the user is not on SafeShare already, they will receive a separate welcome/enrolment email from SafeShare when the link is sent to them. **A message is inserted automatically at the bottom of your email*.

<a id="uploading-attachments-from-emails" />Uploading and Securing Attachments from E-mails:

1. You can also use the add-in to securely upload an attachment from an existing email. Simply click on the email with the attachment and open the SafeShare add-in.
2. Browse to the location within SafeShare that you want to securely upload the file to, and click on the “Secure attachments” button as below:

   ![Secure Attachments](/images/422c309f17c1-secure-attachments-button.png)

   <br />
3. This will open another screen and list all available attachments in the email you selected in Step 1 as below:

   ![List of Email Attachments](/images/b678f57061a2-list-of-attachments.png)

   <br />
4. Select one or multiple attachments and click on the “Secure” button to securely upload the attachments to SafeShare.
5. When done, you will see a success message as below:

   ![Attachment Secured Successfully](/images/6d13030dfe95-file-secured-successfully.png)

   <br />
6. Click Ok and you will be taken back to the Homepage.
7. You can now compose a new message and securely attach a link to the file you just uploaded.
