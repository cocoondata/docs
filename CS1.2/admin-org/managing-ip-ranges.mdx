title: "Managing IP Whitelist"

The **IP Whitelist** page of Organisation Administration ([below](/CS1.2/admin-org/managing-ip-ranges#classifications-page)) allows the following within an organisation:

- The [addition of new IP ranges](/CS1.2/admin-org/managing-ip-ranges#adding-a-new-ip-range) to allow.
- The [removal](/CS1.2/admin-org/managing-ip-ranges#removing-an-existing-ip-range) / editing of existing IP ranges.

Organisation administrators can define a set of *IP ranges* from which [Cocoon Data users](/CS1.2/admin-org/administering-users-within-an-organisation) can choose when [sharing](/CS1.2/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) [files](/CS1.2/admin-org/administering-files) with other people using SafeShare applications, including other client applications utilising the Cocoon Data Platform's API.

IP whitelisting helps Cocoon Data users ensure that files are only shareable with users who access CocoonData from an approved [IP range](/CS1.2/admin-org/managing-ip-ranges). If a Cocoon Data user is not connected from a predefined IP range, then that user cannot access any file that has been specified via an IP whitelist.

## Adding a new IP range

**To add a new IP range to your organisation on the Cocoon Data Platform:**

1. Ensure you are [signed in](/CS1.2/admin-org/accessing-organisation-administration#signing-in-to-organisation-administration) to Organisation Administration.
2. Click the **IP Whitelist** option on the left of the [Organisation Administration interface](/CS1.2/admin-org/accessing-organisation-administration#the-organisation-administration-interface) to open the **IP Whitelist** page.
3. Click the **Add IP Range** tab.
4. On the **Add IP Range** page, specify the:

   - **Alias** - The value of this field is the name of the IP range shown to Cocoon Data users of SafeShare applications (when sharing an item), including client applications utilising the Cocoon Data Platform's API.
   - **IP Range** - You will input the needed IP range or list of IP ranges in this field. The value of this field is only visible to Organisation administrators on this **IP Whitelist** page.
5. Click **Save** and the new IP range is added and will appear as a new entry on the **IP Whitelist** page. <br />
   **Notes:**

   - If you are inputting a list of IP ranges, the list should be comma separated and not contain any spaces or tabs.

## Removing an existing IP range

Removing an IP range removes that IP range from all files it was applied to (when these files were shared).

**To remove an existing IP range from your organisation:**

1. Ensure you are [signed in](/CS1.2/admin-org/accessing-organisation-administration#signing-in-to-organisation-administration) to Organisation Administration.
2. Click the **IP Whitelist** option on the left of the [Organisation Administration interface](/CS1.2/admin-org/accessing-organisation-administration#the-organisation-administration-interface) to open the **Saved IP Ranges** page.
3. Locate/scroll to the relevant IP range and select its check box on the left.
4. Click the **Delete** button.
