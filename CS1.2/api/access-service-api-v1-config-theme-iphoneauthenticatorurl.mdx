## URL structure <a id="access-service-api-v1-config-theme-iphoneauthenticatorurl-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/iphoneAuthenticatorUrl
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-iphoneauthenticatorurl-supported-methods-and-overview" />

- `PUT` - sets the **iPhone Authenticator URL** property (accessible through the [System Details](/CS1.2/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the [Configuration](/CS1.2/admin-platform/configuring-platform-administration-properties) page of SafeShare Administration).

## Detailed description <a id="access-service-api-v1-config-theme-iphoneauthenticatorurl-detailed-description" />

This API endpoint sets the **iPhone Authenticator URL** property (accessible through the **System Details** section of the **Configuration** page of SafeShare Administration).

The current value of this property can be obtained using the [&lt;access-service&gt;/theme...](/CS1.2/api/access-service-theme) API endpoint.

## Supported roles <a id="access-service-api-v1-config-theme-iphoneauthenticatorurl-supported-roles" />

This API endpoint supports the following Cocoon Data user [roles](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [SafeShare Administrator's Guide](/CS1.2/admin-platform)):

- [SafeShare administrator](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Cocoon Data Platform's resources available to a Cocoon Data user meeting the criteria above is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-config-theme-iphoneauthenticatorurl#access-service-api-v1-config-theme-iphoneauthenticatorurl-required-headers) of requests to this endpoint.

Specify the **iPhone Authenticator URL** property value (i.e. the full URL for this property) in the **body** of the request as **plain text**.

If the request succeeded, then an HTTP response status `200 OK` is returned.
