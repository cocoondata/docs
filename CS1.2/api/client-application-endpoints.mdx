---
title: "Client application endpoints"
---

The endpoints in this section are used for handling client applications on the Cocoon Data Platform.

- [&lt;access-service&gt;/api/v1/clientapps](/CS1.2/api/access-service-api-v1-clientapps)
- [&lt;access-service&gt;/api/v1/clientapps/\{clientInfoId\}](/CS1.2/api/access-service-api-v1-clientapps-clientinfoid)
- [&lt;access-service&gt;/api/v1/clientapps/\{clientInfoId\}/enable](/CS1.2/api/access-service-api-v1-clientapps-clientinfoid-enable)

The following endpoint (mentioned in the response to the Access Service discovery endpoint [&lt;access-service&gt;/api/v1](/CS1.2/api/access-service-api-v1-discovery)) is both deprecated and undocumented:

- `<access-service>/api/v1/clientapps/grants/{clientInfo}` ( *Deprecated* )

The purpose of this endpoint is to retrieve a list of OAuth 2.0 grant types through which a client application configured on the Cocoon Data Platform (specified by `{clientInfo}`) can authenticate a Cocoon Data user. However, this information can be retrieved through the first two endpoints (above).
