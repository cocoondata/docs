## URL structure <a id="access-service-api-v1-organisations-orgid-labels-labelid-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{orgId}/labels/{labelId}
```

where `{orgId}` is the ID of an organisation and `{labelId}` is the ID of one of this organisation's classifications.

## Supported methods and overview <a id="access-service-api-v1-organisations-orgid-labels-labelid-supported-methods-and-overview" />

- `GET` - retrieves information about a [classification](/CS1.2/admin-org/managing-classifications) (specified by `labelId`) configured in an organisation (specified by `orgId`).
- `DELETE` - deletes an existing classification (specified by `labelId`) in an organisation (specified by `orgId`).

<Note>

Both of these methods take no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-orgid-labels-labelid-detailed-description" />

This API endpoint serves a number of purposes:

- Retrieves information about a classification (specified by `labelId`) configured in an organisation (specified by `orgId`). A classification's ID can be obtained by calling the `GET` method of the [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/labels](/CS1.2/api/access-service-api-v1-organisations-orgid-labels) API endpoint, which retrieves a list of information for all classifications configured in an organisation (specified by `orgId`). <br />
  **Tip:** All information (except the **description** member) returned in the [response](/CS1.2/api/access-service-api-v1-organisations-orgid-labels-labelid#access-service-api-v1-organisations-orgid-labels-labelid-returns) from a `GET` method call to this API endpoint is also returned in the [response](/CS1.2/api/access-service-api-v1-organisations-orgid-labels#access-service-api-v1-organisations-orgid-labels-returns) from a `GET` method call to the [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/labels](/CS1.2/api/access-service-api-v1-organisations-orgid-labels) endpoint. Therefore, if you do not require a classification's **description** when retrieving information about the classification, there is no need to call the `GET` method on this API endpoint.
- Deletes an existing classification (specified by `labelId`) from an organisation (specified by `orgId`). <br />
  **Important:** Deleting a classification also removes:

  - this classification from all [new](/CS1.2/api/access-service-api-v1-organisations-orggroupid-objects) and [existing](/CS1.2/api/access-service-api-v1-objects-objectid) file objects it had been applied to and more importantly,
  - removes all current collaborators from these file objects.

<Note>

Be aware that by design and for security reasons, it is not possible to edit any aspect of a classification.

</Note>

## Supported roles and conditions <a id="access-service-api-v1-organisations-orgid-labels-labelid-supported-roles-and-conditions" />

This API endpoint supports requests utilising Cocoon Data user accounts with the following [roles](/CS1.2/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organisation Administrator's Guide](/CS1.2/admin-org)) and conditions:

- [Organisation administrator](/CS1.2/admin-org/administering-users-within-an-organisation#organisation-administrator-role), [Originator](/CS1.2/admin-org/administering-users-within-an-organisation#originator-role), [Collaborator](/CS1.2/admin-org/administering-users-within-an-organisation#collaborator-role), [Ad hoc](/CS1.2/admin-org/administering-users-within-an-organisation#adhoc-role) - using the `GET` method, when this user is a member of the organisation specified by the `{orgId}` of the request's URL.
- **Organisation administrator** - using the `DELETE` method, when this user is a member of the organisation specified by the `{orgId}` of the request's URL.

The Cocoon Data Platform's resources available to one of these Cocoon Data users (above) is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-organisations-orgid-labels-labelid#access-service-api-v1-organisations-orgid-labels-labelid-required-headers) of requests to this endpoint.

## Returns <a id="access-service-api-v1-organisations-orgid-labels-labelid-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.

For successful `GET` requests only, a JSON-formatted response containing the following members is also returned:

- **id** - The ID of the classification.
- **name** - The name of the classification.
- **description** - The description of the classification.
- **priority** - The current priority value, which is used for sorting classifications from highest (i.e. a priority integer value of 1) through to the lowest priority (i.e. the highest priority integer value, which equals the total number of all classifications defined in an organisation).
- **applyI18n** - . <br />
  **Example (response):**

  ```json
  {
      "id": "766855749304623104",
      "name": {
          "value": "Confidential"
      },
      "description": {
          "value": "This classification level is used for content that should only be accessible to members of staff with security clearance. Anyone outside the company (including partners) should not access this content."
      },
      "priority": "1",
      "applyI18n": false
  }
  ```
