## URL structure <a id="access-service-api-v1-keys-keyid-url-structure" />

```text
https://access-service.xy-company.com/api/v1/keys/{keyId}
```

where `{keyId}` is the ID of a cryptographic key.

## Supported methods and overview <a id="access-service-api-v1-keys-keyid-supported-methods-and-overview" />

- `DELETE` - deletes an unallocated cryptographic key (i.e. the key specified by `keyId` that has not been associated with a file object or version) to avoid breaching the unallocated keys limit.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-keys-keyid-detailed-description" />

This API endpoint deletes an unallocated cryptographic key (i.e. the key specified by `keyId` that has not been associated with a file object or version). This allows the [generation of more (unallocated) cryptographic keys](/CS1.2/api/access-service-api-v1-keys) and helps avoid breaching the unallocated keys limit (which is 100 per user's session/valid access token).

<Note>

Unallocated keys typically result from failures in [associating a key with a file object](/CS1.2/api/access-service-api-v1-organisations-orggroupid-objects) (i.e. initializing an *Incomplete* file object).

</Note>

## Supported roles and conditions <a id="access-service-api-v1-keys-keyid-supported-roles-and-conditions" />

This API endpoint supports requests utilizing Cocoon Data user accounts with the following [roles](/CS1.2/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organisation Administrator's Guide](/CS1.2/admin-org)) and conditions:

- [Originator](/CS1.2/admin-org/administering-users-within-an-organisation#originator-role), [Collaborator](/CS1.2/admin-org/administering-users-within-an-organisation#collaborator-role) and [Ad hoc](/CS1.2/admin-org/administering-users-within-an-organisation#adhoc-role) - when this user [generated the key](/CS1.2/api/access-service-api-v1-keys) specified by the `{keyId}` of the request's URL.

The Cocoon Data Platform's resources available to a Cocoon Data user meeting the criteria above is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-keys-keyid#access-service-api-v1-keys-keyid-required-headers) of requests to this endpoint.
