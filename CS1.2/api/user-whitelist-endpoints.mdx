---
title: "User whitelist endpoints"
---

The endpoints in this section are used for handling an organisation's user whitelists on the Cocoon Data Platform.

- [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/userwhitelist](/CS1.2/api/access-service-api-v1-organisations-orgid-userwhitelist)
- [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/userwhitelist/\{whitelistId\}](/CS1.2/api/access-service-api-v1-organisations-orgid-userwhitelist-whitelistid)
- [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/userwhitelist/check](/CS1.2/api/access-service-api-v1-organisations-orgid-userwhitelist-check)

The following user whitelist handling endpoints are deprecated:

- [&lt;access-service&gt;/api/v1/userwhitelist/\{objectId\}](/CS1.2/api/access-service-api-v1-userwhitelist-objectid) ( *Deprecated* )
- [&lt;access-service&gt;/api/v1/userwhitelist/bulk](/CS1.2/api/access-service-api-v1-userwhitelist-bulk) ( *Deprecated* )
