## URL structure <a id="access-service-api-v1-dashboard-ldap-url-structure" />

```text
https://access-service.xy-company.com/api/v1/dashboard/ldap
```

## Supported methods and overview <a id="access-service-api-v1-dashboard-ldap-supported-methods-and-overview" />

- `GET` - retrieves the total number of currently enabled [LDAP connections](/CS1.2/admin-platform/configuring-ldap) on the Cocoon Data Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-dashboard-ldap-detailed-description" />

This API endpoint retrieves the total number of currently enabled LDAP connections on the Cocoon Data Platform.

This information is utilised on the [SafeShare Administration dashboard](/CS1.2/admin-platform/accessing-platform-administration#the-platform-administration-dashboard).

## Supported roles <a id="access-service-api-v1-dashboard-ldap-supported-roles" />

This API endpoint supports the following Cocoon Data user [roles](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [SafeShare Administrator's Guide](/CS1.2/admin-platform)):

- [SafeShare administrator](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Cocoon Data Platform's resources available to one of these Cocoon Data users (above) is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-dashboard-ldap#access-service-api-v1-dashboard-ldap-required-headers) of requests to this endpoint.

## Returns <a id="access-service-api-v1-dashboard-ldap-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.

For successful requests only, a JSON-formatted response containing the following members is also returned:

- **totalLdapConnections** - The total number of currently enabled LDAP connections on the Cocoon Data Platform. Any LDAP connections which have already been configured on the Cocoon Data Platform but are disabled are not represented in this total. <br />
  **Example (response):**

  ```json
  {
      "totalLdapConnections": 1
  }
  ```
