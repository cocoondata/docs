## URL structure <a id="access-service-api-v1-i18n-localedetails-url-structure" />

```text
https://access-service.xy-company.com/api/v1/i18n/localedetails
```

## Supported methods and overview <a id="access-service-api-v1-i18n-localedetails-supported-methods-and-overview" />

- `GET` - retrieves a list of field information for all supported locales on the Cocoon Data Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-i18n-localedetails-detailed-description" />

This API endpoint retrieves a list of field information for all supported locales on the Cocoon Data Platform.

## Supported roles <a id="access-service-api-v1-i18n-localedetails-supported-roles" />

This API endpoint supports the following Cocoon Data user [roles](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [SafeShare Administrator's Guide](/CS1.2/admin-platform)):

- [SafeShare administrator](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Cocoon Data Platform's resources available to a Cocoon Data user meeting the criteria above is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-i18n-localedetails#access-service-api-v1-i18n-localedetails-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-i18n-localedetails-required-headers" />
