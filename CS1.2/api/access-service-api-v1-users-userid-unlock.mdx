## URL structure <a id="access-service-api-v1-users-userid-unlock-url-structure" />

```text
https://access-service.xy-company.com/api/v1/users/{userId}/unlock
```

where `{userId}` is the ID of a Cocoon Data user account.

## Supported methods and overview <a id="access-service-api-v1-users-userid-unlock-supported-methods-and-overview" />

- `PUT` - unlocks a [Cocoon Data user](/CS1.2/api/authentication-and-authorisation)'s account (specified by `userId`).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-users-userid-unlock-detailed-description" />

This API endpoint unlocks a Cocoon Data user's account (specified by `userId`).

A Cocoon Data user's account can be come locked if the user of this account had entered their password incorrectly more than the Cocoon Data Platform's [configured maximum](/CS1.2/admin-platform/configuring-platform-administration-properties#maximum-number-of-password-retries) (which can be set through the [&lt;access-service&gt;/api/v1/config/server/\{configId\}](/CS1.2/api/access-service-api-v1-config-server-configid) API endpoint).

## Supported roles and conditions <a id="access-service-api-v1-users-userid-unlock-supported-roles-and-conditions" />

This API endpoint supports requests utilizing Cocoon Data user accounts with the following roles (as described in the [SafeShare Administrator's](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) and [Organisation Administrator's](/CS1.2/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) Guides):

- [SafeShare administrator](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrator-role) - when this user is another SafeShare administrator user to the one whose account (specified by `{userId}` in the request's URL) is being unlocked.
- [Organisation administrator](/CS1.2/admin-org/administering-users-within-an-organisation#organisation-administrator-role) - a bug currently exists, which prevents users with this role from being able to unlock other Cocoon Data users who are members of their organisation through this API endpoint.

The Cocoon Data Platform's resources available to a Cocoon Data user meeting the criteria above is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-users-userid-unlock#access-service-api-v1-users-userid-unlock-required-headers) of requests to this endpoint.
