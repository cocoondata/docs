## URL structure <a id="access-service-api-v1-config-theme-privacyurl-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/privacyUrl
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-privacyurl-supported-methods-and-overview" />

- `PUT` - sets (or clears) the **The URL of the privacy statement** property (accessible through the [System Details](/CS1.2/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the [Configuration](/CS1.2/admin-platform/configuring-platform-administration-properties) page of SafeShare Administration).

## Detailed description <a id="access-service-api-v1-config-theme-privacyurl-detailed-description" />

This API endpoint sets (or clears) the **The URL of the privacy statement** property (accessible through the **System Details** section of the **Configuration** page of SafeShare Administration).

The current value of this property can be obtained using the [&lt;access-service&gt;/theme...](/CS1.2/api/access-service-theme) API endpoint.

<Note>

This property can be overridden at the organisation level using the [&lt;access-service&gt;/api/v1/organisations/\{orgGroupId\}](/CS1.2/api/access-service-api-v1-organisations-orggroupid) API endpoint.

</Note>

## Supported roles <a id="access-service-api-v1-config-theme-privacyurl-supported-roles" />

This API endpoint supports the following Cocoon Data user [roles](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [SafeShare Administrator's Guide](/CS1.2/admin-platform)):

- [SafeShare administrator](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Cocoon Data Platform's resources available to a Cocoon Data user meeting the criteria above is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-config-theme-privacyurl#access-service-api-v1-config-theme-privacyurl-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-config-theme-privacyurl-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer eyJhbGciOiJSUzI1NiJ9.eyJleHAiOjE0NjcwMTY2NjYsInVzZXJfbmFtZSI6ImFsZXgub...`

The following header is required if the body of the request has a JSON object:

- `Content-Type: application/json`

## Required body <a id="access-service-api-v1-config-theme-privacyurl-required-body" />

Specify the **The URL of the privacy statement** property value (i.e. the full URL for this property) in the **body** of the request as **plain text**.

To clear this property's value, specify an empty **JSON object** in the **body** of the request:

- `{}`

## Returns <a id="access-service-api-v1-config-theme-privacyurl-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
