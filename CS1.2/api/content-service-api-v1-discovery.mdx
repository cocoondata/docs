## URL structure <a id="content-service-api-v1-discovery-url-structure" />

```text
https://content-service.xy-company.com/api/v1
```

## Supported methods and overview <a id="content-service-api-v1-discovery-supported-methods-and-overview" />

- `GET` - retrieves a list of callable API endpoints on the Cocoon Data Platform's Content Service, which are available to integrators.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="content-service-api-v1-discovery-detailed-description" />

This API endpoint retrieves a list of every callable API endpoint on the the Cocoon Data Platform's Content Service that are available to integrators.

Regardless of the Cocoon Data user's [role](/CS1.2/api/content-service-api-v1-discovery#content-service-api-v1-discovery-supported-roles) associated with the [access token](/CS1.2/api/access-service-api-v1-discovery#access-service-api-v1-discovery-required-headers) submitted with this request, all callable API endpoints are retrieved. However, each of these API endpoints has their own **Supported roles**.

## Supported roles <a id="content-service-api-v1-discovery-supported-roles" />

This API endpoint supports requests utilizing Cocoon Data user accounts with the following roles (as described in the [SafeShare Administrator's](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) and [Organisation Administrator's](/CS1.2/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) Guides):

- [Originator](/CS1.2/admin-org/administering-users-within-an-organisation#originator-role)
- [Collaborator](/CS1.2/admin-org/administering-users-within-an-organisation#collaborator-role)
- [Ad hoc](/CS1.2/admin-org/administering-users-within-an-organisation#adhoc-role)
- [SafeShare administrator](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrator-role)
- [Organisation administrator](/CS1.2/admin-org/administering-users-within-an-organisation#organisation-administrator-role)

The Cocoon Data Platform's resources available to Cocoon Data users meeting the criteria above is determined by the access token submitted in the [header](/CS1.2/api/content-service-api-v1-discovery#content-service-api-v1-discovery-required-headers) of requests to this endpoint.

## Returns <a id="content-service-api-v1-discovery-returns" />

A JSON-formatted response containing the following members:

- **services** - An array containing information about each callable API endpoint on the Cocoon Data Platform's Content Service. Each element of this array contains information about one of these endpoints (represented as an object containing the following members):

  - **httpMethod** - The method supported by the API endpoint URL (below).
  - **link** - The format of the API endpoint's URL, excluding the base URL component (i.e. **contentServiceURL**, as described in [&lt;access-service&gt;/api/v1](/CS1.2/api/access-service-api-v1-discovery)).
  - **name** - The internal name given to the API endpoint.
