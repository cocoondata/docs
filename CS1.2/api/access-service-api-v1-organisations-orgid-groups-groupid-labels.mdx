## URL structure <a id="access-service-api-v1-organisations-orgid-groups-groupid-labels-url-structure" />

```text
https://access-service.xy-company.com/api/v1/organisations/{orgId}/groups/{groupId}/labels
```

where `{orgId}` is the ID of an organisation and `{groupId}` is the ID of one of this organisation's clearances.

## Supported methods and overview <a id="access-service-api-v1-organisations-orgid-groups-groupid-labels-supported-methods-and-overview" />

- `GET` - retrieves a list of information for all [classifications](/CS1.2/admin-org/managing-classifications) that are currently associated with a [clearance](/CS1.2/admin-org/managing-clearances) (specified by `groupId`) in an organisation (specified by `orgId`).

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-organisations-orgid-groups-groupid-labels-detailed-description" />

This API endpoint retrieves a list of information for all classifications that are currently associated with a clearance (specified by `groupId`) in an organisation (specified by `orgId`).

A clearance's ID can be obtained by calling the `GET` method of the [&lt;access-service&gt;/api/v1/organisations/\{orgId\}/groups](/CS1.2/api/access-service-api-v1-organisations-orgid-groups) API endpoint, which retrieves a list of information for all clearances in the organisation (specified by `orgId`).

## Supported roles and conditions <a id="access-service-api-v1-organisations-groups-groupid-labels-supported-roles-and-conditions" />

This API endpoint supports requests utilizing Cocoon Data user accounts with the following [roles](/CS1.2/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) (as described in the [Organisation Administrator's Guide](/CS1.2/admin-org/index)) and conditions:

- [Organisation administrator](/CS1.2/admin-org/administering-users-within-an-organisation#organisation-administrator-role) - if this user is a member of the organisation specified by `{orgId}` in the request's URL.

The Cocoon Data Platform's resources available to one of these Cocoon Data users (above) is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-organisations-orgid-groups-groupid-labels#access-service-api-v1-organisations-orgid-groups-groupid-labels-required-headers) of requests to this endpoint.
