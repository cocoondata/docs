## URL structure <a id="access-service-api-v1-users-me-expire-url-structure" />

```text
https://access-service.xy-company.com/api/v1/users/me/expire
```

## Supported methods and overview <a id="access-service-api-v1-users-me-expire-supported-methods-and-overview" />

- `PUT` - [invalidates all valid refresh tokens](/CS1.2/user/managing-your-account#terminating-your-user-accounts-sessions) associated with the [Cocoon Data user](/CS1.2/api/authentication-and-authorisation) whose [access token is submitted in the request](/CS1.2/api/access-service-api-v1-users-me-expire#access-service-api-v1-users-me-expire-supported-roles) to this endpoint.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-users-me-expire-detailed-description" />

This API endpoint invalidates all valid refresh tokens associated with the Cocoon Data user whose access token is submitted in the request to this endpoint.

If this request succeeds, all valid refresh tokens associated with this Cocoon Data user are invalidated. Every other active session this Cocoon Data user has with the Cocoon Data Platform will terminate once these sessions' access tokens expire.

Passing any invalidated access token in the header of requests to any Cocoon Data API endpoint will cause these requests to fail.

## Supported roles <a id="access-service-api-v1-users-me-expire-supported-roles" />

This API endpoint supports requests utilizing Cocoon Data user accounts with the following roles (as described in the [SafeShare Administrator's](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) and [Organisation Administrator's](/CS1.2/admin-org/administering-users-within-an-organisation#an-organisation-users-roles) Guides):

- [Originator](/CS1.2/admin-org/administering-users-within-an-organisation#originator-role)
- [Collaborator](/CS1.2/admin-org/administering-users-within-an-organisation#collaborator-role)
- [Ad hoc](/CS1.2/admin-org/administering-users-within-an-organisation#adhoc-role)
- [SafeShare administrator](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrator-role)
- [Organisation administrator](/CS1.2/admin-org/administering-users-within-an-organisation#organisation-administrator-role)

The Cocoon Data Platform's resources available to one of these Cocoon Data users (above) is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-users-me-expire#access-service-api-v1-users-me-expire-required-headers) of requests to this endpoint.
