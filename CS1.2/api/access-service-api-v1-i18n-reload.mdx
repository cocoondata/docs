## URL structure <a id="access-service-api-v1-i18n-reload-url-structure" />

```text
https://access-service.xy-company.com/api/v1/i18n/reload
```

## Supported methods and overview <a id="access-service-api-v1-i18n-reload-supported-methods-and-overview" />

- `PUT` - flushes the internationalization (i18n) bundle cache of the Cocoon Data Platform's Access Service and reload i18n bundles (which are stored in the database) to this cache.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-i18n-reload-detailed-description" />

This API endpoint flushes the i18n bundle cache of the Cocoon Data Platform's Access Service and reloads i18n bundles (stored in the database) to this cache.

## Supported roles <a id="access-service-api-v1-i18n-reload-supported-roles" />

This API endpoint supports the following Cocoon Data user [roles](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrators-and-user-roles) (as described in the [SafeShare Administrator's Guide](/CS1.2/admin-platform)):

- [SafeShare administrator](/CS1.2/admin-platform/administering-platform-administrator-users#platform-administrator-role)

The Cocoon Data Platform's resources available to a Cocoon Data user meeting the criteria above is determined by the access token submitted in the [header](/CS1.2/api/access-service-api-v1-i18n-reload#access-service-api-v1-i18n-reload-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-i18n-reload-required-headers" />

The appropriate access token as the `Bearer` token:

## Returns <a id="access-service-api-v1-i18n-reload-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
