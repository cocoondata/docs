---
title: "Organisation Administration"
---

*Organisation Administration* is a web-based interface for administering an organisation's access to resources on a Cocoon Data Platform instance. This interface also provides access to a number of configurable features of Cocoon Data technologies <sup>&#42;</sup> that apply to the organisation *and* Cocoon Data users who are members of the organisation.

![Organisation Administration dashboard page](/images/e1ab2bf2c0bd-organisation-administration-dashboard-page.png)
*Organisation administrators* are users who, once [signed in](/CS1.2/admin-platform/accessing-organisation-administration#signing-in-to-organisation-administration) to Organisation Administration, can access its [dashboard](/CS1.2/admin-platform/accessing-organisation-administration#the-organisation-administration-dashboard) (depicted above) and have the ability to perform the following administration activities within their organisation on their Cocoon Data Platform instance:

- Configure [users](/CS1.2/admin-platform/administering-users-within-an-organisation) (also known as 'Cocoon Data users') who are members of their organisation, where these user's accounts can be added as newly created ones or accounts which have already been registered on the Cocoon Data Platform.
- Manage their organisation's [contact groups](/CS1.2/admin-platform/managing-contact-groups), defining groups of Cocoon Data users with whom items can be shared.
- Configure and manage their organisation's [user whitelist](/CS1.2/admin-platform/managing-user-whitelists), defining which people can be shared items within the organisation based on their email address/domain, including people who are not organisation members or yet registered on the Cocoon Data Platform.
- Manage their organisation's [classifications](/CS1.2/admin-platform/managing-classifications) and [clearances](/CS1.2/admin-platform/managing-clearances), both of which are used in conjunction to help ensure that classified content is only shareable with Cocoon Data users who have clearance to access this content.
- Manage their organisation's [plans](/CS1.2/admin-platform/managing-users-storage-quotas-through-plans), each of which defines a storage quota used to restrict the amount of storage (managed by the Cocoon Data Platform's Content Service) available to individual Cocoon Data user accounts.
- Disable or re-enable access to any [files](/CS1.2/admin-platform/administering-files) encrypted using Cocoon Data technologies on the Cocoon Data Platform, as well as view all recorded activities on these files.
- Generate [reports](/CS1.2/admin-platform/generating-reports) on requests made by client applications to the Cocoon Data Platform's API.
- Change the [configuration](/CS1.2/admin-platform/configuring-organisation-administration-properties) of Organisation Administration properties.

<sup>&#42;</sup> *Cocoon Data technologies* refers to all features and functionality provided by (and made available through) the Cocoon Data Platform, including Cocoon Data's SafeShare applications, the Cocoon Data Platform's API and the Cocoon Data Platform itself.
