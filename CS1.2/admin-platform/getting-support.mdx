---
title: "Getting Support"
---

If you have any issues with the Cocoon Data Platform or other Cocoon Data technologies, please consult the relevant system administrator(s) who installed and configured the Cocoon Data Platform within your organisation.

Otherwise, if you are using a hosted instance of the Cocoon Data Platform or if you wish to report a bug, please visit the customer support web page at:

`[https://cocoondata.com/support](https://cocoondata.com/support)`
