---
title: "Theming SafeShare's web-based interfaces"
---

<Info>

**To be carried out only during the deployment process.**

</Info>

Themes allow the color schemes and logos utilised throughout [SafeShare for Web](/CS1.2/user) user interface to be customised for individual [organisations](/CS1.2/user#organisations), where each individual organisation is associated with its own theme. (For more information about adding/configuring organisations through [SafeShare Administration](/CS1.2/admin-platform#platform-administration), see [Administering organisations](/CS1.2/admin-platform/administering-organisations).)

In this version of SafeShare and the Cocoon Data Platform, themes are generated using an separate tool (the [Cocoon Data/WebApp Theme Builder](https://www.npmjs.com/package/cocoondata-theme-builder)), which is developed by Cocoon Data and is available as a locally executable [npm package](https://www.npmjs.com/).

These color scheme and logo customisations are also utilised throughout:

- the [Organisation Administration](/CS1.2/admin-platform/organisation-administration) interface,
- the [SafeShare Administration](/CS1.2/admin-platform#platform-administration) interface, as well as
- email notifications sent out by the Cocoon Data Platform.

Newly installed instances of SafeShare are pre-packaged with the *Cocoon Data default theme*. This theme is initially used for all organisations' SafeShare for Web and Organisation Administration interfaces, email notifications, as well as the SafeShare Administration interface.

Using the WebApp Theme Builder tool, you can generate different themes - one for each organisation - as well as your own default theme (aka the 'system' theme), which is used for:

- any organisation that does not have a theme defined for it,
- the SafeShare Administration interface and
- the [My Account](/CS1.2/user/managing-your-account) feature.

Visit the [cocoondata-theme-builder page](https://www.npmjs.com/package/cocoondata-theme-builder) (on the npm web site) for more information about obtaining and using the WebApp Theme Builder tool, as well as deploying themes to a Cocoon Data Platform instance.

<Note>

Other customisable aspects of SafeShare, such as the Application Name, as well as the Company Name and Copyright Notice that appear in email notifications, are configurable through the [System details properties](/CS1.2/admin-platform/configuring-platform-administration-properties#system-details-properties) section of the **Configuration** [page](/CS1.2/admin-platform/configuring-platform-administration-properties) of SafeShare Administration. However, the Company Name can be customised for each organisation (through the **Configuration** [page](/CS1.2/admin-platform/configuring-organisation-administration-properties) of Organisation Administration).

</Note>

<Note>

Email notifications are themed according to the SafeShare 'area' to which the notification's content is related. <br />
 For example, email notifications about activities conducted through:

- SafeShare Administration, such as the addition of a SafeShare administrator user account, use the system theme.
- Organisation Administration, such as the removal of a Cocoon Data user account from an organisation, use the organisation's theme. <sup>&#42;</sup>
- Activities conducted through any SafeShare application, such as sharing an item with another person, use the theme of the recipient's home/default organisation. <sup>&#42;</sup> This principle also applies to a person who is not yet registered on the Cocoon Data Platform (i.e. this person's account is created and added to an organisation as a result of them being shared an item by an existing Cocoon Data user in that organisation).

<sup>&#42;</sup> If an organisation's theme were not defined, then such notifications would instead use the system theme.

</Note>
