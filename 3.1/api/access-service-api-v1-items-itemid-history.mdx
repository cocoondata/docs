## URL structure <a id="access-service-api-v1-items-itemid-history-url-structure" />

```text
https://access-service.xy-company.com/api/v1/items/{itemId}/history
```

where `{itemId}` is the ID of a Secure Object or collection.

## Supported methods and overview <a id="access-service-api-v1-items-itemid-history-supported-methods-and-overview" />

- `GET` - used to retrieve history information about the activities which have been performed on a specified [Secure Object](/3.1/api/creating-secure-objects-and-collections#secure-object) or [collection](/3.1/api/creating-secure-objects-and-collections#collection) (i.e. [item](/3.1/api/creating-secure-objects-and-collections#item)), based on the item's ID.

## Detailed description <a id="access-service-api-v1-items-itemid-history-detailed-description" />

This API endpoint retrieves history information about the activities which have been performed on a specified Secure Object or collection, using this item's ID.

The item's ID can be obtained by calling the [&lt;access-service&gt;/api/v1/items](/3.1/api/access-service-api-v1-items) API endpoint, which retrieves a list of information associated with Secure Objects and collections that can be filtered using various 'search' criteria.

The amount of history information retrieved in a response depends on the role of the currently authenticated Covata user<sup>&#42;</sup> (below), as well as:

- The items that the currently authenticated user<sup>&#42;</sup> owns and
- The items which have been shared with this user.

<sup>&#42;</sup> The currently authenticated user is determined by the access token passed in the [header](/3.1/api/access-service-api-v1-items-itemid-history#access-service-api-v1-items-itemid-history-required-headers) of requests to this endpoint.

## Supported roles <a id="access-service-api-v1-items-itemid-history-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.1/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.1/admin)):

- [Originator](/3.1/admin/administering-users#originator-role)
- [Collaborator](/3.1/admin/administering-users#collaborator-role)
- [System administrator](/3.1/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.1/api/access-service-api-v1-items-itemid-history#access-service-api-v1-items-itemid-history-required-headers) of requests to this endpoint.
