## URL structure <a id="access-service-api-v1-config-theme-supportlink-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/supportLink
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-supportlink-supported-methods-and-overview" />

- `PUT` - sets a new URL for the company's/organization's support page (accessible from the **Support** link in the footer of the Safe Share web application and Covata Administration).
- `DELETE` - see [&lt;access-service&gt;/api/v1/config/theme/...](/3.1/api/access-service-api-v1-config-theme-reset) for more information.

## Detailed description <a id="access-service-api-v1-config-theme-supportlink-detailed-description" />

This API endpoint sets a new URL for the company's/organization's support page (accessible from the **Support** link in the footer of the Safe Share web application and Covata Administration).

To reset this URL back to its default value, see [&lt;access-service&gt;/api/v1/config/theme/...](/3.1/api/access-service-api-v1-config-theme-reset) for more information.

## Supported roles <a id="access-service-api-v1-config-theme-supportlink-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.1/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.1/admin)):

- [System administrator](/3.1/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.1/api/access-service-api-v1-config-theme-supportlink#access-service-api-v1-config-theme-supportlink-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-config-theme-supportlink-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Required body <a id="access-service-api-v1-config-theme-supportlink-required-body" />

Specify the new URL for the company's/organization's support page in the body of the request as plain text.

## Returns <a id="access-service-api-v1-config-theme-supportlink-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
