## URL structure <a id="access-service-api-v1-config-theme-headertextcolor-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/headerTextColor
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-headertextcolor-supported-methods-and-overview" />

- `PUT` - used to set a new color for the header text of the Safe Share web application, Covata Administration and Covata Notification email messages.
- `DELETE` - see [&lt;access-service&gt;/api/v1/config/theme/...](/3.1/api/access-service-api-v1-config-theme-reset) for more information.

## Detailed description <a id="access-service-api-v1-config-theme-headertextcolor-detailed-description" />

This API endpoint sets a new color for the header text of the Safe Share web application, Covata Administration and Covata Notification email messages.

To reset this color back to its default value, see [&lt;access-service&gt;/api/v1/config/theme/...](/3.1/api/access-service-api-v1-config-theme-reset) for more information.

## Supported roles <a id="access-service-api-v1-config-theme-headertextcolor-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.1/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.1/admin)):

- [System administrator](/3.1/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.1/api/access-service-api-v1-config-theme-headertextcolor#access-service-api-v1-config-theme-headertextcolor-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-config-theme-headertextcolor-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Required body <a id="access-service-api-v1-config-theme-headertextcolor-required-body" />

Specify as plain text in the body of the request, the new color (as a 6-digit hex value) for the header text of the Safe Share web application, Covata Administration and Covata Notification email messages.

## Returns <a id="access-service-api-v1-config-theme-headertextcolor-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
