## URL structure <a id="access-service-api-v1-labels-url-structure" />

```text
https://access-service.xy-company.com/api/v1/labels
```

## Supported methods and overview <a id="access-service-api-v1-labels-supported-methods-and-overview" />

- `POST` - used to add a new [label](/3.1/admin/managing-labels).
- `GET` - used to retrieve a list of field information for all existing labels on the Covata Platform.

## Detailed description <a id="access-service-api-v1-labels-detailed-description" />

This API endpoint serves a number of purposes:

- Adds a new label to the Covata Platform. <br />
  **Notes:**

  - To associate this new label with one or more Covata users (as a group), which would allow this label to restrict file sharing to these users, see [&lt;access-service&gt;/api/v1/groups/\{groupId\}](/3.1/api/access-service-api-v1-groups-groupid). Also see [&lt;access-service&gt;/api/v1/groups](/3.1/api/access-service-api-v1-groups) for more information about adding new groups.
  - It is recommended that any [newly added label be associated with at least one group of Covata users](/3.1/api/access-service-api-v1-groups-groupid) as soon as possible, since a label (which is not yet associated with any such group + users) and is then specified when sharing (i.e. modifying collaborators on) a [new](/3.1/api/access-service-api-v1-objects) or [existing](/3.1/api/access-service-api-v1-objects-objectid) Secure Object, prevents that Secure Object from being shared.
  - Be aware that by design and for security reasons, it is not possible to edit any aspect of a label once it has been added to the Covata Platform.
- Retrieves a list of field information for all existing labels on the Covata Platform.

## Supported roles and conditions <a id="access-service-api-labels-supported-roles-and-conditions" />

This API endpoint supports the following Covata user [roles](/3.1/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.1/admin)) and conditions:

- [System administrator](/3.1/admin/administering-users#system-administrator-role)
- [Originator](/3.1/admin/administering-users#originator-role) - a Covata user with this role can call the `GET` method only.

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.1/api/access-service-api-v1-labels#access-service-api-v1-labels-required-headers) of requests to this endpoint.
