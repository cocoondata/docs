## URL structure <a id="access-service-api-v1-dashboard-whitelist-url-structure" />

```text
https://access-service.xy-company.com/api/v1/dashboard/whitelist
```

## Supported methods and overview <a id="access-service-api-v1-dashboard-whitelist-supported-methods-and-overview" />

- `GET` - used to retrieve the total number of [user whitelist](/3.1/admin/managing-user-whitelists) entries (both individual email addresses and domains) currently configured on the Covata Platform.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-dashboard-whitelist-detailed-description" />

This API endpoint retrieves the total number of user whitelist entries (both individual email addresses and domains) currently configured on the Covata Platform.

## Supported roles <a id="access-service-api-v1-dashboard-whitelist-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.1/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.1/admin)):

- [System administrator](/3.1/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.1/api/access-service-api-v1-dashboard-whitelist#access-service-api-v1-dashboard-whitelist-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-dashboard-whitelist-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Returns <a id="access-service-api-v1-dashboard-whitelist-returns" />

A JSON-formatted response containing the following members:

- **totalDomainsWhiteListed** - The total number of user whitelist entries (both individual email addresses and domains) currently configured on the Covata Platform.

  **Example:**

  ```json
  {
    "totalDomainsWhiteListed": 2
  }
  ```
