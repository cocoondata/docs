## URL structure <a id="access-service-api-v1-groups-groupid-labels-url-structure" />

```text
https://access-service.xy-company.com/api/v1/groups/{groupId}/labels
```

where `{groupId}` is the ID of a group.

## Supported methods and overview <a id="access-service-api-v1-groups-groupid-labels-supported-methods-and-overview" />

- `GET` - used to retrieve a list of field information for all [labels](/3.1/admin/managing-labels) associated with an existing [group](/3.1/admin/managing-groups), based on the group's ID.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-groups-groupid-labels-detailed-description" />

This API endpoint retrieves a list of field information for all labels associated with the group whose ID is specified in the URL of this endpoint.

A group's ID can be obtained by calling the `GET` method of the [&lt;access-service&gt;/api/v1/groups](/3.1/api/access-service-api-v1-groups) API endpoint, which retrieves a list of field information for all existing groups on the Covata Platform.

## Supported roles <a id="access-service-api-groups-groupid-labels-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.1/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.1/admin)):

- [System administrator](/3.1/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.1/api/access-service-api-v1-groups-groupid-labels#access-service-api-v1-groups-groupid-labels-required-headers) of requests to this endpoint.
