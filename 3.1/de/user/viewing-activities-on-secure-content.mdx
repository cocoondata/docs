---
title: "Anzeige der an sicheren Inhalten ausgeführten Aktivitäten"
---

Benutzer der Safe Share-Webanwendung können einen Verlauf [bestimmter Aktivitäten](/3.1/de/user/viewing-activities-on-secure-content#types-of-activities-indicated) aufrufen, die an einer Datei oder einem Ordner ausgeführt wurden.

**Anzeige der an einer Datei oder einem Ordner ausgeführten Aktivitäten:**

1. Vergewissern Sie sich, dass Sie bei der Safe Share-Webanwendung [angemeldet sind](/3.1/de/user/signing-in).
2. Wenn das Home-Symbol links oben das Wort „Start“ ohne ein Symbol für ein Dropdown-Menü anzeigt, lesen Sie bitte beim [nächsten Schritt](/3.1/de/user/viewing-activities-on-secure-content#locating-an-item-to-view-its-activity) weiter. (Dies zeigt an, dass Sie Mitglied nur einer Organisation sind.) <br />
   *Andernfalls* wird der Name Ihrer aktuellen Organisation angezeigt. Sie können dann von diesem Bildschirm aus Folgendes tun:

   - Weitergehen zum [nächsten Schritt](/3.1/de/user/viewing-activities-on-secure-content#locating-an-item-to-view-its-activity), um Ihren Zugriff auf ein Element dieser Organisation zu entfernen, oder
   - Entfernen Ihres Zugriffs auf ein Element einer anderen Organisation (der Sie als Mitglied angehören), indem Sie [Ihre Organisation wechseln](/3.1/de/user/uploading-storing-and-sharing-content-securely#changing-organisations), ehe Sie den Vorgang fortsetzen.
3. <a id="locating-an-item-to-view-its-activity" />[Suchen Sie](/3.1/de/user/managing-secure-content#finding-secure-content) die Datei oder den Ordner, deren/dessen Verlauf Sie aufrufen möchten.
4. Vergewissern Sie sich, dass der Bereich **Details/Verlauf** rechts angezeigt wird. (Ist dies nicht der Fall, klicken Sie auf das Symbol **&lt;** rechts oben im Elementebereich, um diesen Bereich aufzurufen.)
5. Klicken Sie auf die Zeile des Elements (bei Ordnern rechts vom Namen), um es *auszuwählen*: <br />
   ![Auswahl eines freigegebenen Elements als Besitzer](/images/2f8c990c0a0a-selecting-a-shared-item-owner.png)
6. Klicken Sie auf das Register **Verlauf**, um den Verlauf der am Element ausgeführten Aktivitäten in umgekehrter chronologischer Abfolge darzustellen: <br />
   ![Aktivitätsfeed als Besitzer](/images/8bc6146c5d0b-activity-feed-owner.png)

## Arten der angezeigten Aktivitäten <a id="types-of-activities-indicated" />

Die Arten der angezeigten, an einer Datei oder einem Ordner (d. h. Element) ausgeführten Aktivitäten hängen von den folgenden Bedingungen ab:

- Für die folgenden Rollen:

  - *Besitzer* eines Elements,
  - Mitwirkender <sup>1</sup> mit **Änderungs-** oder **Verwaltungs-**[Berechtigung](/3.1/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) für ein Element oder
  - Mitwirkender mit **Upload-** Berechtigung für ein von Ihnen erstelltes Element <sup>2</sup>,

  zeigt das Register **Verlauf** an, wann (und von wem) das Element erstellt wurde, sowie jede der folgenden Aktivitäten Zugriffsberechtiger:

  - [Anzeige](/3.1/de/user/accessing-secure-content#viewing-and-printing-content) oder [Download](/3.1/de/user/accessing-secure-content#downloading-secure-content) des Elements (wenn es sich um eine Datei handelt),
  - Änderung:

    - des Namens des Elements oder
    - des Speicherorts des Elements oder
  - Änderung:

    - der [Freigaben](/3.1/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) des Elements oder
    - der [Berechtigungen von Mitwirkenden](/3.1/de/user/uploading-storing-and-sharing-content-securely#selecting-a-permission-set) des Elements

    (als Besitzer des Elements oder Mitwirkender des Elements mit **Verwaltungs**-Berechtigung).
- Für Mitwirkende mit **Download**- oder **Anzeige**-Berechtigung an einer Datei, die sie *nicht* erstellt haben, zeigt das Register **Verlauf** die einzelnen [Anzeigen](/3.1/de/user/accessing-secure-content#viewing-and-printing-content) und [Downloads](/3.1/de/user/accessing-secure-content#downloading-secure-content) der betreffenden Datei an.
- Für Mitwirkende mit **Upload**-, **Download**- oder **Anzeige**-Berechtigung an einem Ordner, den sie *nicht* erstellt haben, zeigt das Register **Verlauf** keine Aktivitäten an.

<sup>1</sup> *Mitwirkende* eines Elements sind Personen mit Zugriffsberechtigung auf das betreffende Element. Mitwirkende besitzen das Element jedoch nicht, da es sich in einem Ordner eines anderen Besitzers befindet. <br />
<sup>2</sup> *Mitwirkender* sind in diesem Kontext Sie selbst, wenn Sie in einem Ordner eines anderen Besitzers einen Unterordner erstellt oder in einen solchen Ordner eine Datei hochgeladen haben. Handelt es sich bei dem betreffenden Element um eine Datei, stuft Safe Share die Berechtigungen automatisch von **Upload** auf **Download** herunter, da es praktisch nicht möglich ist, Inhalte auf eine Datei hochzuladen.
