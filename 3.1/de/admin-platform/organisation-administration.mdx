---
title: "Safe Share-Organisationsverwaltung"
---

Die *Safe Share-Organisationsverwaltung* ist eine internetbasierte Oberfläche für die Verwaltung des Zugriffs einer Organisation auf Ressourcen in einer Instanz der Covata-Plattform. Diese Oberfläche gibt Zugriff auf eine Reihe von konfigurierbaren Funktionen der Covata-Technologien <sup>&#42;</sup>, die auf die Organisation *und* Covata-Benutzer, die Mitglied der Organisation sind, Anwendung finden.

![Organisationsverwaltung Seite Dashboard](/images/279473a45f3a-organisation-administration-dashboard-page.png)
*Organisations-Administratoren* sind Benutzer, die nach ihrer [Anmeldung](/3.1/de/admin-platform/accessing-organisation-administration#signing-in-to-organisation-administration) bei der Safe Share-Organisationsverwaltung auf das [Dashboard](/3.1/de/admin-platform/accessing-organisation-administration#the-organisation-administration-dashboard) (oben gezeigt) zugreifen und innerhalb ihrer Organisation und ihrer Instanz der Covata-Plattform die folgenden Verwaltungsaufgaben ausführen können:

- Konfiguration von [Benutzern](/3.1/de/admin-platform/administering-users-within-an-organisation) (d. h. „Covata-Benutzer“), die ihrer Organisation angehören, durch die anfängliche Hinzufügung neuer oder vorregistrierter Benutzer-Accounts auf der Covata-Plattform
- Konfiguration und Verwaltung der [Benutzer-Positivliste](/3.1/de/admin-platform/managing-user-whitelists) ihrer Organisation, in der definiert ist, welchen Personen innerhalb der Organisation Elemente freigegeben werden können, einschließlich Personen, die der Organisation selbst nicht angehören
- Verwaltung von [Klassifikationen](/3.1/de/admin-platform/managing-classifications) und [Gruppen](/3.1/de/admin-platform/managing-groups), die gemeinsam verwendet werden, um den Personenkreis einzuschränken, dem Inhalte freigegeben werden können
- Verwaltung von [Plänen](/3.1/de/admin-platform/managing-users-storage-quotas-through-plans), die Speicherkontingente definieren und so den für einzelne Covata-Benutzer-Accounts verfügbaren (letztendlich vom Inhaltsdienst der Covata-Plattform verwalteten) Speicher begrenzen
- Deaktivierung bzw. Reaktivierung des Zugriffs auf beliebige, mit Covata-Technologien verschlüsselte [Dateien](/3.1/de/admin-platform/administering-files) auf der Covata-Plattform und Anzeige aller hinsichtlich dieser Dateien aufgezeichneten Aktivitäten
- Erzeugung von [Berichten](/3.1/de/admin-platform/generating-reports) über von Client-Anwendungen an die API der Covata-Plattform gerichtete Anforderungen
- Änderung der [Konfiguration](/3.1/de/admin-platform/configuring-organisation-administration-properties) von Eigenschaften der Safe Share-Organisationsverwaltung

<sup>&#42;</sup> Der Begriff *Covata-Technologien* beinhaltet alle Funktionen, die über die Covata-Plattform bereitgestellt werden, u. a. Covatas Safe Share-Anwendungen, die API der Covata-Plattform sowie die Covata-Plattform selbst.
