---
title: "Konfiguration von Eigenschaften der Safe Share-Verwaltung"
---

Anhand der Seite **Konfiguration** können Safe Share-Administratoren eine begrenzte Zahl an Eigenschaften ihrer Covata-Plattform-Instanz [ändern](/3.1/de/admin-platform/configuring-platform-administration-properties#modifying-a-platform-administration-property-value), um so das Verhalten und spezifische funktionelle Aspekte ihrer Covata-Plattform-Instanz zu optimieren.

<Note>

Weitere Eigenschaften in Konfigurationsdateien können von den Systemadministratoren geändert werden, die für Vor-Ort-Installationen der Covata-Plattform verantwortlich sind.

</Note>

![Seite Konfiguration/Eigenschaften](/images/46b4f3f55b61-platform-administration-property-configuration-page.png)
<a id="platform-administration-properties" />Die folgenden Eigenschaften der Safe Share-Verwaltung sind verfügbar:

| Eigenschaft | Detaillierte Beschreibung |
| --- | --- |
| Mindestlänge des Passworts | Die Mindestanzahl von Zeichen, die für das Passwort eines [lokalen](/3.1/de/admin-platform/administering-users-within-an-organisation#account-type) Benutzers erforderlich ist. Diese Eigenschaft wirkt sich nicht auf das Passwort von [LDAP-Benutzern](/3.1/de/admin-platform/administering-users-within-an-organisation#account-type) aus, da die Authentifizierung von LDAP-Benutzern an ihren jeweiligen LDAP-Server delegiert ist. |
| Ablaufzeit des temporären Passworts in Stunden | Wenn ein neuer [lokaler](/3.1/de/admin-platform/administering-users-within-an-organisation#account-type) Covata-Benutzer-Account angelegt wird, erhält der Benutzer eine E-Mail-Benachrichtigung mit einem temporären (von der Covata-Plattform erzeugten) Passwort, das der Benutzer benötigt, um sein eigenes Passwort für seinen Account einrichten zu können. Der Wert dieser Eigenschaft definiert daher die Gültigkeit dieses temporären Passworts. <br />**Hinweis:** Der Benutzer kann auch nach dem Ablauf dieses temporären Passworts sein Passwort noch über die Covata-Anmeldeseite einrichten, indem er die Schaltfläche **Sie haben kein Passwort?** oder **Passwort vergessen?** anklickt und die Anweisungen in der E-Mail-Benachrichtigung befolgt, die anschließend an seine E-Mail-Adresse gesendet werden.  |
| Mobile Benutzer können Kennungen setzen. | Die Funktionalität dieser Eigenschaft wurde von der Funktion **Geräteregistrierung zulassen** ersetzt (die bei der [Registrierung einer Client-Anwendung auf der Covata-Plattform](/3.1/de/admin-platform/configuring-client-applications#registering-a-new-client-application) verfügbar ist). Diese Funktionalität ist daher nicht mehr in Gebrauch und wird in einer künftigen Version der Covata-Plattform entfernt. |
| Maximal zulässige Passwort-Wiederholungsversuche | <a id="maximum-number-of-password-retries" />Die maximale Anzahl an ungültigen Anmeldeversuchen, die ein Covata-Benutzer durch falsche Eingabe des Passworts unternehmen kann, ehe sein Benutzer-Account gesperrt wird. Der Benutzer muss anschließend seinen Account anhand eines der folgenden Schritte entsperren:  <br />•  Er kann die Anweisungen in der E-Mail-Benachrichtigung befolgen, die er nach der Sperrung seines Accounts erhält. Die E-Mail-Benachrichtigung enthält einen Link zum Entsperren des Benutzer-Accounts. Die Gültigkeit dieses Links entspricht der **Account-Sperrungszeit in Minuten** (siehe unten). <br />•  Er kann warten, bis sein Account entsperrt wird; diese Zeit wird vom Wert **Account-Sperrungszeit in Minuten** (siehe unten) definiert. <br />•  Er kann sein Passwort zurücksetzen, indem er auf der Anmeldeseite für Covata entweder **Sie haben kein Passwort?** oder **Passwort vergessen?** anklickt.  |
| Account-Sperrungszeit in Minuten | Die Zeit, die ein Covata-Benutzer warten muss, ehe sein Benutzer-Account (der bei der Anmeldung gesperrt wurde, da die **maximal zulässigen Passwort-Wiederholungsversuche** erreicht wurden) von der Covata-Plattform automatisch entsperrt wird. Diese Zeit definiert auch die Gültigkeit des Links für die Entsperrung eines Benutzer-Accounts (der in der E-Mail-Benachrichtigung an den Benutzer geschickt wird). <br />**Wichtig:** Achten Sie darauf, dass dieser Wert positiv ist und setzen Sie ihn nicht auf `0` (Null). Wird dieser Wert auf `0` gesetzt, werden Benutzer-Accounts unbefristet gesperrt (wenn Benutzer bei der Anmeldung die **maximal zulässigen Passwort-Wiederholungsversuche** (siehe oben) überschreiten). Für Safe Share-Administratoren erhöht dies das Risiko, dass sie sich selbst aus der Safe Share-Verwaltung aussperren, wenn sie ihr Passwort falsch eingeben. Ist dieser Wert nach einer Aktualisierung der Covata-Plattform auf `0` gesetzt, ändern Sie ihn in einen positiven Wert.  |
| Maximal zulässige Wiederholungsversuche von Passwortübermittlungen per E-Mail | <a id="maximum-number-of-email-my-password-retries" />Die maximale Anzahl von Malen, die ein Covata-Benutzer **Sie haben kein Passwort?** oder **Passwort vergessen?** anklicken, so eine E-Mail-Benachrichtigung mit einem Link/Passwort für einmaligen Zugriff oder Anweisungen zum Zurücksetzen des Passworts anfordern *und* anschließend erfolglos eine Anmeldung versuchen kann, ehe sein Account gesperrt wird. <br /> **Hinweise:**  <br />•  Achten Sie darauf, dass dieser Wert positiv ist und setzen Sie ihn nicht auf `0` (Null). Ein Wert von Null erhöht das Risiko, dass Sie (als Safe Share-Administrator) sich selbst aus der Safe Share-Verwaltung aussperren könnten, falls Sie Ihr Passwort falsch eingeben. <br />•  Covata-Benutzer können zwar den Link **Sie haben kein Passwort?** oder **Passwort vergessen?** mehrmals hintereinander anklicken, aber die entsprechende E-Mail-Benachrichtigung wird nur einmal alle fünf Minuten versandt. Dieser Standardwert wird von einer Eigenschaft definiert, die von Systemadministratoren geändert werden kann, die für Vor-Ort-Installationen der Covata-Plattform verantwortlich sind.  |
| Anzahl der Zeichentyp-Kategorien, die in einem Passwort enthalten sein müssen | <a id="number-of-character-type-categories-that-must-appear-in-a-password" />In Passwörtern können vier verschiedene *Kategorien* von *Zeichentypen* verwendet werden:  <br />•  Kleinbuchstaben <br />•  Großbuchstaben <br />•  Zahlen <br />•  Sonderzeichen <br />Der Wert dieser Eigenschaft bestimmt, wie viele dieser vier Kategorien von Zeichentypen in einem Passwort enthalten sein müssen (wenn dieses festgelegt wird), damit es gültig ist. Zum Beispiel:  <br />•  Ist dieser Wert auf `1` gesetzt, müssen die Zeichen in einem Passwort nur einer der oben angegebenen Kategorien entnommen sein. <br />•  Ist dieser Wert auf `2` gesetzt, müssen die Zeichen in einem Passwort mindestens zwei der oben angegebenen Kategorien entnommen sein.  |
| Der für Google Analytics verwendete Nachverfolgungscode | Der Ihnen bei der Anmeldung zu Google Analytics zugeteilte Nachverfolgungscode. <br />**Hinweis:** Wenn Google Analytics mit Ihrer Covata-Plattform-Instanz arbeiten soll, muss dieser Wert zusammen mit der **für Google Analytics verwendeten Tracking-Domäne** (siehe unten) eingesetzt werden.  |
| Die für Google Analytics verwendete Tracking-Domäne | Die Domäne Ihres Covata-Plattform-Web-Servers. <br />**Hinweis:** Wenn Google Analytics mit Ihrer Covata-Plattform-Instanz arbeiten soll, muss dieser Wert zusammen mit dem **für Google Analytics verwendeten Nachverfolgungscode** (siehe oben) eingesetzt werden.  |
| Ablaufzeit des Links für die Zwei-Faktor-Authentifizierung in Tagen | Wenn Zwei-Faktor-Authentifizierung (2FA) für einen Covata-Benutzer-Account (vom Benutzer selbst über die [Safe Share-Webanwendung](/3.1/de/user/managing-your-account#enabling-or-disabling-2fa-for-your-account), die [Organisationsverwaltung](/3.1/de/admin-platform/administering-users-within-an-organisation#enabling-or-disabling-2fa-on-organisation-user-accounts) oder die Safe Share-Verwaltung, von einem Safe Share-Administrator für [einen beliebigen Safe Share-Administrator-Account](/3.1/de/admin-platform/administering-platform-administrator-users#enabling-or-disabling-2fa-for-a-platform-administrator), oder von einem Organisations-Administrator für [alle Mitglieder seiner Organisation](/3.1/de/admin-platform/configuring-organisation-administration-properties#enforce-2fa-for-organisation-members)) aktiviert ist, erhält der Benutzer eine entsprechende E-Mail-Benachrichtigung. Diese Benachrichtigung enthält einen befristet gültigen Konfigurationslink zu den folgenden detaillierten Anweisungen für den Benutzer:  <br />•  Konfiguration seines Mobilgeräts mit der entsprechenden Authentifizierungs-Anwendung (Authenticator-App) und <br />•  Konfiguration der Authenticator-App mit dem Covata-Benutzer-Account (damit die App die entsprechenden Authentifizierungscodes erzeugen kann). <br />Der Wert dieser Eigenschaft definiert daher die Gültigkeit dieses Konfigurationslinks. |
| Auf iOS-Geräten Smart Banner mit Link zum nativen iOS-Client zeigen | Setzt auf der Covata-Plattform eine Kennung, die am oberen Seitenrand der [Safe Share-Webanwendung](/3.1/de/user) ein Smart Banner aufruft, wenn die Anwendung auf iOS-Geräten über Safari ausgeführt wird. Dies erleichtert es Benutzern von iOS-Geräten, die in der E-Mail-Benachrichtigung „*Eine Datei/ein Ordner wurde Ihnen freigegeben*“ eine direkte URL für ein Element angeklickt haben (wodurch das Element in der Safe Share-Webanwendung geöffnet wird), auf das Element stattdessen über Safe Share for iOS zuzugreifen (indem sie auf das Smart Banner klicken). |
| Höchstzahl der pro Benutzer zulässigen Kontakte | Die Höchstzahl der Kontakte, die ein beliebiger Covata-Benutzer seinem Account über die Safe Share- [Webanwendung](/3.1/de/user/managing-your-account#managing-your-contacts) sowie Safe Share für [Windows](/3.1/de/windows/managing-your-account#managing-your-contacts) oder iOS hinzufügen kann. |
| Höchstzahl der pro Datei/Ordner zulässigen Mitwirkenden | Die Höchstzahl der Mitwirkenden, die für ein Element über die [Safe Share-Webanwendung](/3.1/de/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) sowie Safe Share für [Windows](/3.1/de/windows/uploading-storing-and-sharing-content-securely#sharing-secure-content) oder iOS zulässig sind. <br />**Hinweis:** Beachten Sie hierbei, dass dieser Höchstwert Mitwirkende eines Elements beinhaltet, die *implizit* von Ordnern, in denen das betreffende Element gespeichert ist und denen *explizit* Mitwirkende hinzugefügt wurden, übernommen wurden.  |
| Häufigkeit der Benachrichtigung über die Freigabe von Elementen in Minuten | Das Intervall zur Definition der Häufigkeit, mit der E-Mail-Benachrichtigungen über freigegebene Elemente (d. h. „*Ihnen wurde eine Datei/ein Ordner freigegeben*“) von der Covata-Plattform gesendet werden. <br />**Hinweis:** Wenn einem Covata-Benutzer während eines solchen Intervalls mehrere Elemente freigegeben werden, erhält der Benutzer nur eine E-Mail-Benachrichtigung (am Ende des Intervalls), in der alle Elemente aufgeführt sind, die ihm seit dem vorherigen Intervall/der vorherigen Benachrichtigung freigegeben wurden.  |
| Häufigkeit der Erinnerungen zur Benutzerakzeptanz in Tagen | Die Anzahl an Tagen zwischen jeder Reihe von E-Mail-Benachrichtigungen zur Benutzerakzeptanz, die [neue Covata-Benutzer](/3.1/de/admin-platform/administering-users-within-an-organisation#adding-an-organisation-user-account) mit [Ersteller-Rolle](/3.1/de/admin-platform/administering-users-within-an-organisation#originator-role) erhalten. Siehe die Beschreibung der Eigenschaft **Erinnerungen zur Benutzerakzeptanz aktiviert** (unten) für weitere Informationen über diese Art von E-Mail-Benachrichtigungen. <br />**Hinweise:** Diese Eigenschaft der Safe Share-Verwaltung wird nur wirksam, wenn die Eigenschaft **Erinnerungen zur Benutzerakzeptanz aktiviert** (siehe unten) auf `Wahr` gesetzt ist.  |
| Funktion Erinnerungen zur Benutzerakzeptanz aktiviert | Diese Eigenschaft legt fest, ob die Covata-Plattform an [neue Covata-Benutzer](/3.1/de/admin-platform/administering-users-within-an-organisation#adding-an-organisation-user-account) mit [Ersteller-Rolle](/3.1/de/admin-platform/administering-users-within-an-organisation#originator-role) eine Reihe von E-Mail-Benachrichtigungen zur Benutzerakzeptanz aussendet (d. h. `Wahr`) oder nicht (d. h. `Falsch`). Jede dieser E-Mail-Benachrichtigungen enthält Tipps und Informationen, um diese neuen Covata-Benutzer zur Nutzung von Safe Share-Anwendungen einzuladen (z. B. Informationen über die Freigabe von Daten über diese Anwendungen). <br /> **Hinweise:**  <br />•  Diese E-Mail-Benachrichtigungen werden in einer Reihe von vier E-Mails ausgesendet, die in anhand der Eigenschaft **Häufigkeit der Erinnerungen zur Benutzerakzeptanz in Tagen** (siehe oben) definierten Zeitabständen versendet werden. Der *Zeitraum für die E-Mail-Benachrichtigungen zur Benutzerakzeptanz* ist definiert als die Zahl verschiedener E-Mail-Benachrichtigungen über die Benutzerakzeptanz (vier), multipliziert mit dem Eigenschaftswert der **Häufigkeit der Erinnerungen zur Benutzerakzeptanz in Tagen** (standardmäßig 15 Tage), d. h. der Standardwert beträgt 60 Tage. <br />•  E-Mail-Benachrichtigungen zur Benutzerakzeptanz werden an neue Covata-Benutzer-Accounts nur *ab dem Zeitpunkt der ersten Erstellung des Accounts* ausgesendet (entweder über die [Safe Share-Verwaltung](/3.1/de/admin-platform/administering-platform-administrator-users#adding-a-platform-administrator-account) oder die [Organisationsverwaltung](/3.1/de/admin-platform/administering-users-within-an-organisation#adding-an-organisation-user-account)). Wird ein Covata-Benutzer mit einem bestehenden Account einer neuen/anderen Organisation hinzugefügt (selbst mit der [Ersteller-Rolle](/3.1/de/admin-platform/administering-users-within-an-organisation#originator-role)), erhält er keine E-Mail-Benachrichtigungen zur Benutzerakzeptanz. <br />•  Wird einem bestehenden Covata-Benutzer die Ersteller-Rolle (innerhalb einer Organisation) erstmals zugeteilt, erhält er keine E-Mail-Benachrichtigungen zur Benutzerakzeptanz, sofern seinem Benutzer-Account nicht die Ersteller-Rolle innerhalb des *Zeitraums für die E-Mail-Benachrichtigungen zur Benutzerakzeptanz* ab dem Erstellungsdatum seines Accounts zugeteilt wurde. In diesem Fall würde der Benutzer für den restlichen Teil dieses Zeitraums diese E-Mail-Benachrichtigungen erhalten.  |

## Änderung von Eigenschaftswerten der Safe Share-Verwaltung <a id="modifying-a-platform-administration-property-value" />

**Änderung eines Eigenschaftswerts der Safe Share-Verwaltung:**

1. [Melden Sie sich](/3.1/de/admin-platform/accessing-platform-administration#signing-in-to-platform-administration) bei der Safe Share-Verwaltung an.
2. Klicken Sie auf die Option **Konfiguration** links auf der [Oberfläche Safe Share-Verwaltung](/3.1/de/admin-platform/accessing-platform-administration#the-platform-administration-interface), um die Seite **Konfiguration** zu öffnen.
3. Klicken Sie auf den Link **Bearbeiten** rechts neben der gewünschten [Eigenschaft der Safe Share-Verwaltung](/3.1/de/admin-platform/configuring-platform-administration-properties#platform-administration-properties).
4. Aktualisieren Sie im Dialogfeld **Konfiguration bearbeiten** das Feld **Eigenschaftswert** nach Bedarf.
5. Klicken Sie auf **Speichern**, und der Wert der Eigenschaft Safe Share-Verwaltung wird mit sofortiger Wirkung geändert. <br />
   **Hinweise:**

   - Der Wert im Feld der Spalte **Geändert** wird gemäß dem aktuellen Datum und der aktuellen Uhrzeit aktualisiert (d. h. er zeigt, wann der Wert dieser Eigenschaft zuletzt geändert wurde). Wird hier kein Wert angezeigt, wurde der Wert der Eigenschaft nie geändert und es gilt der Standardwert.
   - Für Eigenschaften, deren Wert lediglich aus `Wahr` oder `Falsch` besteht, hat das Dialogfeld **Konfiguration bearbeiten** ein Kontrollkästchen **Eigenschaftswert**, das für `Wahr` aktiviert bzw. für `Falsch` deaktiviert werden sollte.
   - Die Namen der Eigenschaften der Safe Share-Verwaltung sind fest definiert und können nicht geändert werden.
