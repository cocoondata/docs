---
title: "Accessing secure content"
---

To access secure content, you can:

- [View/print](/3.0/compatweb/accessing-secure-content#viewing-and-printing-secure-content) (through a modern web browser only) or [download](/3.0/compatweb/accessing-secure-content#downloading-secure-content) personally owned files which you had previously uploaded and stored securely with the Safe Share web application (using either an [older web browser such as Internet Explorer 9](/3.0/compatweb/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content) or a [modern web browser](/3.0/user/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content)) or Safe Share for Windows. These actions can also be performed on files that you had uploaded to another user's folder with the Safe Share web (also using either an [older](/3.0/compatweb/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) or [modern](/3.0/user/uploading-storing-and-sharing-content-securely#uploading-content-to-share-through-another-users-folder) browser) or Windows applications.
- [View](/3.0/compatweb/accessing-secure-content#viewing-and-printing-secure-content) (through a modern web browser only) files which someone else has stored securely and shared with you through the Safe Share web (using either an [older](/3.0/compatweb/uploading-storing-and-sharing-content-securely#sharing-secure-content) or [modern](/3.0/user/uploading-storing-and-sharing-content-securely#sharing-secure-content) web browser) or Windows applications. You can only [print](/3.0/compatweb/accessing-secure-content#viewing-and-printing-secure-content) or [download](/3.0/compatweb/accessing-secure-content#downloading-secure-content) these files if the owners who shared the files have granted you permission to perform these actions.

## Viewing and printing secure content

When accessed through a modern web browser, the Safe Share web application has a [content viewer](/3.0/user/accessing-secure-content#content-viewer) which allows you to view and optionally print files that other people have shared with you (including [personally owned files which you had previously uploaded](/3.0/compatweb/uploading-storing-and-sharing-content-securely#uploading-and-storing-personally-owned-content)). See [File formats supported by the content viewer](/3.0/user/accessing-secure-content#file-formats-supported-by-the-content-viewer) (in the main [Safe Share User's Guide for the web application](/3.0/user)) for a list of file types that the content viewer supports.

<Note>

Be aware that the Safe Share Compatibility Mode for Web itself (which is presented when accessing the Safe Share web application through an older web browser like Internet Explorer 9), does not actually possess content viewer (and print) functionality.

</Note>

The ability to view or print (through a modern web browser) + download files is based on the permissions that the owners of these files granted their collaborators (i.e. you) when the files were [shared](/3.0/compatweb/uploading-storing-and-sharing-content-securely#sharing-secure-content). The content viewer is useful when the owner of a file wants to share the file's content but not allow the content to be printed and downloaded.

## Downloading secure content

<Note>

This feature is not available if a file you can [view](/3.0/compatweb/accessing-secure-content#viewing-and-printing-secure-content) was [shared with you](/3.0/compatweb/uploading-storing-and-sharing-content-securely#sharing-secure-content) *and* the owner of that file did not allow their collaborators to download the file's content.

</Note>

**To download secure content:**

1. [Sign in](/3.0/compatweb/signing-in) to the Safe Share web application.
2. [Locate](/3.0/compatweb/managing-secure-content#finding-secure-content) the file to be downloaded.
3. *Highlight* the file, by clicking on the file's row and in the toolbar above the list of items, click the **Download** button. <br />
   ![Highlighting an item as an owner](/images/fcd9e1fde5c7-highlighting-an-item-owner.png)
   <br />
    The file is downloaded through your web browser's usual download feature. <br />
   **Note:** If the owner did not grant **Download** permissions when they [shared the file (or one of its ancestral folders)](/3.0/compatweb/uploading-storing-and-sharing-content-securely#sharing-secure-content) with you, then upon clicking the **Download** button, the message '*You do not have permission to download this item.*' is shown.
