The **Theme** page allows Safe Share administrators to modify the:

- theme property values for [text and URLs](/3.0/admin-platform/re-theming-the-application-and-administration#modifying-a-theme-property-value), which are used to customize:

  - the application and company names + support and help URLs for the:

    - [Safe Share web application](/3.0/user/index) (+ Safe Share Administration and Organization Administration) and
    - Covata Notification email messages,

    as well as,
  - the copyright notice appearing at the base of Covata Notification email messages

  and
- [user interface logos](/3.0/admin-platform/re-theming-the-application-and-administration#modifying-a-logo) of the Safe Share web application, Safe Share Administration and Organization Administration, as well as the logo used for Covata Notification email messages.

<Note>

Please be aware that any modifications to any theme properties or user interface logos on this page apply to *all organizations* configured on the Covata Platform.

</Note>

## Modifying a theme property value

**To modify a theme property value:**

1. [Sign in](/3.0/admin-platform/accessing-platform-administration#signing-in-to-platform-administration) to Safe Share Administration.
2. Click the **Theme** option on the left of the [Safe Share Administration interface](/3.0/admin-platform/accessing-platform-administration#the-platform-administration-interface) to open the **Theme** page.
3. Modify the values of the relevant properties below. <br />
   **Notes:**

   - After modifying a property's value, click its associated **Save** button (to save its value) before moving on to modify another property's value.
   - Clicking a property's **Reset** button sets the property back to its default value.

   | Property | Detailed description |

   | Application Name | <a id="application-name" />The application name which appears to the right of the header logo of the [Safe Share web application](/3.0/user/index) (see [Safe Share web application logos, name and color](/3.0/admin-platform/re-theming-the-application-and-administration#the-web-application-logos-name-and-color) for details) as well as throughout Covata Notification email messages. <br />**Note:** The default value of this property is 'Safe Share'.  |
   | Company Name | The company/organization name which appears throughout Covata Notification email messages. <br />**Note:** The default value of this property is 'Covata'.  |
   | Email Notification Copyright Notice | <a id="email-copyright" />The copyright notice which appears at the base of Covata Notification email messages. <br />**Note:** The default value of this property is '&lt;year&gt; Covata.'.  |
   | Organization Administration Help URL | The URL of the help documentation for Safe Share Organization Administration, which is accessible from the **Help** option/link available from the email address drop-down menu of the Organization administrator at the top-right of Safe Share Organization Administration (and from the footer). <br />**Note:** The default value of this property is the [Organization Administrator's Guide](/3.0/admin-org/index) on the Covata web site.  |
   | Web application Help URL | The URL of the help documentation for the Covata Safe Share web application, which is accessible from the **Help** option/link available from the user's email address drop-down menu at the top-right of the Safe Share web application (and from the footer). <br />**Note:** The default value of this property is the [Safe Share User's Guide](/3.0/user/index) on the Covata web site.  |
   | Safe Share Administration Help URL | The URL of the help documentation for Safe Share Administration, which is accessible from the **Help** option/link available from the email address drop-down menu of the Safe Share administrator at the top-right of Safe Share Administration (and from the footer). <br />**Note:** The default value of this property is the Safe Share Administrator's Guide (i.e. this guide) on the Covata web site.  |
   | Admin Email | <a id="admin-email" />The contact email address, typically for an [Organization administrator](/3.0/admin-platform/administering-users-within-an-organisation#organisation-administrator-role), which is:  <br />•  used in Covata Notification email messages and <br />•  is accessible from the **Need help? To help direct messages (received by this dedicated address) to the appropriate Organization administrator, employ email filters (or a similar feature), each of which filters a message based on the sender's domain and forwards it to the appropriate Organization administrator. <br />•  Set this **Admin Email** property's value to this dedicated email address.  |
   | Legal URL | The URL of the company's/organization's legal page, which is accessible from the **Legal** link in the footer of the [Safe Share web application](/3.0/user/index), Safe Share Administration and Organization Administration. <br />**Note:** The default value of this property is the Covata End User License Agreement.  |

## Modifying a logo

**To modify a logo for the Safe Share web application/Safe Share Administration/Organization Administration or Covata Notification email messages:**

1. [Sign in](/3.0/admin-platform/accessing-platform-administration#signing-in-to-platform-administration) to Safe Share Administration.
2. Click the **Theme** option on the left of the [Safe Share Administration interface](/3.0/admin-platform/accessing-platform-administration#the-platform-administration-interface) to open the **Theme** page.
3. Click the appropriate **Upload Image** button to begin choosing an alternative logo for the Safe Share web application/Safe Share Administration/Organization Administration user interface (i.e. the [Sign-in page](/3.0/admin-platform/re-theming-the-application-and-administration#sign-in-page-logo) as well as [header and footer](/3.0/admin-platform/re-theming-the-application-and-administration#the-web-application-logos-name-and-color)) and/or the Covata Notification email message (i.e. the **Email Logo**).
4. In the **Upload Image** dialog box, click **Choose a file** to upload a local image file. <br />
   **Note:** Take note of the maximum dimensions and file size. Uploading an image that exceeds these maximum values will fail.
5. Click **Close** and manually refresh the page. <br />
   **Notes:**

   - The logo is modified with immediate effect.
   - Clicking a logo's **Reset** button removes the uploaded custom image and sets the logo back to its default image, which are shown in the images below.
