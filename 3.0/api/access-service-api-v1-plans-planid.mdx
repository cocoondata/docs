## URL structure <a id="access-service-api-v1-plans-planid-url-structure" />

```text
https://access-service.xy-company.com/api/v1/plans/{planId}
```

where `{planId}` is the ID of a plan.

## Supported methods and overview <a id="access-service-api-v1-plans-planid-supported-methods-and-overview" />

- `GET` - used to retrieve information about a [plan](/3.0/admin/managing-users-storage-quotas-through-plans), based on the plan's ID.
- `PUT` - used to modify the fields of an existing plan.
- `DELETE` - used to delete an existing plan.

<Note>

The `GET` and `DELETE` methods take no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-plans-planid-detailed-description" />

This API endpoint serves a number of purposes:

- Retrieves information about a plan, using the plan's ID. A plan's ID can be obtained by calling the `GET` method of the [&lt;access-service&gt;/api/v1/plans](/3.0/api/access-service-api-v1-plans) API endpoint, which retrieves a list of field information for all current plans on the Covata Platform.
- Modifies the fields of an existing plan, based on the plan's ID. These fields include the plan's name, description, quota value (in MB) and a flag that determines whether or not this plan will be the new default plan (i.e. which will be applied to [newly added Covata users](/3.0/api/access-service-api-v1-users) or [existing users whose role has been upgraded](/3.0/api/access-service-api-v1-users-userid) to [Originator](/3.0/admin/administering-users#originator-role)).
- Deletes an existing plan from the Covata Platform. <br />
  **Notes:**

  - Any [Covata users](/3.0/admin/administering-users) who were assigned this plan are automatically switched over to the **default** plan. Be aware that if this **default** plan has a quota which is lower than the amount of Content Service-managed storage utilized by any of these users, then these users will no longer be able to upload any data until their storage utilization drops below the **default** plan's quota.
  - It is not possible delete the **default** plan.

## Supported roles <a id="access-service-api-plans-planid-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.0/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.0/admin)):

- [System administrator](/3.0/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.0/api/access-service-api-v1-plans-planid#access-service-api-v1-plans-planid-required-headers) of requests to this endpoint.
