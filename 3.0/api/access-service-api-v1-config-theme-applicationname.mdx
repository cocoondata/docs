## URL structure <a id="access-service-api-v1-config-theme-applicationname-url-structure" />

```text
https://access-service.xy-company.com/api/v1/config/theme/applicationName
```

## Supported methods and overview <a id="access-service-api-v1-config-theme-applicationname-supported-methods-and-overview" />

- `PUT` - used to set a new application name for the Safe Share web application, which appears in Covata Notification email messages.
- `DELETE` - see [&lt;access-service&gt;/api/v1/config/theme/...](/3.0/api/access-service-api-v1-config-theme-reset) for more information.

## Detailed description <a id="access-service-api-v1-config-theme-applicationname-detailed-description" />

This API endpoint sets a new application name for the Safe Share web application, which appears in Covata Notification email messages.

To reset this application name back to its default value (i.e. Safe Share), see [&lt;access-service&gt;/api/v1/config/theme/...](/3.0/api/access-service-api-v1-config-theme-reset) for more information.

## Supported roles <a id="access-service-api-v1-config-theme-applicationname-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.0/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.0/admin)):

- [System administrator](/3.0/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.0/api/access-service-api-v1-config-theme-applicationname#access-service-api-v1-config-theme-applicationname-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-config-theme-applicationname-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Required body <a id="access-service-api-v1-config-theme-applicationname-required-body" />

Specify the new application name for the Safe Share web application (which appears in Covata Notification email messages), in the body of the request as plain text.

## Returns <a id="access-service-api-v1-config-theme-applicationname-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
