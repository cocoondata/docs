## URL structure <a id="access-service-api-v1-groups-url-structure" />

```text
https://access-service.xy-company.com/api/v1/groups
```

## Supported methods and overview <a id="access-service-api-v1-groups-supported-methods-and-overview" />

- `POST` - used to add a new [group](/3.0/admin/managing-groups).
- `GET` - used to retrieve a list of field information for all existing groups on the Covata Platform.

## Detailed description <a id="access-service-api-v1-groups-detailed-description" />

This API endpoint serves a number of purposes:

- Adds a new group to the Covata Platform. <br />
  **Notes:**

  - To add one or more [Covata users](/3.0/admin/administering-users) to this group, see [&lt;access-service&gt;/api/v1/groups/\{groupId\}](/3.0/api/access-service-api-v1-groups-groupid). Also see [&lt;access-service&gt;/api/v1/labels](/3.0/api/access-service-api-v1-labels) for more information about adding new labels.
  - To associate this group with one or more [labels](/3.0/api/access-service-api-v1-labels), which would then allow these labels to restrict file sharing to any Covata users who are members of this group, see [&lt;access-service&gt;/api/v1/groups/\{groupId\}](/3.0/api/access-service-api-v1-groups-groupid).
- Retrieves a list of field information for all existing groups on the Covata Platform.

## Supported roles <a id="access-service-api-groups-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.0/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.0/admin/index)):

- [System administrator](/3.0/admin/administering-users#system-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.0/api/access-service-api-v1-groups#access-service-api-v1-groups-required-headers) of requests to this endpoint.
