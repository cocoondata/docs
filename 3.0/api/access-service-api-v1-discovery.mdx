## Supported methods and overview <a id="access-service-api-v1-discovery-supported-methods-and-overview" />

## Supported roles <a id="access-service-api-discovery-supported-roles" />

This API endpoint supports the following Covata user [roles](/3.0/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.0/admin/index)):

- [Originator](/3.0/admin/administering-users#originator-role)
- [Collaborator](/3.0/admin/administering-users#collaborator-role)
- [System administrator](/3.0/admin/administering-users#system-administrator-role)
- [User administrator](/3.0/admin/administering-users#user-administrator-role)

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.0/api/access-service-api-v1-discovery#access-service-api-v1-discovery-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-discovery-required-headers" />
