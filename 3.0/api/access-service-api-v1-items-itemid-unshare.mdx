## URL structure <a id="access-service-api-v1-items-itemid-unshare-url-structure" />

```text
https://access-service.xy-company.com/api/v1/items/{itemId}/unshare
```

where `{itemId}` is the ID of a Secure Object or collection.

## Supported methods and overview <a id="access-service-api-v1-items-itemid-unshare-supported-methods-and-overview" />

- `PUT` - used to remove all collaborators from a [Secure Object](/3.0/api/creating-secure-objects-and-collections#secure-object) or [collection](/3.0/api/creating-secure-objects-and-collections#collection) (i.e. [item](/3.0/api/creating-secure-objects-and-collections#item)), based on the item's ID.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-items-itemid-unshare-detailed-description" />

This API endpoint removes all collaborators from either a Secure Object or a collection, using this item's ID.

The item's ID can be obtained by calling the [&lt;access-service&gt;/api/v1/items](/3.0/api/access-service-api-v1-items) API endpoint, which retrieves a list of information associated with Secure Objects and collections that can be filtered using various 'search' criteria.

If the item's ID is a collection, then *all* collaborators will also be removed from *all* items contained within this collection; that is, the removal of collaborators from a collection cascades down through the hierarchy of items contained within this collection.

## Supported roles and conditions <a id="access-service-api-items-itemid-unshare-supported-roles-and-conditions" />

This API endpoint supports the following Covata user [roles](/3.0/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.0/admin)) and conditions:

- [Originator](/3.0/admin/administering-users#originator-role) - a Covata user with this role can call this endpoint on an item they own.

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.0/api/access-service-api-v1-items-itemid-unshare#access-service-api-v1-items-itemid-unshare-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-items-itemid-unshare-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Returns <a id="access-service-api-v1-items-itemid-unshare-returns" />

If the request succeeded, then an HTTP response status `200 OK` is returned.
