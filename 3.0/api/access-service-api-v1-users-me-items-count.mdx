## URL structure <a id="access-service-api-v1-users-me-items-count-url-structure" />

```text
https://access-service.xy-company.com/api/v1/users/me/items/count
```

## Supported methods and overview <a id="access-service-api-v1-users-me-items-count-supported-methods-and-overview" />

- `GET` - used to retrieve the total number of [Secure Objects](/3.0/api/creating-secure-objects-and-collections#secure-object) owned by the currently authenticated [Covata user](/3.0/admin/administering-users)<sup>&#42;</sup>.

<Note>

This method takes no parameters.

</Note>

## Detailed description <a id="access-service-api-v1-users-me-items-count-detailed-description" />

This API endpoint retrieves the total number of Secure Objects which are owned by the currently authenticated Covata user<sup>&#42;</sup>.

<Note>

Although this endpoint contains `[items](/3.0/api/creating-secure-objects-and-collections#item)` in its URL, calling it only returns the number of Secure Objects (i.e. [collections](/3.0/api/creating-secure-objects-and-collections#collection) are not counted).

</Note>

## Supported roles and conditions <a id="access-service-api-v1-users-me-items-count-supported-roles-and-conditions" />

This API endpoint supports the following Covata user [roles](/3.0/admin/administering-users#a-users-roles) (as described in the [Covata Platform Administrator's Guide](/3.0/admin)) and conditions:

- [Originator](/3.0/admin/administering-users#originator-role) <br />
  **Note:** Although all other roles support this API endpoint, calling this endpoint as a Covata user with a role other than **Originator** results in a count value of `0` being returned.

The Covata Platform's resources available to one of these Covata users (above) is determined by the access token passed in the [header](/3.0/api/access-service-api-v1-users-me-items-count#access-service-api-v1-users-me-items-count-required-headers) of requests to this endpoint.

## Required headers <a id="access-service-api-v1-users-me-items-count-required-headers" />

The appropriate access token as the `Bearer` token:

- `Authorization: Bearer a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6`

## Returns <a id="access-service-api-v1-users-me-items-count-returns" />

A JSON-formatted response containing the following members:

- **count** - The total number of [Secure Objects](/3.0/api/creating-secure-objects-and-collections#secure-object) which the currently authenticated [Covata user](/3.0/admin/administering-users)<sup>&#42;</sup> owns.

  **Example:**

  ```json
  {
    "count": 16
  }
  ```

<sup>&#42;</sup> The currently authenticated user is determined by the access token passed in the [header](/3.0/api/access-service-api-v1-users-me-items-count#access-service-api-v1-users-me-items-count-required-headers) of requests to this endpoint.
